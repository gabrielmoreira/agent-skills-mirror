# report.html 的设计约定

报告由 `scripts/novel-characters.mjs render --html` 生成，样式全部内联在 `renderHtml()` 里。**改样式只改那一处**，不要另起模板。

这份文档记录为什么长这样，免得后来的改动把它改回一个通用的卡片墙。

## 它是什么

不是营销页，是**制作用的角色设定集**。读者是要拿这些提示词去真出图、真配音的人。页面唯一的工作：**让人快速抓到对的提示词，同时相信画像有原文依据。**

所有设计决定都从这一句推出来。

## 多语言

界面文案在 `novel-characters.mjs` 的 `STRINGS` 表里，`zh` / `en` 两套。加语言就加一个键，**别把中文硬编码进模板**——`renderEntry` / `renderHtml` 拿到的 `t` 就是那张表。

未知语言码退回 `en` 的界面骨架（`strings()` 里做的），但 `<html lang>` 仍写实际语言码。理由：角色内容确实是那个语言，界面词没翻译总比整篇混乱强。

## 四条不能破的规矩

### 1. 双字域

中文印刷体本身就分工，直接用：

| 字体 | 语域 | 用在 |
| --- | --- | --- |
| **宋体** `--serif` | 叙事——关于故事的 | 书名、角色名、一句话、**故事摘要**、**原文引文** |
| **黑体** `--sans` | 分析——关于角色的 | 画像正文、字段标签、界面 |
| **等宽** `--mono` | 机器输入 | 英文提示词、序号 |

真正逐字来自原文的只有 `.source blockquote`，它额外带铁锈红边栏和「」引号——**那对引号是「这是原文」的唯一标记**，别拿去装饰摘要或一句话。

这是这份报告跟任何一个角色卡生成器的区别所在，别把它统一成一种字体。

全部用系统字体，**不许引外部字体**——报告要能离线双击打开。

### 2. 不藏内容

**没有页签、没有折叠、没有「展开更多」。** 整页可以 Cmd+F 搜到任何一个字。

第一版用了三个页签，看着干净，但它让人没法搜索、没法打印、没法一眼扫完一个角色。工作文档不该藏东西。

### 3. 推断标记要高亮

`（推断）` 和 `(inferred)` 由 `marked()` 自动包成 `<span class="inf">`，带浅铁锈红底。

这是本报告的签名细节。这个工具的核心承诺就是「哪些有原文依据、哪些是为了能用而补的」，把它做成视觉，比写在文档里有用。页脚也有一句说明。

## 配色

冷灰印张 + 铁锈红印记。**红色只用在跟原文有关的地方**：引文的边栏和引号、主角标签、hover 态。别拿它当通用强调色。

| token | 浅色 | 用途 |
| --- | --- | --- |
| `--paper` | `#e9eae5` | 冷灰印张，不是暖奶油 |
| `--panel` | `#e1e3dd` | 提示词块 |
| `--ink` | `#191d21` | 蓝黑，不是纯黑 |
| `--seal` | `#8a3324` | 铁锈红，只给原文 |

深色模式由 `prefers-color-scheme` 切换，**三视图的印张永远白底**——它是一张纸，不是 UI 面板。

## 尺寸与栅格 ⚠️ 硬性

- **页面上限 1800px**（`.wrap{max-width:1800px}`）
- **一排最多三个角色**

「最多三个」不是写死列数，是靠 `minmax` 卡出来的：

```css
.cast{grid-template-columns:repeat(auto-fit,minmax(460px,1fr));gap:28px}
```

1800 减去两侧 40 内边距剩 1720：三列 `3×460+2×28=1436` 装得下，四列 `4×460+3×28=1924` 装不下。**这三个数（1800 / 460 / 28）是联动的，改一个要重算另外两个**，自测里有断言盯着。窄屏自然降到两列、一列。

## 结构

```
角色设定集                                    ← eyebrow
《书名》· 角色                                 ← 宋体大标题
4 位角色 · 3 张三视图 · 按戏份排序
════════════════════════════════════════════
┌── 故事摘要 ─────────┐  01 沈知微 ······ 主角   ← 摘要与目录并排，
│ 民国年间的清晨…      │  02 陆行远 ······ 主要     把 1800 的宽度用起来
└────────────────────┘  03 老周  ······· 主要
                        04 胡二爷 ······ 配角   ← 序号是排名不是装饰：
                                                  按出现块数排的戏份权重

┌─ 01 沈知微 主角 ──┐ ┌─ 02 陆行远 ──┐ ┌─ 03 老周 ──┐
│ 一句话            │ │              │ │            │
│ [三视图]          │ │ [三视图]     │ │ [三视图]   │
│ 画像              │ │ …            │ │ …          │
│  外貌 / ▍原文依据 │ │              │ │            │
│ 形象              │ │              │ │            │
│  [提示词] 复制    │ │              │ │            │
│ 声音              │ │              │ │            │
│  [提示词] 复制    │ │              │ │            │
└──────────────────┘ └──────────────┘ └────────────┘
```

卡内三组（画像 / 形象 / 声音）**竖排**，`.groups{display:block}`。卡片只有 555px 宽，再分栏就挤没了。

## 每段提示词一个复制按钮

不能少。目前每个角色 8 个：风格标签、出图 EN、出图中文、反向、三视图 EN、音色 EN、音色中文、整份 JSON。自测里有断言盯着这个数。

## 质量底线

- 响应式到手机（三栏 `auto-fit` 塌成一栏）
- 键盘焦点可见（`.copy:focus-visible`）
- `prefers-reduced-motion` 关掉全部动效和平滑滚动
- `@media print` 隐藏按钮和目录、条目不跨页断
- 角色数据是模型生成的，**一律 `esc()` 转义**后再拼进 HTML

## 动效

只有一处：目录逐行渐显（45ms 阶梯）。其余靠排版和留白，不靠动画。
