# Placeholder Contract

Default placeholder validation applies to generated workflow output only.

Covered generated artifacts:

1. `vision.md` and `status.md` when generated by the helper;
2. `wave.md`;
3. `initiative.md`;
4. `roadmap.md`;
5. `index.md`;
6. `discoveries/*.md`;
7. `sprints/*/sprint.md`;
8. `sprints/*/decision-log.md`;
9. `sprints/*/closeout.md`;
10. `sprints/*/evidence/index.md`.

## Required Findings

Strict mode fails on:

1. any `REPLACE_*` token;
2. plain-language `Replace with ...` prompts in `roadmap.md`, discovery
   briefs, `sprint.md`, or `evidence/index.md`;
3. malformed generated names that do not follow `wNN`, `iNN`, `dNN`, `sNN`, or
   `YYYY-MM-DD` rules.

## Advisory Findings

Strict mode does not fail on:

1. closeout prompts that are meant to be filled after execution;
2. retained-note prompts before final audit;
3. explicit `PENDING_HANDOFF:` markers.

## Intended Use

Use strict mode before declaring a generated artifact ready for the next
workflow phase.
