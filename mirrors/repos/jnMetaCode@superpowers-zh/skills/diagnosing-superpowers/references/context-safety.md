# 会话记录的上下文安全

一条会话记录可能超过一兆字节，或者内嵌整段历史。把一整条记录打印出来，就可能撑爆
正在做诊断的那个会话的上下文。每一个读取会话文件的人——控制者或子智能体——对每个文件、
每一次都遵循这些规则。

1. **先度量再读取。**

   ```bash
   wc -lc "$F"
   awk '{ if (length($0) > 100000) print NR, length($0) }' "$F"   # long lines
   ```

2. **绝不用 `cat` 或 `grep` 取内容。** 先拿行号和计数
   （`grep -n … | cut -d: -f1`、`jq -r '.type' | sort | uniq -c`），
   再从具体的行中取小字段（`sed -n Np | jq -c '{…}'` 或 `| cut -c1-500`）。
   对眼前的这个来源，使用发现阶段确立的字段提取命令。
3. **超过 500 个字符就收窄。** 如果一条命令对一条记录返回了超过 500 个字符，
   收紧字段或切片。
4. **只读。** 绝不修改、移动或删除会话文件。
