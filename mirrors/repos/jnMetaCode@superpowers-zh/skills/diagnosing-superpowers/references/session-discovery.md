# 发现会话历史

用当前环境中可用的工具和信息，解析出你的人类伙伴点名的那个会话。你的知识可以提示
去哪里找；结果要对照实际的历史来核实。

使用该工具暴露的会话工具、已配置的存储、本地帮助、文档，或有界的文件系统检查。读取
内容之前先度量文件大小，并遵循 context-safety.md。环境指向归档或索引时，去检查它们。
对方给出的可用路径不需要再搜一遍。

用可得的会话 id、工作目录、时间戳和匹配的对话内容来确认身份。仅凭"最近"不算确认。
把被请求的会话与它的子会话以及无关的候选区分开。当现有证据无法区分时，询问缺失的
那个识别信息。

对每个文件系统来源，从环境中取得它完整的绝对路径，展开家目录简写和变量。在案例记录
里和你给伙伴的发现答复里，使用同一个路径。

从观察到的记录或文档中，确立本次调查所需的记录含义。把人类消息与注入的消息、工具结果、
父智能体的派发区分开。把工具调用与其结果对应起来。计算总量之前，先确立用量计数器的语义。
不要从另一个工具推断格式，也不要把缺失的字段当成零。

把确切的来源、相关字段的含义、支撑记录的位置、关联会话、被排除的合理候选，以及未决
信息记录到案例文件中。之后的读者使用这份记录，而不是重复发现。如果历史缺失、无法访问
或有歧义，说明具体的局限，并询问缺失的路径、导出文件或识别细节。
