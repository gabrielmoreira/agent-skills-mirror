维度：计划遵循（Plan adherence）

还原会话中约定的计划，然后把计划的每一步对应到实际发生的事。这里的"计划"指任何
约定好的行动方案，不是 git 提交。

1. 找到约定的计划：在对话中约定的设计或计划（找人类回复"yes/ok/go ahead"/"好/可以/
   开始吧"之前的那段助手文本）、会话中写出的规格或计划文件（写到 `docs/`、
   `plans/`、`specs/` 下，或写到人类点名的任何文件的工具调用）、在案例文件中确立了
   含义的待办列表记录，或助手文本中的任何编号清单。引用每个计划步骤及其 `path:line`。
2. 标记计划与执行之间的结构性事件：发现阶段识别出的压缩事件、恢复（resume）、中止的
   轮次、关联会话的派发。记下它们的行号；紧跟在这些事件之后的计划偏离，是一条单独的发现。
3. 对每个计划步骤，找到执行它的工具调用和助手文本，或确认没有任何执行。报告：
   - 被跳过的步骤（找不到执行；引用该计划步骤）；
   - 乱序执行的步骤（用行号表明顺序）；
   - 被悄悄改动的步骤（执行与计划步骤不同，而助手从未说明；两处都引用）；
   - 凭空多出的步骤（做了没有任何计划步骤覆盖的工作）；
   - 紧跟结构性事件之后的偏离（引用事件所在行和第一个偏离的动作）。
4. 如果没有可还原的计划，就把这一点作为唯一的发现，并附上你检查过的行。
