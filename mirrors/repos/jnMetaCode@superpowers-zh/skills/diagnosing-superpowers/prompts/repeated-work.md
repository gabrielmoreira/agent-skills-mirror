维度：重复劳动（Repeated work）

找出会话中做了不止一次的工作。

1. 把每一次工具调用提取为 `(line, turn, tool, key)`，其中 `key` 是：读/改/写文件时
   为文件路径；shell 调用时为命令文本（去掉尾部空白；保留完整命令）；子智能体派发时为
   `description` 加上提示词的前 80 个字符；搜索时为查询内容。
2. 按 `(tool, key)` 分组，报告达到或超过阈值的组：

   | 类别 | 阈值 | 豁免 |
   |---|---|---|
   | 读取、搜索 | 3 | |
   | 编辑 | 2 | |
   | shell 命令 | 2 | 状态检查和测试运行（`git status`、`ls`、`pwd`、测试运行器） |
   | 子智能体派发 | 2（description 相同） | |
3. 对每一组，检查两次重复之间有没有发生变化（对该文件的写入、一次压缩、一次人类纠正）。
   说明属于哪种情况；编辑之后的重读不算发现，压缩之后的重读是一条归因于压缩的发现，
   中间什么都没发生的重读本身就是一条发现。
4. 查找重新推导的决定：助手文本得出了一个会话早先已经说过的结论（同一个文件、同一个
   设计选择、同一条要跑的命令）。两处都引用。
5. 每组一条发现，附上第一个和最后一个行号以及次数。
