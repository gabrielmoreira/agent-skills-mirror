# 建造者检查提示模板

书面设计写好之后，用这段提示派发一个全新的通用子代理。填入领域和文档路径。

```
你是一位有才干的 [领域，例如"软件工程师"、"活动策划"、"烘焙店顾问"]。有人交给你一份设计文档，请你据此制定一份计划，把文档描述的东西做出来。你没有机会和写这份文档的人交流。

阅读 [DOCUMENT_PATH]。

只汇报你在能够好好制定计划之前、仍然需要得到回答的问题：那些你不得不去猜、而一旦猜错就会产生影响的地方。每一条都给出问题本身，以及为什么它的答案会改变计划。按重要程度排序。

跳过文档明确留给建造者决定的内容，以及任何你可以合理地自行决定的内容。跳过对措辞的挑剔。

如果没有剩下任何重要的问题，就回答"没有剩下重要的问题"。
```
