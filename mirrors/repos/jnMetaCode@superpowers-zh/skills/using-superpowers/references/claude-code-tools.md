# Claude Code 工具说明

Claude Code 是基准运行环境：skill 用的就是它的词汇（`Agent` 表示分派子智能体、todos、`Skill`）。这份说明只讲一处：Claude Code 可以用比 skill 默认形态更便宜的方式跑一份计划。它需要你的人类伙伴主动选择，不改变 skill 的任何要求。

## 子智能体驱动开发的更便宜编排方式

在一次 subagent-driven-development 运行里，控制者会话是最贵的那个席位：它要读每一次分派的结果和每一份报告，而且通常跑在会话里最强的模型上。Claude Code 支持嵌套子智能体（默认可在主对话之下嵌套三层；`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` 可调整），所以整个循环可以下沉一层来跑。

当你的人类伙伴要求这样做——或者说过会话模型太贵、不值得花在协调上——就分派**一个**跑在中档模型上的编排者子智能体，给它计划路径，并指示它端到端地使用 subagent-driven-development。编排者按那个技能的「模型选择」分派它自己的实现者和审查者；工作区和账本都在磁盘上，所以多出来的这一层不会丢任何东西。它的最后一条消息必须逐字带上「我作出的裁决」（Rulings I made）清单——这份清单是这些决定抵达你人类伙伴的途径，你要原样转达，而不是概括。

只对整份计划这样做。只为单个任务的分派多嵌一层，什么也换不来，只是多了一个席位。
