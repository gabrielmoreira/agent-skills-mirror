# 腾讯云开发者社区草稿

与公共 `workflow.md` 配合使用；平台名为 `tencent-cloud`。

- 入口：`https://cloud.tencent.com/developer/article/write-new`。核对页面右上角账号；身份不明确时通过“创作者中心”核实。使用新版富文本编辑器，不切换“MD 编辑器”或“旧版编辑器”。
- 标题：“请输入标题”，页面提示“建议 80 字以内”；这是建议，不能当成已验证的硬性上限。遇到页面校验失败停止，不截断标题。
- 正文：唯一 `#cdc-rich-editor[contenteditable=true]`。目录、标题输入框和代码组件不能代替正文区域。按公共流程正常粘贴 HTML，回读标题层级、代码空白和表格内容；页面字数不能证明全文完整。
- 图文顺序：此平台不使用公共流程的“先上传、回填图片地址、整体粘贴”步骤。先用 HTML 解析器记录每张图片的相邻内容和顺序，在平台副本中移除图片元素，再正常粘贴正文。逐处将光标放在原图片对应位置，通过“插入 → 图片”上传对应本地文件，确认相邻段落及顺序保留；重复图片按每个位置插入。无法精确定位时停止，不把图片随意追加到文末。全部插图完成后不再整体替换正文。
- 选图：工具栏“插入”展开“添加内容”，其中“图片”打开文件选择窗口。浏览器直接选文件工具不可用时，按公共流程使用系统文件窗口；macOS 可用 `Command+Shift+G` 输入图片绝对路径，确认选中文件后点“打开”。明确的用户拒绝或系统权限拦截仍须停止，不能绕过。
- 图片保存条件：等待每张图片加载且编辑器不再显示“图片载入中”。仅图片可见不代表上传完成；出现“文章中有载入失败或上传中的文件，无法操作”时不能宣称已保存。不要把正文图片的临时签名地址重新粘贴成新图片；失败时在同稿撤回该次粘贴或通过正常编辑重新上传，再保存重验。
- 保存：点击“存草稿”，等待“正在保存草稿，请稍等...”结束，并出现“文章已于…保存到草稿”。保留带 `draftId` 的实际编辑地址；不猜编号，通用 `write-new` 地址不能用于恢复。
- 恢复：优先重开已记录的唯一编辑地址；保存结果不明或没有地址时，从“草稿箱”结合标题、时间和正文识别同稿，再取得实际编辑地址。不要重复新建。重开后按公共流程核验全文和图片，不能仅凭保存提示或草稿数量报告成功。
- “去发布”不属于本流程，不进入公开发布或修改发布设置。
