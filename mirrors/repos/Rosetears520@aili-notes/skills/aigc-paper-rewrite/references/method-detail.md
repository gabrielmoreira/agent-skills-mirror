# aigc-paper-rewrite detailed method

本文件是 `aigc-paper-rewrite` 技能包内置的详细方法说明。它把论文降调方法、合法改写边界、AI 痕迹识别和论文式自然化规则合并到本技能内部；执行时只需要使用本技能包内的规则。它不是检测器，也不是固定替换表，而是改写时的操作说明。

最高原则：**事实不动、术语保留、连接降调、结论收住。**

目标不是把论文改成闲聊，也不是把文本故意写差，而是把“过度顺滑、概念堆叠、结论圆满、宣传/政策/AI论文腔”的表达，改成“保留学术信息、读起来像作者在解释材料”的本科论文式表达。

## 1. 先保留硬信息，再改表达

改写前先圈出不能动的信息。只要这些信息被改错、删掉、换成泛化说法，后面的降风险都不成立。

必须保护的信息包括：

- 年份、时间段、具体时间点，如 `2016-2019`、`2020-2022`、`2023 年至今`、`2026 年 3 月中旬`。
- 数字、比例、样本量、统计值，如 `25%`、`18%`、`30%`、`980 份`、`683 份`、`83.3%`、`0.914`、`72.6%`、`0.742~0.866`。
- 专业对象和方法，如 `K-prototype 聚类`、`关联规则挖掘`、`Cronbach's α`、`主成分分析`、`最大方差旋转`、`TF-IDF`、`Jieba 分词`。
- 论文锚点，如 `图 1.2`、`表 1.1`、`表 4.1`、`图 4.1`、`Q35`、`Q36`、引用编号。
- 模型名、变量名、维度名、题项名、研究对象、样本来源、研究地点、问卷/访谈对象。

处理方式：

1. 先把这些硬信息在脑中标记出来。
2. 改句子时优先检查硬信息是否仍在原位置或合理位置。
3. 如果术语密集，不要把术语全部白话化；只改术语前后的连接和判断。
4. 如果原文事实可能有问题，不在本技能中自行纠错；优先保持原文事实和术语不变，只调整表达。需要提示时，在 `说明` 中写“该处按原文保留，未做事实判断”。

错误做法：

- 为了“更具体”补一个不存在的案例、访谈、引用或数据。
- 把变量名当普通词替换，导致论文前后不一致。
- 把专业术语改成口语，损害论文准确性。

## 2. 把高完成度论文腔降成自然本科论文腔

高风险的论文腔通常有几个特征：

- 每句话都完整、顺滑、像模板生成。
- 每句话都有价值判断。
- 概念密集，但具体材料很少。
- 结尾总想拔高到“意义、机制、路径、价值”。
- 读起来像政策材料、宣传文案或标准综述模板。

降调的目标不是变随意，而是变朴素。可以把官方、宏大、过于完整的表达改成普通论文表达。

常见方向：

| 高完成度写法 | 更自然的本科论文倾向 | 作用 |
|---|---|---|
| 提供较具操作性的精准营销策略 | 给出较有借鉴意义的精细化营销方法 | 语气少一点官方和营销味 |
| 可清晰呈现其演化脉络 | 能够反映出其发展过程 | 降低综述模板感 |
| 提升景区营销触达效率 | 提高景区的营销效果 | 少用互联网营销套话 |
| 为用户分群方法提供早期实证范式 | 是用户分群应用的早期实证案例 | 把宏大评价改成普通事实 |
| 具备继续分析的基础 | 可以进一步探究 | 结论更朴素 |
| 为后续策略设计提供实证依据 | 为下一步对策制定提供一定基础 | 加入限定，降低绝对感 |

判断标准：

- 改后仍然是论文语体。
- 改后不再像每句都在做总结或意义拔高。
- 改后能看到材料、对象、过程或后文用途。
- 改后没有变成聊天、口号或宣传文案。

## 3. 减少抽象名词串

高风险文本常把多个抽象名词连在一起，读者看不到具体对象或动作。重点处理这类词：

- 价值、机制、路径、体系、维度、基础、赋能、触达、转化、格局、链条、范式、本体、增益、支撑。

常见问题和处理：

| 原表达问题 | 可改方向 | 说明 |
|---|---|---|
| 游客深层体验价值挖掘 | 游客深层体验的价值追求 / 对游客深层体验的分析 | 把“价值挖掘”拆开 |
| 体验链衔接问题 | 体验链断层问题 | 更像在描述具体问题 |
| 营销触达效率 | 营销效果 | 少用互联网套话 |
| 文化资源本体价值挖掘 | 文化资源本身的价值探索 / 分析 | 保留对象，降低抽象度 |
| 后续消费者聚类分析与营销策略设计的维度基础 | 后续消费者分群以及营销策略制定的依据 / 参考维度 | 把堆叠名词拆成用途 |

操作方法：

1. 找连续抽象词，不急着换同义词。
2. 判断它到底说的是对象、动作、过程、依据，还是用途。
3. 能换成动作就换成动作，能换成对象就换成对象。
4. 如果是论文固定构念或变量名，不改术语本身，只改周围句子。

## 4. 用普通动词替代密集 AI 常用动词

不是所有高级动词都不能用，而是不能一段里密集堆叠，尤其要避免“基于……结合……从而……进一步……为……提供依据”的链条。

高风险感较强的动词和连接：

- 基于、结合、呈现、反映、凸显、回应、考察、构建、提炼、转化、赋能、推动、促进、提供依据。

更自然的论文表达：

- 根据、从……可知、说明、可以看出、主要是、找出、得到、用于、用来、可以、能够、作为参考。

使用原则：

- `呈现/反映/说明` 本身不是禁词，但连续出现会有模板感。
- `构建/赋能/驱动/转化` 在政策或商业文案里常见，论文中要谨慎。
- 方法段多用“采用、处理、得到、用于”。
- 数据段多用“占比、达到、说明、反映、可以看出”。
- 综述段多用“研究了、使用了、发现、指出、仍存在”。

## 5. 适度限定，避免结论过满

低风险论文表达常会加入或保留有限判断，但限定词不能乱加。

可用限定词：

- 较为、一些、一定、基本、相对、主要、一般、目前、可以、能够。

适合使用的位置：

- 结论、评价、推断、策略意义、研究不足、后续用途。

不适合使用的位置：

- 明确数字事实。
- 模型名、方法名、变量名。
- 每一句都机械添加。

例子：

| 过满表达 | 降调表达 | 原因 |
|---|---|---|
| 形成成熟的理论与实践体系 | 形成了较为完善的理论与实践体系 | 降低绝对感 |
| 已有较多成果 | 已经有了许多研究成果 | 更普通 |
| 具有较高解释作用 | 有着较强的解释力 | 更像论文表述 |
| 可为后续营销策略调整提供依据 | 可以指导以后的营销工作的开展 / 可以作为后续调整的参考 | 从意义句转为用途句 |

注意：

- “一定程度上、较为、相对、可能”用太多，会形成新的模板感。
- 如果每个结论都加“在一定程度上”，文本会显得刻意。

## 6. 保留专业术语，但改术语周围的话

不要把专业内容全部口语化。统计方法、模型、变量、量表和指标必须稳定。

应保留的例子：

- `K-prototype聚类算法`
- `二元逻辑回归`
- `USEM模型`
- `Cronbach's α系数`
- `主成分分析`
- `TF-IDF算法`

真正要改的是术语前后的连接方式。例如：

- “运用多元线性回归和二元逻辑回归，分别考察……”
- 可以改成：
- “采用多元线性回归与二元逻辑回归的方法分别找出……”

这样专业信息还在，但句子不像自动生成的标准科研表述。

## 7. 把意义句改成用途句

AI 论文腔常把段落结尾写成“研究意义”。更自然的论文写法，是说明它在后文或具体工作中怎么用。

常见意义句：

- 为……提供参考。
- 为……提供实证依据。
- 对……具有参考价值。
- 服务于……发展目标。
- 为……留下进一步讨论空间。

更合适的用途句：

- 可以作为……参考。
- 用来指导……。
- 为下一步……提供基础。
- 有助于后文概括……。
- 可以为后续分类、产品设计、营销调整提供参考。

判断标准：

- 不急着把研究抬高。
- 尽量说本段结果能在论文下一步怎么用。
- 如果没有材料支持，不写“重要意义、战略价值、深刻揭示”。

## 8. 长句不一定要变短，但要不那么机器顺

不要把“降低 AI 腔”理解成全部短句。样本里有些低风险修改反而更长，因为它把压缩的概念句改成了过程说明。

适合保留或拉长的情况：

- 调研方法段。
- 问卷发放和回收过程。
- 样本筛选过程。
- 访谈对象覆盖情况。
- 数据处理流程。

方法段可按过程展开：

- 获取数据 → 发放问卷 → 回收问卷 → 筛选有效样本 → 覆盖对象 → 访谈对象 → 用于后续分析。

这样虽然字数不少，但读起来像作者在说明自己怎么做，而不是输出标准方法模板。

## 9. 文献综述段处理

文献综述最容易高风险，因为它容易写得整齐、宏大、抽象。

有效处理：

1. 阶段划分可以保留，但每个阶段不要都用同一种句式。
2. 少密集使用“研究热点、研究前沿、演化脉络、实证范式、价值挖掘”。
3. 引用案例后，优先写“做了什么、用了什么数据或方法、得到什么结果”。
4. 结尾写“还存在不足、研究相对较少、可进一步探讨”即可，不要拔高到宏大意义。

推荐结构：

> 图表或数据库来源 → 阶段划分 → 每阶段主要关注点 → 代表研究或数据 → 仍存在的不足。

例子方向：

- 不要写：“该研究奠定了用户分群方法的实证范式。”
- 可写：“该研究是用户分群应用中较早的实证案例。”

## 10. 数据分析段处理

数据段要降低风险，重点不是改数字，而是改解释方式。

推荐顺序：

处理思路：数据段的中心是表图和数字本身。先保留谁占多少、累计多少、是否达到标准等硬信息，再说明这些数字在本样本里能直接看出什么。有限用途只在原文确实需要承接后文时简短写出；没有承接需要时，不要硬补“参考价值”。

不要写成：

- “充分体现了……战略价值。”
- “深刻揭示了……机制。”
- “全面证明了……发展潜力。”

可写成：

- “这一结果说明样本中……占比较高。”
- “该结果可以作为后续分群或策略调整的参考。”

## 11. 处理思路：七个判断点

下面不是固定模板，也不是要求每段都机械走完七步。它是一组判断点：硬信息决定边界，抽象词和过满结论决定降调方向，连接链要回到材料本身的关系，句长、节奏和格式痕迹负责最后的自然度检查。

### 11.1 先看不能动的信息

数字、年份、模型、变量名、图表编号、引用、专有名词先在心里标出来。它们决定改写边界，不是后面用来随意替换的素材。

### 11.2 判断问题是不是来自模板词和抽象词

重点看这些词是否过密，而不是看到一个就删：

- 基于、结合、呈现、赋能、推动、促进、体系、路径、机制、价值、格局、触达、转化、依据。

### 11.3 判断结论是不是说得太满

显著、充分、重要、关键、成熟、清晰、深层这类判断，如果没有数据、语境或材料支撑，就收回到本段能说明的范围。不是每句都加“较为、一定程度上”，而是看结论原本是否越过了材料。

### 11.4 把名词化还原成对象和动作

- “进行客群层次划分” → “把游客分成不同群体”。
- “形成变量依据” → “作为聚类时的参考变量”。

### 11.5 按材料关系处理连接链

“通过……从而……进一步……为……”的问题，不只是连接词太多，而是把材料、动作、结果和意义硬连成一个闭环。处理时先问三件事：这一段真正发生了什么？哪些结果是原文已经给出的？哪些用途只是后文承接？只保留这些真实关系。能拆成两句就拆开；能直接说对象、动作和有限用途就直接说；不要把它换成另一套固定的“先/再/最后”句式。

### 11.6 保留一点自然重复，也让句长有变化

不要为了避免重复不断换高级同义词。真实论文里“游客、景区、满意度、产品”等词重复出现是正常的。

句子也不要每句都同样完整、同样长、同样收束。方法段为了说明发放、回收、筛选、统计过程，可以保留长句；数据段和判断句可以短一些；综述段可以把“谁研究什么”和“得到什么发现”分开写。长短变化服务于清楚，不是为了故意制造破碎感。

### 11.7 最后读一遍语气和格式痕迹

- 如果像宣传材料、政策文件或 AI 综述，继续降调。
- 如果像随口聊天或不严谨，把必要术语补回来。
- 如果句子都一样长、一样对称、一样圆满，调整节奏，让材料句、解释句和判断句有差别。
- 如果出现过多引号、括号、破折号、加粗、装饰性项目符号或行内小标题，尽量改回普通论文自然段；必要的引用格式、统计符号和输出代码块保留。

## 12. 高频替换思路参考

这些不是固定替换表。必须按语境判断。

| 高风险感较强的表达 | 可考虑的自然表达 | 注意 |
|---|---|---|
| 以……为切入点 | 围绕……展开 / 从……入手 | 不要机械替换论文标题或固定说法 |
| 清晰呈现演化脉络 | 反映发展过程 | 降低综述模板感 |
| 重点围绕 | 主要关注 / 主要是 | 避免一段多个“重点” |
| 实现客单价提升 | 使客单价提高 | 说结果，不写商业口号 |
| 提升营销触达效率 | 提高营销效果 | 少用互联网营销套话 |
| 精准营销的增益效果 | 精准营销的效果 | 不必过度学术化 |
| 场景化应用仍相对不足 | 相关应用研究还比较少 | 适合文献不足 |
| 体验链衔接问题 | 体验链断层问题 | 保留原概念含义 |
| 消费停留 | 滞留时间 / 停留时间 | 看统计口径 |
| 复游率 | 回头率 / 重游意愿 | 如果是变量名“复游率”，不要改 |
| 提供实证依据 | 提供一定基础 / 作为参考 | 意义句转用途句 |
| 具备继续分析的基础 | 可以继续分析 / 可以进一步探究 | 降低结论完整感 |
| 后续行为意向 | 之后的行为选择 / 未来行为意愿 | 变量名不动，普通表达可调整 |
| 高载荷题项 | 高负荷题目 / 载荷较高的题项 | 统计语境优先保留“载荷” |
| 价值感知 | 感受 / 感知程度 | 构念名必须保留 |
| 维度基础 | 分析依据 / 参考维度 | 改掉抽象名词串 |

## 13. 不建议使用的做法

1. 不要只做表面替换。只把“本文”改成“本研究”、把“说明”改成“显示”，通常没有实质作用。
2. 不要故意制造错别字或病句。低风险不是低质量。
3. 不要编造数据、案例、引用、访谈、实验或检测结果。
4. 不要把术语全部白话化。统计方法、模型名称、变量名称必须保留。
5. 不要每句都加限定词。“一定程度上、较为、相对、可能”过密也会变成新模板。
6. 不要把所有段落都改成同一种句式。综述段、方法段、结果段、策略段应当不同。
7. 不要把非正文材料扩写成正文段。标题、表格、参考文献、问卷选项默认跳过。
8. 不要为了“更像人”使用第一人称、情绪、玩笑、吐槽或聊天口吻。

## 14. 可复用段落类型写法

### 14.1 文献综述段

推荐结构：

> 图表或数据库来源 → 阶段划分 → 每阶段主要关注点 → 代表研究或数据 → 仍存在的不足。

注意：少用“研究前沿、演化脉络、范式、价值挖掘”，多写“谁研究了什么、用了什么数据、得到了什么结果”。

### 14.2 理论基础段

推荐结构：

> 概念是什么 → 常用在哪类研究中 → 本文用它解释什么。

注意：概念定义不要过度抽象。可以加入“也就是……”式的普通解释，但不要变成闲聊或教材式扩写。

### 14.3 研究方法段

推荐结构：

> 使用什么方法 → 处理什么数据 → 得到什么结果 → 用于后文哪一步。

注意：少写“为……提供科学依据”，多写“用于后续客群划分 / 策略制定 / 指标比较”。方法段可以比原文稍长，只要是在讲真实过程。

### 14.4 数据结果段

推荐结构：

> 表图位置 → 核心数字 → 直接含义 → 有限参考价值。

注意：不要把一个百分比解释成很大的战略结论。数据段应围绕数字和样本内含义展开；用途只在原文需要承接后文时写，而且要收得住。

### 14.5 景区或案例概况段

推荐结构：

> 位置 → 面积 / 人口 / 资质 → 核心资源 → 与研究主题的关系。

注意：避免宣传语堆叠，如“独具魅力、底蕴深厚、璀璨明珠、重要引擎”。

### 14.6 策略或建议段

虽然源文件重点不在策略段，但可按同一原则处理：

> 前文发现的问题 → 对应对象 → 可以怎么做 → 适用条件或限制。

避免只写“优化、完善、强化、提升”。要写清楚优化什么对象、通过什么动作、解决什么问题。

## 15. 输出范围和报告来源

根据用户给的材料确定输出范围：

- 如果用户给整篇文章、章节或连续正文，按原文顺序逐段处理所有可处理正文段落。不要只挑高风险段落。
- 如果用户给 AIGC 检测报告、AI率报告或风险段落清单，按报告标出的风险段落处理。
- 如果用户给混合材料，正文段落处理，标题、表格、参考文献、问卷选项等非正文默认跳过。

每个修改项的 `说明` 要说清：

- 保留了哪些硬信息。
- 主要降低了哪类风险：抽象名词、过满结论、模板连接、宣传腔、术语周边表达、段落结构等。
- 如果某段只做轻改，也要说明是因为该段硬信息较多或风险较低。

## 16. 合法改写边界、忠实度门槛和有效修改门槛

本技能只能做论文表达层面的降调和改写，不能把它变成事实生成器、检测承诺工具或学术造假工具。

### 16.1 不做的事

- 不伪造数据、案例、引用、访谈、实验过程、检测结果、个人经历。
- 不为了“像人写的”故意加错别字、语病、口水话或低质量表达。
- 不把论文正文改成聊天语气、朋友圈语气、营销口播或情绪化随笔。
- 不为降风险牺牲术语和事实。术语密集时，先保留术语，再改术语周边的话。
- 不处理未脱敏的密钥、账号、身份证号、联系方式等隐私凭据；这类内容如果出现在输入中，不要在修改报告里引用。

### 16.2 忠实度门槛

每个 `修改后` 必须同时满足：

1. 同一语言：中文论文仍写成中文论文，不切换成解释性英文、聊天语或提示词。
2. 同一主题：不把别的段落、摘要、通用模板或无关示例的内容写进这一条。
3. 同一位置语境：原段是综述、方法、数据结果、理论基础还是案例概况，改后仍服务于同一论文位置。
4. 硬信息保留：数字、年份、变量、路径、表号图号、方法名、模型名、引用、专业术语不丢失、不错位、不近义误换。
5. 原文事实优先：缺少上下文时，不补新事实；能改表达就改表达，不能判断的事实按原文保留。

### 16.3 有效修改门槛

有效修改不是同义词游戏。至少要改到下面一类问题：

- 抽象名词串减少了，读者能看到对象、动作或用途。
- 模板连接链断开了，不再是“通过……从而……进一步……为……提供……”一路到底。
- 过满结论收住了，宏大意义变成了有限判断或后文用途。
- 宣传腔、政策腔、AI论文腔减少了，句子回到普通论文表达。
- 段落顺序更贴近材料本身：哪些是事实材料，哪些是解释，哪些只是有限用途，由原文关系决定，而不是为了闭环补齐每个环节。
- 句长和节奏有变化了，不再每句都同样完整、对称、圆满。

无效修改的例子：

- 只把“本文”改成“本研究”。
- 只把“说明”改成“显示”。
- 只替换标点或连接词。
- 为了显得改得多，增加一串“本研究认为、一定程度上、相对而言”的模板限制句。

整篇文章模式下，即使某段风险较低，也应按段落输出；但可以轻改或基本保留，并在 `说明` 中说明该段硬信息较多、只做连接或语气调整。

### 16.4 `修改后` 不能出现编辑指令

`修改后` 是可直接放回论文的正文，不写：

- “建议改为……”
- “可补充真实材料……”
- “这里需要进一步核实……”
- “待用户提供数据后再完善……”

这类提醒如果确实必要，只能放在 `说明` 中，并且不应替代正文改写。

## 17. 论文场景下的 AI 痕迹细分检查

下面这些规则已经内置到本技能中。它们不是泛用“人性化聊天”规则，而是论文正文可用的 anti-AI-register 检查。

### 17.1 夸大意义、遗产和趋势

高风险写法常把普通事实拔高成“标志着、见证了、体现了、奠定基础、关键转折点、重要贡献、持续影响”。论文中除非有直接证据，不要把段落结尾写成宏大历史意义。

处理方式：

- 先写事实、数据或研究对象。
- 如果需要评价，只写本段能支持的范围。
- 把“重要意义”改成“可作为后文分析的参考”“为下一步分类提供基础”。

### 17.2 宣传和广告式语言

需要重点删减：

- 景区/文化宣传词：独具魅力、底蕴深厚、璀璨明珠、令人叹为观止、必游之地、迷人的自然风光。
- 政策/商业套话：赋能、驱动、构建体系、形成路径、打造格局、推动高质量发展、重要引擎。
- AI论文套话：清晰呈现、充分体现、深刻揭示、有效促进、全面提升、具备重要意义、具有深刻价值。

更合适的论文表达：

- “说明、反映、可以看出、主要是、有一定作用、可以作为参考、为后续分析提供基础”。
- 景区概况写位置、面积、人口、资质、资源和研究主题关系，不写宣传口号。
- 策略段写对象、动作、适用条件，不只写“优化、完善、提升”。

### 17.3 模糊归因和无来源权威

高风险写法：

- “专家认为……”
- “有研究表明……”
- “行业报告显示……”
- “资料显示……”但不给出处或与论文引用不对应。

处理方式：

- 如果原文有引用、表号、数据来源，保留并靠近结论。
- 如果没有来源，不新增“专家/报告/研究表明”。
- 可以改成“从原文材料看”“结合本文样本”“在当前数据范围内”，但不要制造权威背书或暗示存在未列明资料来源。

### 17.4 规则三段式和过度对称结构

AI 文本常把内容强行排成三项：首先/其次/最后，创新/价值/意义，理论/实践/社会。论文中可以有层次，但不要每段都三分法。

处理方式：

- 能用两项就用两项，能直接顺着材料写就不用编号。
- 段落之间可以有不完全对称的重点。
- 不要每段都以“综上所述/由此可见/总体来看”收束。

### 17.5 否定式排比和“不是……而是……”

高风险写法：

- “这不仅是……更是……”
- “并非只是……而是……”
- “不仅体现了……也反映了……”

处理方式：

- 如果只是强调，直接删掉排比，写核心事实。
- 如果两层含义都需要保留，拆成普通说明，不要做口号式升级。

### 17.6 同义词循环

为了避免重复而不断换词，会让论文概念漂移。例如同一研究对象一会儿叫“游客”、一会儿叫“消费者”、一会儿叫“受众”、一会儿叫“体验者”，如果论文变量不是这样定义，就会造成不一致。

处理方式：

- 论文中的核心对象、变量、构念可以自然重复。
- 不为避免重复而换掉专业名词。
- 需要变化时，只换普通连接和判断，不换术语本体。

### 17.7 虚假范围和万能跨度

高风险写法：

- “从理论构建到实践应用……”
- “从游客感知到景区治理……”
- “从数据分析到策略优化……”

如果 X 和 Y 不是论文中真实展开的两个层级，就像 AI 生成的空泛范围。

处理方式：

- 只写原文真实覆盖的范围。
- 不为了显得全面而补跨度。
- 可以改成“本文主要分析……，并据此讨论……”。

### 17.8 格式痕迹

默认把这些格式痕迹降到很低，基本不使用：

- 过多引号。
- 过多括号。
- 破折号。
- 加粗强调。
- 装饰性项目符号。
- 行内小标题加冒号。
- 表情符号。

必要的 Markdown 代码块用于输出格式，可以保留。论文正文中的专业括号或引用格式如果原文已有，按原文保留，不为了降风险乱删。

### 17.9 聊天残留和助手口吻

如果输入里混入“当然、希望这对你有帮助、下面是、你说得对、如需我继续”等聊天痕迹，正文改写时删除。论文正文不写助手口吻，也不写“我们可以看到”这种不必要的对话式引导。

### 17.10 填充词和通用积极结尾

减少这些空泛收束：

- “未来前景广阔”。
- “具有重要现实意义”。
- “为相关研究提供了新的思路”。
- “值得进一步深入探索”。

如果确实需要结尾，写具体后文用途、研究不足或可继续分析的方向。

## 18. 论文式 human flavor：只吸收可用于论文的部分

论文式“人味”不是第一人称、幽默、情绪或混乱旁白，而是让文字像作者在解释自己的材料。

### 18.1 AI式写作和论文式自然写作的区别

- AI式写作：元评论很多、通用脚手架很多、每段都完整闭环、意义拔得很高、抽象名词堆得密。
- 论文式自然写作：有材料锚点、有过程顺序、有具体限制、有自然重复、有有限判断，不追求每段都漂亮收束。

### 18.2 降低抽象：写对象、动作、过程和用途

把抽象表达落地时按这六类处理：

1. 抽象名词 → 具体对象：把“文化资源本体价值挖掘”改成“对文化资源本身价值的分析”。
2. 宏大判断 → 直接用途：把“具有重要参考价值”改成“可以作为后文对策制定的参考”。
3. 概念堆叠 → 操作过程：把“后续消费者聚类分析与营销策略设计的维度基础”改成“作为后续消费者分群和营销策略制定的参考维度”。
4. 价值/意义 → 后文怎么用：写“用于后续分群、产品设计或策略调整”，少写“彰显价值”。
5. 机制闭环 → 局部解释：不要每段都写“形成机制/路径”，先说明本段能解释的现象。
6. 高级动词 → 普通动词：把“赋能、驱动、构建、提炼、转化”按语境改成“用于、带动、整理、得到、变成”。

### 18.3 引入“约束”和“摩擦”，但只能来自原文

可以写限制、条件、过程中的不完整性，例如样本范围、问卷回收、数据来源、适用对象、研究不足。但这些必须来自原文或用户材料，不能编造“低概率细节”。

正确方向：

- 原文有样本量，就写“在本次样本中”。
- 原文有问卷回收过程，就写发放、回收、筛选。
- 原文有表格读数，就写该表能直接说明什么。

错误方向：

- 编一个访谈对象。
- 编一个现场观察细节。
- 编一个作者经历。
- 编一个数据采集困难。

### 18.4 句长和节奏

不要每句都同样完整。可以有长短变化：

- 方法段可以较长，因为要交代过程。
- 数据段可以短一些，先说数字，再说含义。
- 综述段可以把引用和发现分开写。
- 策略段不要长串排比，写对象和动作即可。

短句不是唯一答案。关键是不要机器式顺滑，也不要为了变化牺牲清楚度。

### 18.5 结尾不要每段都圆满

AI 文本喜欢用“综上”“由此可见”“具有重要意义”让每段完整闭合。论文正文中，很多段落只需要把材料说明清楚，或者自然过渡到下一步。

可以的结尾：

- “这一结果可以作为后续分群的参考。”
- “相关研究仍主要集中在……，对……讨论较少。”
- “因此，后文将结合该结果继续分析……。”

不建议的结尾：

- “具有重要理论和实践意义。”
- “为行业高质量发展提供了有力支撑。”
- “展现出广阔的发展前景。”

## 19. 最终检查表

交付前逐项问自己：

- 硬信息有没有全部保留？
- 专业术语是否还在？是否只改了术语周边的话？
- 是否减少了抽象名词串？
- 是否把过满意义句改成了用途句？
- 是否有长过程句把方法过程讲清楚，而不是机械缩短？
- 文献综述是否写成“谁研究什么、怎么研究、得到什么、不足是什么”？
- 数据段是否围绕表图、数字和样本内含义展开，而不是被拔高成战略结论？
- 句长是否有自然变化，没有每句同长、同结构、同结尾？
- 格式痕迹是否已经降到很低，没有滥用引号、括号、破折号、加粗、装饰性项目符号或行内小标题？
- 是否没有机械套替换表？
- 是否没有滥加限定词？
- 是否没有把所有段落改成一种句式？
- 是否没有伪造数据、引用、案例、访谈或检测结果？
- 是否没有承诺官方检测通过，也没有证明文本一定是 AI 写的或人写的？
- 是否没有把论文改成聊天、宣传稿或政策口号？
- 是否只依赖本技能包内的规则就能理解和执行？
- 是否已经把 AI 痕迹处理为论文可用表达，而不是泛用人性化聊天？

如果不能同时满足“保留专业性”和“降低模板感”，优先保留专业性，并在 `说明` 中解释限制。
