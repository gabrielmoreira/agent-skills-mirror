# aigc-paper-rewrite pattern reference

本文件是 `SKILL.md` 的补充速查。这里列的是本技能内置的常见处理思路，但不能机械套用。任何替换都必须先保留事实、术语、数据、表图编号和引用。

## 高频处理思路

| 高风险感较强的表达 | 可考虑的自然表达 | 使用提醒 |
|---|---|---|
| 以……为切入点 | 围绕……展开 / 从……入手 | 看论文是否需要“切入点”这个术语。 |
| 清晰呈现演化脉络 | 反映发展过程 | 降低综述模板感。 |
| 重点围绕 | 主要关注 / 主要是 | 不要连续使用“重点”。 |
| 实现客单价提升 | 使客单价提高 | 改成动作结果。 |
| 提升营销触达效率 | 提高营销效果 | 少用互联网营销套话。 |
| 精准营销的增益效果 | 精准营销的效果 | 不必过度学术化。 |
| 场景化应用仍相对不足 | 相关应用研究还比较少 | 适合文献不足处。 |
| 体验链衔接问题 | 体验链断层问题 | 仍需看原文概念。 |
| 消费停留 | 滞留时间 / 停留时间 | 保留统计口径。 |
| 复游率 | 回头率 / 重游意愿 | 变量名为“复游率”时不要换。 |
| 提供实证依据 | 提供一定基础 / 作为参考 | 把意义句改用途句。 |
| 具备继续分析的基础 | 可以继续分析 / 可以进一步探究 | 降低过满结论。 |
| 后续行为意向 | 之后的行为选择 / 未来行为意愿 | 变量名不动，普通表达可调整。 |
| 高载荷题项 | 高负荷题目 / 载荷较高的题项 | 统计语境优先保留“载荷”。 |
| 价值感知 | 感受 / 感知程度 | 如果是构念名，必须保留。 |
| 维度基础 | 分析依据 / 参考维度 | 改掉抽象名词串。 |

## 抽象到具体的转换

- 抽象名词 → 具体对象：把“文化资源本体价值挖掘”改成“对文化资源本身价值的分析”。
- 宏大判断 → 直接用途：把“具有重要参考价值”改成“可以作为后文对策制定的参考”。
- 概念堆叠 → 操作过程：把“后续消费者聚类分析与营销策略设计的维度基础”改成“作为后续消费者分群和营销策略制定的参考维度”。
- 机制闭环 → 局部解释：不要每段都写“形成……机制/路径”，先说明现象和本段能解释的范围。
- 高级动词 → 普通动词：把“赋能、驱动、构建、提炼、转化”按语境改成“用于、带动、整理、得到、变成”。

## 段落类型模板

| 类型 | 推荐顺序 | 避免 |
|---|---|---|
| 文献综述 | 图表或数据库来源 → 阶段划分 → 每阶段主要关注点 → 代表研究或数据 → 不足 | 研究热点、研究前沿、演化脉络、实证范式、价值挖掘密集出现 |
| 理论基础 | 概念是什么 → 常用在哪类研究中 → 本文用它解释什么 | 定义过度抽象，或改成闲聊 |
| 研究方法 | 使用什么方法 → 处理什么数据 → 得到什么结果 → 用于后文哪一步 | “为……提供科学依据”式拔高 |
| 数据结果 | 表图位置 → 核心数字 → 直接含义 → 有限参考价值 | 把一个百分比解释成宏大战略结论 |
| 景区/案例概况 | 位置 → 面积/人口/资质 → 核心资源 → 与研究主题的关系 | 独具魅力、底蕴深厚、璀璨明珠、重要引擎 |

## 反模式

- 只做表面替换，原句结构和判断力度不变。
- 为了“像人写的”故意加错别字、病句或口水话。
- 为了具体而编造数据、案例、引用、访谈或个人经历。
- 把专业术语全部换成白话，导致论文准确性下降。
- 每句都加“较为、一定程度上、相对、可能”，形成新的模板。
- 所有段落都改成同一种“材料 + 意义 + 展望”格式。

## 论文场景下的 AI 痕迹速查

| 风险模式 | 典型表现 | 处理方向 |
|---|---|---|
| 夸大意义 | 标志着、见证了、奠定基础、关键转折点 | 回到事实、数据、后文用途 |
| 宣传腔 | 独具魅力、底蕴深厚、璀璨明珠、广阔前景 | 写位置、资源、样本、对象和研究关系 |
| 政策腔 | 赋能、驱动、构建体系、打造格局、高质量发展 | 改成用于、带动、整理、形成参考 |
| 模糊归因 | 专家认为、研究表明、资料显示但无来源 | 有引用就保留引用；无来源不新增权威背书 |
| 三段式过密 | 首先/其次/最后，每段都三项并列 | 能两项就两项，能顺写就不用编号 |
| 否定式排比 | 不仅是……更是……、并非……而是…… | 直接写核心事实或拆成普通说明 |
| 同义词循环 | 同一对象不断换称呼导致概念漂移 | 核心对象、变量、术语可以自然重复 |
| 虚假范围 | 从理论到实践、从感知到治理等空泛跨度 | 只写原文真实覆盖范围 |
| 格式痕迹 | 过多引号、括号、破折号、加粗、行内标题 | 默认降到很低，保留必要代码块和原文引用格式 |
| 聊天残留 | 当然、下面是、希望有帮助、你说得对 | 删除助手口吻，改成论文正文 |

## 最终四原则

1. 具体材料优先于宏大意义。
2. 普通动词优先于抽象名词。
3. 有限判断优先于圆满结论。
4. 按材料本身的关系展开，不用连接词闭环凑完整。
