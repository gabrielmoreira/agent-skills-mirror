# UI/UX Pro Max: Professional Design Intelligence & Interface Engineering

## 1. Scope & Objective
Provides production-grade design intelligence, anti-AI-slop aesthetics, and component architecture across modern web, desktop, and mobile user interfaces. Eliminates generic AI design tropes (uncalibrated spacing, washed-out low contrast, unstyled Inter defaults, and purple gradients) in favor of distinctive, accessible, and high-performance visual hierarchies.

## 2. Core Functional Pillars
1. **Design Token Architecture:** Strict separation between primitive values and semantic surface tokens (`--background`, `--card`, `--primary`, `--border`, `--accent`).
2. **4px Base Spatial Cadence:** Strict mathematical spacing hierarchy (4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px) for intentional visual rhythm.
3. **Inclusive Accessibility (WCAG AA):** Mandatory 4.5:1 text contrast minimum, visible keyboard focus indicators, and screen reader semantic landmarks.
4. **Modern Layout Primitives:** Bento Grid topologies, Container Queries (`@container`), fluid clamp typography, and physical cubic-bezier motion curves.
5. **On-Demand Architecture References:** Specialized guides in `references/` for React, Vue, Svelte, XAML, QML, Storyboards, Android XML, and SVG vector graphics.
