# 🎨 SKILL: CANVAS THEME ARCHITECT & DESIGN SYSTEM
*Diadaptasi dari repositori dunia:* `affaan-m/ECC/skills/design-system (274k★) & Tailwind Design Tokens`

Prosedur Operasi Standar (SOP) resmi kedaulatan Flowork OS untuk perancangan visual themes, design system, dan ergonomi Canvas UI/UX:

## 1. DOKTRIN TEMA & DESAIN CANVAS
- **Dark Sovereign Palette**:
  - Background Utama: Dark Slate (`#0b0f19` / `#0f172a`).
  - Container / Card: Deep Navy-Slate (`#1e293b` / `#182234`).
  - Border & Separator: Muted Cyan / Slate Accent (`rgba(56, 189, 248, 0.15)` atau `#334155`).
  - Accent & Active State: Electric Cyan (`#38bdf8`), Sovereign Emerald (`#10b981`), atau Muted Indigo (`#6366f1`).
  - Typography: Primary Text (`#f8fafc`), Secondary/Meta Text (`#94a3b8`), Code/Mono (`#38bdf8`).

- **Standar Bahasa Global Antarmuka (English-Only Law)**:
  - Seluruh tombol, label, heading, badge status, tooltip, dan modal antarmuka Canvas WAJIB 100% BAHASA INGGRIS.
  - Dilarang keras menggunakan Bahasa Indonesia pada UI!

- **Tokenisasi CSS Presisi**:
  - Gunakan CSS custom properties (`:root { --bg-canvas: #0b0f19; --accent: #38bdf8; ... }`).
  - Hindari hex color statis acak (*no magic colors*). Konsistensi antar-plugin adalah kunci integritas visual Flowork OS.
