# 🏢 Software Company SOP Skill Runbook

## 1. Overview & Operational Mandate
Defines strict software engineering operating procedures across PRD drafting, threat modeling, API contract definition, zero-trust test verification, and formal handoff.

## 2. Core Pillars
1. **Requirements Definition**: Structured PRD with explicit acceptance criteria.
2. **Deterministic Architecture**: Micro-modular separation between UI and backend logic.
3. **Rigorous Verification**: Unforgiving terminal proof with Exit Code 0.
4. **Zero Flakiness**: Total prohibition of untested mock code.
