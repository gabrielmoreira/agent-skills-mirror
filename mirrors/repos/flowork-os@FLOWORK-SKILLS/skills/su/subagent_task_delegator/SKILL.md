# 🛠️ SKILL: SUBAGENT TASK DELEGATOR & ROLE DISPATCHER
*Diadaptasi untuk tool Flowork:* `invoke_subagent` | *Referensi:* Superpowers Subagent-Driven Development

Prosedur Operasi Standar (SOP) resmi kedaulatan Flowork OS untuk delegasi subtugas ke subagen otonom.

## 1. DOKTRIN DELEGASI SUBAGEN
- **Konteks Terisolasi**: Berikan subagen deskripsi prompt dan boundary yang spesifik tanpa mencemari memori utama.
- **Fresh Agent Per Task**: Gunakan subagen terpisah untuk peran penguji (tester) vs peran pembuat (implementer).
- **Agregasi Hasil**: Gabungkan artefak keluaran subagen dan verifikasi keutuhan sistem sebelum melapor ke Super Admin.
