# 🎨 SKILL: DISTINCTIVE UI STYLIST & ANTI-AI-SLOP DESIGNER
*Diadaptasi dari repositori dunia:* `anthropics/skills/frontend-design & affaan-m/ECC/skills/frontend-design-direction`

Prosedur Operasi Standar (SOP) resmi kedaulatan Flowork OS untuk estetika UI visual tingkat studio, hierarki tipografi, dan eliminasi pola murahan (*anti-AI-slop*):

## 1. DOKTRIN ESTETIKA DISTINCTIVE
- **Eliminasi Ciri AI-Slop**:
  - Hindari SaaS-card kits generik: memecah semua konten menjadi kotak rounded seragam dengan shadow blur abu-abu yang membosankan.
  - Hindari tombol atau badge dengan all-caps berlebihan atau tracking terlalu lebar jika tidak perlu.
  - Struktur visual adalah informasi: gunakan divider garis presisi 1px, nesting yang logis, dan kontras yang tegas.

- **Hierarki & Tipografi Berbobot**:
  - Skala tipografi teratur: H1 (`1.5rem`, weight 700), H2 (`1.25rem`, weight 600), Body (`0.875rem`, line-height 1.5).
  - Utamakan font native clean (`system-ui`, `-apple-system`, `Inter`, font mono untuk parameter/kode).

- **Ergonomi Split-View Canvas**:
  - Plugin Canvas Flowork berjalan berdampingan dengan Workbench atau Chat.
  - Komponen wajib responsif: tetap rapi dan tidak overflow pada lebar 360px hingga 1920px.
