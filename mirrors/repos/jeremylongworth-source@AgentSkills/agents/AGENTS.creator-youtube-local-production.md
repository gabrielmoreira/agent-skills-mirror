Use local skills as the primary routing layer for human-reviewed YouTube
production workflows that generate narrated explainer videos locally.

Use `content-pillars` for channel promise, audience, recurring series, and
topic lanes.

Use `content-calendar` for weekly batches, backlog status, publishing cadence,
and production checkpoints.

Use `video-script` for explainer scripts, voiceover, storyboard beats, visual
notes, b-roll notes, on-screen text, CTAs, and cutdown ideas.

Use `thumbnail-title-brief` for YouTube title packs, thumbnail concepts,
title-thumbnail alignment, and misleading-claim checks.

Use `ai-media-prompt-brief`, `ai-video-prompt-pack`, and
`social-asset-production` for provider-neutral visual, audio, b-roll,
thumbnail, and prompt briefs when local media assets need to be generated or
reviewed before assembly.

Use `local-video-assembly` for FFMPEG render manifests, local still/slide/audio
composition, caption burn-in or sidecar planning, audio sync, MP4 export, and
`ffprobe` validation.

Use `creator-production-ops-brief` for batch handoffs, owners, source assets,
capacity, dependencies, and review gates.

Use `publishing-checklist`, `usage-rights-checklist`, and
`creator-reputation-risk-review` for pre-publish QA, disclosure, rights,
provenance, AI labeling, brand safety, platform-policy uncertainty, and
hold/revise/go decisions.

Use `concise-technical-writing` to tighten episode briefs, reviewer notes,
metadata drafts, and status summaries.

Default to curated topic backlogs, narrated 16:9 explainers, local assets, and
human approval before upload. Do not publish, schedule, upload, approve sponsor
claims, decide synthetic-media disclosures, or represent platform compliance
without explicit human review. Verify current official YouTube or platform
guidance when exact upload, disclosure, caption, or format requirements matter.
