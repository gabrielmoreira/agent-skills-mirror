# Prompts for everyone

These work for anyone with a Copilot licence, whatever their role. Start here if you're new.

---

### Summarise a long email thread into decisions, open questions and owners

**App:** Outlook · **Role:** Everyone · **Licence:** Microsoft 365 Copilot · **Last verified:** pending re-test

**Prompt:**
> Summarise this thread in three sections. **Decisions:** what has been agreed, and by whom. **Open questions:** what is still unresolved, and who is expected to answer it. **Actions:** each task with an owner and a due date if one was mentioned. If an owner or date wasn't stated, write "not stated". Don't guess. Ignore signatures, disclaimers and greetings.

**Use when:** you've been copied into a 30-message thread late, or you need to brief someone who wasn't on it.

**Where it falls short:** Copilot only sees the messages in the thread it's pointed at. A decision made by phone or in a separate chain won't appear. It's also inclined to infer an owner from whoever spoke last, which is why the prompt tells it to write "not stated" instead. Check the actions list against the thread before you forward it.

### Get Copilot to teach you the feature you've been avoiding

**App:** Learning agent (in Microsoft 365 Copilot) · **Role:** Everyone · **Licence:** Microsoft 365 Copilot · **Last verified:** pending re-test

**Prompt:**
> Show me, step by step, how to use Copilot in [app] to [the task you've been putting off]. Use an example that fits my role as [your role]. Then give me a short practice exercise and test me on it.

For example:
> Show me, step by step, how to use Copilot in Excel to check a supplier invoice against our agreed rates. Use an example that fits my role as a project coordinator. Then give me a short practice exercise and test me on it.

**Use when:** there's a Copilot feature you know you should be using and haven't, because nobody has shown you.

**Where it falls short:** the Learning agent has to be added first (Microsoft's link: `aka.ms/LearningAgent/add`). What it teaches depends on how your organisation has set up Viva Learning, and some of its features are still in preview. It was listed as Windows-first at launch. It teaches the general feature, not your organisation's process, so the practice exercise will be generic.
