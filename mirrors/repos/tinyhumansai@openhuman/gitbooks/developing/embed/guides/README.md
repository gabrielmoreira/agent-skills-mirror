# Embedding guides

Choose the guide that matches your host:

- [CLI chatbot](cli-chatbot.md): create an agent and collect or stream its reply.
- [Multiple agents](multi-agent.md): give agents independent prompts, access, and working folders.
- [SaaS with multiple tenants](saas-multi-tenant.md): isolate user state through profiles.
- [Deploy a server](deploy-server.md): call an embedded agent from your HTTP host.
- [Lean and headless hosts](lean-headless.md): select runtime services and Cargo features separately.
- [Test with a mock backend](mock-backend-testing.md): run the entire example suite offline.

Start with [Embedding](../README.md) for the library boundary and quickstart. See [Integrations](../integrations/README.md) for providers, storage, MCP, and channels.
