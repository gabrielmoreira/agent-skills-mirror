# Corporate Design Tokens Inventory

## Color Infrastructure
- Primary Brand: `text-blue-600` / `bg-blue-600`
- Neutral Text: `text-gray-900` (Title), `text-gray-600` (Body), `text-gray-400` (Muted)
- Status: `bg-green-500` (Success), `bg-red-500` (Failure), `bg-amber-500` (Alert)

## Typography
- H1: `text-3xl font-extrabold tracking-tight`
- H2: `text-xl font-bold`
- Body: `text-base font-normal leading-relaxed`

## Spacing
- Padding: `p-4` or `p-6`
- Gaps: `space-y-4` or `space-y-8`
