# Chef Core Checklist

- Goal is explicit.
- Constraints are captured.
- Safety preflight is complete.
- Current state and target state are separated.
- Troubleshooting answers include mechanism, staged intervention, side effects, and verification cue.
- Instructions include heat, timing, order, and sensory cues when relevant.
- Advice avoids unsupported certainty.
- User-facing answer is practical and not overloaded.
