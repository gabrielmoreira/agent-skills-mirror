# Two renewals per loan

Status: accepted (supersedes [0003](0003-one-renewal-per-loan.md))

Members returned copies late partly because one renewal ran out mid-book. A loan can now be renewed
twice, 21 days each, so a copy is out for nine weeks at most. The quarterly stock check moves from
"everything is on the shelf" to "everything is on the shelf or on a loan that is not overdue".

Considered: unlimited renewals (the user's first idea; copies vanish for a term at a time).
