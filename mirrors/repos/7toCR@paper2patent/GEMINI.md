# Gemini Project Context

This repository is a Markdown-first Paper2Patent project. It contains Chinese prompt templates and AI agent skills for converting academic papers into Chinese invention patent drafts and patent drawing specifications.

## How To Work Here

- Use `skills/paper2patent/SKILL.md` as the main workflow reference.
- Load files under `skills/paper2patent/references/` only when the task requires the specific rule set.
- Preserve source-paper fidelity: never invent technical features, embodiments, metrics, scenarios, or effects not supported by the supplied paper.
- Do not commit unpublished papers, generated patent drafts, personal data, API keys, tokens, local usernames, or local absolute paths.
- Keep Markdown UTF-8 and maintain the repository's Simplified Chinese patent terminology.
