# 方法审计的匿名模式

以下模式只用于解释检查顺序。因子、节点和表型均为占位符，不能替代目标论文证据。

## 1. 候选筛选到定向验证

**场景**：筛选提示因子 A 与表型 C 有关。

检查顺序：

1. 筛选的选择压力或直接读出是什么？
2. 因子 A 是富集候选、相关候选还是已经接受定向扰动？
3. 独立敲低、敲除或过表达能否复现方向一致的表型？
4. 定向验证使用了独立试剂、独立样本或替代读出吗？
5. 表型 C 是核心表型还是代理指标？

结论边界：筛选命中加单向验证通常支持候选依赖关系，不足以建立完整机制。

## 2. 扰动—表型—机制

**场景**：操纵因子 A 后节点 B 和表型 C 同时变化。

检查顺序：

- A 的操纵是否经过确认？
- B 是直接读出、中间节点还是与 C 并列的变化？
- 是否证明 A→B 的方向，而不仅是共同变化？
- 移除 B 是否阻断 A 对 C 的影响？
- 单独操纵 B 是否足以影响 C？
- 是否存在未检查的节点 D 或背景依赖？

输出时逐箭头标注相关、方向、必要性、充分性或未知。

## 3. Rescue 的方向和层级

**场景**：扰动 A 导致节点 B 下降并出现表型 C；随后恢复 B。

检查顺序：

1. B 的恢复方向是否正确且确实达到预期水平？
2. 恢复的是 B 本身、下游代理读出还是核心表型 C？
3. rescue 是否只在一个剂量、一个背景或一个时间点成立？
4. 是否有空载体、非靶向处理和背景特异性对照？
5. 部分恢复应解释为局部依赖还是接近完整恢复？

若仅恢复下游标志物而未恢复 C，只能支持较窄的分子层关系。

## 4. 药理与遗传证据

**场景**：药物处理与遗传扰动都影响同一表型。

检查顺序：

- 两种扰动是否指向同一节点且方向一致？
- 药物是否可能存在脱靶、毒性或剂量相关的非特异效应？
- 遗传扰动是否存在补偿、编辑效率或背景差异？
- 二者是独立支持，还是共享同一未解决偏差？

不同手段结果一致可增强支持，但不能自动消除各自的替代解释。

## 5. 方法正交性

**场景**：论文使用互作、表达、定位、细胞功能和动物结果支持同一主张。

检查顺序：

1. 每种方法直接测量什么？
2. 它们是否独立检验同一个命题的不同可观察后果？
3. 是否把复合体相关误写为直接结合？
4. 是否把定位、表达变化或表型变化误写为彼此的因果证明？
5. 哪个关键环节仍只有一种方法支持？

输出应形成方法矩阵，而不是只罗列技术名称。

## 6. 数据库预测与模式图

**场景**：网络分析预测 A—B—C 关系，论文随后展示有限验证。

检查顺序：

- 预测来自相关性、富集、已知网络还是论文自己的实验？
- 哪些边由目标材料直接检验？
- 模式图是否包含未被结果支持的箭头？
- 是否把候选通路当成唯一解释？

数据库预测和模式图用于组织假设；没有独立数据的边必须标为待验证。

## 7. 不完整材料

只有截图和 caption 时仍可完成：变量、分组、可见对照、直接读出和局部 panel 逻辑。

不得补写：全文背景、未展示的重复数、统计方法、不可见 panel 结果或完整机制。应精确请求缺失的
caption、相邻正文、方法段或高分辨率图像，而不是笼统要求“更多信息”。
