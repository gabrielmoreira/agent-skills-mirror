Explore, modality menus and Studio shortcuts use one [catalogue](../../shared/studio-catalog.ts). A scene declares its inputs, output, owning Studio and preferred entry surface. A gallery work carries its own template ID. Model IDs include the provider, so two providers serving the same model remain separately addressable.

## Three journeys

1. Short-form video collects portrait works and original Shorts, Reels and TikTok video posts. Open the collection, choose the shortlist technique and set the footage and vertical brief in Shorts Studio. A connected Agent can use that brief to create an editable project. Back to Explore restores the collection.
2. Open Creators, choose a credit and open its work. Editable templates can be opened in the editor. Reference entries provide a recreation instruction. Browser Back returns to the source collection. A credit may identify the publisher of the original linked post. The interface labels this separately from explicit authorship.
3. Open a model from a modality menu. Its overview lists scenes compatible with the model’s input, output and reference support. Choose a scene, supply the required inputs and submit through the shared gateway. Provider setup and job recovery use the existing Settings and Assets surfaces.

The installation’s catalogue determines which models, credits and templates appear. Explore’s communities are curated scene and template collections. Public account publishing, social follows, competitions and hosted API key issuance require additional services. See [product architecture](architecture.md#discovery-and-generation) and the [route contract](../editor-fork.md#workspace-page-routes) for history, draft lifetime and integration details.
