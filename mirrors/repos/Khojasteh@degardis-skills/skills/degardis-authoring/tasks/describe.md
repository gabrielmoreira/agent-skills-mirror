Take each statement from the material rather than from what a source of this shape usually does, and where the compiler settles a question the bytes do not — what a page ends up carrying, which task a page is written for, what a build would ship — prefer its own report to a reading of the source prose.

A supplied scenario is either what the request asks about or one case of a wider question about the material, and an account of the case alone answers the wider question only for that case. Either way, trace the instructions the agent would reach in the scenario and the conditions deciding its actions, stops, and hand-offs. Answer a wider question at its own width, with the scenario as its worked case; where the request supports both readings and they lead to different answers, give the case's account as covering that case alone and ask whether the wider question is meant. Report the account as prescribed guidance: the material establishes what it teaches, while what an agent actually did requires interaction evidence. A scenario supplied to make the account concrete does not itself request a run.
