---
title: Whole-construct rewrite
applicability:
- When the work depends on changing a construct as a whole
---

Build the candidate outside the maintained source where the tooling allows it, compare it against the preservation account, and replace only once preservation closes. If it does not close, keep the original rather than leave a half-migrated hybrid in place: a partly replaced construct is worse than either version, because the child agent receives both and cannot tell which one governs.

A rename is part of the rewrite. Replacing the declaration is not enough — obsolete deliberate references have to go too, and ordinary prose that happens to contain the same word must not be rewritten with them.

Placement changes alter what the child agent receives without changing a sentence's wording, so after moving or consolidating material, rebuild the coverage picture and rehearse every affected request path.
