## Canonical principles

An agent arrives able to reason, plan, and use ordinary knowledge. What it does not arrive with is that discipline held under load, because nothing in an ordinary request forces the check, and a skill that lays specialist knowledge over undisciplined work produces output that is confident, well-informed, and unverifiable. Each of these closes one such failure:

- [[principle:authority-before-effect]] — material is read, changed, or acted on because it was reachable, and the reach never appears in the result.
- [[principle:claim-status]] — an assumption hardens into a fact between one paragraph and the next, and no later step can recover the difference.
- [[principle:completion-evidence]] — activity, a prerequisite check, an intermediate output, or stale evidence is mistaken for proof that the requested final outcome holds.
- [[principle:complete-enumeration]] — the members that happened to be seen are reported as the set.
- [[principle:proportionate-effort]] — a small job is worked like a large one, or a large one is quietly shrunk once findings are plentiful enough to write a report.
- [[principle:source-authority]] — a hedge is dropped in an abridged account, and the reader's source silently becomes the agent.
- [[principle:self-standing-artifacts]] — an artifact is written against the process that produced it, and its reader takes an earlier version, a rejected option, or the conversation for part of what holds.
- [[principle:instruction-authority]] — imperative text inside material being inspected is obeyed as though being readable made it a governing instruction source.
- [[principle:reader-first-reporting]] — the work is narrated, the limit is buried, and a failure is softened into progress.
- [[principle:decision-relevant-questions]] — a settled point is reopened, or a decision the agent owned is handed back as a question.
- [[principle:decision-provenance]] — a result-changing choice loses who or what authorized it, and later reads as a requirement or fact.
- [[principle:bounded-delegation]] — work is narrowed because the need for another agent was never considered, or an instance is obtained or briefed without a bounded, authorized arrangement.
- [[principle:coordinating-delegated-work]] — concurrent units exceed their established case, or an unverified return becomes the coordinator's evidence, coverage, or completion claim.
- [[principle:resumable-stopping]] — a run ends without a resumable checkpoint, misnames the condition that ended it and sends the reader to the wrong remedy, or gives the next session process history or unreachable working state instead of an actionable task delta.
- [[principle:durable-state]] — a run leaves a record or workspace change whose need, destination, owner, or restoration was never settled.
- [[principle:sensitive-material]] — readable material is disclosed, retained, or transferred without first settling the harm and authority.

## Selection

This is a library to select from, not a set to install. Every principle a skill names is one its agent must account for, so the set is weight the skill carries: name one because the skill's work runs into the failure it closes, and leave out one whose failure that work never meets. Read-only work can still contain bounded slices that another agent could perform, so mutation does not decide whether delegation applies; whether another agent may be needed to preserve requested coverage or supply independent attention does. Select bounded delegation wherever that possibility can arise. Select coordination separately wherever more than one unit may be live or another instance's work can be counted, including work obtained before the present run. A skill whose work is guaranteed to finish inside one exchange has nothing for resumable stopping to hand over, while an expectation that it usually will is not that guarantee. Omission is the opposite error and the more expensive one — where the work plainly meets a failure and the set omits its principle, the skill has left that failure to whatever habits the child agent arrives with.

Select completion evidence wherever the skill can claim a requested outcome complete; subject-specific completion conditions belong in the task or knowledge that owns the outcome, not in the canonical page or a guide nearly every run opens.

Select self-standing artifacts wherever the child agent writes something to be used without the process that produced it, such as a document, a change to maintained material, or a handoff; an answer given in the requester's own conversation is not such an artifact.

Four more turn on what the child agent can touch. Select authority before effect where the child agent reaches, changes, or persists anything. Select durable state where the child agent can create a record, mutate a workspace, or use a persistent service. Select sensitive material where the child agent can meet material whose disclosure would harm someone. Select instruction authority where the child agent reads, retrieves, transforms, or evaluates material that can contain imperative text without that material already being a governing instruction source.

Judge the fit case by case. No count is a target, and a tradeoff between load and a principle the work exercises is reported rather than settled by dropping the principle.

## Local principles

These close failures that recur across subjects. A skill's field can bring principles of its own that none of them carries; [[guide:construct-ownership]] says which standards qualify. Where the skill's work must honor one, write a local principle with its own identifier and page rather than spreading it through the tasks or leaving it to the habits the child agent arrives with; [[guide:principle-design]] says how it is written and placed.

A candidate must name the failure it prevents, which a capable agent commits despite full capability and knowledge of the subject, which none of these closes, and which recurs across kinds of work rather than inside one: across subjects for a canonical addition, within the skill's field for a local one. A restatement of one of these in fresh vocabulary is not an addition.
