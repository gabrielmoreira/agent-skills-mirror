---
title: Path rehearsal
applicability:
- When the work depends on what the child agent derives on a source's generated paths
---

Keep the recorded cases in re-readable working state. For final source, close the [[guide:obligation-ledger]], the [[guide:construct-agreements]], and these cases, each separately, against the exact generated state after the last edit and before claiming completion.

Build recorded cases from the obligation ledger and affected decision surface. Cover:

- every affected request class and materially distinct initial state;
- every outcome of each discriminator;
- both sides of every prerequisite, fallback trigger, hand-off condition, authorization gate, and completion check;
- success, failure, partial, and ambiguous results;
- every added, removed, merged, or re-homed decision; and
- for a revision, every affected starting contribution and authorized changed behavior.

For each case, record the request-visible start, generated pages, host-visible resources/permissions, observations available before each governed decision, derived action/stop/hand-off, expected and actual disposition, and pass/fail. Rehearse as the cold reader of [[principle:cold-reader-derivation]]. A case passes only when that path derives the required result without an unstated author step. If facet applicability becomes knowable after routing, test late discovery before specialization is consumed. For each affected facet, run the facet removal and addition tests on one fixed in-domain instance; task prose needed only to suppress or override facet procedure fails the comparison. Repair and rerun every failed case. An unrecorded walkthrough is not rehearsal.

Static rehearsal establishes whether the generated path derives a decision; it does not establish live performer, tool, service, mutable-runtime, or nondeterministic behavior. Mark acceptance questions depending on such behavior as runtime-only. Never close them from rehearsal; obtain behavioral evidence under its own contract or leave the functional claim unresolved.
