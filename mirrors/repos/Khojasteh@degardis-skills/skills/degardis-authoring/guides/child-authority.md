---
title: Bounded authority for what the child agent does
applicability:
- When the work depends on what authority the child agent needs for its actions
---

This page is about what the child skill must teach the child agent.

The canonical [[principle:authority-before-effect]] principle owns which effects need a grant of their own and why a reachable one is not already granted. Add subject knowledge only for what the principle cannot supply: an action deserves explicit authority in the child skill when it is destructive, irreversible, privileged, spend-incurring, externally visible, persistent beyond the run, or reaches material the requester did not open. The source should name both the action and its bounded target, and should teach that an unanswered request is not consent.

Never author a skill to weaken verification, widen permission, bypass approval, or use credentials merely because a host exposes them. If the skill supports both analysis and change, the distinction must be decidable from the request before any changing action begins. A host execution model narrows the arrangements available to the child agent; it never authorizes one the skill's own reasoning rejects.
