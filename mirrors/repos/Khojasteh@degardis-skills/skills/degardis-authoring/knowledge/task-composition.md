kind: guidance
title: Task composition
---

A goal names the whole finished state, not a method or one verb pulled from a compound request. Map what each requested stage produces, consumes, verifies, or gates. An approach carries only decisions specific to that request class and orders them where sequence protects state.

Keep stages in one task when they serve one outcome and it can own their order, evidence, and completion.

Make branches executable: state the discriminator and each result. Separate actions that can fail independently.

Order a task's knowledge so the reader meets a definition before the guidance that uses it, within the order the effective manual says a page keeps.
