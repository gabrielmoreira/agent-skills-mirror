---
title: Coordinating delegated work
applicability:
- Before a delegated unit starts
- Before another agent instance's return is relied on
---

Treat every return not yet usable by the coordinator as lost unless the host establishes otherwise; live units can fail together and each increases spend, reset delay, and repeat cost. Therefore one live unit at a time is the default: obtain it immediately before start and close it before obtaining the next. Authority to delegate is not authority for concurrency.

Before a second live instance, establish all of these: waiting for serial return would harm the outcome; known shared resources cover every unit through usable return plus acceptance, synthesis, and reporting; the requester or standing instructions permit the spend and width; and losing the whole batch is tolerable for the requester. Unknown means unmet; divisibility, open capacity, or easy repetition does not establish these conditions. Use the smallest width that avoids the demonstrated timing harm and never exceed requester, host, or shared-resource limits. If no safe width is established, stay serial or report the timing limit. If a shared brief has not yet produced an accepted return, run its first unit alone so the brief can be corrected before replication unless the same timing harm requires otherwise.

The coordinator owns acceptance and synthesis. Never forward a delegate's conclusion unchecked.

Bind each return to the exact material and state observed. For a state-changing unit, record the starting observation before launch using the same method that will judge the returned state. After return, confirm the named material has not moved to another revision, inspect the complete changed surface and any effect outside the boundary, and revalidate late returns against current state.

Read only the named return, not transcripts, logs, scratch output, or other working state the delegate did not stand behind. The one exception is a record the unit's contract designated before launch as evidence of the delegate's conduct: read it once the unit has observably stopped, as observation of what the delegate did, never as a conclusion it stood behind. If the unit is still live, do not read material it may still be writing.

Count coverage only against the brief. Useful observations outside it may create new coordinator-owned questions but do not enlarge verified coverage. Verify every relied-on claim at its cited evidence, repeat reproducible checks that acceptance depends on, and treat unsupported completion as incomplete.

Give every failed, short, unverified, or missing return one disposition: retry under a corrected contract and established attempt bound, complete the unit in the coordinator, or mark it uncovered with the judgments its absence prevents. Retry only when the next attempt differs in a way that could repair the failure.

Never infer that a unit stopped from silence, inactivity, or partial state. Missing return or an unrecognized state means live. Until return or observable stop, leave its surface alone. Close every started unit explicitly as integrated, canceled, or uncovered before synthesis, and synthesize replicated judgments only after every observer is closed.
