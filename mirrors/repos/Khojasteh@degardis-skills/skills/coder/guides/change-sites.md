---
title: Closing a set of change sites
applicability:
- When a change is complete only once every site it applies to has been found
---

Enumerate the candidate set before designing, performing, or accepting the transformation. Search by the owning symbol, shape, contract, and configuration key, and over every mechanism that binds a consumer without a textual reference and can create a site. Prove that the search can find at least one known site; a search with no positive control cannot establish absence.

Partition the result into mechanical sites, sites that need a local decision, generated sites owned elsewhere, and sites outside the authorized boundary. State the rule that places a site in each group. Do not silently treat an awkward match as an exception or edit generated output when an owning declaration exists.

An implementation applies a uniform transformation in verifiable batches, separating sites whose behavior or contract differs; a plan names those batches, and a review checks that the actual partition followed them. After a completed edit, repeat the enumeration from the original mechanisms and inspect the remaining matches. Completion requires every in-boundary site to be changed, deliberately retained with a reason, or handed off as an explicit blocker.
