# LinkedIn post intake (ask BEFORE writing)

Ask these in one or two grouped prompts. Keep it short — most answers are one line.

1. **Language** — English only, or **English + French** (two versions in one post,
   EN first then a `— — —` divider then FR)? Default: match the audience.
2. **Target audience** — who is this for? (e.g. insurers/underwriters, Microsoft
   sellers, C-level, developers, the general tech community) — drives jargon and
   angle.
3. **Complexity / register** — executive/business (outcome-led, minimal tech) ·
   practitioner (name the services, show the how) · deep-technical (architecture,
   trade-offs). Drives how much Azure/AI detail to include.
4. **Main messages** — the 2–4 points the post MUST land (e.g. "PDF → traced
   decision", "human keeps the pen", "mainframe → MVP in 2 weeks"). Ask the user
   to list them, or propose a draft from the video/asset and confirm.
5. **Mandatory links** — every URL that must appear (demo, repo, docs, an event,
   a landing page). Ask explicitly; never invent a link. Note LinkedIn ranks
   posts with external links lower — see `linkedin-playbook.md` for placement.
6. **Assets** — the video file(s), the poster/cover image, and whether both FR
   and EN subtitle files (SRT) should be provided/attached.
7. **Call to action** — comment / DM / try the demo / read the repo / book a chat?
8. **Hashtags** — let the user give preferred tags, or propose 3–5 relevant ones.
9. **Disclaimers** — anything mandatory (e.g. "technical demonstration, not a
   product", "fictitious/among demo data", employer disclaimer). Ask and include
   verbatim if given.

## Tone research (do this, don't guess the voice)
The user asked to write in THEIR voice. Attempt to ground it:
1. Try to fetch their LinkedIn profile/articles. LinkedIn usually blocks
   server-side fetches (HTTP 999 / login wall) — if so, do NOT fake it.
2. Ask the user to paste 1–3 of their recent posts/article intros, OR to pick a
   tone from a short list (see `tone-and-voice.md`).
3. Mirror their observed patterns (sentence length, emoji use, FR/EN mix,
   first-person vs company voice) and state which sample you matched.
