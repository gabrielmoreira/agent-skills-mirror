# skillshilp-create

Create production-quality Agent Skills from ideas, requirements, reusable prompts, or specifications.

`skillshilp-create` is a meta-skill that helps agents design Agent Skills as reusable software components rather than large prompts. It applies software engineering principles such as modularity, progressive disclosure, maintainability, discoverability, and token efficiency to produce skills that are easy to understand, reuse, and evolve.

## When to Use

Use this skill to:

- Create a new Agent Skill from scratch.
- Convert a reusable prompt into an Agent Skill.
- Design a modular skill collection.
- Architect the structure of a new Agent Skill.
- Generate supporting reference files, scripts, and assets.
- Validate basic skill structure with the bundled portable Bash validator.

## When Not to Use

Do **not** use this skill to:

- Modify an existing Agent Skill.
- Refactor or improve an existing skill.
- Review skill architecture.
- Modernize prompts or documentation.

For these tasks, use **skillshilp-edit**.

## Example Requests

- Create an Agent Skill for reviewing pull requests.
- Convert this reusable prompt into an Agent Skill.
- Design an Agent Skill for analysing Kubernetes logs.
- Create a modular collection of skills for API development.
- Generate a production-ready Agent Skill from this specification.

## Related Skills
