# Chain Example Skill

This skill demonstrates skill chaining capability, where one skill can invoke another skill.

## Usage

```
/skill chain-example
```

This skill chains by invoking `/skill example-skill` internally.

## Description

This skill serves as a test case for skill chaining feature in the bundled skills registry (#3324).
