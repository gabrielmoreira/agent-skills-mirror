# Plain language checklist

Target reader: an average U.S. high-school student (about grade 8–10 reading level). This applies to
page copy, labels, definitions, charts, graphs, tables, error messages, docs for editors and emails.

## Sentences and words

- One idea per sentence. Most sentences under 20 words.
- Common words: "start" not "commence", "use" not "utilize", "help" not "facilitate", "about" not "approximately".
- Active voice: "We hold dances every Tuesday" not "Dances are held…".
- Talk to the reader: "you", "your".
- Explain any dance or event term the first time: "Lindy Hop (the original swing dance from 1920s Harlem)".
- Numbers: "$15" not "fifteen dollars"; "7:30 PM"; "Tuesday, October 6".
- No ALL CAPS sentences, no "click here", no "please note that".

## Structure

- Lead with the answer. Put the most important fact first (date, time, price, place).
- Headings that are questions people ask ("Do I need a partner?").
- Short paragraphs (1–3 sentences), lists for steps, tables only when comparing.
- Every table/chart: a one-sentence summary above it saying what it shows and what to notice.
- Define abbreviations on first use (ECS = East Coast Swing, WCS = West Coast Swing).

## Labels

- Buttons say what happens: "Add to calendar", "Get directions", "Show 7 more dances", "Switch to dark mode".
- Use well-known names: "Frequently Asked Questions", "Contact", "Membership", "Gallery", "Events".
- Status words people understand: "Cancelled", "Postponed", "Sold out", plus an icon (not color only).

## Quick test

Read it aloud. If you would not say it to a new dancer at the door, rewrite it.
Optional: check Flesch-Kincaid grade level (aim ≤ 9) with a readability tool on long pages.
