# Third-Party Notices

Kungfu depends on third-party software from the C++, Python, Node.js, Electron,
and operating-system ecosystems.

This repository-level notice file records the project policy:

- Source dependencies are tracked through package manifests, lockfiles, Conan
  recipes, Python project metadata, and build configuration files.
- Binary and bundled release artifacts must include the license texts and
  notices required by the third-party components they redistribute.
- If a dependency requires attribution in a repository-level notice file, add it
  here or in a clearly referenced generated notices file.
- Do not remove third-party copyright, license, patent, trademark, or
  attribution notices from vendored or redistributed material.

There are no additional project-level attributions recorded here yet.
