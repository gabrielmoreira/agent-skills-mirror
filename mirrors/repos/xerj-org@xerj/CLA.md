## How to sign

Signing is a one-time act per contributor, not per pull request.

1. Read this document.
2. Open a pull request adding your GitHub username to
   [`.contributors`](./.contributors).

That pull request **is** your signature: it is made from your own GitHub
account, and its commit history is the durable record of your agreement. Please
add nothing to it but your username.

3. Once it is merged, comment `@cla-bot check` on your original pull request and
   the CLA check will go green.

If you contribute on behalf of an employer that requires a corporate agreement,
say so on your pull request before signing individually.
