# 长篇续航与诊断

解决「写长之后如何保持吸引力、如何修订与收束」。规划见 `premise-and-outline.md`，人物与规则见 `characters-and-rules.md`，单场写法见 `scene-and-payoff.md`。

长篇失效通常不是「敌人不够强」，而是某一种吸引力被消耗完了。先诊断，再开方；四项检查只用于定位问题，不需要另建文档或系统。

## 四问诊断

对当前阶段（一卷、一个副本、一段连载）逐项回答：

| 关注点 | 检查问题 | 健康信号 | 失效信号 | 对应处方 |
| --- | --- | --- | --- | --- |
| 回报 | 读者获得了什么有意义的满足？ | 近期有可感知的进展或兑现 | 只有铺垫，迟迟不兑现；收获变成例行公事 | 提前小回报；兑现一个已经建立的期待 |
| 压力 | 主角已经成长，为什么成功仍有不确定性或代价？ | 阻碍来自规则、关系、信息或代价 | 敌人只是数值更高；主角必胜 | 换压力类型：信息差、期限、保护对象、使用限制 |
| 更新 | 问题本身或解决方式发生了什么变化？ | 新问题需要新策略 | 重复同一副本 / 打脸循环 | 改变目标、规则或解法，不换皮 |
| 积累 | 过去的选择、收益、损失和关系如何影响现在？ | 早期成果和后果仍在生效 | 换地图后一切归零 | 让旧关系、旧承诺、旧损失进入当前冲突 |

**组合判断**：

- 回报不足 + 压力不足 → 读者觉得「主角赢麻了」，没有追更动力。
- 压力足够 + 回报不足 → 读者疲惫，觉得一直在受虐。
- 更新足够 + 积累不足 → 一段段冒险互不相关，像单元剧。
- 回报和压力都在 + 更新不足 → 重复感，读者能预测下一章。

## 目标接力

认真兑现重大期待，避免无限推迟；兑现后的后果、责任、发现或关系变化，自然生成下一阶段目标。

**模板**：

```
兑现（读者等到了什么）：
后果（责任 / 发现 / 关系变化 / 新威胁 / 代价）：
新目标（谁现在想要什么，为什么不能不做）：
情绪理由的变化（从证明自己 → 承担责任 / 从求生 → 守护 / 从复仇 → 理解）：
```

- 等待重大兑现期间，要有阶段回报；长期拖延且没有小回报，会消耗信任。
- 读者可以期待结果，但无法轻易预测过程、代价和余波。
- 新目标最好由前一个目标的结果自然长出，而不是作者宣布「下一个副本开始」。

## 成长设计

成长要让读者看到过程和新的选择，而不是只换数值。

**成长链**：

```
瓶颈（当前能力 / 认知 / 资源不够）：
准备（训练、交易、探索、求助）：
代价（时间、资源、承诺、暴露）：
收益（新能力 / 新信息 / 新关系）：
新选择（现在能做什么以前不能做的事）：
新约束（仍然解决不了什么）：
```

**三种常见写法**：

- **能力成长**：新能力解决旧问题，但带来新责任或新敌人。
- **处境成长**：地位、资源、关系变化，改变别人如何对待主角。
- **认知成长**：主角理解规则、人性或自己的错误，改变选择方式。

**避免**：

- 每次突破都附带惩罚，会让成长变成负担；后果应自然产生，不凑固定数量的变化。
- 换地图就让能力、知识、关系归零，会抹掉积累；可以改变比较的坐标系，但保留已有成果。
- 金手指解决一个问题后，要保留其他重要约束。

## 压力维持

力量增长不必消除不确定性。求生、恐怖和规则型威胁尤其如此。压力可以来自：

| 压力源 | 写法 | 例子 |
| --- | --- | --- |
| 信息不完整 | 规则只露出一部分，人物要调查、试错 | 副本规则有隐藏条款 |
| 成功条件特殊 | 赢不等于通关，还要满足额外条件 | 必须救下所有人，或不能使用某能力 |
| 保护与协作 | 强者要保护弱者，或必须与他人合作 | 队友不信任主角 |
| 使用限制 | 能力有次数、范围、时机或代价 | 每次使用都会暴露位置 |
| 价值两难 | 两个重要目标只能选一个 | 救人还是保住证据 |

**规则型威胁检查**：

- 是否给出了足够的规则线索，支持人物调查与应变？
- 代价是否可信，还是只在需要时出现？
- 是否临时让过去的能力失效，或事后补规则？
- 解决问题是否需要改变做法（脱身、限制、理解、选择救谁），而不只是数值更高？

## 场景更新与线索汇入

新副本、新地区、新组织可以更新局部规则、目标和策略，但人物积累要继续生效，让各段冒险组成持续发展的故事。

**换场景时保留清单**：

- 能力与知识：主角会什么、知道什么，哪些在新场景仍然有用？
- 关系与承诺：谁在等他、欠谁、答应过什么？
- 损失与后果：之前的失败、暴露、结仇还在追着他吗？
- 未解决线索：哪些伏笔需要在新场景继续推进？

**主支线汇入**：

- 支线通过选择、资源、信息或后果影响主线，而不是轮流热闹却互不影响。
- 每条线标注：现在推进什么、什么时候与主线交汇、交汇后改变什么。
- 允许支线暂时独立，但不要让读者感觉「这段可以跳过」。

## 记忆与衔接

读者可能隔几天才看一章，旧人物、规则和伏笔重新发挥作用时，需要自然唤醒记忆。

**三种唤醒方式**：

1. **行动中带出**：人物在使用旧能力、旧关系或旧线索时，用必要细节提醒读者。
2. **后果重现**：过去的损失、承诺或敌人以新形式出现，让读者自己回忆起前因。
3. **他人反应**：新人物对旧事的评价、忌惮或误解，侧面重申设定。

**避免**：

- 大段复述前情。
- 要求读者记住很早以前的一次提及，却不给任何提示。
- 为了提醒而让角色互相解释已经知道的事。

讨论连载安排时，根据作者可持续的产能建议稳定节奏，不承诺无法维持的更新量。

## 修订

**先分诊，再改**：

| 症状 | 先查什么 | 最小有效修改 |
| --- | --- | --- |
| 读不下去 | 期待是否建立、开篇是否进入具体处境 | 补一个具体压力或选择，删掉前置说明 |
| 人物动机薄弱 | 目标是否具体、选择是否有代价 | 增加一次有取舍的选择，交代底线 |
| 因果牵强 | 结果是否来自前文能力 / 准备 / 选择 | 补铺垫或改变结果来源，不硬加解释 |
| 信息混乱 | 谁知道什么、何时揭晓 | 补信息边界表，删掉视角人物不该知道的内容 |
| 冲突重复 | 问题与解法是否变化 | 改变阻碍类型或代价，不重复同一打脸 |
| 结局不满足 | 是否回应开篇承诺 | 回到核心期待和人物选择，补兑现，不改句子 |

**修改原则**：

- 先定位原因，再动文字；改好句子救不了缺少铺垫的结局。
- 保留有效段落、作者有意的留白和文风。
- 修改后检查对后文的影响：伏笔、人物状态、关系、时间线。
- 把读者反馈当作阅读体验证据，由作者决定方向；区分事实矛盾与审美偏好。

## 收束

长篇持续好看，不等于始终保持开篇那种好看。从弱者求生转向责任承担、从个人复仇转向更大冲突，需要情感铺垫和新的吸引力。

**阶段迁移检查**：

- 新的核心体验是什么？读者原来的投入理由（人物、关系、世界）还在吗？
- 迁移是否有事件推动，而不是作者宣布「进入新篇章」？
- 旧的能力、关系、承诺是否仍然有用？
- 是否为了重演开篇而让主角归零？
- 是否悄然把原始体验替换成了单纯的战力表演？

**完结清单**：

- 核心承诺是否得到回应？
- 主角的关键选择是否体现了他最终成为怎样的人？
- 外在目标与内在需求是否都有交代？
- 重要关系是否得到安顿？
- 后果是否落地（责任、损失、收益、世界变化）？
- 是否停止不断开新坑，只保留作品有意留下的开放问题？

## 常见乏力症状与处方

| 症状 | 可能原因 | 先做什么 |
| --- | --- | --- |
| 读者追更下降 | 期待建立不足，或长期不兑现 | 补一个明确的近期期待，尽快给小回报 |
| 主角越来越强但不好看 | 压力类型没变，只剩数值 | 换压力源：信息、期限、保护、限制、价值两难 |
| 副本一个接一个，像单元剧 | 积累不足，支线不汇入 | 让旧关系 / 旧后果进入新副本，设置主线交汇点 |
| 配角越来越像工具 | 缺少独立目标与信息 | 给关键配角一个不能退让的目标 |
| 反派降智 | 对手没有合理的信息与资源 | 让对手掌握主角不知道的信息，或让他的目标也合理 |
| 高潮不够爽 | 期待没有建立，或兑现来自临时能力 | 回到前文补铺垫，让结果来自已有能力 / 准备 / 选择 |
| 结局仓促 | 核心承诺没有逐项收束 | 列承诺清单，按人物、关系、世界、后果逐项兑现 |
