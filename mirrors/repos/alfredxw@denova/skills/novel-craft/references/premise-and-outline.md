# 构思与大纲

解决「这本书是什么、整体怎么排」。人物与规则见 `characters-and-rules.md`，具体场景与爽点见 `scene-and-payoff.md`。

## 一句话故事

**怎么做**：用一句话回答四件事：谁、想要什么、被什么挡住、独特之处在哪里。再补一句读者主要获得什么体验。

**模板**：

> 一个【身份 / 处境】的人，为了【具体目标】，必须【行动】，但【核心阻碍】；这个故事最特别的是【独特设定如何改变选择】，读者主要获得【成长 / 关系 / 解谜 / 求生 / 幽默 / 悲伤中的哪一种】。

**例子**：

> 一个被宗门逐出的杂役，为了找回被夺走的身份，必须在大比前学会被禁止的旧术，但每用一次都会暴露行踪；最特别的是旧术只在救人时生效，读者主要获得「被低估者用代价换回尊严」的满足。

**检查**：

- 目标是否具体到能判断成败？
- 阻碍是否直接针对目标，而不是泛泛的「世界很危险」？
- 独特设定是否改变人物的选择？删掉它，故事是否还一样？

## 叙事动力

先确定读者主要为什么追更，再安排事件。常见动力：

| 动力 | 读者在追什么 | 进展标志 | 容易写坏 |
| --- | --- | --- | --- |
| 成长 | 人物能走多远 | 新能力、新策略、新地位 | 只涨数值，不改变选择 |
| 关系 | 人物将如何相处 | 信任、亏欠、立场变化 | 靠误会反复拉扯 |
| 解谜 | 真相是什么 | 线索拼合、旧信息被重新解释 | 只加谜团，不给阶段答案 |
| 求生 | 能否活过当前处境 | 规则被理解、代价被支付 | 危险靠作者临时加码 |
| 复仇 / 证明 | 能否讨回什么 | 目标逼近、代价累积 | 反复打脸，缺少新问题 |

可以主次组合，但每卷要能说清「这一卷主要满足哪一种」。不要把战力升级当成所有类型的默认进展。

## 全书大纲

**怎么做**：

1. 写清主线问题、人物起点与预期终点、核心对抗、结局方向。
2. 选 4–6 个关键转折，每个转折都写「谁做了什么选择 → 局势怎么变 → 下一步目标怎么来」。
3. 标出主要伏笔、关系变化和核心爽点的铺垫与兑现阶段。
4. 检查中段是否出现新的问题与解法，结局是否能回应开篇承诺。

**模板**：

```
主线问题：
主角起点（缺口 / 处境 / 错误认知）：
预期终点（能力 / 认知 / 关系 / 处境）：
核心对抗（谁、争什么、为什么不能退）：
关键转折：
  1. 【事件】→【选择】→【局势变化】→【新目标】
  2. ...
伏笔与兑现：
  伏笔：          埋设位置：          兑现阶段：          兑现时改变了什么：
核心爽点：
  期待：          铺垫：          兑现：          余波：
```

**转折写法示例**：

> 主角为救同伴暴露隐藏身份（选择）→ 宗门提前站队，盟友被迫切割（局势）→ 他必须在下一次围剿前找到能证明清白的旧档（新目标）。

**检查**：每个转折是否由人物选择触发？删掉任一转折，后文是否还能成立？如果还能，说明它只是事件，不是结构。

## 卷结构

一卷至少回答四件事：读者期待什么、受到什么阻碍、兑现什么、留下什么持续影响。持续影响可以是关系加深或线索收束，无须总引出另一场危机。

**模板**：

```
本卷承诺（读者追这一卷的理由）：
本卷阻碍（为什么现在解决不了）：
本卷兑现（高潮回应什么）：
本卷余波（结束后留下什么：后果 / 关系 / 线索 / 新目标）：
关键事件（按因果排列，3–6 个）：
  1. 目标建立：
  2. 行动推进：
  3. 局势转折：
  4. 关键选择：
  5. 阶段高潮：
  6. 余波：
小回报位置：
主要兑现位置：
章组职责（只细化即将写的部分）：
承接前卷（人物处境、未解决后果）：
修正下一卷（根据实际正文，不照抄旧计划）：
```

**检查**：

- 本卷是否有独立分量？删掉本卷，全书主线是否仍然完整？如果完整，说明它只是填充；如果不完整，说明它有结构作用。
- 小回报是否出现在主要兑现之前？
- 余波是否改变了人物处境或关系，而不只是宣布下一场危机？
- 是否围绕本卷主要矛盾取舍事件，而不是把无关冒险串成流水账？
- 按实际叙事单元划分章组，不机械凑章数。

## 开篇

**怎么做**：

1. 用一个具体处境让主角面临压力。
2. 让主角做一个能体现性格或目标的选择。
3. 给出足够理解处境的背景，但不要先讲设定。
4. 留下读者能理解、且愿意追下去的疑问。
5. 把眼前需求、阶段目标和长期方向连起来。

**开篇检查**：

- 前三段是否出现了具体的人、具体的问题和具体的行动？
- 读者是否知道该关心谁、为什么关心？
- 核心看点（独特设定、关系张力、主要动力）是否已经露头？
- 是否用设定说明代替了人物处境？
- 阶段目标是否看得到进展，而不是只画长期大饼？
