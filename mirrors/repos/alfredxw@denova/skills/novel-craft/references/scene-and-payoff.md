# 场景与爽点

解决「这一章 / 这一场怎么写、读者等待的回报如何兑现」。整体结构见 `premise-and-outline.md`，长篇中的场景更新见 `long-form.md`。

## 场景

**怎么做**：先确定场景要改变什么（局势 / 认知 / 关系 / 情绪），再选行动或反应结构。

**行动场景模板**：

```
目标（人物此刻要什么）：
阻力（谁 / 什么阻止，为什么不能绕过）：
选择（可选方案与代价）：
结果（来自前文能力、准备或选择）：
余波（局势 / 关系 / 认知 / 代价的变化）：
```

**反应场景模板**：

```
情绪（对上一个结果的真实反应）：
困境（接受什么、放弃什么）：
决定（下一步行动，以及理由）：
```

**信息边界表**（悬念场景尤其需要）：

| 信息 | 视角人物 | 其他人物 | 读者 |
| --- | --- | --- | --- |
| 谁知道什么 | | | |
| 谁误以为什么 | | | |
| 何时揭晓 | | | |

**检查**：

- 场景结束后，有没有什么东西和开始时不同？
- 选择是否有真实取舍？是否允许局部成功但付出代价？
- 对话是否在推进诉求、博弈或关系，而不是只解释设定？
- 揭晓时，前面的线索是否可以被重新解释？

## 章首与章尾

章首负责让读者进入当前处境，章尾负责让读者想翻下一页。两者都只服务本章功能和下一章承接，不为凑字数解释。

**章尾类型**（按本章停下的情绪选）：

| 类型 | 停在哪里 |
| --- | --- |
| 危机 | 下章必须回应的威胁或倒计时 |
| 悬念 | 新信息出现，但含义尚未揭晓 |
| 渴望 | 奖励、突破或关系进展已经在望 |
| 选择 | 两个都有代价的选项摆出来，不给结果 |
| 情绪 | 关系变化、背叛、示弱或未回应的请求 |
| 反转 | 身份、动机或认知被推翻 |
| 留白 | 只给反应，不解释发生了什么 |

**章首类型**：动作进行中被截断、意味深长的对话、异常或反常细节、倒计时。避免天气 / 风景 / 前情复述开场；前三章可以更强，日常章不必强行制造危机。

**检查**：

- 章尾是否落在变化上，而不是总结、感悟或「回去休息了」？
- 钩子是否在期待成立的那一刻就停，没有补一段解释？
- 连续两章是否用了同一种钩子？
- 钩子强度是否与章节阶段匹配？过渡章可以弱，但不能没有未闭合的东西。
- 章首是否尽早出现具体的人、行动或异常，而不是先讲设定？

## 爽点

爽点是读者在意的事情得到有分量的回应，不等于打脸或升级。

**检查链**：

```
期待（读者具体在盼什么）：
铺垫与阻碍（为什么现在得不到）：
人物行动（用了什么能力、准备或选择）：
兑现（结果是什么，改变了什么）：
余波（谁受影响，下一步怎么来）：
```

**安排表**：

| 层级 | 作用 | 间隔原则 | 例子 |
| --- | --- | --- | --- |
| 即时小回报 | 维持追更 | 每个章组至少有可感知进展 | 拿到关键线索、赢下一次小博弈 |
| 阶段兑现 | 回应本卷期待 | 本卷高潮 | 身份揭晓、关系确认、阶段目标达成 |
| 核心大高潮 | 回应全书承诺 | 结局或大转折 | 主线真相、最终对抗、人物完成选择 |

**微兑现**：不一定每个章组都有大高潮，但读者每章都该拿到一点东西。常见类型：

| 类型 | 读者拿到什么 |
| --- | --- |
| 信息 | 新情报、规则被理解、旧信息被重新解释 |
| 关系 | 信任、亏欠、立场或距离变化 |
| 能力 | 新用法、熟练度、限制被突破 |
| 资源 | 物品、渠道、机会、资格 |
| 认可 | 被看见、被需要、被畏惧 |
| 情绪 | 压抑释放、共鸣、心疼或心动 |
| 线索 | 伏笔推进或回收 |

过渡章、低压章可以没有大爽点，但不能整章无收获；通常至少保留一个微兑现，避免读者觉得「这章可以跳过」。

**重复疲劳**：同一种爽点模式连续出现三章以上，读者通常会开始预测。换执行方式（铺垫长短、代价、见证者层级）、换兑现类型，或轮换副线。升级不只看数值，还可以升级规模、对手层级、解决方式和被谁看见。

**写法提醒**：

- 结果要来自前文已有的能力、准备或选择；旁人震惊只能做反应，不能代替结果。
- 先抑后扬时，压抑段要让人物仍在行动、仍有希望或进展；避免长期受辱和反复打断兑现。
- 交替使用胜利、成长、揭秘、情感、幽默与恢复，避免同一种循环。
- 胜利后的新问题应承接成果，不要立刻抹掉刚获得的满足。

**检查**：这个爽点兑现的是读者之前被明确引导去期待的东西吗？兑现后，局势、资源或关系真的变了吗？

## 正文表达

- 成功可以是脱身、发现、守护、谈判、克制或接受损失，不必总是击败对手。
- 按需要连接短期疑问、中期秘密与长期谜题；阶段答案要改变读者对更大问题的理解，而不只是再添一个谜团。
- 用具体细节、有辨识度的人物声音和作者选择的视角；压缩重复解释，同时保留能制造张力、情感和氛围的细节。表达高效不等于始终快进。
- 对话要带诉求：试探、回避、施压、诱导、拖延，都比完整回答更像人在说话。允许打断、答非所问和沉默；不同角色有不同的句长、口头禅和回避方式。
- 情绪优先通过动作、生理反应、注意力和决定呈现。直写情绪不是错误，但「他感到愤怒」之后要落到他此刻做不成什么、身体哪里紧了、下一步要做什么。

**去 AI 味**：下面是模型最容易留下的痕迹，写完一段就对照一次。只改表达，不改事实、剧情、人物所知；不要为了「像真人」新增事件、微动作或粗话；作者有意的文风保留。

| 痕迹 | 怎么改 |
| --- | --- |
| 段末总结 / 感悟（「他终于明白了」） | 删掉，落在动作、对话或后果上 |
| 万能副词 + 动作（缓缓 / 淡淡 / 微微） | 换成具体动作、生理反应或不同感官细节 |
| 情绪贴标签（「他感到恐惧」） | 写身体反应、注意力和下一个决定 |
| 全员同一套反应（瞳孔微缩 / 心中一凛） | 给每个角色专属的小动作和说话节奏 |
| 对话一问一答、信息播报 | 加试探、回避、打断、答非所问或沉默 |
| 段落长度和信息密度均匀 | 制造疏密对比；紧张时短句，平静时允许长段 |
| 展示后解释 | 删掉解释句，信任读者 |
| 章末安全着陆 | 至少留一个未解决的问题或不安感 |

**写完一段的五个即时检查**：

1. 这段是否在结尾补了感悟或总结？删掉后是否更利落？
2. 最近三个动作是否都靠「缓缓 / 淡淡 / 微微」修饰？
3. 情绪是告诉读者，还是让读者从行为里看出来？
4. 这句对话是在推进诉求，还是在解释背景？
5. 这一段的节奏是否过于均匀？需要短句、停顿、动作或场景切换吗？
