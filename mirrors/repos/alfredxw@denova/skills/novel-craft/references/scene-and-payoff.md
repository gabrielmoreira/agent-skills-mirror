# 场景与爽点

解决「这一章 / 这一场怎么写、读者等待的回报如何兑现」。整体结构见 `premise-and-outline.md`，长篇中的场景更新见 `long-form.md`。

## 场景

**怎么做**：先确定场景要改变什么（局势 / 认知 / 关系 / 情绪），再选行动或反应结构。

**行动场景模板**：

```
目标（人物此刻要什么）：
阻力（谁 / 什么阻止，为什么不能绕过）：
选择（可选方案与代价）：
结果（来自前文能力、准备或选择）：
余波（局势 / 关系 / 认知 / 代价的变化）：
```

**反应场景模板**：

```
情绪（对上一个结果的真实反应）：
困境（接受什么、放弃什么）：
决定（下一步行动，以及理由）：
```

**信息边界表**（悬念场景尤其需要）：

| 信息 | 视角人物 | 其他人物 | 读者 |
| --- | --- | --- | --- |
| 谁知道什么 | | | |
| 谁误以为什么 | | | |
| 何时揭晓 | | | |

**检查**：

- 场景结束后，有没有什么东西和开始时不同？
- 选择是否有真实取舍？是否允许局部成功但付出代价？
- 对话是否在推进诉求、博弈或关系，而不是只解释设定？
- 揭晓时，前面的线索是否可以被重新解释？

**正文表达**：

- 成功可以是脱身、发现、守护、谈判、克制或接受损失，不必总是击败对手。
- 按需要连接短期疑问、中期秘密与长期谜题；阶段答案要改变读者对更大问题的理解，而不只是再添一个谜团。
- 用具体细节、有辨识度的人物声音和作者选择的视角；压缩重复解释，同时保留能制造张力、情感和氛围的细节。表达高效不等于始终快进。

## 爽点

爽点是读者在意的事情得到有分量的回应，不等于打脸或升级。

**检查链**：

```
期待（读者具体在盼什么）：
铺垫与阻碍（为什么现在得不到）：
人物行动（用了什么能力、准备或选择）：
兑现（结果是什么，改变了什么）：
余波（谁受影响，下一步怎么来）：
```

**安排表**：

| 层级 | 作用 | 间隔原则 | 例子 |
| --- | --- | --- | --- |
| 即时小回报 | 维持追更 | 每个章组至少有可感知进展 | 拿到关键线索、赢下一次小博弈 |
| 阶段兑现 | 回应本卷期待 | 本卷高潮 | 身份揭晓、关系确认、阶段目标达成 |
| 核心大高潮 | 回应全书承诺 | 结局或大转折 | 主线真相、最终对抗、人物完成选择 |

**写法提醒**：

- 结果要来自前文已有的能力、准备或选择；旁人震惊只能做反应，不能代替结果。
- 先抑后扬时，压抑段要让人物仍在行动、仍有希望或进展；避免长期受辱和反复打断兑现。
- 交替使用胜利、成长、揭秘、情感、幽默与恢复，避免同一种循环。
- 胜利后的新问题应承接成果，不要立刻抹掉刚获得的满足。

**检查**：这个爽点兑现的是读者之前被明确引导去期待的东西吗？兑现后，局势、资源或关系真的变了吗？
