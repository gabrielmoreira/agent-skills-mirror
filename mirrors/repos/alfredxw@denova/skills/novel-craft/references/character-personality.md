# 人物性格：三层结构与属性库

用于设计主角、对手和重要配角，也用于检查已有角色是否只有标签、没有行为。三层各管一件事，不要求每个角色填满。

## 三层结构

| 层 | 内容 | 回答的问题 | 产出的东西 |
| --- | --- | --- | --- |
| 1 | 核心人格（MBTI 16 型） | 这个人通常怎么思考、判断、决策？ | 默认行为路径 |
| 2 | 性格表现（萌属性 / 属性标签） | 别人看到什么？在不同情境下怎么表现？ | 可观察的言行与关系模式 |
| 3 | 人物内核 | 他为什么是这样，什么会让他改变？ | 欲望、恐惧、价值、缺陷、弧线 |

- 第一层保证一致性，第二层保证辨识度，第三层保证深度和变化。缺任何一层，人物都会以不同方式变薄。
- 属性标签不是互斥分类。高冷、傲娇、操心可以同时存在，因为它们描述的是不同方面。
- **标签必须落到行为**：每个选中的标签，至少能说出一个顺利时的表现、一个压力下的表现和一个代价。写不出，它就还只是形容词。

## 第一层：MBTI 16 型

四个维度：

| 维度 | 两端 | 在人物身上的表现 |
| --- | --- | --- |
| 精力与注意力 | E 外倾 / I 内倾 | 能量从人群还是独处恢复；主动开口还是先观察 |
| 信息获取 | S 实感 / N 直觉 | 相信具体经验还是模式与可能；注意细节还是走向 |
| 判断偏好 | T 思考 / F 情感 | 先看逻辑与效率，还是先看关系与感受 |
| 生活组织 | J 判断 / P 感知 | 先定计划再行动，还是边做边调整 |

四个大组：

按四组排列：NT 理性探索型（INTJ / INTP / ENTJ / ENTP）、NF 理想与情感型（INFJ / INFP / ENFJ / ENFP）、SJ 秩序与责任型（ISTJ / ISFJ / ESTJ / ESFJ）、SP 自由与行动型（ISTP / ISFP / ESTP / ESFP）。

| 类型 | 默认运作方式 | 常见创作方向 |
| --- | --- | --- |
| INTJ | 先建长期模型，再按目标配置资源；独立、重效率，不轻易解释过程 | 谋略家、幕后布局者、冷面军师 |
| INTP | 先拆原理再下判断；好奇、抽离，对规则本身感兴趣 | 学者、研究者、怪才、技术宅 |
| ENTJ | 先定目标与结构，再推动他人执行；果断、强势、要结果 | 领袖、野心家、改革者 |
| ENTP | 先找漏洞与可能性，再试新解法；机敏、好辩、讨厌定式 | 诡计师、革新者、麻烦制造者 |
| INFJ | 先读人和动机，再按理想布局；洞察、内敛、有使命感 | 先知、引导者、幕后精神领袖 |
| INFP | 先对照内心价值，再决定行动；敏感、重信念、有想象力 | 理想主义者、诗人、逃亡者 |
| ENFJ | 先感知群体需要，再组织人走向目标；善于理解与感召 | 导师、感召型领袖、团队核心 |
| ENFP | 先被可能性吸引，再边走边找意义；热情、发散、追求新鲜 | 冒险者、梦想家、破局者 |
| ISTJ | 先核对事实与先例，再按责任执行；严谨、可靠、守序 | 执行官、纪律维护者、老兵 |
| ISFJ | 先照顾具体需要，再维持稳定；细致、体贴、记恩也记伤 | 守护者、照顾者、家族支柱 |
| ESTJ | 先确认秩序与职责，再推动落实；务实、果断、重规则 | 管理者、指挥官、铁腕家长 |
| ESFJ | 先维护关系与体面，再安排事务；热心、负责、重和谐 | 协调者、团队支柱、社交中心 |
| ISTP | 先观察现场，再用最小动作解决问题；冷静、独立、临场强 | 独行侠、技术高手、冷静执行者 |
| ISFP | 先感受当下与个人边界，再行动；随性、细腻、重体验 | 艺术家、自由灵魂、沉默的叛逆者 |
| ESTP | 先抓眼前机会，再边做边调整；果敢、机灵、爱挑战 | 行动派、冒险家、机会主义者 |
| ESFP | 先投入现场与人群，再享受反馈；活泼、感性、会带动气氛 | 气氛担当、表演者、今朝有酒者 |

同一类型可以写出完全不同的角色。类型只决定「他先想到什么」，属性与内核决定「他最终怎么做」。

| 同一 MBTI | 属性组合 | 人物走向 |
| --- | --- | --- |
| INTJ | 高冷 / 御姐 / 毒舌 / 操心 / 冷娇 / 外冷内热 | 控制型保护者：用冷漠和安排掩饰害怕失去 |
| INTJ | 慵懒系 / 毒舌 / 摸鱼系 / 轻浮而深情 | 懒散天才：嘴上嫌麻烦，关键时一步不错 |
| ENFP | 开朗 / 元气 / 自来熟 / 狡黠 / 天然撩 / 外热内冷 | 社交中心：和谁都能聊，却不真正依赖谁 |
| ISFJ | 清冷 / 三无 / 认真 / 忠犬 / 白切黑 | 沉默守护者：平日顺从，越线后做出极端决定 |

使用要点：

- MBTI 是创作原型，不是心理诊断；不要把类型当命运，也不要用类型替代经历与内核。
- 类型描述默认路径，不描述能力、立场或道德。T 不等于冷酷，F 不等于善良，J 不等于死板。
- 给重要角色留一个「不典型轴」：例如在陌生场合极度疏离、在家人面前话很多的 INTJ；做事极有计划、却总在感情上临时起意的 ENFP。这个偏离比类型本身更容易形成记忆点。
- 不要向读者解释 MBTI；它只用于作者设计。

## 第二层：可观察性格（萌属性）

七类属性各回答一个问题。按需选择，不要求每类都选；同一角色可以跨类组合。

### A. 气质与气场

这个人第一眼给别人什么感觉？

| 属性 | 特征 |
| --- | --- |
| 高冷 | 冷淡、难以接近，保持距离 |
| 清冷 | 清雅、安静、疏离 |
| 冰山 | 冷漠、沉稳、不易显露情绪 |
| 御姐 | 成熟、独立、自信、有气场 |
| 女王 | 强势、有威严、喜欢主导 |
| 大小姐 | 娇贵、高傲，或具有优雅教养 |
| 姐姐系 | 成熟、包容、令人安心 |
| 王子系 | 帅气、英朗、举止得体 |
| 知性系 | 理性、博学、优雅 |
| 软萌系 | 柔软、乖巧、可爱 |
| 神秘系 | 深不可测，难以捉摸 |
| 高岭之花 | 优秀、耀眼、有距离感 |
| 禁欲系 | 自律、克制、严谨 |
| 慵懒系 | 悠闲、散漫、不紧不慢 |
| 危险系 | 富有压迫感，让人不敢轻易接近 |

写法：

- 气质是别人第一眼看到的形象，不等于性格。同一个「御姐」可以是温柔御姐、天然呆御姐或冷血御姐。
- 用出场时的动作、语速、距离感、穿着和他人反应来写，不要用旁白直接贴标签。
- 同一角色在不同人面前可以呈现不同气质；对陌生人高冷、对熟人软萌，本身就是可利用的落差。

### B. 情绪与性格底色

这个人日常的情绪状态是什么样？

| 属性 | 特征 |
| --- | --- |
| 开朗 | 乐观、爱笑、容易交流 |
| 元气 | 活力充沛、精力旺盛 |
| 阳光 | 积极向上、充满希望 |
| 活泼 | 好动、热情、喜欢热闹 |
| 温柔 | 体贴、善解人意 |
| 治愈 | 能安抚他人、带来安全感 |
| 天真 | 纯真、容易相信别人 |
| 冷静 | 情绪稳定、遇事不慌 |
| 淡然 | 情绪平和，不容易被影响 |
| 佛系 | 不争不抢、随遇而安 |
| 忧郁 | 感情细腻、容易伤感 |
| 阴沉 | 情绪低落、不太积极 |
| 悲观 | 容易预想不好的结果 |
| 暴躁 | 易怒、缺乏耐心 |
| 敏感 | 对情绪和环境变化反应明显 |
| 多愁善感 | 容易被事情触动，感情丰富 |

写法：

- 情绪底色决定角色在普通场景里的默认反应和叙事温度；它不必与 MBTI 一致。
- 底色是基调，不是每场戏都重复同一种情绪。长期忧郁的人偶尔轻松一次，反而更可信。
- 不要把「温柔」「阳光」写成没有阴暗面；底色越稳定，偶尔的失控越有力量。

### C. 社交与对外表达

这个人如何跟其他人相处、交流？

| 属性 | 特征 |
| --- | --- |
| 三无 | 无口、无心、无表情的典型形象 |
| 无口 | 沉默寡言、很少主动讲话 |
| 面瘫 | 缺乏明显的表情变化 |
| 社恐 | 不擅长社交，容易紧张 |
| 社牛 | 社交大胆，不怕生 |
| 自来熟 | 很快与陌生人熟络 |
| 毒舌 | 言语尖锐、擅长讽刺 |
| 闷骚 | 外表矜持、内心活跃 |
| 话痨 | 话很多，喜欢聊天 |
| 傲慢 | 自视甚高，容易轻视别人 |
| 谦逊 | 不喜欢炫耀，态度低调 |
| 礼貌疏离 | 待人礼貌，但保持距离 |
| 直率 | 想到什么就说什么 |
| 圆滑 | 善于察言观色、处理关系 |
| 电波系 | 思路独特，言行难以预测 |
| 恶作剧系 | 喜欢捉弄和逗弄别人 |

写法：

- 区分社交距离与表达匮乏：高冷是「不让别人靠近」，三无是「没有可读的表达」，两者可以叠加，也可以分开。
- 说话方式是最省力的辨识手段：句长、称呼、是否反问、是否打断、沉默时做什么。
- 社交属性会在压力下变形：社恐可能突然话多，社牛可能突然沉默；变形点比标签本身更有戏。

### D. 情感与亲密关系

这个人面对喜欢、信任、依恋的人，会变成什么样？

| 属性 | 特征 |
| --- | --- |
| 傲娇 | 明明在乎，却不肯坦率承认 |
| 冷娇 | 平日冷淡，只对特定的人温柔 |
| 病娇 | 爱意混合偏执、过度占有或控制 |
| 娇羞 | 亲密时容易害羞 |
| 忠犬 | 忠诚、专一、喜欢陪伴 |
| 猫系 | 独立、别扭、忽冷忽热 |
| 犬系 | 热情、亲近、喜欢表达 |
| 黏人 | 渴望陪伴，不愿分离 |
| 直球 | 坦率表达好感与情绪 |
| 纯情 | 感情单纯、容易心动 |
| 恋爱迟钝 | 不容易察觉爱情信号 |
| 天然撩 | 无意识地做出撩人举动 |
| 占有欲强 | 希望重要的人只属于自己 |
| 献身系 | 愿为重要的人付出巨大代价 |
| 慢热 | 需要很长时间建立亲密感 |
| 口是心非 | 语言和真实感情不一致 |
| 回避亲密 | 渴望亲近，却害怕暴露弱点 |

写法：

- 这一类只在特定关系中显现。先确定「对谁」，不要让人物对所有人都傲娇或黏人。
- 关系属性会随信任变化：慢热的人一旦靠近，可能比自来熟更黏；冷娇的温柔只给一个人，才有分量。
- 病娇、占有欲强等属性要写清边界与代价，不能只当卖点；它们会伤害关系，也会推动冲突。

### E. 行为习惯与处事风格

这个人日常遇事通常怎么做？

| 属性 | 特征 |
| --- | --- |
| 操心系 | 喜欢担心别人，主动关照 |
| 老妈子系 | 总想替他人安排生活 |
| 认真系 | 对待事情一丝不苟 |
| 可靠系 | 有担当，遇事值得信任 |
| 热血系 | 充满激情和行动力 |
| 完美主义 | 对细节和结果要求很高 |
| 优等生系 | 自律、守规矩、追求优秀 |
| 冒失系 | 经常粗心或行动过快 |
| 天然呆 | 反应脱线，不自觉犯傻 |
| 笨拙系 | 不擅长某些表达或行动 |
| 懒散系 | 不喜欢麻烦，能躺就躺 |
| 摸鱼系 | 擅长偷懒、逃避事务 |
| 工作狂 | 把大量精力投入工作 |
| 独行侠 | 喜欢独立解决问题 |
| 行动派 | 想到就做，不爱犹豫 |
| 谨慎派 | 行动前喜欢考虑风险 |
| 固执系 | 不轻易改变自己的决定 |
| 老好人 | 不善于拒绝别人的请求 |

写法：

- 处事风格与性格温度无关：高冷、毒舌、强势的人完全可以是操心系。
- 习惯要在日常里反复出现，在关键选择中付出代价；两者缺一，标签就只是设定。
- 给习惯一个反面情境：认真系在必须妥协时怎么办？老好人在必须拒绝时怎么办？回答这些比列举习惯更有用。

### F. 思维与心理策略

这个人处理信息、隐藏意图、应对冲突的方式是什么？

| 属性 | 特征 |
| --- | --- |
| 腹黑 | 内心有城府，擅长算计 |
| 心机系 | 善于洞察和利用人心 |
| 狡黠系 | 聪明机灵，喜欢小计谋 |
| 天然黑 | 无意识地说出或做出危险、腹黑的事 |
| 单纯系 | 心思简单，不喜欢算计 |
| 理性至上 | 优先遵循逻辑和效率 |
| 感性优先 | 优先考虑心情和个人感受 |
| 洞察系 | 能敏锐识别他人的想法 |
| 多疑系 | 难以轻信别人 |
| 反骨系 | 天生不喜欢服从权威 |
| 胜负欲强 | 不能容忍自己失败 |
| 自我中心 | 习惯以自身需求为出发点 |
| 自卑系 | 自我评价偏低，容易否定自己 |
| 自负系 | 过度相信自己的能力 |
| 理想主义 | 坚持信念和理想 |
| 现实主义 | 注重利益、条件与可行性 |

写法：

- 这一类与 MBTI 可能重叠，但层级不同：MBTI 是默认思维路径，心理策略是具体手段。INTJ 不等于腹黑，腹黑可以出现在任何类型身上。
- 策略要在信息不对称中体现：他选择说多少、隐瞒什么、试探谁、何时摊牌。
- 给策略留失效条件：多疑的人可能因为太累而轻信一次；理性至上的人可能在涉及亲人时破例。

### G. 内外反差

这个人的外在形象和真实内心有什么不一致？

| 属性 | 特征 |
| --- | --- |
| 外冷内热 | 外表冷漠，内心温柔 |
| 外热内冷 | 外表亲切，内心疏离 |
| 白切黑 | 表面善良无害，内心狠厉或有心机 |
| 黑切白 | 外表危险可怕，本性善良 |
| 反差萌 | 意料之外的行为让人觉得可爱 |
| 强势而脆弱 | 外表强大，内心缺乏安全感 |
| 温柔而冷酷 | 平常体贴，关键时刻毫不留情 |
| 懒散而可靠 | 平日摸鱼，重要时刻值得信赖 |
| 轻浮而深情 | 表面不正经，实际上非常专一 |
| 胆小而勇敢 | 平常畏缩，却会为重要之事挺身而出 |
| 天真而残酷 | 思想纯粹，却缺乏常规道德界限 |
| 自信而自卑 | 表面自信，内心害怕失败 |
| 顺从而叛逆 | 日常服从，内心渴望反抗 |

写法：

- 反差是至少两个属性之间的关系，不是独立标签。写「外冷内热」前，必须先让读者相信「外冷」。
- 反差需要基线、触发条件和揭示节奏；没有铺垫的反差只是前后矛盾。
- 反差最好由内核解释：他不是「其实很温柔」，而是「害怕失去，所以先用冷漠把人推开」。
- 一个角色最多保留一个主反差；堆太多会让读者无法形成预期。

### 属性怎么选

先按类别选，再压缩到真正会反复使用的标签。建议上限：

| 类别 | 建议数量 | 说明 |
| --- | --- | --- |
| 气质与气场 | 1–2 | 第一眼印象 |
| 情绪底色 | 1–2 | 日常反应基调 |
| 社交表达 | 1–2 | 说话与距离感 |
| 情感与亲密关系 | 0–2 | 只对特定的人显现 |
| 行为与处事风格 | 1–2 | 遇事怎么做 |
| 思维与心理策略 | 0–2 | 如何隐藏、试探、算计 |
| 内外反差 | 0–1 | 必须有基线和一个内核原因 |

- 全部加起来，主角控制在 3–6 个、重要配角 2–4 个、功能角色 1–2 个；不要求填满每一类，留白比堆满更有用。
- 同一类里不要堆近义词（高冷 + 清冷 + 冰山），它们不会让人物更丰富，只会让描述重复。
- 优先选能互相拉扯的组合：例如「行动派 + 完美主义」会让他反复在出手和再检查一遍之间挣扎。
- 每个属性至少能回答三件事：顺利时怎么表现？压力下怎么变形？让别人付出什么代价？
- 反差类最多一个，并且必须由一个内核原因支撑。
- 群像里，任意两个重要角色至少在一个属性类别上形成可见差异；不要只靠外貌和口癖区分。
- 允许留白。没有写到的类别，人物会在写作中自然长出来；一开始填满反而僵硬。

## 第三层：人物内核

| 维度 | 问题 | 可用方向 |
| --- | --- | --- |
| 核心欲望 | 他最想得到什么？ | 自由、爱情、认可、力量、真理、归属、复仇、安稳 |
| 核心恐惧 | 他最怕失去或面对什么？ | 被抛弃、失控、失败、孤独、失去价值、被看穿 |
| 核心价值观 | 他认为什么最重要、什么不能交换？ | 秩序、正义、忠诚、利益、自由、责任、亲情、真相 |
| 性格缺陷 | 什么会让他在关键时刻做错？ | 傲慢、偏执、懦弱、控制欲、过度牺牲、逃避、轻信 |
| 成长方向 | 故事要让他学会什么？ | 信任、接纳失败、放下执念、独立、拒绝、承担 |

- 欲望和恐惧最好指向同一件事的两面：渴望被爱 / 恐惧被看穿；渴望自由 / 恐惧被抛弃。这样人物一行动就自带张力。
- 价值观决定他「宁可付出什么代价也不做什么」，是底线和两难选择的来源。
- 缺陷不是缺点清单，而是一种会反复造成具体错误的机制：过度保护 → 替别人做决定 → 把重要的人推远。
- 成长不是换一个人格，而是改变追求欲望的方式：仍然想保护，但学会先问对方要不要。
- 成长方向要能用一场选择来验证：到结尾时，他会做出哪个和开头不同的选择？
- 关键矛盾：写出两条互相拉扯的设定（责任 vs 自由、忠诚 vs 真相、想被爱 vs 不相信自己值得），它比五个孤立的词更能生成剧情。

## 人物性格卡

```
姓名：
MBTI（默认运作方式 + 一个不典型轴）：
属性标签（按类别列，每个标签后写一个可观察行为）：
核心欲望：
核心恐惧：
核心价值观：
性格缺陷：
成长方向：
关键矛盾（哪两股力量在拉扯）：
关系中的另一面（对谁、在什么条件下显现）：
压力下的默认选择：
可能让他改变的条件：
语言 / 行为标记（口头禅、动作、回避的话题）：
```

这张卡用于设计；写进资料库时按 `characters-and-rules.md` 的人物条目裁剪，只保留稳定结论。

示例：

```
姓名：沈砚
MBTI：INTJ；在亲近的人面前会放弃效率，先照顾情绪（不典型轴：T→F）
属性：
- 气质：高冷、御姐（说话短，站得远，不解释）
- 处事：操心系（提前替人准备好所有东西）
- 亲密关系：冷娇（只对一个人温柔，且不承认）
- 反差：外冷内热（先写她拒绝帮忙，再写她半夜把药放在门口）
核心欲望：保护身边的人
核心恐惧：再一次因为自己没准备好而失去重要的人
核心价值观：责任高于个人幸福
性格缺陷：以「为你好」越过别人的边界
成长方向：学会在保护之前先询问，允许别人自己承担
关键矛盾：想掌控一切 vs 害怕被当成冷酷的人

写进场景时：
不写「她很关心人」，写她提前查了路线、把药塞进包里、被问起时说是顺手。
不写「她很傲娇」，写她说「谁管你」，但没有走开。
```

## 群像与关系

- 先检查群像的 MBTI 分布：如果所有重要角色都用同一种方式解决问题，换掉其中一两个的类型或「不典型轴」，比给所有人继续加属性更有效。
- 先定每人在故事里的功能，再选性格；性格要服务冲突，不是反过来。
- 用「同一目标、不同方法」或「同一价值、不同优先级」配对，比单纯写一冷一热更容易产生戏。
- 关系属性（D 类）必须指定对象和触发条件：对谁傲娇、在什么情况下黏人、信任到什么程度才露出另一面。
- 镜像人物：面对同一困境做出另一种合理选择的人，用来照出主角的变化；不要让镜像人物只是主角的失败版。
- 对手的性格要能解释他的手段和底线；他的缺陷最好是他优势的过度使用。
- 检查群像：遮住名字，只看对话和行为，读者能否分辨是谁在说话？分不出时，先改说话方式、反应速度和底线，而不是加外貌细节。

## 检查

- 每个属性标签都能说出一个动作、一句台词或一个选择吗？不能，就删掉或改写成行为。
- 人物在顺利、受压、涉及重要关系时，表现是否一致又可预期？变化有没有触发条件？
- 反差有没有事前基线？读者在没有解释的情况下，能先感受到「外冷」吗？
- 内核能否解释第二层的属性？如果不能，属性是贴上去的。
- 缺陷是否真的让他在情节里犯过错？成长方向是否能被一场选择验证？
- 遮住名字，能否从对话和行为认出这个角色？
- 同一 MBTI 的两个角色，是否因为属性与内核不同而明显可区分？

## 常见错误

- 把属性当成人设本身，选了一堆标签，却写不出他会怎么选。
- 只选褒义属性，人物没有摩擦、没有代价。
- 同一类属性堆近义词，或者把互不相关的属性当成互斥（高冷不等于不会操心）。
- 反差没有铺垫，变成前后不一致。
- 让 MBTI 决定一切，同一类型的角色全写成同一个模子。
- 内核写得很深，但行为和属性完全不支持；或者属性很鲜明，内核却只是「他就是这样」。
- 成长写成换性格，结尾突然变得温柔 / 开朗，却没有经过选择与代价。
