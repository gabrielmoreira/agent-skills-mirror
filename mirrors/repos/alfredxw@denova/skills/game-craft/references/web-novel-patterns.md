# 网文体验与题材适配

解决“游戏怎样像沉浸式网文一样持续运转”。通用判断见 `SKILL.md`；世界与角色见 `world-and-cast.md`；状态与规则见 `state-and-rules.md`；规划与回合见 `planning-and-scenes.md`；开局与诊断见 `opening-and-diagnosis.md`。

## 一、网文体验引擎

网文不是“一直发生事件”，而是持续制造“我想要/我怕失去 → 现在得不到 → 我做了什么 → 兑现 → 更大的问题”。

```text
期待：玩家想要什么、怕失去什么
→ 压制：为什么现在得不到（资源差、规则、对手、身份、误会、期限）
→ 准备：玩家调查、修炼、交易、结盟、布置、藏底牌
→ 爆发：玩家的选择/底牌/准备兑现
→ 回报：资源、地位、名声、关系、真相、新地图
→ 新钩子：更大的威胁、代价、未解问题
```

不是每个场景都要走完六步；一个场景可以只做“期待 + 压制”，一个篇章才做完整循环。关键是：**压制要合理，爆发要来自玩家的选择或准备，回报要可见，新钩子要能继续。**

| 阶段 | 玩家感受 | 设计杠杆 | 常见失效 |
| --- | --- | --- | --- |
| 期待 | 我想要 / 我怕失去 | 明确目标、公开承诺、倒计时、稀缺机会 | 目标模糊，玩家不知道在等什么 |
| 压制 | 不甘、紧张、好奇 | 资源差、规则限制、对手强、身份暴露风险、误会 | 无理打压、对手降智、为虐而虐 |
| 准备 | 掌控感、投入感 | 调查、修炼、交易、结盟、布置、藏底牌 | 跳过准备，直接开挂 |
| 爆发 | 爽、解脱、被看见 | 正确选择、底牌、公开反转、越级、团队配合 | 全靠运气/金手指，玩家没有贡献 |
| 回报 | 满足、被认可 | 资源、地位、名声、关系、真相、新地图 | 回报不可见、被立刻没收、没有见证者 |
| 新钩子 | 想继续 | 更大威胁、代价、未解问题、新目标 | 完结感太强，玩家没有下一步 |

### 爽点的类型

爽点不只是“打脸”。常见类型：

- **逆袭/打脸**：被低估 → 公开证明 → 地位/名声变化。
- **获得**：拿到稀缺资源、功法、装备、身份、地盘。
- **突破**：跨过瓶颈，获得新能力/新权限。
- **识破**：看穿骗局、规则、内鬼、伪装。
- **救援/守护**：在压力下保护重要的人或东西。
- **复仇/清算**：兑现长期积压的债。
- **建设**：把荒地/破局/组织经营成势力。
- **解谜**：把碎片信息连成真相。
- **情感回应**：关系推进、被理解、被选择。
- **生存**：在绝境中活下来，并付出可见代价。

每一种爽点都需要：**铺垫 → 压制 → 玩家的选择/准备 → 兑现 → 见证者/后果**。没有铺垫的爽点是偶然；没有玩家贡献的爽点是看戏；没有后果的爽点是空转。

### 力量幻想的契约

网文玩家通常希望“我变强了/我做对了/我被看见了”。如果游戏只强调代价和失败，会变成苦修模拟器；如果只给免费胜利，会变成点击器。

- 让玩家感到“我做了正确准备/选择，所以赢了”，而不是“系统让我赢”。
- 失败应制造“我再试/换方法/付代价”的下一步，而不是无意义的羞辱。
- 代价要 sharpen 选择，不要抹掉能力感；强敌可以强，但不能让玩家永远没有还手空间。
- 早期给小胜，中期给阶段胜利，后期给大兑现；不要把全部回报留到最后。
- 公开场合的认可是一种奖励；不是所有回报都要变成数值。
- 允许玩家“装到”，但要让装到有依据、有风险、有后果。

### 网文向补充判断

1. 玩家现在期待什么？这个期待多久没被回应？
2. 什么在压制玩家？压制是否合理、是否可被理解/反制？
3. 玩家能做什么准备？准备是否会被兑现？
4. 这次爆发来自玩家的哪个选择/底牌？如果没有，补铺垫。
5. 回报改变了什么？谁看见了？下一个钩子是什么？

## 二、成长体系

网文的“升级”不是数字变大，而是**能做的事、能进的地方、能见的人、能承担的敌人**发生变化。

### 阶梯模板

```text
阶段名称：
能力边界（能做什么 / 不能做什么）：
社会意义（别人怎么看你、谁能命令你、你能进入哪里）：
突破条件（资源 / 领悟 / 试炼 / 人物 / 时间）：
代价 / 风险：
越级规则：
新地图 / 新对手 / 新资源：
```

### 设计原则

- 长线一般 5–9 个阶段，短局 3–5 个；阶段名称要能被玩家记住。
- 每个阶段至少改变一项**访问权**：能进的区域、能接的任务、能交易的对象、能对抗的敌人、能影响的政治层级。
- 瓶颈不要只有经验值。可用资源、领悟、试炼、师承、身份、时间、关系、地点、公开资格。
- 突破要有代价/风险：失败、受伤、暴露、欠债、错过窗口、被更高层注意。
- 越级要有规则：准备、克制、环境、团队、一次性底牌；不要让“越级”变成常态。
- 每个阶段解决旧问题的同时，制造新问题；否则升级只是数值膨胀。
- 旧能力不要消失；可以让它变成基础、被克制、被制度限制，或需要更高成本维持。
- 成长要能被玩家看见：称号、权限、NPC 态度、地图开放、敌人反应、交易价格、宗门地位。

### 成长循环

```text
当前瓶颈 → 寻找资源/师承/试炼 → 准备与取舍 → 突破/失败
→ 新权限/新地图/新对手 → 更大的瓶颈
```

常见失效：

- 只有境界名，没有能力边界和社会意义。
- 瓶颈=刷经验；玩家不需要做选择。
- 每个阶段玩法一样，只是数字更大。
- 主角什么都会，没有 build 取舍。
- 旧能力/旧角色/旧地图全部作废。
- 越级靠“隐藏血脉/突然觉醒”，没有铺垫。

## 三、金手指

金手指是主角相对世界的特殊优势。它不是“万能答案”，而是**加速某个循环、改变某个瓶颈**的工具。

常见类型：

| 类型 | 例子 | 主要作用 | 主要风险 |
| --- | --- | --- | --- |
| 导师/残魂 | 药老式 | 提供知识、功法、经验 | 依赖、暴露、导师有自己目的 |
| 随身空间/资源 | 小瓶式 | 加速资源获取/培育 | 被觊觎、破坏平衡、需要隐藏 |
| 系统/主神 | 主神空间式 | 发布任务、兑换、成长 | 规则残酷、债务、被控制 |
| 血脉/体质/异眼 | 鬼眼式 | 特殊感知/能力 | 反噬、暴露、被研究 |
| 重生/先知 | 重生式 | 信息优势、避开错误 | 蝴蝶效应、记忆不可靠 |
| 身份/组织 | 双面身份式 | 资源、权限、人脉 | 暴露、双重义务、牵连 |

### 金手指契约

```text
金手指：
解决哪个瓶颈：
不能解决什么：
代价 / 限制：
暴露风险：
成长方式：
反制 / 天敌：
与主角目标的关系：
```

设计原则：

- 只加速一个循环，不要解决所有问题；否则其他系统会失去意义。
- 有成本/限制/冷却/稀缺性；越强越要有限制。
- 有暴露风险；世界会反应（觊觎、追捕、研究、争夺）。
- 有反制/天敌；对手可以用规则、封印、污染、复制、制度限制它。
- 不替代玩家选择；玩家决定怎么用、何时用、是否隐藏。
- 如果金手指有声音/人格，不要让它抢走主角的决策和戏份。
- 金手指应与主角目标冲突或互相塑造；不要只是“外挂”。

常见失效：万能、无代价、无暴露、无counterplay、系统话太多、奖励不需要行动、主角变成金手指的挂件。

## 四、资源、经济与社会资本

网文里的资源不是背景数字，是选择的燃料。

| 资源 | 来源 | 消耗 / 沉淀 | 作用 |
| --- | --- | --- | --- |
| 货币 | 任务、交易、掠夺、经营 | 购买、拍卖、维护 | 交易媒介 |
| 修炼资源 | 秘境、宗门、采集、交易 | 突破、炼丹、喂养 | 成长 |
| 消耗品 | 制作、购买、掉落 | 战斗、探索、救援 | 应急 |
| 装备/功法 | 掉落、传承、交易、打造 | 修理、升级、替换 | build |
| 人情/贡献 | 帮助、任务、承诺 | 兑换、求助、晋升 | 社会资本 |
| 名声/称号 | 公开行为、战绩、作品 | 门槛、敌人、机会 | 社会地位 |
| 信息 | 调查、交易、审问 | 使用、泄露、误导 | 决策 |
| 地盘/人手 | 建设、征服、继承 | 维护、防御、治理 | 长期 |

### 经济原则

- 有来源就要有沉淀；没有 sink 的货币会失去意义。
- 稀缺要有感知：价格、限量、竞争、门槛、维护成本。
- 战利品不是“自动进背包”；让玩家选择拿/不拿/卖/用/送/藏。
- 基地、宗门、团队、势力都需要维护成本；这会产生持续压力。
- 拍卖/交易是场景：竞争者、信息差、人情、债务、抢夺/伏击。
- 不要无限通胀；价格锚点要稳定，稀有物要有稳定获取路径或替代。

### 社会资本

经典网文的世界不只靠武力，还靠**名声、面子、师承、阵营、贡献、官职、武评、人情**。

- 机构：宗门、学院、公会、朝廷、公司、警方、组织、主神空间。
- 地位阶梯：外门/内门/核心、弟子/执事/长老、职员/主管/老板、队员/队长。
- 名声：公开战绩、称号、榜单、传闻、作品、救过谁/得罪过谁。
- 义务：债务、承诺、师承、婚约、阵营任务、人情；义务会产生选择。
- 机构模板：

```text
机构：
它想要：
它能给：
它要你付：
晋升 / 贡献规则：
谁保护你 / 谁竞争：
```

常见失效：钱没用、资源无 sink、名声只是一个数字、势力静止、没有义务、机构只有名字。

## 五、世界阶梯

长线网文通常不是一张地图，而是多层阶梯。每层有自己的规则、势力、资源和门槛。

```text
层级：
范围：
主要势力：
稀缺资源：
公开规则 / 禁忌：
进入条件：
离开条件 / 代价：
上一层如何影响这一层：
```

设计原则：

- 层级至少改变一项规则/资源/势力/威胁，不只是换风景。
- “换地图”要有原因、代价和携带物：关系、敌人、名声、功法、债务不能全部重置。
- 旧地图/旧角色仍可回归；不要让上一层完全作废。
- 力量尺度要一致；不要上一层的强者到下一层变成杂鱼，除非有解释。
- 进入/离开有条件：通行证、推荐、实力门槛、身份、时间窗口、代价。
- 上一层的力量可以影响下一层，但不要直接碾压所有本地冲突；保留政治/规则/信息限制。

常见失效：地图只有名字、新地图重置一切、旧角色消失、力量尺度崩、旅行没有成本。

## 六、沉浸感：人物、事物、外观

资料库不是百科。它要能让玩家“看见、听见、碰到、记住”这个世界。

### 人物

至少写 1–2 个可记忆的视觉/声音/行为特征：

- 外观：身形、衣着、伤痕、饰品、武器、习惯动作；外观要透露身份/阶层/职业/经历。
- 声音：语速、口音、口头禅、沉默方式、称呼习惯。
- 物件：随身物、信物、工具、作品；物件可以承载关系/秘密/目标。
- 感官：气味、温度、触感、脚步声；让玩家在场景里认出他。
- 第一印象：玩家第一眼看到什么？这个印象会怎样被后续推翻/加深？

不要写“万能美人”或全套履历；写会出现在场景里的细节。

### 事物

- 材质、重量、温度、磨损、声音、气味。
- 来历、主人、用途、代价、禁忌。
- 它会让玩家做什么选择？拿/不拿、用/不用、给/不给、修/不修。
- 它透露什么信息？谁认得它？谁会为它来？

不要只写数值和外观清单；物品要是一个行动/选择/线索。

### 地点

- 3 个感官细节：看到/听到/闻到/触到什么。
- 谁控制、普通人怎么生活、外来者要付什么。
- 玩家能做什么：进入、躲藏、交易、调查、破坏、谈判。
- 一个可记忆画面：玩家离开后还能想起什么？

不要写旅游宣传；地点要提供权力、资源、危险和行动接口。

### 势力

- 标志、制服、建筑、仪式、称呼、等级、黑话。
- 成员典型行为；外人如何识别；内部如何区分。
- 它控制什么资源/门槛；玩家如何被它影响。

### 场景

- 一个“明信片画面”：如果截一张图，玩家能认出这是哪里/发生了什么？
- 玩家第一眼看到什么？第一耳听到什么？第一件想碰的东西？
- 这个画面暗示什么危险/机会/关系？

### 资料条目补充字段

```text
外观 / 标志性细节（1–2 个可记忆特征）：
物件 / 载体（随身物、武器、信物、作品）：
感官锚点（声音、气味、温度、触感）：
玩家第一眼看到什么：
```

这些字段不是每条必填；但重要人物、关键物品、核心地点至少有一个可记忆细节。

常见失效：外观与机制无关、所有角色都好看、物品只有数值、地点只有风景、资料像百科、玩家记不住任何画面。

## 七、六类题材 lens

### 1. 斗破苍穹式升级爽文

核心体验：废物逆袭、师徒、异火/炼药、家族/宗门、学院/拍卖/大比、三年之约、公开打脸、越级挑战。

必须构建：

- 有社会意义的成长阶梯（斗气/炼药/异火/功法）。
- 导师型金手指（知识/功法/经验），但有依赖/暴露/目的。
- 资源经济（丹药、异火、功法、材料）与拍卖/交易。
- 家族/宗门/学院/公会等机构与地位阶梯。
- 公开比试/大会/拍卖等“被看见”的场景。
- 复仇/三年之约/宗门压力等长线时钟。
- 地图阶梯（小城 → 帝国 → 黑角域 → 中州式）。

容易缺失：只有数值没有社会反应；打脸没有铺垫；所有问题靠隐藏血脉；没有代价；配角只是观众。

游戏钩子：三年之约时钟、炼药师大会公开测试、异火 build 选择、宗门大比 bracket、拍卖会争夺。

### 2. 凡人修仙传式凡人流

核心体验：谨慎、资源、寿元、信息差、跑路、底牌、宗门/坊市、秘境、长期积累。

必须构建：

- 资源经济与 sink（灵石、丹药、功法、材料、洞府、寿元）。
- 风险/收益与撤退选择；不是每战必胜。
- 信息差与准备：侦查、底牌、替身、后手、交易。
- 宗门/坊市/散修等机构与规则。
- 秘境/副本的进入条件、时限、队伍、出口、代价。
- 长期规划：寿元、瓶颈、闭关、游历、投资。
- “苟”的玩法：隐藏实力、避免暴露、留后路。

容易缺失：主角无敌、敌人降智、资源免费、没有寿元/维护压力、被迫英雄主义。

游戏钩子：寿元时钟、坊市拍卖、秘境探索（可撤退）、底牌准备、宗门贡献、洞府经营。

### 3. 雪中悍刀行式江湖/庙堂

核心体验：江湖与庙堂、武评/一品四境、北凉/离阳/北莽、人情/门客/军队、名场面、诗意/悲剧、群像。

必须构建：

- 社会资本：武评、名声、师承、门客、军功、朝堂位置。
- 政治势力与地缘：北凉、离阳、北莽式三方/多方博弈。
- 旅行/游历：江湖路线、驿站、城池、名胜、人情。
- 关系与义务：家人、门客、朋友、对手、承诺、旧债。
- 公开场面/对决：见证者、规矩、名声后果。
- 基调契约：江湖气、诗意、风流、悲剧；不能只升级。

容易缺失：只有等级没有江湖；没有政治后果；人物只是战力；没有日常/人情；基调变成普通玄幻。

游戏钩子：武评榜、北凉/离阳/北莽势力时钟、门客/军队基地、江湖游历、名场面决斗、人情债。

### 4. 无限恐怖式无限流

核心体验：主神空间、副本、奖励点、基因锁、团队、生死、恐怖片、支线、智斗。

必须构建：

- Hub（主神空间/基地）与 Run（副本）分离。
- 副本契约：入口、任务、规则、时限、队伍、支线、BOSS/出口、奖励、失败。
- 团队：角色分工、信任、命令、冲突、牺牲、投票。
- 奖励点/商店/强化：兑换、债务、长期 build。
- 死亡/失败：不是无痛重来；失败有代价/永久后果。
- 恐怖/压力：信息不足、资源有限、规则残酷。
- Meta 成长：基因锁式突破、队伍升级、空间秘密。

容易缺失：副本像普通地牢；没有团队；没有失败；没有资源 tradeoff；主角光环。

游戏钩子：主神契约、副本 3–5 场景、奖励点商店、基因锁突破、团队信任/投票、隐藏支线。

### 5. 神秘复苏式规则恐怖

核心体验：鬼的规则、驭鬼者、厉鬼复苏、代价、规则推理、鬼蜮、官方/民间。

必须构建：

- 规则：鬼的触发、规律、优先级、例外、反制；规则要可发现、可推理、可利用。
- 信息：线索、目击、记录、试验；玩家靠信息活下来。
- 代价：驾驭厉鬼会侵蚀身体/精神/人性；力量越强，复苏越近。
- 对抗：只有鬼能对抗鬼；用规则冲突/平衡/死机/异类/诅咒。
- 机构：官方、民间、驭鬼者组织、封锁/掩盖。
- 失败/死亡：恐怖需要真实风险；不能靠战斗数值解决一切。

容易缺失：用 d20 战斗打鬼；规则随意、没有线索；鬼无解但玩家无 counterplay；力量没有代价；只靠 jump scare。

游戏钩子：规则卡发现、复苏时钟、代价字段、鬼蜮副本、官方/民间阵营、用鬼对抗鬼。

### 6. 隐杀式都市隐杀

核心体验：重生/杀手、双面身份、组织、商战/黑道/警方、日常/后宫、装逼打脸、保护/复仇。

必须构建：

- 双面身份：公开身份 vs 隐藏身份；暴露风险、伪装、证据、目击者。
- 现代机构：公司、警方、媒体、法律、黑道、特工组织。
- 日常/暴力节奏：日常关系、生活细节、任务/冲突交替。
- 关系/情感：保护对象、搭档、对手、旧人；关系会约束行动。
- 任务/目标：暗杀、保护、调查、交易、复仇；每个任务有情报/风险/退出。
- 信息/法律风险：证据、监控、舆论、警方、组织规则。
- 基地/安全屋/公司：资源、人员、掩护。

容易缺失：都市只是换皮奇幻；只有战斗没有日常；身份暴露没有后果；现代机构不存在；关系只是数值。

游戏钩子：身份暴露时钟、日常/任务交替、公司/组织阵营、目标情报、关系 stakes、安全屋/基地。

### 通用扩展

- **系统流/签到流/模拟器流**：系统 UI、任务、奖励、惩罚、冷却；注意系统话太多/代替玩家。
- **重生/穿越**：信息优势、蝴蝶效应、原世界知识边界；不要全知。
- **种田/经营**：资源、人口、设施、维护、外部威胁；见基地/经济。
- **克苏鲁/诡异**：规则、理智/污染、信息、代价；见规则恐怖。
- **科幻/末世**：技术/资源、设施、组织、环境压力；见资源/世界阶梯。
- **历史/权谋**：机构、派系、礼法、信息、名分；见社会资本。
- **同人/改编**：先列不可变 canon、可改写空白、玩家可改变分歧；不要让玩家随意改写已确认事实，除非明确平行世界。

## 八、网文场景模板

### 公开比试 / 大会

- 规则与赛制：谁能参加、怎么赢、禁止什么。
- 观众与见证者：谁在看、他们期待什么、结果如何传播。
- 赌注：名额、资源、名声、婚约、宗门地位。
- 反转：对手底牌、规则漏洞、身份暴露、越级。
- 余波：名声、仇恨、招揽、挑战、下一轮。

### 拍卖 / 交易

- 物品与稀缺性：谁想要、为什么。
- 竞争者：财力、背景、威胁、托。
- 信息差：真伪、来历、副作用、隐藏代价。
- 交易之外：人情、债务、抢夺、伏击、交换条件。

### 秘境 / 机缘

- 入口与条件：谁开放、何时、需要什么。
- 规则与危险：环境、守卫、时限、规则怪谈。
- 队伍与竞争：队友、对手、背叛、分工。
- 宝物与选择：拿什么、放弃什么、给谁。
- 出口与代价：怎么离开、失去什么、带出什么。

### 宗门任务 / 贡献

- 发布者与动机：宗门、长老、同门、外部委托。
- 目标与隐藏变数：表面任务、真实目的、额外发现。
- 奖励与晋升：贡献、权限、功法、地位。
- 失败后果：声望、处罚、债务、被除名。

### 副本 / 无限流

- 入口与契约：怎么进、主神/系统规则、任务目标。
- 时限与失败：倒计时、死亡、扣分、抹杀。
- 队伍与分工：角色、信任、命令、冲突。
- 支线与隐藏：额外奖励、真相、风险。
- 出口与结算：奖励点、伤势、带回物、下一副本。

### 基地 / 经营

- 资源与产出：收入、消耗、维护。
- 人员与职责：谁做什么、忠诚、特长。
- 威胁与防御：外敌、内鬼、灾害、期限。
- 升级与取舍：先建什么、放弃什么。
- 政治与关系：势力、许可、联盟、义务。

### 团队

- 角色与分工：输出、情报、后勤、谈判、医疗。
- 信任与秘密：谁知道什么、谁有保留。
- 命令与冲突：谁决定、谁不服、何时分裂。
- 高光与牺牲：每人有作用；死亡有后果。

### 日常 / 关系

- 生活细节：吃、住、工作、节日、训练。
- 关系推进：试探、误会、承诺、边界、回应。
- 反差：日常与暴力/危险的对比。
- 伏笔：日常里埋下一条线索/威胁/身份。

## 九、诊断与检查

| 症状 | 可能原因 | 最小修复 |
| --- | --- | --- |
| 升级无感 | 阶段只有名字/数值，没有新权限/社会反应 | 给每个阶段新访问权、NPC 态度、地图/任务门槛 |
| 爽点不足 | 没有铺垫、见证者、玩家贡献 | 加压制、公开场合、准备选择、可见回报 |
| 金手指万能 | 没有代价/限制/反制 | 加成本、暴露风险、天敌、不能解决的问题 |
| 世界像一张地图 | 各层规则/资源/势力一样 | 给每层不同规则、稀缺资源、机构、进入条件 |
| 资源无意义 | 没有 sink/维护/稀缺 | 加维护、交易、消耗、限量、替代路径 |
| 名声没用 | 没有机构/门槛/传播 | 加武评/榜单/门派/朝廷/公司门槛与反应 |
| 副本像普通地牢 | 没有契约/队伍/失败/结算 | 加任务、规则、时限、团队、奖励点、失败后果 |
| 恐怖靠 jump scare | 没有可发现/可利用的规则 | 加规则、线索、优先级、代价、counterplay |
| 都市像换皮奇幻 | 没有现代机构/双面身份/法律风险 | 加公司/警方/媒体/组织/暴露后果 |
| 日常拖节奏 | 日常没有目标/关系/伏笔 | 给日常一个关系目标、身份风险或线索 |
| 关系只有数值 | 没有场景/承诺/边界 | 加关系场景、义务、选择、后果 |
| 敌人降智 | 没有独立目标/资源/反制 | 给敌人目标、情报、底牌、下一步行动 |

### 检查清单

- 玩家现在期待什么？这个期待多久没被回应？
- 压制是否合理、可理解、可反制？
- 玩家能做什么准备？准备是否会被兑现？
- 这次爆发来自玩家的哪个选择/底牌？
- 回报改变了什么？谁看见了？下一个钩子是什么？
- 成长阶段是否改变了访问权/社会意义，而不只是数字？
- 金手指解决了什么、不能解决什么、代价/反制是什么？
- 资源是否有来源/消耗/稀缺/维护？
- 名声/地位/机构是否真的影响选择？
- 世界阶梯是否改变了规则/资源/势力，而不是只换地图？
- 人物/事物/地点是否有可记忆的外观/感官锚点？
- 重要场景是否有一个“明信片画面”？
- 题材承诺是否被兑现：升级、凡人、江湖、无限、恐怖、都市？
- 是否存在“只有数值/只有设定/只有过场”的空转？
