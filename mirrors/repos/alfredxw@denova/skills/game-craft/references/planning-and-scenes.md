# 规划、场景与回合

解决“接下来可能怎样、谁在行动、玩家每个回合经历什么”。世界与角色见 `world-and-cast.md`，状态与规则见 `state-and-rules.md`。

## 何时启用游戏规划

规划是可选模块。它适合：

- 长线故事、篇章结构、悬疑/调查、势力政治、关系推进、生存/经营、开放世界；
- 需要提前埋线索、安排角色登场/退场、控制揭示节奏；
- 玩家偏航后仍需要保持方向和连续性的故事。

不一定需要：

- 短局、纯即兴、每局独立单元剧；
- 玩家主导的纯沙盒，规划容易变成过度约束；
- 当前回合只需要一个即时反应，提前写完整季没有收益。

规划要解决的是“未来可能”，不是“已经发生”。已完成回合、精确状态值和推荐选项不属于规划。

## 规划模板

一个够用的规划通常包含这些 section：

```text
长期方向：
当前篇章：
近期情境：
人物议程：
线索与回收：
分支可能：
重规划触发：
```

各 section 写什么：

- **长期方向**：可能终局、核心戏剧问题、不可逆变化、必须留给玩家决定的部分。远端只写方向，不写完整剧本。
- **当前篇章**：目标、阻力、发现、反转、中点、高潮、余波、出口。只细化当前正在玩的篇章。
- **近期情境**：接下来 2–4 个候选场景。每个写地点/时间、在场角色、压力、可能信息、可行动作、代价、出口。
- **人物议程**：谁想做什么、什么时候行动、玩家不干预会怎样、什么会改变他的计划。
- **线索与回收**：承诺、线索、秘密、威胁、债务、伏笔，以及合适的回收窗口。回收要改变局势，不只是解释。
- **分支可能**：哪些可变、哪些不变、准备内容如何复用、玩家偏航时哪些剧情功能可以转移。
- **重规划触发**：什么情况下局部调整，什么情况下整体重写。

选择模板时：

- 经典冒险适合通用长篇；主线长篇适合强剧情/升级；角色与关系适合情感驱动；悬疑与恐惧适合真相/线索；单元与涌现适合 episodic/沙盒。
- 模板只决定“规划有哪些章节”，不决定故事模块、规则、状态或 canon。
- 可以自定义模板，但不要为每个故事发明一套新结构；优先复用并做小幅调整。

## 长线、当前弧、近期情境

按距离分级细化：

| 距离 | 写到什么程度 | 不要写什么 |
| --- | --- | --- |
| 长期 | 可能终局、核心问题、不可逆变化、主要势力方向 | 每一章的具体事件、玩家必须做的选择 |
| 当前弧 | 目标、阻力、转折、中点、高潮、余波、出口 | 已完成回合的 recap、精确状态值 |
| 近期 | 2–4 个候选场景，每个有压力、信息、选择、后果 | 固定台词、固定结果、唯一解 |
| 本回合 | 当前情境、NPC 意图、可用信息、可能后果 | 段落级草稿、完整工具 JSON |

原则：

- 越远越抽象，越近越具体；不要一次写完整季。
- 规划是**未来意图**，不是已发生事实；不要用它 recap 已完成回合。
- 规划不要重复状态精确值；状态是当前事实，规划是未来可能。
- 已完成/失效的内容删掉，不要当进度日志。
- 规划在导演控制台可见，可能剧透；叙事不能直接引用尚未揭示的计划内容。

## 人物议程与前线

让世界在玩家之外运转，靠的是议程和时钟，不是随机事件。

### 人物议程

- 每个重要角色想要什么？他下一步会做什么？
- 如果玩家不干预，他何时、以什么方式行动？
- 玩家做什么会改变他的计划？他会如何反击/妥协/升级？
- 他的行动会留下什么可观察信号？玩家如何发现？
- 他失败后会怎样？退出、报复、交易、换目标？

### 前线与时钟

```text
前线：
目标：
资源：
手段：
时钟（4 / 6 / 8 段）：
每段的可见信号：
玩家干预点：
不干预的结果：
```

- 时钟 4/6/8 段；每段都要有可见信号；不要隐藏所有进度。
- 玩家忽略/失败时推进时钟；玩家干预时改变时钟、资源、目标或联盟。
- 时钟不是惩罚条；它让世界显得在运转。
- 一个势力可以有多条前线，但只建与当前故事有关的；不要给每个势力都建全套。
- 不干预也要有结果；世界不会等玩家。

## 线索、铺垫与回收

- 重要结论至少 3 条线索，分布在不同地点、人物、行动方式。
- 线索可以被误解，但不能不存在；失败给代价、噪音、延迟或新压力，不给“什么都没”。
- 线索要有物理/社交存在：一封信、一道痕迹、一个说谎时的停顿、一个账本、一个目击者。
- 伏笔要有回收窗口；回收时改变局势，不只是解释。
- 不要把唯一必要线索藏在单一选项、单一技能或单一角色后面。
- 玩家可以错过线索，但不能因为一次错过就永远无法推进；准备替代路径或让线索以代价再次出现。

## 分支与玩家能动性

### 准备情境，不准备路线

- 准备“节点 + 多个出口”，不是“路线 A/B/C”。
- 情境写：谁想要什么、什么压力、哪些信息、可能的选择、可能的后果。
- 玩家偏航时，转移“剧情功能”而不是强制原路线；不要让所有选择都通向同一个结果。
- 分支差异应体现在代价、关系、信息、资源、后续压力，不只是文本。
- 允许失败分支、撤退分支、拒绝分支；不要所有分支都回到同一结果。
- 复用准备内容：同一个地点/角色/事件可以在不同分支承担不同功能，但不要假装玩家选择没发生。

### 避免“量子食人魔”

“量子食人魔”指无论玩家选哪条路，都会遇到同一个预设结果。它会让选择失去意义。

替代做法：

- 为每个合理方向准备不同的**代价/信息/关系**，即使最终都通向同一类冲突；
- 让玩家选择改变“怎么面对”，而不是“是否面对”；
- 如果某个剧情功能必须发生，就让它在不同分支以不同形式发生，并承认玩家选择的影响；
- 允许玩家彻底绕过某些内容；被绕过的内容可以转化成后果/资源/新压力，而不是强行搬回来。

## 场景设计

一个场景不需要很长，但要有目的和出口。

```text
地点 / 时间：
在场角色（各自想要什么）：
压力 / 威胁：
玩家可能获得的信息：
可行动作（至少 3 类不同方法）：
代价 / 风险：
如果玩家不动，会发生什么：
场景出口（新信息 / 新选择 / 新压力）：
```

检查：

- 这个场景的目的是什么？揭示、施压、关系变化、准备、余波？
- 谁想要什么？没有欲望的场景容易变成描述。
- 玩家能做什么？至少 3 类不同方法，不是同一个动作换措辞。
- 如果玩家失败/不做，场景会怎样变化？
- 场景结束时，局势/关系/信息/位置变了什么？
- 是否有明确的出口，而不是等玩家“聊到没话说”？

场景类型可以交替：

- **压力场景**：时间、危险、对抗、资源消耗。
- **发现场景**：线索、真相、新区域、新人物。
- **关系场景**：信任、误解、承诺、边界、情感变化。
- **余波场景**：处理后果、恢复、结算、重新定位。
- **准备场景**：计划、交易、训练、建设、结盟。

网文向常用场景还包括：公开比试/大会、拍卖/交易、秘境/机缘、宗门任务、副本、基地经营、团队、日常关系。它们的结构模板见 `web-novel-patterns.md` 的「网文场景模板」。这些不是必选项；按题材和玩家体验选择，不要为了凑类型塞场景。

呼吸场景也要有目的：关系、信息、准备或恢复；不要为了拖长度加无决策的日常。

## 回合循环

```text
情境（谁想要什么 / 什么压力）
→ 玩家意图
→ 裁定（直接裁定 / 规则检定）
→ 后果（成功、失败、代价、新信息）
→ 状态与关系变化
→ 新的选择
```

- 每个回合至少改变一项：信息、位置、资源、关系、威胁、目标。
- 不要每个小动作都停下来问“你做什么”；在有意义的决策点交还控制权。
- NPC 要主动行动、拒绝、讨价还价、升级；不要排队等玩家。
- 结尾停在有压力的选择，不停在总结或空问句。
- 不要用旁白替玩家做决定，也不要把玩家的意图写成既成事实。

## 选项设计

非终局回合通常给 3–5 个选项。选项是建议，不是限制；玩家仍可自由输入。

- 动词/方法不同：战斗、交涉、调查、潜行、撤退、牺牲、利用环境、等待。
- 每个选项有不同的代价、受益者、信息或后续压力；不要只有措辞不同。
- 不要有明显正确项，也不要有无提示的陷阱。
- 至少一个非战斗/非正面选项；让玩家可以选择谨慎、社交、迂回或放弃。
- 不要把唯一必要线索藏在单一选项后。
- 选项要和正文结尾一致；不要在选项里引入正文没建立的资源/人物。
- 选项文本要短、具体、可判断；不要写成小说段落。
- 允许“其他”自由输入；不要用选项菜单限制玩家的创造力。

检查选项：

- 如果把所有选项的文本删掉，只留下后果，它们是否仍然不同？
- 玩家能否从正文推断每个选项的风险/收益？
- 是否存在一个选项明显最优，或一个选项纯粹是惩罚？
- 是否有至少一个选项体现角色/关系/价值观，而不只是效率？

## 节奏

- 压力/发现/关系/余波/准备交替；不要连续多个同类型场景。
- 用时钟/前线升级，不要突然加难度。
- 给呼吸场景，但呼吸场景也要有目的。
- 剪掉没有决策的流程；直接跳到下一个有意义的选择。
- 不要每回合都推进主线；允许支线、关系、准备和恢复。
- 不要用无意义检定填充时间；检定应改变局势。
- 长线要有阶段性的“收束—再出发”：完成一个目标、结算后果、重新选择方向。
- 网文向节奏要检查“期待 → 压制 → 准备 → 爆发 → 回报 → 新钩子”：不要连续压制不兑现，也不要无铺垫爆发；小胜、中胜、大兑现要有梯度。爽点与成长设计见 `web-novel-patterns.md`。

## 重规划

出现以下情况时，考虑局部调整或整体重写：

- 玩家做出改变主线方向的选择；
- 当前弧完成/失败/提前结束；
- 已建立的 canon 与计划冲突；
- 连续几回合没有有效推进，玩家失去方向；
- 规划中的内容已失效或已被玩家绕过；
- 新信息让原计划不再合理；
- 角色死亡/离场/关系破裂，原议程不成立。

重规划原则：

- 保留已确认事实和玩家选择造成的后果；不要为了回到原计划而 retcon。
- 先删掉失效内容，再补新方向；不要在原计划上不断叠加补丁。
- 局部调整优先；只有主线方向/核心冲突变了才整体重写。
- 重规划后检查：玩家是否仍有明确目标？世界是否仍在运转？线索是否仍可达？

## 常见错误

- 规划写成剧本，玩家只能按路线走。
- NPC 没有议程，世界等玩家。
- 线索单点，错过就卡死。
- 分支只有文本差异，后果相同。
- 时钟隐藏，玩家无法判断风险。
- 每回合都推进主线，没有余波/关系/准备。
- 场景没有目的和出口，靠闲聊拖长度。
- 选项只有措辞不同，或存在明显最优解。
- 用无意义检定填充节奏。
- 重规划变成 retcon，否定玩家选择。
- 规划里写已完成回合/精确状态值/推荐选项。

## 检查清单

- 是否真的需要规划？如果关掉规划，游戏会失去什么？
- 长期方向是否只写可能，不写强制？
- 当前弧是否有目标、阻力、转折、出口？
- 近期是否有 2–4 个有压力、有信息、有选择的情境？
- 重要角色/势力是否有议程和时钟？不干预会发生什么？
- 重要结论是否至少有 3 条不同入口的线索？
- 分支是否改变了代价/关系/信息/资源，而不只是文本？
- 每个场景是否有目的、压力、可行动作和出口？
- 每回合是否至少改变一项？结尾是否留下有意义的选择？
- 选项是否有不同方法/代价，且没有明显最优？
- 节奏是否有压力/发现/关系/余波的交替？
- 是否定义了重规划触发？重规划是否保留已确认事实？
