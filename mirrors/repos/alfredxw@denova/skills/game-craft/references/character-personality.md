# 角色性格：三层结构与属性库

用于设计固定主角、核心 NPC、对手和重要配角，也用于检查角色是否只有形容词、没有可演出的行为。游戏里的性格不只是背景：它决定 NPC 在玩家不干预时做什么、面对玩家选择怎么回应、在什么条件下翻脸或转向。

三层各管一件事。不是每个 NPC 都需要完整三层：核心 NPC 写全，功能 NPC 只写与当前冲突有关的部分，路人只给一个可记忆特征。

## 三层结构

| 层 | 内容 | 游戏里的用途 |
| --- | --- | --- |
| 1 | 核心人格（MBTI 16 型） | NPC 的默认决策路径；玩家不在场时他会怎么行动 |
| 2 | 性格表现（萌属性 / 属性标签） | 玩家每回合能看到的语气、动作、距离感；角色之间的辨识度 |
| 3 | 人物内核 | 议程、底线、翻脸条件、关系变化与可能的转向 |

- **能演出**：每个标签至少对应一句台词、一个动作或一种反应。
- **能预测**：玩家做出某类选择时，角色会怎么回应；不能每回合临时换态度。
- **有压力点**：什么情况下他会违背平时的样子？这比标签本身更能制造剧情。
- **逐步揭示**：不要在登场时把性格说完；让玩家通过重复互动、压力和关系变化逐步发现。
- 标签不是互斥分类。高冷、傲娇、操心可以同时存在，因为它们描述的是不同方面。

## 第一层：MBTI 16 型

四个维度：

| 维度 | 两端 | 在角色身上的表现 |
| --- | --- | --- |
| 精力与注意力 | E 外倾 / I 内倾 | 能量从人群还是独处恢复；主动开口还是先观察 |
| 信息获取 | S 实感 / N 直觉 | 相信具体经验还是模式与可能；注意细节还是走向 |
| 判断偏好 | T 思考 / F 情感 | 先看逻辑与效率，还是先看关系与感受 |
| 生活组织 | J 判断 / P 感知 | 先定计划再行动，还是边做边调整 |

四个大组：

按四组排列：NT 理性探索型（INTJ / INTP / ENTJ / ENTP）、NF 理想与情感型（INFJ / INFP / ENFJ / ENFP）、SJ 秩序与责任型（ISTJ / ISFJ / ESTJ / ESFJ）、SP 自由与行动型（ISTP / ISFP / ESTP / ESFP）。

| 类型 | 默认决策方式 | 常见 NPC 用法 |
| --- | --- | --- |
| INTJ | 先建长期模型，再按目标配置资源；独立、重效率，不轻易解释过程 | 幕后布局者、冷面军师、控制型盟友 |
| INTP | 先拆原理再下判断；好奇、抽离，对规则本身感兴趣 | 学者、研究者、只对真相感兴趣的怪才 |
| ENTJ | 先定目标与结构，再推动他人执行；果断、强势、要结果 | 势力领袖、野心家、强硬上司 |
| ENTP | 先找漏洞与可能性，再试新解法；机敏、好辩、讨厌定式 | 诡计师、情报贩子、麻烦制造者 |
| INFJ | 先读人和动机，再按理想布局；洞察、内敛、有使命感 | 引导者、教派核心、幕后精神领袖 |
| INFP | 先对照内心价值，再决定行动；敏感、重信念、有想象力 | 理想主义者、逃亡者、坚持底线的普通人 |
| ENFJ | 先感知群体需要，再组织人走向目标；善于理解与感召 | 导师、团队核心、感召型领袖 |
| ENFP | 先被可能性吸引，再边走边找意义；热情、发散、追求新鲜 | 冒险者、破局者、社交型情报源 |
| ISTJ | 先核对事实与先例，再按责任执行；严谨、可靠、守序 | 执行官、纪律维护者、难通融的守卫 |
| ISFJ | 先照顾具体需要，再维持稳定；细致、体贴、记恩也记伤 | 守护者、照顾者、忠于旧约的人 |
| ESTJ | 先确认秩序与职责，再推动落实；务实、果断、重规则 | 管理者、指挥官、铁腕执法者 |
| ESFJ | 先维护关系与体面，再安排事务；热心、负责、重和谐 | 协调者、社交中心、地方势力的话事人 |
| ISTP | 先观察现场，再用最小动作解决问题；冷静、独立、临场强 | 独行侠、技术高手、冷静执行者 |
| ISFP | 先感受当下与个人边界，再行动；随性、细腻、重体验 | 艺术家、自由灵魂、沉默的叛逆者 |
| ESTP | 先抓眼前机会，再边做边调整；果敢、机灵、爱挑战 | 行动派、冒险家、机会主义者 |
| ESFP | 先投入现场与人群，再享受反馈；活泼、感性、会带动气氛 | 气氛担当、表演者、今朝有酒者 |

同一类型可以写出完全不同的 NPC。类型只决定「他先想到什么」，属性与内核决定「玩家实际遇到的是谁」。

| 同一 MBTI | 属性组合 | NPC 用法 |
| --- | --- | --- |
| INTJ | 高冷 / 御姐 / 操心 / 冷娇 | 控制型盟友：先安排玩家的路线，被质疑时冷淡，但会暗中兜底 |
| INTJ | 慵懒系 / 毒舌 / 摸鱼系 | 懒散高人：平时推脱，玩家真正遇险时给出关键解法 |
| ENFP | 开朗 / 自来熟 / 狡黠 / 外热内冷 | 情报贩子：和谁都能聊，但真话只说给信任够高的人 |
| ISFJ | 清冷 / 三无 / 忠犬 / 白切黑 | 沉默守卫：日常顺从，玩家触碰其底线后转为敌对 |

使用要点：

- MBTI 是创作原型，不是心理诊断；不要把类型当命运，也不要用类型替代立场、利益和信息边界。
- 类型描述默认路径，不描述能力、立场或道德。T 不等于冷酷，F 不等于善良。
- 给核心 NPC 留一个「不典型轴」：例如在陌生人面前极度疏离、对队内却话很多的 INTJ。这个偏离比类型本身更容易被玩家记住。
- 不要把类型写进玩家可见文本；玩家通过行为判断他是什么人。

## 第二层：可观察性格（萌属性）

七类属性各回答一个问题。按需选择，不要求每类都选；同一角色可以跨类组合。

### A. 气质与气场

玩家第一眼见到他时，得到什么印象？

| 属性 | 特征 |
| --- | --- |
| 高冷 | 冷淡、难以接近，保持距离 |
| 清冷 | 清雅、安静、疏离 |
| 冰山 | 冷漠、沉稳、不易显露情绪 |
| 御姐 | 成熟、独立、自信、有气场 |
| 女王 | 强势、有威严、喜欢主导 |
| 大小姐 | 娇贵、高傲，或具有优雅教养 |
| 姐姐系 | 成熟、包容、令人安心 |
| 王子系 | 帅气、英朗、举止得体 |
| 知性系 | 理性、博学、优雅 |
| 软萌系 | 柔软、乖巧、可爱 |
| 神秘系 | 深不可测，难以捉摸 |
| 高岭之花 | 优秀、耀眼、有距离感 |
| 禁欲系 | 自律、克制、严谨 |
| 慵懒系 | 悠闲、散漫、不紧不慢 |
| 危险系 | 富有压迫感，让人不敢轻易接近 |

演出方式：

- 登场第一眼就给出可读信号：站姿、语速、称呼、与玩家的距离。
- 气质决定玩家第一次接触时的策略：敢不敢搭话、要不要绕开、是否先示弱。
- 气质不等于性格。同一个「御姐」可以是温柔御姐、天然呆御姐或冷血御姐；后续属性和内核负责拆掉第一印象。

### B. 情绪与性格底色

他日常的情绪状态是什么样？

| 属性 | 特征 |
| --- | --- |
| 开朗 | 乐观、爱笑、容易交流 |
| 元气 | 活力充沛、精力旺盛 |
| 阳光 | 积极向上、充满希望 |
| 活泼 | 好动、热情、喜欢热闹 |
| 温柔 | 体贴、善解人意 |
| 治愈 | 能安抚他人、带来安全感 |
| 天真 | 纯真、容易相信别人 |
| 冷静 | 情绪稳定、遇事不慌 |
| 淡然 | 情绪平和，不容易被影响 |
| 佛系 | 不争不抢、随遇而安 |
| 忧郁 | 感情细腻、容易伤感 |
| 阴沉 | 情绪低落、不太积极 |
| 悲观 | 容易预想不好的结果 |
| 暴躁 | 易怒、缺乏耐心 |
| 敏感 | 对情绪和环境变化反应明显 |
| 多愁善感 | 容易被事情触动，感情丰富 |

演出方式：

- 情绪底色决定默认语气和同一事件里的第一反应；它是玩家最常读到的稳定信号。
- 底色可以在压力下翻转一次：一直开朗的人突然沉默，比一直阴沉的人发火更有信息量。
- 不要每回合都重复同一种情绪；底色是基准，不是唯一表情。

### C. 社交与对外表达

他如何跟玩家和其他角色相处、交流？

| 属性 | 特征 |
| --- | --- |
| 三无 | 无口、无心、无表情的典型形象 |
| 无口 | 沉默寡言、很少主动讲话 |
| 面瘫 | 缺乏明显的表情变化 |
| 社恐 | 不擅长社交，容易紧张 |
| 社牛 | 社交大胆，不怕生 |
| 自来熟 | 很快与陌生人熟络 |
| 毒舌 | 言语尖锐、擅长讽刺 |
| 闷骚 | 外表矜持、内心活跃 |
| 话痨 | 话很多，喜欢聊天 |
| 傲慢 | 自视甚高，容易轻视别人 |
| 谦逊 | 不喜欢炫耀，态度低调 |
| 礼貌疏离 | 待人礼貌，但保持距离 |
| 直率 | 想到什么就说什么 |
| 圆滑 | 善于察言观色、处理关系 |
| 电波系 | 思路独特，言行难以预测 |
| 恶作剧系 | 喜欢捉弄和逗弄别人 |

演出方式：

- 对话长度、主动性、是否反问、是否打断、沉默时做什么，是玩家最常读取的性格面。
- 区分社交距离与表达匮乏：高冷是「不让别人靠近」，三无是「没有可读的表达」，可以叠加，也可以分开。
- 给每个核心 NPC 一句标志性说话方式；但不要只靠口癖，压力下的变形才是性格。

### D. 情感与亲密关系

面对喜欢、信任、依恋的人，他会变成什么样？

| 属性 | 特征 |
| --- | --- |
| 傲娇 | 明明在乎，却不肯坦率承认 |
| 冷娇 | 平日冷淡，只对特定的人温柔 |
| 病娇 | 爱意混合偏执、过度占有或控制 |
| 娇羞 | 亲密时容易害羞 |
| 忠犬 | 忠诚、专一、喜欢陪伴 |
| 猫系 | 独立、别扭、忽冷忽热 |
| 犬系 | 热情、亲近、喜欢表达 |
| 黏人 | 渴望陪伴，不愿分离 |
| 直球 | 坦率表达好感与情绪 |
| 纯情 | 感情单纯、容易心动 |
| 恋爱迟钝 | 不容易察觉爱情信号 |
| 天然撩 | 无意识地做出撩人举动 |
| 占有欲强 | 希望重要的人只属于自己 |
| 献身系 | 愿为重要的人付出巨大代价 |
| 慢热 | 需要很长时间建立亲密感 |
| 口是心非 | 语言和真实感情不一致 |
| 回避亲密 | 渴望亲近，却害怕暴露弱点 |

演出方式：

- 这一类只在特定关系中显现。先确定「对谁」，不要对所有人都傲娇或黏人。
- 关系属性是玩家投入的回报：初始只露基线，信任或好感达到条件后再展示另一面。
- 病娇、占有欲强等属性要写清边界与代价；它们会伤害关系，也会制造新的冲突。
- 关系变化要能被状态读取：信任提高后，哪些台词、帮助或让步会解锁？

### E. 行为习惯与处事风格

玩家求助、委托、施压时，他通常怎么做？

| 属性 | 特征 |
| --- | --- |
| 操心系 | 喜欢担心别人，主动关照 |
| 老妈子系 | 总想替他人安排生活 |
| 认真系 | 对待事情一丝不苟 |
| 可靠系 | 有担当，遇事值得信任 |
| 热血系 | 充满激情和行动力 |
| 完美主义 | 对细节和结果要求很高 |
| 优等生系 | 自律、守规矩、追求优秀 |
| 冒失系 | 经常粗心或行动过快 |
| 天然呆 | 反应脱线，不自觉犯傻 |
| 笨拙系 | 不擅长某些表达或行动 |
| 懒散系 | 不喜欢麻烦，能躺就躺 |
| 摸鱼系 | 擅长偷懒、逃避事务 |
| 工作狂 | 把大量精力投入工作 |
| 独行侠 | 喜欢独立解决问题 |
| 行动派 | 想到就做，不爱犹豫 |
| 谨慎派 | 行动前喜欢考虑风险 |
| 固执系 | 不轻易改变自己的决定 |
| 老好人 | 不善于拒绝别人的请求 |

演出方式：

- 处事风格决定 NPC 是主动帮忙、讨价还价、拖延还是拒绝；它直接影响玩家能走的路线。
- 习惯要在日常里反复出现，在关键选择中付出代价；两者缺一，标签就只是设定。
- 给习惯一个反面情境：认真系在必须妥协时怎么办？老好人在必须拒绝时怎么办？这些时刻最适合做关系转折。

### F. 思维与心理策略

他如何处理信息、隐藏意图、应对冲突？

| 属性 | 特征 |
| --- | --- |
| 腹黑 | 内心有城府，擅长算计 |
| 心机系 | 善于洞察和利用人心 |
| 狡黠系 | 聪明机灵，喜欢小计谋 |
| 天然黑 | 无意识地说出或做出危险、腹黑的事 |
| 单纯系 | 心思简单，不喜欢算计 |
| 理性至上 | 优先遵循逻辑和效率 |
| 感性优先 | 优先考虑心情和个人感受 |
| 洞察系 | 能敏锐识别他人的想法 |
| 多疑系 | 难以轻信别人 |
| 反骨系 | 天生不喜欢服从权威 |
| 胜负欲强 | 不能容忍自己失败 |
| 自我中心 | 习惯以自身需求为出发点 |
| 自卑系 | 自我评价偏低，容易否定自己 |
| 自负系 | 过度相信自己的能力 |
| 理想主义 | 坚持信念和理想 |
| 现实主义 | 注重利益、条件与可行性 |

演出方式：

- 这一类决定 NPC 是否隐瞒、试探、利用或背叛；它直接影响冲突中的可预测性。
- 策略要在信息不对称中体现：他说了多少、隐瞒什么、试探谁、何时摊牌。
- 给策略留失效条件：多疑的人可能因为太累而轻信一次；理性至上的人可能在涉及亲人时破例。
- 与 MBTI 的层级不同：MBTI 是默认思维路径，心理策略是具体手段。INTJ 不等于腹黑。

### G. 内外反差

他的外在形象和真实内心有什么不一致？

| 属性 | 特征 |
| --- | --- |
| 外冷内热 | 外表冷漠，内心温柔 |
| 外热内冷 | 外表亲切，内心疏离 |
| 白切黑 | 表面善良无害，内心狠厉或有心机 |
| 黑切白 | 外表危险可怕，本性善良 |
| 反差萌 | 意料之外的行为让人觉得可爱 |
| 强势而脆弱 | 外表强大，内心缺乏安全感 |
| 温柔而冷酷 | 平常体贴，关键时刻毫不留情 |
| 懒散而可靠 | 平日摸鱼，重要时刻值得信赖 |
| 轻浮而深情 | 表面不正经，实际上非常专一 |
| 胆小而勇敢 | 平常畏缩，却会为重要之事挺身而出 |
| 天真而残酷 | 思想纯粹，却缺乏常规道德界限 |
| 自信而自卑 | 表面自信，内心害怕失败 |
| 顺从而叛逆 | 日常服从，内心渴望反抗 |

演出方式：

- 反差是至少两个属性之间的关系，不是独立标签。写「外冷内热」前，必须先让玩家相信「外冷」。
- 在游戏里最好绑定揭示条件：信任达到、秘密暴露、玩家越线、共同经历某件事。条件明确，玩家才有发现感。
- 反差要由内核解释：他不是「其实很温柔」，而是「害怕失去，所以先用冷漠把人推开」。
- 一个角色最多保留一个主反差；堆太多会让玩家无法形成预期。

### 属性怎么选

先按类别选，再压缩到真正会改变玩家体验的标签。建议上限：

| 类别 | 建议数量 | 说明 |
| --- | --- | --- |
| 气质与气场 | 1–2 | 第一眼印象与接触策略 |
| 情绪底色 | 1–2 | 默认语气与第一反应 |
| 社交表达 | 1–2 | 对话长度、主动性与距离感 |
| 情感与亲密关系 | 0–2 | 关系达到条件后才显现 |
| 行为与处事风格 | 1–2 | 玩家求助、委托、施压时的反应 |
| 思维与心理策略 | 0–2 | 是否隐瞒、试探、利用、背叛 |
| 内外反差 | 0–1 | 必须有基线与揭示条件 |

- 全部加起来，核心 NPC 控制在 2–5 个、功能 NPC 1–2 个、路人 1 个可记忆特征；只选会改变玩家体验的部分。
- 同一类里不要堆近义词（高冷 + 清冷 + 冰山）；它们不会增加玩法，只会让描述重复。
- 优先选能产生不同回合反应的组合：同一类属性越接近，玩家越感觉不到区别。
- 每个标签至少回答三件事：玩家做什么？他大概率怎么回应？什么情况会例外？
- 至少给核心 NPC 一个压力点或翻脸条件；没有压力点的 NPC 只是信息台。
- 主角若是玩家投射，只固定身份、能力边界、底线和少量说话风格，不预设玩家在每个情境下的态度。

## 第三层：人物内核

| 维度 | 问题 | 可用方向 |
| --- | --- | --- |
| 核心欲望 | 他最想得到什么？ | 自由、爱情、认可、力量、真理、归属、复仇、安稳 |
| 核心恐惧 | 他最怕失去或面对什么？ | 被抛弃、失控、失败、孤独、失去价值、被看穿 |
| 核心价值观 | 他认为什么最重要、什么不能交换？ | 秩序、正义、忠诚、利益、自由、责任、亲情、真相 |
| 性格缺陷 | 什么会让他在关键时刻做错？ | 傲慢、偏执、懦弱、控制欲、过度牺牲、逃避、轻信 |
| 成长 / 转向 | 什么条件下他会改变？ | 信任、接纳失败、放下执念、独立、拒绝、承担 |

- 核心欲望决定议程；核心恐惧决定他会在哪里过度反应；价值观决定底线；缺陷决定他会犯什么错、会在哪一步把玩家推开。
- 对游戏来说，「会改变的条件」往往比完整的成长弧更常用：信任达到多少、玩家做了什么、什么秘密被揭开，他会转向、结盟或敌对。
- 欲望和恐惧最好指向同一件事的两面：渴望被爱 / 恐惧被看穿；渴望自由 / 恐惧被抛弃。
- 关键矛盾要能生成选项：例如他想保护家人 vs 不敢违抗组织，玩家就能利用这个矛盾施压，或帮他破局。
- 成长 / 转向必须能用状态或事件验证；不要写「他后来想通了」却没有触发条件。

## 从标签到回合

每个性格标签至少写成一条可执行的 if-then，不要只留在形容词里：

- 顺利时：玩家正常求助，他会怎么做？
- 受压时：玩家的要求触碰他的恐惧或利益，他会怎么变形？
- 越线时：什么行为会让他拒绝、涨价、告密或翻脸？
- 关系变化后：信任提高或破裂，他的哪些表现会变？

示例（操心系 NPC）：

- 玩家出发前，他主动塞补给，并反复确认路线。
- 玩家拒绝帮助时，他先说「随你」，随后暗中跟随或托人照看。
- 玩家受伤时，他自责，并开始替玩家做决定；玩家若坚持自主，关系出现裂痕。
- 信任提高后，他学会先问「你需要我做什么」，而不是直接安排。

## 群像与区分

- 检查 NPC 的决策方式分布：如果所有重要角色都用同一种方式解决问题，给其中一两个换类型或不典型轴，比继续加属性更有效。
- 每个势力至少有一种典型决策风格；但不要让所有成员一个模子。
- 用「同一目标、不同方法」或「同一价值、不同优先级」配对，比单纯写一冷一热更容易产生戏。
- 关系属性（D 类）必须指定对象和触发条件：对谁傲娇、在什么情况下黏人、信任到什么程度才露出另一面。
- 对手的性格要能解释他的手段和底线；他的缺陷最好是他优势的过度使用，也是玩家可以利用的突破口。
- 检查群像：遮住名字，只看台词和反应，玩家能否认出是谁？分不出时，先改说话方式、反应速度和底线，而不是加外貌细节。

## 检查

- 这个 NPC 在没有玩家输入时会做什么？能否从他的欲望、恐惧和议程推出来？
- 玩家做出不同选择时，他的反应是否可预测又有区别？
- 每个属性标签都有可演出的台词、动作或反应吗？
- 他的底线和翻脸条件清楚吗？玩家能否提前看到信号？
- 反差有揭示条件吗？还是突然变脸？
- 遮住名字，玩家能区分两个 NPC 吗？
- 这个 NPC 是否只有性格，没有议程、资源和信息边界？如果是，先补功能。
- 主角若是玩家投射，是否保留了玩家决定态度和立场的空间？

## 常见错误

- 给每个 NPC 都写满人格卡，资料库膨胀，玩法没有变化。
- 性格标签只有形容词，没有台词、动作和反应。
- 所有 NPC 对玩家都用同一种态度，只是措辞不同。
- 反差没有条件，变成随机变脸。
- 用 MBTI 替代立场、利益和信息边界；NPC 的敌意来自利益冲突，不是类型。
- 让玩家角色按固定人格行动，剥夺玩家的选择。
- 把「成长方向」写成必然剧情，却不给触发条件和玩家影响的空间。
