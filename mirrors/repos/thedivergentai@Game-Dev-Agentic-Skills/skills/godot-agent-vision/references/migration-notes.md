# Migration notes: godot-agent-vision

Incremental upgrade for topics this skill covers. Apply **one hop**, stabilize/test, then next. Never skip hops.

If the project is **< 4.0**, follow [godot-version-migration](https://github.com/thedivergentai/gd-agentic-skills/blob/main/skills/godot-version-migration/SKILL.md) era bridges (legacy → 3→4) until 4.0, then these hops. Official 3→4: [Upgrading from Godot 3 to Godot 4](https://docs.godotengine.org/en/stable/tutorials/migrating/upgrading_to_godot_4.html).

This skill is an **agentic host utility** (Python CLI + TEMP EditorPlugin). Hops below track EditorInterface / Viewport capture APIs the bridge uses — not game runtime screenshot nodes.

## 3.x → 4.0

Official: [Upgrading from Godot 3 to Godot 4](https://docs.godotengine.org/en/stable/tutorials/migrating/upgrading_to_godot_4.html)

- EditorPlugin scripting targets Godot 4 `@tool` + typed GDScript.
- Viewport texture → `get_texture().get_image()` (Image API renamed from Godot 3 patterns).
