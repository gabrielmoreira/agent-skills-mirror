# Bridge: Godot 3.x → 4.0

Tier **A** — official guide: [Upgrading from Godot 3 to Godot 4](https://docs.godotengine.org/en/stable/tutorials/migrating/upgrading_to_godot_4.html).

Also use: [docs changelog](https://docs.godotengine.org/en/stable/about/docs_changelog.html), [interactive changelog](https://godotengine.github.io/godot-interactive-changelog/), [GitHub releases](https://github.com/godotengine/godot/releases).

## Preconditions

1. Full backup / VCS — the upgrade tool does **not** create backups.
2. Project on **latest 3.x** stable when possible.
3. Optional prep (3.5+): Tweener + Time; rename `.shader` → `.gdshader`.

## Run the converter

- Project Manager: Import → **Convert Full Project** (not only `project.godot` unless advanced recovery).
- CLI: `--validate-conversion-3to4` then `--convert-3to4` (optional size limits for huge files).
- Only Godot **3.0+** projects.

## After convert (expect manual work)

- Auto renames cover many nodes (`KinematicBody`→`CharacterBody*`, `Spatial`→`Node3D`, `Particles`→`GPUParticles*`, ARVR→XR, …).
- Manual: FileAccess/DirAccess, DisplayServer/Time splits, signal Callable style, Tween→Tweeners, `super()` in lifecycle, `call_group` immediacy, Camera2D zoom invert, shader hints, Environment quality → project settings.
- Caveats: Bullet removed; no GLES2; ArrayMesh format break; C#/.NET platform gaps historically.
