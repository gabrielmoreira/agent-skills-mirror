# OpenMotion Design Library

Starter HTML templates, design systems, design Skills, craft rules and scenario guides used by Design Studio and exposed to external Agents via `openmotion_design_catalog`.

## Inventory

- **Scenarios (`scenarios/`):** 6 HTML scenarios (`prototype`, `deck`, `document`, `web-clone`, `live-artifact`, `webgl`) + MCP mapping guide.
- **Templates (`templates/`):** 156 HTML starter templates (deck: 81, document: 12, live-artifact: 4, prototype: 47, web-clone: 1, webgl: 11).
- **Design systems (`systems/`):** 152 design systems (`DESIGN.md`, `tokens.css`, `manifest.json`).
- **Skills (`skills/`):** 157 design Skills (`SKILL.md` + text references).
- **Craft (`craft/`):** 11 foundational UI/typography/accessibility craft guides.
