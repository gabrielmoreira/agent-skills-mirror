# Story Outline Rules

用于长篇卷纲与章节细纲；短篇小节大纲按其写作 skill 执行。字段与写法以 story-long-write 出卷纲、出细纲时给的模板为准，有任务包时以任务包为准；这里只列落盘时不能少的部分。

## Rules

1. **卷纲**：按 story-long-write 的卷纲模板写，每个标题下一行写作用域（`> 作用域：卷级常任` 或 `> 作用域：单元级 {单元ID}`）；供给自查、建纲追加写进 `大纲/排纲底稿_{单元ID}.md`，不进卷纲。

2. **细纲必填项**：每个细纲（细纲_*.md）必须包含当前“章节蓝图”：
   - 基础执行字段：核心事件、字数目标、字数口径、单元ID/位置、目标情绪、主角目标/关键选择、章首钩子、爽点
   - 本章禁止提前释放：本章不得提前揭示的真相、底牌、关系结论或终局矛盾（与上一行合为九个必填字段）
   - 内容概括（五段式）：起因 / 发展 / 转折 / 高潮 / 结尾——结尾写本章最后落在什么动作或画面上，不写状态判词
   - 情节安排（多线）：主线推进 / 辅线推进（指向卷纲 L 编号）/ 事件线或任务线 / 感情线或关系线 / 逻辑线
   - 人物关系和出场顺序：按实际出现顺序列角色/势力/关键物件，并写人物关系变化
   - 情节细化：情节点序列写成表格 `# | 情节点（谁做了什么） | 功能标签 | 执行边界（禁＋放）`，不填写逐点字数、不按 beat 数预测容量；并标 行动成本（可无）/收益归属，不硬造代价
   - 结尾设定和钩子：结尾设定（落到最后的具体动作或画面）、未解决问题、下一章推动力、章尾钩子
   - 可选（需要时再写，不写不拦）：字数范围（作者给了上下限才写，如 2000-2600）、阶段位置、章节定位、本章结构公式、本章标价、闭环状态、写手自由区、镜头准入、信息差触发点、情节点「分辨率」列；契约风险只在本章让单元卡「契约风险」变化时写

3. **缺项处理**：旧细纲缺章节蓝图字段不阻止续写，回退读旧字段（核心事件、情节点序列、目标情绪、章首/章尾钩子、字数目标），只在明确补纲、改纲时按当前模板补齐；新建、补建、改纲的细纲必须补齐后再写正文。旧卷纲同样不阻塞，按字段结构回退读取，已写区间的卷纲不自动改写。材料确认不了的辅线、关系变化或代价收益写 `[待补充]`，不编造。
