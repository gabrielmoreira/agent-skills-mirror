# 长篇参考资料索引

规划或作者点名问技法时查下表。写正文只读 SKILL.md「本章技法」点到的那一份，不按本表加读。

## 按时刻

| 时刻 | 流程 | 方法 |
|---|---|---|
| 定方向 | `references/workflow-setup.md` Phase 1 | `references/genre-readers.md`（市场与平台）；题材框架：男频 `references/long-genre-catalog.md`，女频 `references/female-audience-writing.md` |
| 定设定 | `references/workflow-setup.md` Phase 2 | `references/long-genre-mechanics.md`（核心梗、金手指）、`references/character-basics.md`、`references/character-relations.md`（关系与感情线）、`references/reader-contract-and-progression.md` |
| 出卷纲 | `references/workflow-volume.md` | `references/outline-methods.md`（卷结构与节奏）、`references/artifact-protocols.md`（模板）、`references/emotional-arc-design.md`（弧线）、`references/long-reversal.md`（反转） |
| 出细纲 | `references/workflow-outline.md` | `references/plot-core-methods.md`（细纲与章级）、`references/long-chapter-hooks.md`（章首章尾钩子）；前 3 章加 `references/opening-design.md`「开篇规划」 |
| 写一章、日更 | `references/workflow-chapter.md`、`references/workflow-daily.md` | `references/writing-craft.md`、`references/long-format.md`、本章技法一份；第 1-3 章读 `references/opening-design.md`「开篇落笔」；题材卡 `references/genre-prose-cards.md` |
| 回炉 | `references/workflow-revision.md` | 作者只说症状时读 `references/revision-diagnosis.md` |
| 成稿检查 | `references/long-chapter-quality.md` | `references/banned-words.md`、`scripts/check-ai-patterns.js` |

## 按症状

| 症状 | 先读 |
|---|---|
| 拖、水、期待接不上、追读掉、主角憋屈、卡文、说不清好坏 | `references/revision-diagnosis.md` |
| 开头留不住人 | `references/opening-design.md` |
| 单元平、没有高低 | `references/emotional-arc-design.md` |
| 打脸不爽、装逼尴尬 | `references/style-combat-face.md` |
| 反转没冲击、被猜到 | `references/long-reversal.md` |
| 悬念散、线索不公平 | `references/long-suspense.md` |
| 感情线没进展、主角像舔狗 | `references/character-relations.md` |
| 金手指失控、战力崩 | `references/long-genre-mechanics.md` |
| 情绪写空、套式反应 | `references/emotion-on-page.md` |
| 对话平、人物一个腔调 | `references/dialogue-mastery.md` |
