
# 长篇章节质量检查清单

只查写好的这一章。严重度与写章流程一致：必须修、建议看、仅提示。去味按检测器提示处理；要完整三层去味走 `/story-deslop`。

## 一、单章检查

### 章节结构
- [ ] 开头有钩子（不是天气/风景/日常开场）；第 1-3 章另按 opening-design「开篇落笔」查
- [ ] 中段有推进（快节奏题材要有可见事件；慢热题材状态变化即可）
- [ ] 局势有变化（读完这章，世界跟之前不一样了）
- [ ] 结尾落在变化上（不是总结）

### 章节推进
- [ ] 本章至少改变目标 / 风险 / 信息 / 关系 / 资源 / 身份 / 情绪立场七类状态之一；快节奏（番茄/爽文）应有可见事件或爽点，慢热/情感文才可只靠低压小变化达标，不强求每章高潮
- [ ] 不是水字数（删掉这章会损失哪项状态变化？答不出才需压缩）
- [ ] 任务卡点有用：卡住之后是否带来上述状态变化？
- [ ] 推进强弱是否符合本书已建立的题材、兑现节奏与对标，而非套固定通用字数
- [ ] 兑现或高潮之后，是否允许短暂低压和小而可见的收益，而非机械立即加危机？

### 信息传递
- [ ] 没有大段设定说明文
- [ ] 信息跟着冲突走（通过事件传递设定）
- [ ] 设定量可控（一章不超 3 个新概念）

### 场景检查
- [ ] 场景有目标（人物要什么）
- [ ] 场景有阻碍（什么挡着）
- [ ] 场景有变化（结束后跟之前不同）
- [ ] 心理段写的是新判断、误判或决定，不是反复翻译同一情绪
- [ ] 删掉某段后，事实、因果、声口、关系或情绪延续都没有损失，才删

### 章尾
- [ ] 有危机/决定/发现/反转中的至少一个
- [ ] 不是总结式结尾
- [ ] 拉住读者翻下一页

### 语言
- [ ] 没有空洞的抒情段落
- [ ] 对话符合人物身份（不同人说话方式不同）
- [ ] 情绪词有落点（融进动作句、当对话提示语、结句后直接换事或接场内物件），不是接更多情绪
- [ ] 标题行以外没有章节/写作元信息：不得出现 `第[一二三四五六七八九十百千万两0-9]+章|上一章|上章|前一章|本章|这一章|前文|后文|伏笔|细纲|读者` 这类词；需要承接前文时改成角色能感知的事件锚点或相对时间；故事内真实阅读/讨论“第X章”或真实读者身份语境除外

### 连载连续性
- [ ] 没有遗忘之前的承诺/伏笔
- [ ] 没有突然塞入大量新设定
- [ ] 主角行为符合人设，反派逼格匹配当前阶段
- [ ] 对照本章批准细纲核对新增物：闲话、即时反应和服务既有情节点的微连接不算；写了要报：本章写出的新关系、承诺、后续义务要在申报表里列出，由主会话处置；只有与细纲或已登记事实冲突的才是必须修

### 水（filler）检测
以下信号出现 = 可能水了：
- 全章对话没有任何新信息
- 同一情绪反复写，人物的理解和行动始终没变
- 大段场景描写不推进剧情、人物或氛围
- 角色回忆之前发生的事但没有任何新视角
- 删掉无损的流程细节 / 任务卡点 = 水；压缩或删除

## 二、五维评分

每个维度 0-100 分，根据评分结果选择精修办法。

### 维度 1：核心一致度
检查：关键冲突、关键行动、人物动机是否前后一致。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 人物动机突然改变无铺垫 | 必须修 | 补充动机转变的触发事件 |
| 核心冲突前后不一致 | 必须修 | 回溯修改冲突设定 |
| 关键行动与人物性格矛盾 | 必须修 | 调整行动或补充解释 |
| 次要矛盾遗忘 | 建议看 | 回收或弱化 |

### 维度 2：表达
检查：句式和措辞是否套路化。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 检测器 blocking 命中 | 必须修 | 按检测器那条提示改写 |
| 同一句式重复出现 | 建议看 | 按功能合并或改写 |
| 描写过于文学化（辞藻堆砌、书面腔、比喻成串） | 建议看 | 改为口语化/动作化，不切成三五字短句串 |

### 维度 3：格式一致度
检查：段落是否按戏剧单元/镜头自然断开，主语/角色名节奏是否自然，开头结尾格式是否统一。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 机械按字数切段或主语过密 | 建议看 | 按戏剧单元重排段落，段首点名、段中代词/省略、关键转折再点名 |
| 章节字数偏离目标 | 建议看（长篇欠字交作者定） | 先核对情节点是否都写到；都写到就不为字数加戏，超字最多净删一次；去AI味已有正文时不得新增剧情 |
| 格式混乱（对话/描写不统一）| 仅提示 | 统一格式 |

### 维度 4：可读性
检查：是否有啰嗦、AI 腔、空泛总结、套路修辞。

| AI 腔特征 | 如何识别 | 如何修复 |
|-----------|----------|----------|
| 空泛总结 | 「他终于明白了」「一切尽在不言中」 | 删掉，用行动代替 |
| 套路修辞 | 「命运仿佛在和他开玩笑」 | 删掉或换成具体描述 |
| 比喻堆叠 | 连续多处「像/好像/仿佛/如同」，每个画面都靠比喻解释 | 只留最有叙事功能的少数比喻，其余改成动作、物件、声音或后果 |
| 空转情绪句 | 「他感到一阵悲伤」，无落点 | 删，或写他此刻做不成的事；直写本身不算缺陷 |
| 心理描写空转 | 内心独白无新信息、重复同一情绪或复述读者已知 | 只压缩空转部分；带新信息、决断或情绪转折的独白不按句数压缩 |

### 维度 5：逻辑连贯
检查：句间/段间是否通顺，有无设定冲突。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 设定前后矛盾 | 必须修 | 查找并统一设定 |
| 时间线错误 | 必须修 | 标记时间线并修正 |
| 角色信息不一致 | 必须修 | 建立角色档案对照 |
| 因果链断裂 | 建议看 | 补充过渡 |

### 精修办法

| 主要问题 | 办法 |
|----------|------|
| 核心一致度低 | 围绕核心冲突重写相关段落 |
| 字数超标或卡点无意义 | 删减不推动剧情的内容，保留卡出的变化 |
| AI 腔重 | 按检测器提示改写，不逐词替换；要完整去味走 `/story-deslop` |
| 小问题多 | 打磨语言细节 |
