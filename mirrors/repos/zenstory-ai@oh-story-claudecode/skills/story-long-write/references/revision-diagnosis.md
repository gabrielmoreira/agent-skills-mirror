# 回炉诊断：从症状找原因

作者只说读者反应或感受（「中间拖了」「读者说主角憋屈」「追读掉了」「卡住写不下去」），没指出具体改哪儿时读本文件。按症状挑出最可能的一两条原因，对照卷纲、细纲和正文找出问题章，列给作者选；作者选定后回 workflow-revision.md 逐章改。问题出在选材或剧情设计时，回设定或大纲改，不只润句子。只改一场戏的写法不读本文件。

## 症状对照

| 作者或读者说 | 先查 | 常见原因 | 改法 |
|---|---|---|---|
| 拖、水、不知道这几章在干嘛 | 每章有没有期待点或爽点；剧情期待、每章甜头、新鲜感哪项断了 | 上一个期待兑现了，下一个还没立起来；兑现拖得太久；过渡章没有在推进的线 | 兑现前一两章埋下下一个目标；过渡章至少留一条在推进的线；拖太久的兑现前移；砍掉不服务核心梗的支线。急救四选一：主角得知反派的新动作、计划外的意外、配角陷险、超出预期的收获 |
| 爽不起来、「就这？」 | 兑现章前后的压与放 | 压得不够或放得太轻 | 兑现前补一处压力或代价，兑现时写足旁人和局面的变化 |
| 「又是这一套」 | 最近几个单元的核心梗 | 同一个梗连着几次没有变化 | 按 outline-methods.md「剧情单元设计」重构：保留读者要的情绪和功能位，人物、场景、事件、手段全换 |
| 换地图后没意思了 | 新地图前几章 | 旧期待跟着旧地图一起丢了 | 让一条旧目标、旧关系或旧仇跨地图延续 |
| 变味了、不是想看的 | 本单元爽点满足的是哪种需求；对照题材卖点和本书卖点 | 卖点偏移：爽点偏到别的题材的卖点上，就是偏题 | 拉回开书承诺的那种情绪 |
| 主角憋屈、毒、圣母 | reader-contract-and-progression.md「契约四问」 | 叙事立场没站在主角一侧；主角因可避免的蠢事闯祸再由别人收拾；连着几次打破读者期待 | 补主角的筹码、因果权或结算；按题材契约判断，不一刀切成「主角不能吃亏」 |
| 目标有了但读者不在乎 | 目标有没有变成期待 | 只写了角色要做什么，没写达成后会怎样、过程有什么看头 | 写清得失和落差；爽文读者知道主角会赢，看点放在怎么赢 |
| 卡文，不知道下一步 | 题材、金手指、主角身份 | 三者对不上，循环转不起来；升级后没给新挑战 | 先把三者对齐，再按 outline-methods.md「题材单元循环」选循环；每次提升后马上给新目标。也可倒推：想让某个关系或局面成立，问它要什么前提（要房东租客关系→家里得有空房→家境和压力从哪来），每推一步都可能长出新剧情点 |
| 没人看，自己也说不清好坏 | 写给谁看、他们想看什么、本书给了哪些 | 三问有一问答不上，或题材选错 | 这是定方向的问题，回 workflow-setup.md Phase 1 或先扫榜，不靠改章解决 |
| 开头留不住人 | 前 3 章 | 开局类型、三基点或背景顺序出了问题 | 按 opening-design.md「开篇落笔」重写；开局类型或三基点章位本身选错时，先按「开篇规划」改细纲 |

## 参考同类书重排一段剧情

某段剧情立不住、想借同类书的写法时：先写清这段要解决的矛盾和目标情绪；在主对标的 `剧情/情绪模块.md` 或同题材书里找同类矛盾，只取情绪链和功能位（谁压、谁翻、读者在等什么），按 workflow-volume.md「对标节奏迁移」把人物、场景、事件全换成本书的；改完核对动机、因果和兑现能否接上前后章。
