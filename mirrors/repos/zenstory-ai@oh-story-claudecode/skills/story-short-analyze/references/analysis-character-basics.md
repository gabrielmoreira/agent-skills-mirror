# 源文角色基础分析标尺

> Stage 5 对照人物的目标、动机、行为与叙事功能。

## 用作拆文标尺时

先记录源文中可定位的行为，再用下列模型解释其作用。卡片括注保留写作示例，只填已知信息，未写明的填“未交代”；其中的特征和数量不构成源文合格条件。

---

## 决策路由

| 你在分析什么 | 用这个模板 | 见哪个章节 |
|------------|-----------|-----------|
| 主角 | 主角卡模板 | 第1节 |
| 配角 | 配角卡模板 | 第2节 |
| 反派 | 反派层级表 → 反派建立四要素 → 反派性格四步法 | 第3节 |
| 角色动机 | 动机链模板 → 动机冲突类型 | 第4节 |
| 角色塑造/深化 | 塑造方法速查（四层法/执念法/重复点/分层展示等） | 第5节 |
| 主角特殊问题 | 逼格/成长/红线/调子太高/身份与金手指 | 第6节 |
| 反派塑造深化 | 反派渲染/人设主角化 | 第7节 |

## 第1节：主角卡

### 填空模板

```
姓名：
性别：
角色定位：（一句话说清主角在故事中的功能）
身份标签：（如：废柴大学生、前特种兵、落魄皇子）
外貌特征：（3-5 个关键词，要有记忆点）
  例：瘦高、总穿旧夹克、左手有疤、眼神懒散
性格关键词：（3-5 个，必须有矛盾面）
  例：嘴毒心软、看似冷漠实则护短、冲动但有底线
核心目标：（全书终点想达成什么）
核心动机：（必须达成的理由——情感驱动，非理性驱动）
致命弱点：（让角色犯错的性格缺陷，非能力缺陷）
口头禅/标志动作：（让读者秒认的标签）
```

### 设计要点

- 区分目标与动机，说明角色为何在意这个目标；情感、利益与信念都可能构成动机
- 弱点是否影响关键选择，还是只存在于人物介绍中？
- 外貌、口头禅或动作如何帮助辨认人物？没有这些标签时，人物是否仍有辨识度？

## 第2节：配角卡

### 填空模板

```
姓名：
性别：
角色功能：（导师/盟友/情报源/牺牲品/镜像对照）
与主角关系：
核心特质：（1-2 个关键词）
标志性特征：（一句话让读者记住）
退场方式：（何时/如何退出故事）
```

### 设计要点

- 记录配角对因果、情绪、关系或氛围的作用
- 退出故事后是否留下尚未处理的承诺或关系？
- 多人对白中，说话人和关系是否清楚？不按人数直接判定优劣

## 第3节：反派设计

### 3.1 反派层级表

根据对手承担的冲突范围比较层级，不按章数套用长篇模型。

#### 小反派（局部冲突）

| 维度 | 要求 |
|------|------|
| 功能 | 单个小弧线的障碍 |
| 设计 | 1-2 个鲜明特征即可（嚣张/贪财/欺软怕硬） |
| 退场 | 被打败或被揭穿，干脆利落 |

#### 中等反派（主要冲突的一段）

| 维度 | 要求 |
|------|------|
| 功能 | 一段主要冲突的对手 |
| 动机 | 何种目标、利益或信念促成对立 |
| 手段 | 武力/权谋/资源 |
| 逼格 | 已有行为如何证明威胁，给主角造成什么损失 |
| 退场 | 被主角正面击败，要有爽感 |

#### 大弧Boss（贯穿多段冲突）

| 维度 | 要求 |
|------|------|
| 功能 | 代表一个阶段的核心矛盾 |
| 人弧 | 完整的人物弧线，有自己的目标和逻辑 |
| 冲突 | 与主角有理念冲突（不只是利益冲突） |
| 对决 | 是否迫使主角改变解法或承担代价 |
| 侧面 | 是否呈现对立之外的特质，其作用是什么 |
| 退场 | 有仪式感的终战 + 有余味的落幕 |

#### 最终Boss（全文核心对手）

| 维度 | 要求 |
|------|------|
| 功能 | 全文核心矛盾的具象化 |
| 伏笔 | 回查前文如何建立其影响 |
| 对立 | 与主角的目标/动机直接对立，代表故事主题的反面 |
| 实力 | 优势如何限制主角，主角凭什么应对 |
| 信念 | 言行能否由自身信念或利益解释 |

### 3.2 反派设计铁律

- 对手的判断与能力是否使主角的胜利具有分量？
- 行为能否由对手的经历、利益和已知信息解释？
- 失败来自人物选择、条件限制，还是突然丧失原有能力？

### 3.3 反派建立四要素

对照源文建立威胁的方式：

1. **实力展示**——何处展示实力或手段
2. **动机可信**——从反派视角看行为说得通
3. **真实威胁**——造成了什么损失或行动限制
4. **终极意图时机**——何时揭示目的，前文是否支持

### 3.4 反派性格确立四步法

| 步骤 | 操作 |
|------|------|
| 1. 反派也有梦想 | 在反派眼中他是自己故事的主人公 |
| 2. 挖掘创伤性过去 | 谁抚养他？谁爱他？谁伤害他？他避免什么痛苦？ |
| 3. 磨练性格缺陷 | 遭遇逆境时不调动积极特质，而是磨练缺陷——"优势"本身就是致命缺陷 |
| 4. 反派是主角的镜子 | 长处、弱点或价值取向的差异如何形成冲突 |

### 3.5 反派渲染分量的关键

- 障碍从反派人设上来，而不是故意给主角制造障碍
- 反派渲染公式：明确动机 → 动机驱动行为 → 行为形成障碍 → 障碍强度来自反派分量
- 对手强势时，检查主角的破局条件是否在前文建立

## 第4节：动机设计

### 4.1 动机链模板

```
起因（Cause）    → 角色经历了什么
意图（Intent）   → 角色想做什么
约束（Constraint）→ 什么在阻碍他
风险（Risk）     → 失败的代价是什么
```

**示例**：
```
起因：母亲被仇家杀害
意图：找到凶手并复仇
约束：凶手是当朝权臣，主角只是平民
风险：复仇失败会被灭门，复仇成功会失去所有现有生活
```

### 4.2 动机链设计要点

- 起因能否定位到具体经历或事件？
- 约束如何限制选择，或被主角突破？
- 风险涉及什么重要事物，文本如何使其可信？
- 动机变化是否有触发事件与行为证据？

### 4.3 动机冲突类型

按下表识别角色的内心挣扎，可同时存在多种冲突：

| 类型 | 定义 | 示例 |
|------|------|------|
| 目标 vs 道德 | 想做的事和应该做的事冲突 | 复仇但不想伤及无辜 |
| 情感 vs 利益 | 感性和理性的拉扯 | 知道对方不可靠但放不下 |
| 短期 vs 长期 | 眼前利益和远大目标的矛盾 | 妥协保命 vs 坚持原则赌未来 |
| 自我 vs 他人 | 个人需求和他人期望的冲突 | 想过平静生活但背负家族使命 |

## 第5节：角色塑造方法速查

### 5.1 角色塑造核心原则

**主角行为三个观察面**：
1. **可理解性**——文本是否交代选择的原因
2. **共鸣**——哪些处境或情感可能使读者代入
3. **价值判断**——文本让读者认同、质疑还是疏远主角；理解不等于赞同

**展示与概述**：分析目的、行动和态度分别由行为、对白、独白还是旁白传递，以及详略是否适合当前场景。

### 5.2 展示人物特质的方法

| 方法 | 操作 | 示例 |
|------|------|------|
| 敏感性 | 触碰弱点，看反应方式 | 惊慌失措/匆忙逃跑/转移注意力=不同性格 |
| 逃避 | 展现回避行为暗示弱点 | 角色的"不做什么"比"做了什么"更揭示深层性格 |
| 先正后缺 | 先展示吸引人特质，再揭示缺陷 | 读者先喜欢角色，才能容忍缺陷 |

### 5.3 四大性格属性

| 属性类别 | 定义 | 设计要点 |
|---------|------|---------|
| 道德属性 | 是非信念 | 影响其他性格形成 |
| 成就属性 | 推动达成目标 | 与道德属性一致，服务目标 |
| 互动属性 | 与人交流方式 | 数量最多的积极特质 |
| 身份属性 | 身份认同感 | 定义个性的基本组成部分 |

选择技巧：以其中一个特质为主要特质，其他为辅。

### 5.4 角色塑造四层法

| 层次 | 方法 |
|------|------|
| 移情作用 | 开头不要太多角色，先让读者了解主角并产生期待 |
| 最小特征（标签） | 主角由内而外塑造，配角由外到内塑造（贴标签） |
| 角色的不真诚 | 所说与所想、举动与态度是否形成反差；日常和生死关头可暴露不同特质 |
| 角色的聚光灯 | 不同角色如何分享叙事焦点，是否影响核心人物和主线的清晰度 |

### 5.5 人物塑造与人物真相

| 层面 | 定义 | 示例 |
|------|------|------|
| 人物塑造（显型） | 读者第一眼看到的特质 | 外表青春可爱的萝莉 |
| 人物真相（隐性） | 角色内在的真实面貌 | 实际上是冷血杀手 |
| 价值取向（内隐） | 关键选择时起决定作用的价值观 | 在道义与野心间选择野心 |

观察价值取向何时通过选择显现；真相揭示的效果取决于前文期待和后续空间，不以越晚越好。

### 5.6 人设分层展示法

| 层次 | 操作 |
|------|------|
| 第一层 | 告诉读者类型模型（萝莉/御姐/少妇） |
| 第二层 | 贴特点标签（胸大/腿长/小麦色皮肤） |
| 第三层 | 为性格找原因（家庭/内在冲动） |
| 第四层 | 打破——可爱天然呆其实什么都知道，人设立刻升华 |

重复标签是否形成记忆点，还是只复述已知信息？

### 5.7 人物经历三线时间法

| 时间线 | 内容 |
|--------|------|
| 过去 | 身世背景、遭遇变故、性格成因 |
| 现在 | 与主角的关系定位、当前互动模式 |
| 未来 | 制造变强动力或危机（老师被劫/女主被抓/反派揭底） |

### 5.8 配角执念设定法

快速让读者认同支线配角：

- 给角色一个执念 → 所有行为/爱好/性格围绕执念展开
- 不需要每次贴合执念，只要不写与执念冲突的东西，关键时揭示即可
- 过于极端的执念 → 加入"亲民"小细节 → 便于读者认同
- 适用：支线配角，不适合频繁出现的主要配角

### 5.9 人物行为重复点设计

观察同一行为特质在短篇中的有限复现：

- 抓住一个人物行为特质反复写
- 构建方法：确定读者喜欢什么类型 → 具体化为行为 → 不同场景重复
- 人物看点 + 核心看点 = 层次感，两者循环产生差异化
- 反派/配角也需要重复看点，能让人爱上的反派会增加读者新鲜感

### 5.10 围绕人设写行为

对照行为、语言和思维的一致性；出现偏离时，回查处境、信息和动机是否变化，不替源文补理由。

### 5.11 人推事件 vs 事件推人

| 驱动方式 | 特点 |
|---------|------|
| 人推事件 | 情节是人物性格/动机/选择的自然结果，深化人物弧光 |
| 事件推人 | 外部事件打破平衡，迫使暴露真实自我 |

区分人物主动选择与外部事件逼迫，说明两者如何衔接。

## 第6节：主角特殊问题

### 6.1 主角逼格

- 记录能力、判断或态度如何建立人物吸引力
- 检查内心戏和粗口是否符合人物、提供新信息
- 软弱、失败或失态可能服务人物塑造，须结合目标情绪判断

### 6.2 主角的成长

- 成长不只体现在实力上，更体现在心智和选择上
- 成长由哪些事件和选择体现，是否依赖独白解释？
- 稳定人设也可承担故事，不因没有成长弧线直接判为缺陷

### 6.3 主角红线

下列特征可能影响部分爽文读者的接受度，须结合源文承诺与反馈判断：

| 特征 | 可能的影响 |
|------|------|
| 无代价地原谅伤害 | 可能与反击承诺冲突，须检查人物动机 |
| 只呈现战斗能力 | 若缺少选择与代价，可能难以理解人物 |
| 恶人主角 | 需区分理解、认同与批判视角 |
| 因判断失误或过度利他犯错 | 检查当时的信息与后果，不能只贴性格标签 |
| 自暴自弃 | 可表现失落或转变，须看其在全文中的作用 |

### 6.4 主角调子起太高怎么办

**危害信号**：
- 失去成长空间——能力/地位/资源触达天花板
- 剧情缺乏张力——陷入"砍瓜切菜"的重复循环
- 读者失去追更动力

**化解方法**：
- **压势不压人**——压低气势和期待，但不打压主角本身的能力和尊严
- **留出维度差距**——即使某方面很强，总有其他维度是短板
- **超额收获法**——看似收获很大，经主角盘算后发现更大

### 6.5 主角开篇立人设

- 定位开篇建立人设的选择、反应或处境
- 比较智斗、行动与旁观各自交代了什么人物特征
- 代入效果须由具体文本或反馈支持，不由能力强弱推定

### 6.6 主角的两个身份与两个金手指

| 维度 | 定义 | 作用 |
|------|------|------|
| 显性身份 | 社会身份/职业+状态 | 形成可见的身份关系与冲突 |
| 隐性身份 | 不凡的身世来历 | 汇集中后期矛盾 |
| 显性金手指 | 系统/玉坠/重生记忆 | 改变关键行动条件 |
| 隐性金手指 | 主角性格 | 让主角与众不同的就是金手指 |

**观察重点**：特殊能力如何显露人物选择；社会身份、身世、能力与性格是否相互支持，或形成有依据的反差。

### 6.7 性格单一缺陷型主角+动物伙伴体系

性格单一或淡漠的主角可能借动物伙伴补充对白、反应与行动能力。若源文采用此模式，观察伙伴是否各有功能，不预设数量。

| 伙伴类型 | 功能 |
|---------|------|
| 蠢萌犯二型 | 负责搞笑，主角不宜吃瘪但动物可以 |
| 聪敏嘴贱型 | 负责嘴替，主角不该说的话由它说，保持主角逼格 |
| 耿直蠢笨型 | 负责反差萌 |
| 奇特能力胆小型 | 负责能力补充 |

### 6.8 核心情绪与表达欲平衡

- 需求的内核不变，变的只是形式
- 写完一段剧情后，站在读者角度审视是否偏离核心梗
- 主角付出与收获是否回应了前文承诺
- 表达欲旺盛时最容易偏离——要主动检查

### 6.9 压势不压人：矛盾的正确来源

**错误做法**：让反派莫名其妙针对主角，背后逻辑站不住脚。

**另一种来源**：对手追求自己的目的，行动波及主角。与直接针对主角的冲突比较时，分别检查动机与因果。

**矛盾链条**：反派目的 → 压制主角所在群体（压势） → 主角推翻 → 底层依旧麻木 → 主角改变路径 → 新冲突自然产生

核心：所有人被自己想要的利益驱动，背后是三观不同，更深是成长环境，最深层是世界观。

## 第7节：反派塑造深化

### 7.1 反派塑造核心原则

- 对手的价值判断是否足以解释其关键行为
- 同样的外部事件发生在不同人身上产生不同变化——外因与内因共振
- 区分外部遭遇与人物对遭遇的解释、选择

### 7.2 反派人设主角化写法

对手也可用自身目标与选择形成行动线。比较新旧角色互相衬托的方式，以及能力变化是否有依据，不外推长篇换地图循环。

## 质量检查清单

完成分析后逐项回查证据；卡片中的写作建议不作为验收条件：

### 主角检查

- [ ] 目标与情感、利益或信念动机有对应证据
- [ ] 已说明弱点如何影响选择；未出现时如实记录
- [ ] 已定位外貌、动作、语言或选择中的辨识特征
- [ ] 已分析失败、失态和价值选择如何影响读者判断
- [ ] 核心目标与全文主线的关系清楚

### 配角检查

- [ ] 有明确功能（导师/盟友/情报源/牺牲品/镜像对照）
- [ ] 核心特质 1-2 个关键词能概括
- [ ] 有标志性特征让读者记住
- [ ] 退场及遗留承诺已记录
- [ ] 多人对白的说话人与关系清楚

### 反派检查

- [ ] 已按冲突范围识别对手功能
- [ ] 已定位威胁成立的能力或手段
- [ ] 动机从反派视角说得通
- [ ] 已记录对主角造成的实际损失或限制
- [ ] 没有降智送赢
- [ ] 已区分利益冲突与理念冲突
