# 源文角色设计分析标尺

> Stage 5 对照反差、人物功能、关系推进与代入感。

## 用作拆文标尺时

先定位源文行为，再用模型解释作用。下列分类可帮助描述不同写法，不要求每个角色具备全部特征；未写明的内心和动机不补写。

## 三层标签反差人设法

### 三层结构

| 层级 | 名称 | 含义 | 示例 |
|------|------|------|------|
| 第一层 | 身份标签 | 外界看到的身份 | 豪门弃妇 |
| 第二层 | 表现标签 | 角色展现给外界的行为 | 隐忍不发、逆来顺受 |
| 第三层 | 内核标签 | 角色真正的内心 | 冷静、有计划、步步为营 |

### 执行指令

1. 从源文填写身份、表现与内核，区分外界认知和已证实的内心
2. 对照三层是否一致，以及哪些行为支持差异
3. 定位揭示反差的时刻，说明它如何改变读者判断
4. 没有反差时如实记录；反差不直接等于人物立体
5. 行为对照示例：

```
身份标签：豪门弃妇
表现行为：被骂不还口，被赶不反抗
内核行为：悄悄录音、收集证据、提前转移财产
```

---

## 三层标签行为反差进阶

关系亲密后，人物可能因更在意对方而难以维持早期的调戏或冷漠。这是行为变化的一种模式，与身份、表现、内核三个标签维度分开记录。

| 关系阶段 | 可做行为 | 不可做行为 |
|----------|---------|-----------|
| 身份标签期（陌生） | 调戏、冷漠、保持距离 | — |
| 表现标签期（熟悉） | 继续之前的行为模式 | — |
| 内核标签期（亲密） | 展露真实自我 | 之前的调戏/冷漠反而做不出来了 |

### 执行指令

1. 定位关系变化前后的行为
2. 检查改变是否由共同经历或态度变化触发
3. 若人物从敢于调戏变为不敢表白，说明其在意和顾虑如何显现
4. 行为保持不变也可能成立，须按源文证据解释

## 人设关联分层（强/中/弱关联）

| 层级 | 定义 | 功能 | 数量要求 |
|------|------|------|---------|
| 强关联 | 直接改变主线选择或结果的设定 | 推动人物碰撞、剧情推进 | 记录实际设定，不设配额 |
| 中关联 | 通过配角或支线间接影响主线的设定 | 提供功能性和辨识度 | 同上 |
| 弱关联 | 不改变主要因果的个人偏好 | 增加真实感和记忆点 | 同上 |

### 执行指令

1. 把主角的实力、钱财、人脉、背景等影响剧情走向的属性归为强关联
2. 说明这些属性在哪个节点改变了因果
3. 把"喜欢吃蛋糕""爱好看美女"等归为弱关联，仅用于丰富人设
4. 确保弱关联不喧宾夺主——强关联才是延伸剧情的核心

---

## 人设执行规则

区分人物资料与人物作用：身高、外貌、家庭背景是资料；目标、性格与价值选择如何驱动行为，才是分析重点。资料也可能通过身份关系或限制条件参与因果。

## 配角功能化设计

### 核心原则

1. 定位配角能力、特质与情节的联系
2. 区分助力、对照、阻碍与独立行动，不预设配角只能服务主角

### 复合型配角——白手套角色

| 功能 | 说明 |
|------|------|
| 替主角说话 | 凡是主角不适合说的话，他来说 |
| 替主角发狠 | 凡是主角不应该发的狠，他来发 |
| 绝对维护 | 对侵犯主角利益的人坚决反击 |
| 粗中有细 | 将反派密谋录音再播放，取得大众支持 |
| 适时搞笑 | 不断输出正反馈，缓解紧张情绪 |

**观察重点**：该配角承担了主角不便直接完成的哪些言行，是否仍有自身动机。

### 立体人物 vs 扁平人物

1. 先看角色功能及所需篇幅，再比较人物展开程度
2. 信息较少可能保留神秘感，也可能造成动机缺失，须结合效果判断
3. 复杂化、洗白与实力变化是不同维度，不能直接等同
4. 功能集中与人物立体可以并存

### 人设反差六维度法

| 反差对 | 操作 |
|--------|------|
| 表面性格 vs 内在性格 | 笑面虎/刀子嘴豆腐心 |
| 外表形象 vs 表面性格 | 看着凶实际软 |
| 外表形象 vs 内在性格 | 看着柔实际狠 |
| 身份 vs 生活方式 | 豪门子弟住地下室 |
| 身份 vs 爱好特长 | 杀手擅长插花 |
| 身份 vs 内在性格 | 军人内心文艺 |

### 执行指令

1. 识别配角实际承担的功能
2. 从六维度中定位有行为支持的反差
3. 分析配角与主角如何分享焦点
4. 说明简略或深入展开各自带来的效果

---

## 配角人设逻辑

1. "正戏反写"——看似正面的行为背后有反派动机
2. 配角情感保护壳：看似冷漠无情，实则有深层情感驱动
3. 避免崩人设：角色的行为选择必须符合已建立的人设逻辑
4. 题材标签只能提供比较对象，人物是否成立仍看具体行为

---

## 凸显人设的方法

### 执行指令

1. 定位角色最突出的特质及其文本证据
2. 比较行动与旁白各自传递了什么信息
3. 说明反差如何改变关系、选择或读者判断
4. 有反馈时再判断读者是否接受该反差

---

## 高情商/聪明人桥段写法

### 执行指令

1. 定位察言观色、临场应变或接话的具体场景
2. 说明人物如何识别需求、调整表达并改变局面
3. 若存在“预期尴尬—成功化解”的反转，回查双方筹码与信息
4. 没有反转时，直接分析沟通效果

---

## 用配角做期待枢纽（人物扣）

### 执行指令

1. 检查某个配角是否同时承载多个期待
2. 记录主角与其互动如何引出下一步行动
3. 比较有限几次互动是否带来新信息、选择或后果
4. 角色退场时，分析关系损失与实际收获，不预设必须获得补偿

---

## 群像写作法

### 执行指令

1. 分析各角色出场的因果、情绪或氛围作用
2. 区分引路人、对手、伙伴等关系功能
3. 比较说话风格和行为是否足以区分人物
4. 说明行为与旁白各自如何建立人物特征

### 配角脸谱化描写

1. 抓住 1-2 个突出特点做鲜明标签（口头禅/标志性动作/极端性格）
2. 标签化让读者迅速记住，不过多占用笔墨
3. 功能性配角要有明确功能：推动剧情、衬托主角、提供信息

### 角色使用的节奏

1. 比较角色每次出现的间隔、信息与功能，不设通用章数
2. 人气与读者兴趣须有反馈支持，不能仅凭分析者喜好判断
3. 观察新角色是否借已有关系被引入，以及这种联系带来的期待

### 角色池编织法

1. 以角色带角色：女主讨喜 → 写女主爸妈/姐姐/闺蜜 → 喜爱延续到新角色
2. 像网一样编织下去 → 很快就有取之不尽的角色池
3. 每个新角色贴一个标签，个个鲜明

## 向人设深化法

### 执行规则

区分新鲜感主要来自事件还是人物：

| 条件 | 优先方向 | 执行动作 |
|------|------|------|
| 主线已经复杂、多势力、多反转 | 向人设深化 | 保持故事结构简单，在人物欲望、反差、关系互动上制造新鲜感 |
| 主线过直、人物已经鲜明但事件不足 | 向故事深化 | 增加阻碍、目标变化、信息差或代价，不新增无功能角色 |
| 短篇/轻量篇幅 | 向人设深化 | 用 1-2 个强人设标签驱动冲突，不铺大世界观 |
| 关键转折或高潮 | 两者结合 | 对照事件变化与人物关系变化如何相互促成 |

### 执行步骤

1. 概括事件结构，区分熟悉模式与独有变化
2. 定位人物欲望、反差或关系带来的趣味
3. 说明几次互动如何改变后续事件，而非只重复效果

### 互动链示例（下列章位仅表示顺序）

- 第1章：主角装逼 → 师叔更迫切
- 第2章：师叔逼女生 → 恋人帮着威逼利诱
- 第3章：女生靠近主角 → 恋人在暗地暗爽
- 第4章：女生回去哭诉 → 恋人假意安慰一边暗爽
- 第5章：复命领赏 → 女生发现恋人对奖赏没那么高兴

## 人物塑造技巧

### 女性角色塑造（男频）

1. 观察外貌、身份标签与实际行为分别如何建立吸引力
2. 类型意象可能唤起刻板印象，须检查文本是否支持或改写它
3. 外貌描写的篇幅是否承担视角、关系或情绪功能？
4. 极端性格与无条件付出是否有动机，并承担后果？
5. 行为变化能否由经历和选择解释？

### 主角可以犯错但需把握尺度

| 可原谅 | 不可原谅 |
|--------|---------|
| 因不可抗力或信息差导致的错误 | 因蠢、因圣母心泛滥导致的错误 |
| — | 与实力不匹配的错误（斗帝强者因小人物犯蠢） |

### 主角人设内外反差

1. 可设计表面与内心的反差（如表面色牛实际内心孤僻）
2. 反差感增加角色深度和趣味，提供丰富的情节冲突可能性

### 反派的本质

区分立场对手与道德反派，分析其自身目标、利益和判断依据。

### 渣人设写法

1. 开头就清晰传达主角人设，穿越前后保持一致
2. 避免"又当又立"——前面没描写主角是老色皮后面突然追女读者反感
3. 明确人设 = 筛选接受这种人的读者 = 预期管理

---

## 人物记忆点法

1. 定位使人物可辨认的性格、语言、动作或选择
2. 比较突出标签与多次细节积累各自的作用
3. 日常聊天若无主线变化，仍可检查其人物和关系功能

---

## 金手指绑架人设法

### 执行指令

1. 金手指不只是给主角超能力，目的是让主角的性格合理化
2. 用金手指规则绑架行为 → 配角反应自然塑造形象 → 不需要直接描写主角品格
3. 若产生道德认同，指出具体选择及其代价，不给爽感类型排高低

---

## 以梗为中心塑造人设

### 执行指令

1. 单一标签"杀伐果断""热血"太模糊 → 用具体梗来建设角色 → 读者产生强记忆点
2. 例：配角每次看到主角成功 → 羡慕嫉妒恨 → "你真该死啊" → 强记忆点+趣味性
3. 好人设+平平无奇的金手指+俗套套路 → 也能发挥意想不到的吸引力

## 九维人设框架

| 维度 | 内容 | 要点 |
|------|------|------|
| 基本信息 | 前身今世/外貌特征 | 从人物下手建立长期期待感 |
| 性格 | 反差人设 | 为成长弧线铺垫 |
| 爱好习惯 | 贪财/好色/杀人后超度 | 做强烈记忆点反复强调 |
| 人际关系 | 谁与谁有利益、权力或情感联系 | 关系复杂度是否仍可理解，每条联系是否参与选择 |
| 背景 | 家族/出身/成长环境 | — |
| 成长弧线 | 见下方三阶段 | — |
| 对比反差 | 恶人vs好人/医生救死扶伤→扛起枪杀人 | — |
| 价值观态度 | 不同身份地位看法不同 | 态度=行动目标 |
| 人物小传 | 典型重要故事 | 浓缩的生平经历 |

### 人物成长弧线（三阶段）

| 阶段 | 核心 | 对应 |
|------|------|------|
| 小我（幼年） | 虚构自己，想要成为他人眼中的我 | 动机 |
| 自我（青年） | 真实自己，夹在两者之间痛苦 | 态度 |
| 他我（成熟） | 别人眼中的自己就是追求的目标 | 价值观 |

情绪公式：满足（认同）→ 打击（同情）→ 怀疑（共鸣）→ 心痛（共情）

## 人设关系四阶段标签

| 阶段 | 了解程度 | 表现 |
|------|---------|------|
| 相遇（陌生人） | 只知道外表 | 警惕/保持距离/设防 |
| 相识（过客） | 初步了解不知底线 | 察言观色/阿谀奉承 |
| 相知（好哥们/闺蜜） | 知道秉性和底线 | 聊骚话/吐露心声/倾诉烦恼 |
| 相恋（爱人） | 了解内心伤疤 | 占有欲强/喋喋不休/任劳任怨 |

## 用职场思维理解网文关系结构

### 执行规则

学校、宗门、公司等组织可用层级、资源与合作关系比较；这只是组织冲突模型，不能概括所有网文。

### 共性与差异

| 共性维度 | 说明 |
|---------|------|
| 层级 | 任何环境中都有上下级关系 |
| 互助 | 同级之间的合作和互利 |
| 互害 | 同级之间的竞争和倾轧 |

| 差异维度 | 说明 |
|---------|------|
| 合作方式 | 不同环境合作模式不同 |
| 资源类型 | 不同环境争夺的资源不同 |
| 个体能力 | 主角的独特优势 |

### 执行步骤

1. 识别故事中的组织环境
2. 标注上级、同级、下级与对手
3. 追踪资源和权力如何产生冲突
4. 以源文内的关系变化和终局为边界，不外推换地图循环

## 代入感构建法

### 执行规则

- 检查目标、选择、情绪与后果之间的联系
- 现实逻辑、设定矛盾或视角混乱均可能影响代入，不能一律归因于节奏
- 实际读者反应需有评论或反馈支持

### 执行方法

| 方法 | 做法 | 效果 |
|------|------|------|
| 共情切入点 | 用日常生活常见事件 | 瞬间拉近距离 |
| 细节真实性 | 填充生活化细节 | 强化世界真实性 |
| 救猫咪情节 | 开头一个情节强调主角人设某方面 | 读者快速熟悉并代入 |
| 共情前提 | 让角色暴露真实一面（弱点/困境） | 读者产生保护欲 |
| 合理化虑点 | "缺钱"这类人人都懂的困境 | 天然共情 |

### 共情三层次

1. **表层共情**：经历类似
2. **深层共情**：情感类似
3. **认同感**：价值观一致

### 破坏代入感的行为（避免）

- 角色做出读者无法理解的选择
- 大段设定说明打断叙事
- 节奏拖沓导致情感链条断裂
- 主角三观与目标读者严重偏离

---

## 安全感与核心情绪把控

1. 不同题材的读者对安全感需求不同，先确认题材
2. 极道流等紧张感题材：安全感拉爆 = 危机感消失 = 核心情绪偏移——不要给主角找过强的靠山
3. 若靠山可随时解除危机，检查其限制与代价；确实使核心威胁失效时再指出问题
4. 精力有限时，情节始终是第一位的，世界观只是加分项

---

## 质量检查清单

完成分析后逐项回查，不将模型特征当成源文配额：

- [ ] 身份、表现、内核的判断是否各有文本证据
- [ ] 影响主线的设定是否在行动与后果中得到验证
- [ ] 人设是功能性设计还是只有外貌信息堆砌
- [ ] 配角是否有明确功能，是否抢了主角风头
- [ ] 角色辨识度来自哪些可定位特征
- [ ] 配角出场是否都有功能，没有无用水分
- [ ] 不同角色是否有不同的说话风格和行为特征
- [ ] 主角犯错的原因与后果是否交代清楚
- [ ] 对手的目标与行动逻辑是否有依据
- [ ] 人设言行是否前后一致，有没有崩人设
- [ ] 代入感情感链条是否连续，有没有被设定说明打断
- [ ] 助力的限制与代价是否保留了源文承诺的紧迫感
- [ ] 高情商桥段是否通过具体剧情展现，而非旁白夸赞
