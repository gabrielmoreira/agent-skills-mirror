
# 短篇成稿质量检查清单

## 目录

- [一、通用检查](#一通用检查)
- [三、短篇专项](#三短篇专项)

## 一、通用检查

### 开篇检查（前 300-500 字）
- [ ] 有钩子，能抓住注意力
- [ ] 不从天气/风景/日常开始
- [ ] 主角快速出场
- [ ] 卖点或危机可见

### 章节推进
- [ ] 有核心事件
- [ ] 局势有变化
- [ ] 不是水字数（删掉这章会影响理解吗？不会 = 水了）
- [ ] 任务卡点有用：卡住之后是否带来信息、情绪、关系、代价或伏笔变化？
- [ ] 推进了主线/关系/设定中的至少一项

### 信息传递
- [ ] 没有大段设定说明文
- [ ] 信息跟着冲突走（通过事件传递设定）
- [ ] 设定量可控（一章不超 3 个新概念）

### 场景检查
- [ ] 场景有目标（人物要什么）
- [ ] 场景若有阻碍，能看清它如何影响人物选择
- [ ] 场景有变化（结束后跟之前不同）
- [ ] 人物的感受与事件、选择或行动相连
- [ ] 没有可删除的段落

### 章尾
- [ ] 结尾落在变化上
- [ ] 有危机、决定、发现、反转、局部兑现或关系余波
- [ ] 审判句或预告指向具体人物与事件，无空洞升华
- [ ] 拉住读者翻下一页

### 语言
- [ ] 没有空洞的抒情段落
- [ ] 没有连续多段同一情绪
- [ ] 对话符合人物身份（不同人说话方式不同）
- [ ] 情绪词有落点（融进动作句、当对话提示语、结句后直接换事或接场内物件），不是接更多情绪

### 全文连续性
- [ ] 没有遗忘之前的承诺/伏笔
- [ ] 没有突然塞入大量新设定
- [ ] 伏笔有推进
- [ ] 故事引擎持续运转：核心问题推进，已揭示信息影响后续行动

### 注水检测
出现以下信号时复核叙事作用：
- 全章对话没有任何新信息
- 同一个情绪写了 3 段以上
- 场景描写超过 500 字但不推进剧情
- 角色回忆之前发生的事但没有任何新视角
- 连续 2 章以上没有冲突
- 删掉无损的流程细节 / 任务卡点 = 水；压缩或删除

### 五维评分标准

每个维度 0-100 分，根据评分结果选择精修策略。
严重度：critical、high＝必须修；medium＝建议看；low＝仅提示。

### 维度 1：核心一致度
检查：关键冲突、关键行动、人物动机是否前后一致。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 人物动机突然改变无铺垫 | critical | 补充动机转变的触发事件 |
| 核心冲突前后不一致 | high | 回溯修改冲突设定 |
| 关键行动与人物性格矛盾 | high | 调整行动或补充解释 |
| 次要矛盾遗忘 | medium | 回收或弱化 |

### 维度 2：表层重写度
检查：句式与措辞是否足够原创，避免套路化表达。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 照搬原句导致语气不自然 | medium | 只在确有 AI 腔时改写，正常原句可保留 |
| 大量使用 AI 标志词 | high | 替换为具体描述 |
| 同一句式重复出现 | medium | 变换表达方式 |
| 描写过于文学化（辞藻堆砌、书面腔、比喻成串） | medium | 改为口语或具体动作，相关动作连贯叙述，避免三五字碎句成串 |

### 维度 3：格式一致度
检查：段落是否按戏剧单元/镜头自然断开，主语/角色名节奏是否自然，开头结尾格式是否统一。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 机械按字数切段或主语过密 | medium | 按戏剧单元重排段落，段首点名、段中代词/省略、关键转折再点名 |
| 整篇字数不在锁定范围 | **high** | 先核对批准情节点是否写完整，缺了才补回原计划内容，不为凑字新增冲突、对话或独立事件；超字删不推动剧情的内容；去AI味已有正文时不得新增剧情 |
| 格式混乱（对话/描写不统一）| low | 统一格式 |

### 维度 4：可读性
检查：是否有啰嗦、AI 腔、空泛总结、套路修辞。

| AI 腔特征 | 如何识别 | 如何修复 |
|-----------|----------|----------|
| 空泛总结 | 「他终于明白了」「一切尽在不言中」 | 删掉，用行动代替 |
| 套路修辞 | 「命运仿佛在和他开玩笑」 | 删掉或换成具体描述 |
| 比喻堆叠 | 连续多处「像/好像/仿佛/如同」，每个画面都靠比喻解释 | 只留最有叙事功能的少数比喻，其余改成动作、物件、声音或后果 |
| 空转情绪句 | 「他感到一阵悲伤」，无落点 | 删，或写他此刻做不成的事；直写本身不算缺陷 |
| 心理描写空转 | 内心独白无新信息、重复同一情绪或复述读者已知 | 只压缩空转部分；带新信息、决断或情绪转折的独白不按句数压缩 |

### 维度 5：逻辑连贯
检查：句间/段间是否通顺，有无设定冲突。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 设定前后矛盾 | critical | 查找并统一设定 |
| 时间线错误 | high | 标记时间线并修正 |
| 角色信息不一致 | high | 建立角色档案对照 |
| 因果链断裂 | medium | 补充过渡 |

### 精修策略

根据五维评分结果，选择精修策略：

| 主要问题 | 策略 | 说明 |
|----------|------|------|
| 核心一致度低 | rewrite | 围绕核心冲突重写相关段落 |
| 字数超标 | compress | 删减不推动剧情的内容 |
| 无意义卡点 | compress | 保留卡出的变化，压掉流程 |
| AI 腔重 | de_ai | 替换禁用词、改写句式 |
| 小问题多 | polish | 打磨语言细节 |

## 三、短篇专项

### 虐爽节奏检查

虐爽题材检查虐点与爽点的分布，其他题材按本篇目标情绪判断：

```
理想分布：虐1 → 虐2 → 虐3 → 爽1(小) → 虐4 → 爽2(大)
禁忌分布：虐1 → 虐2 → 虐3 → 虐4 → 虐5（无爽点，读者流失）
禁忌分布：爽1 → 爽2 → 爽3 → 爽4（无铺垫，爽感疲劳）
```

检查规则：
- 每个场景或小节应改变风险、信息、关系、资源、决定、行动或读者理解之一，或让上一个选择的后果落地
- 压力可以来自任务、证据、等待、手艺、空间和关系，不把直接冲突当成固定字数配额
- 最大爽点放在前因汇合、主角选择和证据足以支撑的位置，并为后果留出篇幅；不按固定百分比挪动
- 结尾应有情绪落点、局部兑现或明确余波，不强制同一种收法

### 对话密度检查

| 检查项 | 通过标准 | 需复核信号 |
|--------|----------|------------|
| 对白功能 | 改变信息、策略、权力、关系或下一步行动 | 删掉对白后场景没有任何变化 |
| 无对白场景 | 由任务、物件、证据、空间、等待或手艺推动 | 只有解释和情绪复述，没有可见动作或新信息 |
| 对话节奏 | 话轮长度服从人物权力和现场压力 | 连续微型问答、换说法重复、每句都配动作标签 |
| 对白占比/条数 | 只作同题材、同平台样本的观察数据 | 不设跨题材通过阈值，不为抬高占比补对白 |

### 主角筹码与情绪检查（打脸/复仇文专用）

| 检查项 | 通过标准 |
|--------|----------|
| 主角的冷静是否可见？ | 通过取证、选择、延迟回应或资源调度体现；不强配端水杯、整理西装、转笔等标志动作 |
| 情绪失控是否成立？ | 次数和位置服从累积压力；失控必须改变行动、关系或代价，不按百分比禁用 |
| 主角与反派的反差来自哪里？ | 来自筹码、判断、行动后果或信息差，不强制反派歇斯底里 |
| 台词长短是否体现权力？ | 长短、打断、沉默和回避随现场筹码变化，不设固定比例 |
| 审判式对话是否必要？ | 只在提问能迫使对方选择、暴露矛盾或改变关系时使用，不设最低处数 |

### 证据链完整性检查（复仇/打脸文专用）

| 检查项 | 标准 |
|--------|------|
| 证据是否按判断变化释放？ | 每次释放都应改变行动或读者判断；完整证据链可在同一场景集中落地，不设次数 |
| 每个证据是否有铺垫？ | 前文必须埋过线索 |
| 反派反应是否有因果？ | 由其筹码、误判和损失决定，不重复“先得意再被打脸”模板 |
| 最终证据是否最致命？ | 最后一个证据要改变全局认知 |
| 是否需要"定时炸弹"证据？ | 仅在提前布局符合主角能力、时间线和取证条件时使用 |

### 追妻/情绪流雷区检查（女频情绪流专用）

| 雷区 | 自查 |
|------|------|
| 女主心死后还在照顾男主？ | 拉扯清零——心死后必须彻底抽离，不看不听不在意不照顾 |
| 男主只渣不苏？ | 没颜值/能力/地位的资本，读者只觉女主眼瞎，不会期待追回 |
| 回忆杀冗长？ | 大段回忆打断当下情绪，必须短而精、与当下场景一一对应 |
| 女主觉醒太晚？ | 全程虐到底读者弃文——最迟付费卡点前女主须彻底心死离开 |
| 男主醒悟太早？ | 女主没走就后悔，虐不透、火葬场没力度——须等女主抽离后再后知后觉 |
| 轻易破镜重圆？ | 伤太深却随便原谅，前期的虐全白写 |
| 反派降智无动机？ | 坏得没理由立不住，给个真实动机反而更戳人 |

### 读者期待与因果速查

> 悬念承接与收束见 `hooks-chapter.md`；AI 腔自检见 `short-deslop.md`。

| 检查项 | 标准 |
|--------|------|
| 爽文不爽 | 反击兑现前文承诺的具体后果，不只靠旁人震惊证明 |
| 压制无目的 | 困境带来代价、判断或行动变化，不反复压同一情绪 |
| 反派结局突兀 | 报应与此前行为、证据或主角选择有因果 |
| 经济/战力崩坏 | 设定前后一致，以普通人为锚点 |
| 女主/女配降智 | 人设正常可写，老套路别写 |
| 读者期待长时间不满足 | 交付新证据、误判修正或局部兑现，推进核心问题 |
| 主角行为不可理解 | 必须能理解、能共鸣 |
| 氛围被突兀梗破坏 | 氛围 > 突兀梗（乐子文除外） |
| 核心问题未兑现 | 终局回答本篇承诺；开放结尾也应有足够线索支撑判断 |
