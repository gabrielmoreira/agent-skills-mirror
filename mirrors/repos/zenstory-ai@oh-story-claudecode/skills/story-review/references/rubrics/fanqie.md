# 番茄小说 Quality Rubric

## 评分标准

下列阈值用于快节奏、强情绪写法的初筛，不代表平台算法；先对照本书题材与已定节奏。

| 指标 | PASS 标准 | FAIL 标准 |
|------|----------|----------|
| 开头吸引力 | 前 3 段包含冲突/悬念/钩子 | 前 3 段纯描写/背景介绍 |
| 读者留存 | 每章结尾有"翻页动力"（悬念/反转/新信息） | 连续 3 章结尾无翻页动力 |
| 题材匹配 | 内容符合标签类型（如甜宠/逆袭/重生） | 偏离标签类型超过 3 章 |
| 阅读节奏 | 段落便于手机阅读，节奏和信息量支撑核心卖点 | 机械切段或拖沓，信息不足以支撑阅读期待 |
| 情绪节点 | 每 1000 字有情绪起伏 | 连续 2000 字情绪平直 |
| 完读风险 | 前 3 章 Hook 有效，节奏不拖 | 前 3 章无 Hook 或连续拖沓；完读率须用实际数据验证 |

## 使用方式

- story-architect 用本表检查番茄题材的开局、节奏与情绪交付。
- 本表只作 advisory，不 blocking；具体判断须有原文证据。
