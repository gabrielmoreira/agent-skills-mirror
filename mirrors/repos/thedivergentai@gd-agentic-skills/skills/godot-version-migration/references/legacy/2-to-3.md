# Legacy: Godot 2.x → 3.x

Tier **B** — no official migrating-index tutorial. Primary structured community notes: [godot-migrationnotes](https://github.com/dploeger/godot-migrationnotes). Cross-check [docs changelog](https://docs.godotengine.org/en/stable/about/docs_changelog.html), [interactive changelog](https://godotengine.github.io/godot-interactive-changelog/), and archive docs ([2.1](https://docs.godotengine.org/en/2.1/), [3.5](https://docs.godotengine.org/en/3.5/), [3.6](https://docs.godotengine.org/en/3.6/)).

## Checklist (high signal)

- `engine.cfg` → `project.godot`
- `_fixed_process` → `_physics_process`; `pos`/`rot` → `position`/`rotation`
- `Globals` → `ProjectSettings`; prefer `$Node` paths
- Signals: present→past tense (`mouse_entered`, …); Control `input_event` → `gui_input`
- `KinematicBody2D.move` → `move_and_slide`
- Typed pools: `RawArray`→`PoolByteArray`, `Matrix3`→`Basis`, `Matrix32`→`Transform2D`
- `Patch9Frame`→`NinePatchRect`; `z`→`z_index`; opacity → `modulate.a`
- Audio buses rewrite; import dock; watch degrees→radians on some properties
- Avoid shadowing built-ins (`position`, `scale`, `name`, `filename`, …)

## Stabilize gate

Reach **latest 3.x** before the official 3→4 converter (requires Godot 3.0+).
