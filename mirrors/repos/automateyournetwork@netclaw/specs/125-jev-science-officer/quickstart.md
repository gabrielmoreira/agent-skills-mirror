# Quickstart

Select optional Jev Science Officer in installer; enable explicitly and enter key securely or set compatible endpoint. Defaults: $5/day and $0.25/task. Use operator settings to change caps; never embed key in a tool call or browser.

Call jev_status first (no inference charge). Border constructs questions from the current human request and referenced member observations, calls jev_evaluate and communicates concise support/challenge/influence. For private hosted evidence, prepare request, review exact disclosure and grant scoped consent through operator CLI before evaluation. One reconsideration allowed. Existing network write gates still apply.

Executable commands and verified live results are documented in [server reference](../../mcp-servers/jev-mcp/README.md) and [verification](verification.md). Missing trusted task context uses a conservative shared case; bind tasks through operator/runtime settings for separate case accounting.
