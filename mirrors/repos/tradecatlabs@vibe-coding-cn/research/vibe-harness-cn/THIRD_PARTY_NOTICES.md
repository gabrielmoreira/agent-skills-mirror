# 来源与许可说明

本目录是 `vibe-harness-cn` 的研究与工程快照。上级仓库的许可证不替代第三方来源自身的许可条件。

当前提交不包含 `research/upstreams/` 下的上游 Git 工作树；该目录仅作为本地、可重建的研究缓存并被 `.gitignore` 排除。上游 URL、revision、许可证、研究范围和限制记录在：

- `research/upstreams.sources.json`
- `research/upstreams.lock.json`

重新拉取或使用任一上游项目时，应以对应仓库的当前许可证和锁定 revision 为准；本项目不对未随提交分发的上游源码重新许可。
