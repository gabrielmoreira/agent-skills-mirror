This page does nothing on load. Starting sends STUN traffic to stun:stun.cloudflare.com:3478 and can reveal your network's exit address to Cloudflare. Local host candidates may also be gathered. There is no camera, microphone, remote peer, TURN, or media call. This is not a fully offline test.

Use the actual intended browser profile. This sample does not establish the selected media path, effective browser policy, Claude routing, account safety, or a kill switch. No candidates, timeout, and error 701 leave the path unknown.

The optional address is locally visible before you start. Enter only a canonical IPv4 address from an HTTPS sample you already obtained: four decimal octets, with no URL, port, spaces, or leading zeroes. This page does not obtain or verify that sample or certify the address as public. Starting captures a valid reference in temporary memory and immediately clears the input. The reference is used only for local equality comparisons with observed IPv4 srflx candidates; it is not sent to STUN or included in results. Finish, cancel, and leaving the page release that reference and clear the input; this is not a secure memory-erasure guarantee.

A same result means only the compared IPv4 srflx addresses equal your supplied sample. It does not establish the same path or show that the whole machine is leak-free. IPv6 srflx observations are counted separately and cannot establish an IPv4-only pass. All observed comparable candidates contribute to the comparison, including after the displayed candidate list is truncated. A mismatch remains different; missing/invalid references or no comparable candidates remain unknown. Error 701, timeout, cancellation, and truncation still limit the sample; selected media traffic remains unobserved.

The 12-second timer depends on browser scheduling and may run late if the tab is suspended or throttled. Keep this tab active; cancel or close it to stop collection.
