## WebRtc  🌟🌟🌟🌟🌟
浏览器功能：WebRTC 在建立连接时，会通过 STUN 服务器主动获取你的真实外网 IP
测试链接：[[https://ip.net.coffee/webrtc/]]
## IPv6 不要开 🌟🌟🌟🌟🌟
IPv6 很容易绕过你的代理规则
你配的代理规则，大多数情况下只匹配 IPv4，或者 domain 匹配时只命中 A 记录。但 Anthropic 的服务同时有 A 记录（IPv4）和 AAAA 记录（IPv6）
工具至少吧主要的策略ipv6关闭保持ipv4
相关文章: [[https://ip.net.coffee/claude/ipv6.html]]
## 指纹浏览器 🌟🌟🌟
指纹浏览器的重要程度不高，如果追求极致可以选择，但是市面上的指纹浏览器太多，建议现有一个自己使用claude的完整流程再折腾指纹浏览器（指纹浏览器尽量选择付费的，售后好的）

⚠️如果是正常使用普通浏览器基本是不会封的，注意不要到处换浏览器登录账号，不要泄漏自己的cookie数据，如果是Chrome使用的引擎要保持是Google Edge是Bing（也就是保持原生引擎，尽量不要用国内套壳，在浏览Claude网页时不要有奇奇怪怪的浏览器插件，脚本等）<mark style="background: #FF5582A6;">注意webrtc</mark>

## 支付 🌟🌟🌟🌟🌟

支付必须给5颗🌟，A\真的畜，钱不到位立马死（骗你的到位也死）
这里需要注意几个点，账单地址，支付IP，支付货币，主流支付方式这几个必须高度对齐，不要出现付款账单与支付IP不同的情况
<mark style="background: #BBFABBA6;">支付方式最重要 这里用几种常见的支付方式 🌟越多代表越好</mark>
以下所有内容遵循<mark style="background: #ADCCFFA6;"> 新号不要直接冲，被封过的号不要冲，被标记的卡不要充，不要上来就冲MAX（先养Pro 一个月）</mark>
#GooglePlay套国内visa或万事达 🌟🌟🌟🌟🌟 此方法除了多个税 基本全是优点，最大的优点退款友好，封号退全款（不是按剩余天数退）这里要注意自己的Google账号资历问题
#Apple礼品卡 🌟🌟🌟🌟 礼品卡 海鲜市场杂鱼多，退款也算友好，缺点就是礼品卡可能是黑卡，且同样要注意Apple id 注册区域 资历问题，低价区以及新号不要直接冲
#外币实体卡 🌟🌟🌟🌟🌟 此方法最稳，例如美国运通卡等，但是此方法门槛较高，尽量不要是小众的开卡机构
#虚拟卡 普通虚拟卡🌟🌟 拉完了 基本活不久 U卡 🌟🌟🌟🌟 加上返现 还可以（U卡可能遇到黑充，且要注意开卡机构要大众，不要有已被风控的机构）
#官方礼品卡/赠礼 🌟 拉完了，全是鱼龙混杂
#企业认证号/官方开发者合作等 直接给号 如果是认识的🌟🌟🌟🌟🌟 如果是要购买 🌟 拉完了 鱼龙混杂
#成品号 🌟🌟 拉完了，注册机批量注册，和未知充值渠道，封号大概率不退款，所有信息都是未知
#代充 🌟🌟🌟🌟 如果有稳定渠道，价格比正价不超过200可以

<mark style="background: #FFF3A3A6;">这里的代充和成品号尽量能自己充就自己充，虽然目前良心的代充很多，但是封号都是补新号（这里都不说用户已有数据迁移的成本）代充收到官方的退款也不会给你（基本都是写着官方退我们就退，以及按天数退，可以自己算笔账，他们基本稳赚不赔）自己充值退款能到自己掌上，可以走退款流</mark>
## 一个月的养号期

新注册的号不要立马充值，低价区最少半个月的养号期，不要上来就冲Max先从pro开始，并且每个周期不要撞限用完，并且使用时间要跟所在ip地区的工作时间一样（就是不要在大半夜长时间在线，账号作息要规律）并且<mark style="background: #ADCCFFA6;">注意内容规范，不要破限，不要涉及医疗等敏感话题，尽量不要在vps，虚拟机内使用，少用cli多用desktop和网页端，不要把账号共享</mark>
