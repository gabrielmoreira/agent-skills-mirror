## 小鸡

## 母鸡

## 超兽
“超售”的谐音，指卖出的 CPU、内存、带宽等资源超过宿主机合理承载范围。

## 传家宝
性价比很高、数量少、已经绝版或难买到的服务器套餐，二手往往有溢价。

## 落地鸡 / 中转鸡 / NAT 鸡
- **落地鸡**：线路可能一般，但 IP 解锁、地区属性等较好，适合作为最终出口。
- **中转鸡**：通常线路较好，用于把本地流量中转到最终服务器。
- **NAT 鸡**：共享公网 IPv4，通过端口映射使用。

## MJJ

## 总裁 / 烈马 / 剑皇 / 127
这些主要是历史社区黑话：
- **总裁 / 烈马**：特定人物或团队的圈内称呼
- **剑皇**：“鉴黄”的谐音
- **127**：来自 `127.0.0.1`，用于调侃网站打不开

## PT / 盒子
- **PT**：Private Tracker，一类私有 BT 下载体系
- **盒子**：用于 PT 下载、上传和做种的服务器或 Seedbox

## 灵车
指稳定性、商家信誉或存续时间不确定的服务，可能随时失效或跑路。

## 晚高峰
通常指北京时间晚间国际网络最拥堵的一段时间，常见表现为延迟、丢包和速度下降。

## 4837
通常指经过联通 AS4837 的线路。VPS 圈常把它作为较常见的回国线路之一。

## CN2 GIA

## CMI

## 9929 / 10099

## CN2
中国电信 CN2 网络体系，常见讨论包括：
- CN2 GT
- CN2 GIA

## 163
通常指中国电信传统 ChinaNet / AS4134 骨干网。

# 关于 VPS 线路

原帖的经验总结大致是：

- 国际线路去程、回程并不一定一致；
- 日本、香港、新加坡、美西等方向在不同运营商下表现差异很大；
- 软银、IIJ、NTT、CMI、4837、9929、CN2 等经常用于判断线路质量；
- 实际体验要看地区、运营商、路由和晚高峰表现。

## #576
一位 IDC 从业者补充了更多行话：

### 虚拟化
- **VM**：VMware
- **HY**：这里指 Hyper-V
- **PVE**：Proxmox VE
- **帆船**：Docker

### 服务器
- **宕机**：服务器无法连接或业务中断
- **xx hang**：某资源 / 服务卡死，例如 IO hang
- **DC**：Disconnect
- **28 / E28**：常见于磁盘空间耗尽
- **石油盘**：调侃低 IO 云硬盘

### 运营商
- **移不动**：中国移动
- **联不通**：中国联通
- **电不信**：中国电信
- **世界加钱可及**：对高价优质线路 / 专线的调侃

### IP
- **吃 D 单 / 吃 C 单**：IP 因 DDoS / CC 等问题收到投诉
- **脏 IP**：存在攻击、垃圾邮件、欺诈等不良历史的 IP
- **A 段 / B 段 / C 段**：圈内对不同 IPv4 地址范围的俗称
- A段：即1.0.0.1 - 1.255.255.255 这个段  
  B段：即1.1.0.0 - 1.1.255.255 这个段  
  C段：即1.1.1.0 - 1.1.1.255 这个段
- **Anycast / BGP / 任播**：网络路由相关概念
