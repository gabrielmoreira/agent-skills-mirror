# 本机路线：固定出口 IP 的三种来源（2026-10-21）

**适用范围：** 只在用户已经选择**本机**运行路线（见 [R-LOCAL](routes-and-platforms.md)）、并要把出口固定为一个 IP 之后使用。选 VM 或 VPS 路线时不触发本文。目标与[现行整机统一路径](agent-remediation.md#ipv4-only-policy)一致：所有流量走同一个指定出口，不泄漏。

本文只讲“怎么得到一个稳定、干净的出口 IP”。Agent 提供方案，并可在用户给出服务器访问后部署（如 3x-ui）；不代买、不代付款。部署按备份、差异展示和[分级授权](authorization-tiers.md)执行，付款由用户本人完成；面板账号密码和节点链接由用户本人保存，Agent 不读取、不回显。

## 三种来源

| 来源 | 优点 | 缺点 |
| --- | --- | --- |
| **纯净机场 IP** | 方便，折腾度低 | 纯净、优质的线路价格高；多人共用，风险高 |
| **自建梯** | 价格合适，IP 纯净度高，线路自选；可搭配家宽出口 | 折腾度高 |
| **家宽拼车** | 价格合适，适合小白 | 容易遇到“黑车”；渠道沟通不方便 |

## 推荐

- **用 Max：推荐自建梯。** 综合价格、纯净度和线路，最推荐。
- **用 Pro：推荐机场。** 省心，折腾度低。

- **机场**：本项目不提供机场推荐或教程，请用户自己上网搜索，并自行判断商家、价格和风险；Agent 可按 [补充资料来源](../SKILL.md#agent-补充资料来源) 帮忙检索讨论，只列出带来源和日期的信息，不替商家背书。
- **家宽拼车**：同样不提供渠道和教程，请用户自己搜索；Agent 只提醒上表的风险（黑车、渠道沟通不便），不推荐具体卖家。检索入口：**家宽拼车去 IDC Flare 找，家宽去 Linux.do（L 站）的 VPS 分区找**（[家宽总结篇](https://linux.do/t/topic/585764)）；Agent 可在这些渠道检索并带来源汇报，邀请码、返佣和推广只当线索。
- **自建梯**：只给下面的简短提示词，不展开成完整教程。

## 自建梯提示词（简版）

自建梯可以按下面的组合去搜索教程和搭建：

1. **服务端面板**：3x-ui。
2. **VPS**：选 CN2 GIA 等优化线路的 VPS；可选再叠加**家宽出口**。VPS 的选择见下一节的推荐报告。
3. **客户端**：
   - iOS：小火箭（Shadowrocket）
   - Android：FlClash
   - 桌面端：Clash Verge 或 FlClash
4. **重点注意版本兼容性**（2026-10-25）：不要出现桌面端 Clash Verge 能连上、移动端小火箭和 FlClash 连不上的情况。3x-ui 的 Xray core、协议和传输选项要选**用户所有客户端都支持**的组合，面板里新加的选项不确定客户端支不支持就先不开。节点建好后，用用户实际要用的每一个客户端（桌面、iOS、Android）各连一次、各测一次出口，全部能连才算建好；只测了桌面端不算。

Agent 说明方向和需要注意的点；用户买好 VPS 并给出访问方式后，Agent 可按最新教程部署，不代买、不代付款。部署前走备份、差异展示和分级授权。

[S10 第七节：3x-ui、REALITY、Hysteria2、证书与订阅实战](../sources/S10-windows-deployment-sanitized.md#vps-protocols)保留了完整排障过程；客户端 UDP 和配置是否加载接着看[第八节](../sources/S10-windows-deployment-sanitized.md#verge-runtime)。这是历史版本组合的案例，先核对当前版本与实际客户端，不把“全系不兼容”等原作者判断当通则；安装、订阅和证书操作仍按原有授权执行。

## 自建梯怎么选 VPS

已收录三类 VPS 推荐报告，见 [VPS 推荐报告索引](../sources/vps-recommendations/INDEX.md)：

- **业务**：AWS、Azure、DMIT 等通用机房 VPS。
- **性价比**：VMISS、VMRACK、千宿网络、搬瓦工。
- **高端家宽**：NodeMach、AaITR、QQPW、ResidentialVPS、ZoroCloud 等，对应“自建梯搭配家宽出口”。报告里提到家宽 VPS 国内直连丢包较重时宜配线路机中转。

**这些报告是项目参考来源，相关回答要主动附上对应报告的链接（见 SKILL.md 的资料随答附带）。** 使用边界：报告里的价格、配置、测试都是历史记录；星级是报告作者的推荐指数，不是验证结论。购买前到商家官网核验当前价格、库存、条款和 IP 状态。千宿网络、NodeMach 两份报告含商家推广或邀请链接，不作排序理由。

## 线路优化

自建梯的 VPS 连接不稳（晚高峰慢、断流），或想在优化线路机和家宽出口之间加中转时，按[线路优化](line-optimization.md)，依据 [R02](../sources/R02-vps-line-optimization.md)。Agent 只做诊断和一次一项的改动建议，用户批准后才执行。

## 选好之后

1. 出口入口按[网络与解决方法](network-and-remedies.md)的口径：Claude Code 不直接使用 SOCKS 入口，本地要有 HTTP 或 mixed 入口；配置已导入不等于已生效。
2. 用 [IP 质量与网络测试清单](../sources/S07-vps-script-catalog.md)自行检查出口 IP，由用户在自己的 VPS 上运行，结果只描述当时的观测，不能推出免封概率。
3. 同一台电脑的出口保持稳定：不要频繁切换节点和地区，节点失效时报告不可用，不静默换出口。
4. **出口和本机环境要一致：**TCP 延迟选线路优秀的美国 VPS 或物理距离近的出口（如日本）；出口是 Linux，本机也用同系统或接近的系统；不改 UA。见[出口与本机环境一致](exit-consistency.md)。
5. 支付、注册、使用节奏见[账号注册与使用节奏](account-onboarding.md)和[支付说明](accounts-and-payments.md)。

不承诺免封，也不承诺任何 IP 一定稳定或纯净。
