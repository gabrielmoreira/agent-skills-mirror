# Originality sight (assets from images)

> Deep load for **Family ORIG** in [taste-receptors.md](taste-receptors.md) (rollup V7). Image-only production review — **not legal advice**. When IP is uncertain → **ESCALATE**, never auto-PASS.
>
> Map every fail to an `ORIG-*` receptor ID in the zero list.

Filter **scènes à faire** (genre necessities) before crying infringement. Fail on **protectable expression** copies and stacked synthetic construction tells.

---

## Synthetic / AI-slop asset tells

| Tell | Visible evidence | Fail when |
|------|------------------|-----------|
| Texture smear / tiling break | Mirrored noise; seams that do not continue | Tiling material / repeating prop skin |
| Material logic mismatch | Wear ignores contact; busy albedo without form | Close-up prop/character |
| Contact / grip failure | Float jewelry, melting clasps, impossible grips | Hero prop / character sheet |
| Lighting without source | Uniform rim; identical softness near/far | Key art / splash / portrait |
| Anatomy / structure mush | Fused plates, ear-into-hair, duplicate BG props | Character/creature close-ups |
| Icon family drift | Stroke/corner/rivet/metaphor changes per icon | Same HUD/menu set |
| Unreadable micro-glyphs | Fake runes/UI text collapses on zoom | Badges, signage, diegetic screens |
| Smooth-symmetry “AI illustration” | Over-smooth SSS, centered blob hero, no world link | Marketing as game identity |

## Originality / IP risk tells

| Tell | Evidence | Fail when |
|------|----------|-----------|
| Franchise silhouette match | Costume + proportion + signature palette combo | Player names another franchise first |
| Logo / mark appropriation | Wordmarks/crests match real brands/games | Non-parody commercial screen |
| Trace / near-trace | Pose + costume breakpoints + accessories = famous piece | Immediate side-by-side memory match |
| Style-mark cloning | Distinctive living-artist signature wholesale | Hero/key art only works as that substitute |
| Kitbash identity collision | Marketplace packs with conflicting anatomy/render | Same screen, multiple authorships |
| “Transformative” recolor myth | Recolor/filter of protected design | Expression still dominates |

**Do NOT fail solely for scènes à faire:** coins/lives *as concepts*, golf balls in golf games, stock fantasy *archetypes*, basic HUD *ideas*. Fail when **specific expression** is copied.

## Positive criteria

### Independent expression
- After removing stock genre parts, silhouette/costume/motif combo feels specific to *this* game.
- Cast/props share internal design logic (proportion grid, edge language).
- Marks distinct — not near-matches.

### Reference transformation
- Traits borrowed separately (palette from A, silhouette from B) → new whole.
- Gear looks generic-functional, not branded replica (unless clear licensed diegesis).

### Construction integrity
- Edges, materials, contacts hold at native zoom.
- Tiled surfaces show planned seam/wear logic.
- Painted detail matches supporting form (noise ≠ detail).

### Set authorship unity
- Icons share grid, stroke, corner, metaphor rules.
- Characters share proportion/feature rules.

### Readability at target size
- Silhouette IDs subject in ~2s at likely in-game size.
- Value grouping supports read — not hue mush that only works at 2K.

### Provenance humility
- Process/craft cues **or** clearly labeled concept-only.
- Polished hero + stacked synthetic tells → ESCALATE / FAIL as final ship art.
