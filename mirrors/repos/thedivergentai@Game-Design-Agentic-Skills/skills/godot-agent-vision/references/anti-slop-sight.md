# Anti-slop sight (stacked AI defaults)

> Deep load for **Family SLOP** in [taste-receptors.md](taste-receptors.md). Taste is secondary sight — reject the median; do not rubber-stamp “pretty.”

**Co-occurrence rule:** one tell is weak; **three or more** (T≥3) without compensating owned art direction → `SLOP-STACK=0` and often overall **F**.

---

## Default centroids → SLOP receptors

| Cluster | Pixels | Receptor | Counter to PASS |

| Purple / indigo / pink wash | Hero gradients, CTA glows | SLOP-PURPLE | Motif + type + shape beyond hue |
| Neon glow-as-hierarchy | Box-glow every card | SLOP-NEON / SLOP-BLOOM | Hierarchy via size/position/contrast |

| Glassmorphism everywhere | Frosted low-contrast over play | SLOP-GLASS | Plates/outlines |

| Smooth AI key art | Over-smooth, sourceless rim | SLOP-SMOOTH / SLOP-RIM | Construction + motivated light |
| Equal weight | Everything screams | SLOP-EQUAL | Urgency ladder |
| Interchangeable crop | Paste onto any AI game | SLOP-SPEC | Owned specificity |

---

## Stack scoring (T)

Let **T** = count of distinct clusters clearly present without ownership.

| T | Typical SLOP family % | Notes |
|---|----------------------|-------|
| 0 | ≥90% | Restrained owned system |
| 1 | ~60–80% | Weak tell OK if world-justified |
| 2 | ~35–55% | Demand ownership proof |
| ≥3 | ≤25% → **F** path | Cap; hard-gate with HIER/CTRST fails |

**Ownership override (costs T−1, min 0):** diegetic reason + repeated motif grammar + non-default type + silhouette-capable icons. Gradient alone **never** buys override.

COMP/LIGHT co-tells: see [composition-fx-receptors.md](composition-fx-receptors.md).
