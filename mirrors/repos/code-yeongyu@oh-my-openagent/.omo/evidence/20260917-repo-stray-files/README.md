- `typecheck-and-lint.txt`: both `tsgo --noEmit` runs exit 0; `biome lint` on the three new files reports nothing (the repo has no lint config, so formatting output from biome defaults is not a gate).
- `readme-lint-before.*` / `readme-lint-after.*`: score 6.14 (`fix`, 142 hits, em dashes 3.27/1k, bullet ratio 0.19, colon labels 8.91/1k) to 0.59 (`pass`, 64 low hits, 0 mid/high, no metric over threshold except the advisory paragraph-length notice).

## Why it is enough

The audit test pins the invariant that motivated the cleanup, and it was captured red on the tree that violated it. The argv helper is unit-tested on every branch and the real driver was exercised on both failure paths and the happy path. The deletions touch nothing that code reads: every path was grepped for consumers (`.omo/fixtures/releases.json` and `.omo/init-deep.json` are read by scripts and stay; the plugin skill copies are regenerated by `sync-skills` at build time). Test runs happened on a fresh worktree of the branch on a second machine after `bun install --frozen-lockfile`.
