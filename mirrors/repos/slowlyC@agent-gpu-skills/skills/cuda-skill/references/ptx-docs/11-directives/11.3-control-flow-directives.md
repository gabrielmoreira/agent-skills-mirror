## 11.3. Control Flow Directives


PTX provides directives for specifying potential targets for `brx.idx` and `call` instructions. See the descriptions of `brx.idx` and `call` for more information.


  * `.branchtargets`

  * `.calltargets`

  * `.callprototype`
