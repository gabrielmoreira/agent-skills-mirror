## Smell Checks

- If the first probe needs a full architecture diagram, it is too big.
- If success depends on everything working together, it is too big.
- If the user cannot say what would falsify the current idea, the spec is still weak.
- If the output looks polished but no uncertainty was reduced, the probe failed.
