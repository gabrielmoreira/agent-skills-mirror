# 短剧写作

把单集意图写成可表演、可拍摄、会改变故事状态的 `剧集/<EP>/剧本.md`。

## Quick Start

只维护一份剧本 Markdown，不另建 episode card、beats、block index、录音表、QA 或接受记录。
一级标题使用 `# EP001 集名`，场景标题使用 `## EP001-SC001 内 · 地点 · 时间/天气`。
对白写 `角色（可选表演提示）：台词`；生产标签使用 `[VO]`、`[OS]`、`[SFX]`、`[画面文字]`、
`[连续性]`、`[转场]`。不要把含冒号的动作叙述误写成对白。

## 入口

- 有分集规划：读取本集进入状态、目标、转折、回报和交接事实。
- 只有想法/大纲：在上下文形成最小单集契约和因果节拍，再直接写剧本。
- 已有剧本：保留作者语言，只做用户点名的定点修订。
- 非规范文本要进入制作：保留原文，只做必要的场景、动作、对白和生产标签规范化。

开发大纲和长篇分析都是可选上游；当前材料足够时直接写。

## 工作流

1. 锁定谁现在要什么、阻力、当集兑现和不可逆变化。
2. 对核心选择保留双方仍然有效的价值与代价；对关键证据写清它能证明什么、最强的现场反解释是什么。
3. 在上下文排“因为—行动—局部结果—选择代价—由此引出的下一股压力”，不落盘节拍表；关系物若只在开头和结尾被摆放、没有参与验证或取舍，换成真正会改变行动的载体。
4. 逐场确定议程对撞、每个出场人物改变局面的动作、验证反应与场尾状态。
5. 把动作、对白、画外音、声音事实和画面文字写入同一份剧本。
6. 用户要求整集就写完整集，场景批次自动续跑。
7. 交稿前静默反查：只看剧本能否看懂赌注、私人动机与选择代价；关键证据是否挡住最强普通反解释；压缩动作段是否有受阻、改策和可见结果；结尾新压力是否由刚发生的选择或既有物件引出。有问题直接改稿。
8. 局部修订保留无关段落；明确问题直接修正，只把真实剧情分叉交给用户。

## 写作要求

- 每场改变信息、权力、关系、情绪、物理状态或风险；无变化的场删掉或合并。
- 对白必须在争取、回避、试探、逼迫或重新定义关系，不用解释替代行动。
- 用可见、可听、可触的行为表现状态，不写无法拍摄的内心结论。
- 人物声音靠策略、词汇、句长、回避方式和权力位置区分。
- 核心赌注必须在剧本内被观众看见或听见，不能依赖任务说明；用会改变行动的通知、出口、持物、对手或时间事实承载。
- 选择代价与外部时限要在选择被触发前建立；不在人物将要决定时才用一条新短信、广播或陌生规则临时加码。
- 有对白的次要人物不能只负责报时、递信息或听主角解释；除非“无力介入”本身是戏，他至少用自己的判断或行动改变一次阻力、选择、证据或结果。
- 选择发生前不能先宣布一边无效；用反事实比较两条路径的退出状态，只有因这次选择新增或加重的损失才算代价，人物原本就必然失去的店、关系或机会不能重复记账。决定由已经活跃的人物行动和价值冲突触发，不让故障设备恰在犹豫瞬间自行恢复来替角色下决心。
- 选择只关闭真正互斥的行动，不额外牺牲可兼得的收益：冲突若是“拿钱立刻离开 / 留下抢修”，选择留下不等于必须把已收的钱退回。
- 证据先被人物获取和验证；把最强普通反解释写成反事实——若它为真，哪个现场结果应不同——验证必须让该结果失败，否则人物只能缩小结论，不能让一个物证同时证明身份、动机和完整真相。
- 验证依赖“仍连接、未拆封、原位或无触碰”时，逐步追踪证据状态；不能先扯断、取出、开封或重新塞回，再把已经破坏的连续性当证明。
- 倒计时中的动作链必须做得到，时间标记要对应已完成的步骤；“今天/明天”等相对日期必须由手机、正在运行的系统或当日通知等活跃来源确认，不让停摆日历或过期告示单独作证。
- 所有精确时间、整点报时和倒数必须单调一致；不能先报整点，再显示更早的20:59:58。
- 维修、取证、上传等压缩过程不堆工序清单；保留会改变策略的诊断、受阻、协作与结果，压掉可互换步骤。缩小目标不能临时发明可拔存储、云备份、免登录账号或恰好兼容设备来绕开输入确立的核心障碍。
- 动作已经让观众看清的技术结论，不再由人物完整复述；人物对结果的称呼也只到证据支持的程度，临时接入完成提交不等于“手机修好”。短时长高潮优先一个决定性障碍和一次有代价的改策。
- 同一压力不叠用系统时间、墙钟、口头倒数和广播重复报时；75–90 秒内的关键验证优先一个连续测试和一次关系反应，不把拆机、倒转、复位、解释各写成独立展示段。
- 压缩不能删掉转向后的关系反应：证据改变判断后，让怀疑者至少改变一次持物、站位、称呼、阻拦或下一策略，再进入主角选择。
- 钩子来自未解决压力或新事实，并优先由人物刚作出的选择、对手反应或既有物件变化引出；环境声只有改变判断或下一动作才算钩子，不机械停在一句“你竟然”。
- 重大选择的私人动机优先落在会参与当前行动的关系物、称呼或重复动作上；不只靠一段往事说明，也不为煽情另塞一次性道具。主题由这些载体的状态变化显现，不在收束处用口号复述。
- 阶段回报之后的每一拍都要增加新的代价、关系或下一步压力，不用多轮对白重复“成功了但问题未完”。
- 回报后只保留最强的一项代价/钩子动作；若人物因选择错过搬运、撤离或关门窗口，就让该路径明确关闭，不用继续收拾、捡物的尾声把损失重新变得可挽回。
- 结尾持物和空间状态必须从前文动作连续过来，不突然出现密封袋、钥匙或已移动的钱；已有物件能制造具体新事实时，不只靠惯例汽笛、雷声或黑场充当钩子。
- 正文已经清楚呈现的出去状态不再用 `[连续性]` 复述；只标真正易在下游丢失、又无法从末段动作直接读出的事实。
- 输入给出目标时长时，把它当写作约束：没有项目语速也要按真实表演、动作和停顿通读压稿，先删重复验证、解释和同义收尾；不因无法精确估秒就忽略目标。
- 不用统一字数、镜头数或节拍数填模板；长度服从本集戏剧动作。
- 用户原文优先；“去 AI 味”是定点修订，不抹平作者个性。

## 按需知识

默认只读本 SKILL 和直接输入。出现下列明确信号时，在写正文前读取对应知识；同一输入有多个不同问题
可以分别读取，但不遍历无关引用：

- 阶段边界与规则分级：[阶段契约](references/stage-contract.md)
- 场景标题、对白和生产标签语法：[剧本格式](references/screenplay-format.md)
- 项目特有的制作稿方言：[制作格式方言](references/production-format-dialect.md)
- 输入含核心选择、精确倒计时或会改变人物判断的关键物证：[剧作手艺](references/script-craft.md)
- 过去关系必须通过对白进入，或关键人物容易只剩说明功能：[对白手艺](references/dialogue-craft.md)
- 声源、留白与 sound bridge：[场景声音戏剧](references/scene-sound-dramaturgy.md)
- 同一故事义务的不同可拍实现：[可替代实现](references/substitutable-realization.md)
- 长单集跨上下文时的最小交接：[场景交接胶囊](references/scene-handoff-capsule.md)，只留在上下文

## 时长估算（按需）

用户问时长时才把索引写入临时目录。`--speaker` 必须替换为本集实际说话者；只有存在项目配置时才
添加 `--project short-drama.json`：

```bash
TMP_DIR=$(mktemp -d)
python3 "{技能目录}/scripts/screenplay_index.py" 剧集/EP001/剧本.md --output "$TMP_DIR/index.jsonl" \
  --speaker <本集角色一> --speaker <本集角色二>
python3 "{技能目录}/scripts/duration_estimate.py" 剧集/EP001/剧本.md --index "$TMP_DIR/index.jsonl"
```

估算是参考，不是门禁；没有语速或动作段速率时只报告可数事实，不猜秒数。但任务已给目标时长时，
写作者仍须用真实朗读和动作通读判断能否容纳，并直接压缩重复节拍；“不能精确估秒”不是忽略目标的理由。

## 完成

点名范围已写入、场景因果连贯、对白与行动可表演、承诺有兑现或有意延迟、结尾状态明确，即完成。最后一拍若只再次宣告人物已经作出的选择、收起纪念物、望向目的地或播放不改变行动的环境声，仍未完成；它必须新增可见的代价、关系回应、事实或被迫的下一动作。
资产、分镜、审查与生产只有用户点名时开始。

## 安装维护

只有安装、升级或排障时运行 `python3 scripts/selftest.py`。
