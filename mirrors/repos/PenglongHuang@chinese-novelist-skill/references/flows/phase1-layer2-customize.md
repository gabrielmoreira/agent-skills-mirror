# 第一阶段·第二层：深度定制与创作规格

> 本层用 **2 次合并调用**完成全部提问。遵守第一层定义的提问惯例：每问 ≤4 选项、"自由描述"由内置 Other 承担、"随机/跳过"是全局约定（用户回答"随机"则 AI 根据已有信息智能生成并简短展示一句话供确认）、偏好项动态换入选项。
>
> 用户随时可以说"跳过"、"下一个"、"直接看配置确认"来加速流程。

---

## 调用一：世界观与叙事规格（单次调用含 4 问）

```
Question: 故事发生在什么样的世界？
Options:
- 现实世界（当代中国或其他现实背景）
- 架空历史（特定朝代或虚构朝代）
- 完全虚构世界（需自建规则体系，如魔法/修真）
- 未来/科幻世界

Question: 你希望用什么视角讲故事？
Options:
- 第三人称限制视角（跟随主角所见所感）
- 第三人称全知视角（可切换角色）
- 第一人称（代入感最强）
- 多视角切换（每章或每段换视角）

Question: 故事的氛围风格（基调）是？
Options:
- 紧张刺激（快节奏、高冲突、悬念驱动）
- 温情治愈（慢节奏、情感向）
- 轻松幽默（喜剧感）
- 沉重深刻（探讨人性/社会、有文学性）

Question: 这部小说最想表达的核心主题是什么？
Options:
- 成长与蜕变（主角的内在变化是核心）
- 正义与复仇（善恶对决）
- 爱与牺牲（感情线驱动）
- 权力与欲望（野心、堕落与救赎）
```

> **智能推荐**：题材 = 奇幻/玄幻/科幻 时，世界观问可加"（推荐⚠️）"后缀到虚构世界选项；题材 = 都市现实 时提示"世界观可跳过（默认现实世界）"。Q1 自由输入已含世界观信息则该问标记"已覆盖"可跳过。
>
> **追问**：仅当世界观选了"完全虚构世界"且 Other 中无细节时，一句话追问独特规则/设定要素（2-3 个基于题材的方向 + Other，或"后面再定"）。
>
> **偏好集成**：`preferredPerspective` / `preferredTone` 有值时换入对应问。
>
> 生存与希望、自由与束缚等主题变体走 Other。

**记录**：`世界观`、`叙事视角`、`基调`、`核心主题`

## 调用二：读者与规模（单次调用含 3 问）

```
Question: 主要写给谁看？（目标读者）
Options:
- 大众读者（网文受众，追求爽感和代入感）
- 青少年读者（青春、成长、校园向）
- 成熟读者（偏好深度和文学性）

Question: 你计划创作多少章？
Options:
- 10章（短篇，约3-5万字）
- 20章（中篇，约6-10万字）⭐常用
- 30章（中长篇，约9-15万字）
- 50章（长篇，约15-25万字）

Question: 有没有特殊要求？
Options:
- 没有，按标准来（每章3000-5000字）
- 调整每章字数（经 Other 说明）
- 有必含情节/禁止内容（经 Other 说明）
```

> **偏好集成**：`typicalChapterCount` 有值时换入章节数问并提示"上次你选了XX章"；15章或自定义数量走 Other。`styleReferences` 中的作者可在展示配置时作为风格参考建议提及，不占选项。

**记录**：`目标读者`、`章节数`、`特殊要求 = [用户回答 / 无]`
