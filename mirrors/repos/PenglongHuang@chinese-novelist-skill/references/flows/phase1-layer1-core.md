# 第一阶段·第一层：核心定位（必答）

> 本层确定小说的基本骨架，使用 `AskUserQuestion` 工具提问。
>
> **工具约束与提问惯例**（本层所有问题都遵守）：
> - 每问最多 **4 个选项**，且至少 2 个；用户总能通过内置的 "Other" 自由输入，**不要为"自由描述"单设选项**
> - "🎲 随机生成"是全局约定：任何问题用户都可回答"随机"或"跳过"，不必占用选项位
> - 偏好⭐标记：把 `user-preferences.json` 中匹配的偏好项**换入**前 4 个选项（替换热度最低的），而不是追加
> - 单次 `AskUserQuestion` 调用最多可包含 4 个问题——尽量合并提问，减少打断用户的轮次

---

## Q1：题材与创意概要（单问调用）

```
Question: 你想要创作什么题材的小说？
Options（动态生成）:
- [从题材池中按用户首句线索 + favoriteGenres 选出 3 个最可能的]
- [剩余题材中热度最高的 1 个]
```

题材池：悬疑推理 / 言情（现代、古代、穿越）/ 奇幻玄幻 / 科幻未来 / 武侠仙侠 / 历史架空 / 都市现实 / 成长校园

用户想写的题材不在选项里时，会直接经 Other 输入——这正是**创意概要**的主要来源，注意从中提取关键设定信息。

**记录**：`题材 = [用户选择]`，`创意概要 = [Other 输入中的关键信息]`

---

## Q2：主角设定与驱动力（合并提问，单次调用含 3 问）

```
Question: 主角是什么设定？
Options:
- 男性主角（独角戏）
- 女性主角（独角戏）
- 双主角（对手戏 / 双线）
- 群像戏（多线叙事）

Question: 主角的核心性格是？
Options:
- 热血正义（勇敢、有担当）
- 冷静智慧（理性、高智商）
- 成长逆袭（从弱到强、打脸升级）
- 阴暗腹黑（心机、算计、复仇）

Question: 是什么推动主角不断向前？（内在驱动力）
Options:
- 复仇/雪恨
- 爱情/守护
- 责任/使命
- 野心/生存
```

> 温暖治愈、高冷孤傲等性格变体，好奇心、求知欲等驱动力变体，由用户经 Other 补充。`preferredProtagonist` 有值时换入第一问。

**记录**：`主角类型`、`核心性格`、`驱动力`

**可选追问**（仅当回答信息量不足时，用一句话向用户索取，不强制）：
- 主角的职业或身份（可给 3-4 个基于题材的推荐项）
- 已想好的关键配角（对手、盟友、恋人，可跳过）

**记录**：`职业/身份`、`关键配角 = [用户回答 / 无]`

---

## Q3：核心冲突（单问调用）

```
Question: 小说的核心冲突是什么？
Options:
- 查明真相（解谜、揭露秘密）
- 生死存亡（生存危机、逃出生天）
- 爱情阻碍（克服阻碍、追求所爱）
- 权力争夺（竞争上位、资源争夺）
```

> 成长突破、守护保护等变体走 Other。若 Q2 的驱动力已隐含冲突（如驱动力=复仇），可将对应项换入选项并默认关联。

**记录**：`核心冲突 = [用户选择]`

## 第一层完成 → 摘要展示与过渡

Q1-Q3 全部完成后，执行以下两步：

### 1. 展示已明确信息

向用户展示：

```markdown
## 已收集信息

📖 **题材**：[题材] — [创意概要]
🧑 **主角**：[主角类型] | [职业/身份] | [核心性格]
💥 **冲突**：[核心冲突] | 驱动力：[驱动力]
```

### 2. 静默更新偏好

将第一层的回答同步到 `user-preferences.json`（不打扰用户）。

偏好数据结构与更新规则详见 → [shared-infrastructure.md](shared-infrastructure.md)

一句话引导进入深度定制：

→ 进入 **第二层：深度定制与创作规格**，详见 [phase1-layer2-customize.md](phase1-layer2-customize.md)
