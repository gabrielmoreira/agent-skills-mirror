# Slide Deck Target

Support sequential presentation. Give each slide one primary cognitive task, keep it legible at presentation distance, and fit the specified aspect ratio. Provide keyboard navigation in both directions, current-position feedback, visible focus, and optional speaker notes.

Use constraints the user has already provided or confirmed. Briefly confirm talk length, aspect ratio, presentation mode, or another relevant constraint only when missing information would materially change the work. When the user authorizes the Agent to decide, state the assumption and continue.

A PageStory scene is not a slide. Pagination is a creative judgment based on the content, talk length, and presentation mode; do not use word-count, seconds-per-slide, or fixed-slide formulas. A Render Target creates no new factual obligations.

After rendering, inspect every slide at the target ratio for composition, clipping, overflow, presentation-distance legibility, and forward/back navigation. Do not rely only on source inspection or a mechanical detector.
