# 多镜头序列与蒙太奇

## 何时使用多镜头

适合：

- 一个镜头时长无法容纳全部叙事动作。
- 需要建立空间后切入反应或细节。
- 对话需要正反打或反应镜头。
- 动作需要准备、接触和结果分镜展示。
- 蒙太奇需要表达时间推移或并列信息。

不适合：只是想让画面“更丰富”，却没有明确切点、镜头数量和叙事关系。

## 序列总契约

先写：

```text
总时长
精确镜头数量
序列目标
每个镜头的叙事功能
切点规则
全序列必须保持的资产和连续性
最终落点
```

总时长必须等于每段时长、必要过渡和尾部停顿的总和。

## 每段镜头卡

每段至少包含：

- CUT/SHOT ID。
- 每段时长和累积时间。
- 起始构图。
- 允许角色和状态。
- 一个主动作或信息。
- 摄影机主运动或锁定。
- 对白与 audio cues。
- 结束构图和动作接点。
- 与下一段的切点。

结构：

```text
CUT A [0.0–2.0s]
目的：建立人物与门的空间
画面/动作：……
摄影机：……
声音：……
尾帧/接点：右手悬停在门把上，视线屏幕左
HARD CUT on eyeline
```

## 切点类型

### 硬切

最清楚，适合动作、对话和空间重组。写切发生的准确事件或时间。

### 动作匹配切

上一镜动作阶段必须与下一镜开始阶段匹配，例如抬手在接触前切到手部特写继续接触。

### 视线匹配切

上一镜建立人物看向屏幕方向，下一镜显示目标。目标不能出现在错误方向。

### 声音桥

声音先进入或跨切持续。记录来自哪镜、何时开始/结束、空间是否改变。

### 遮挡切/甩镜切

需要明确遮挡物或运动方向，不能只写“酷炫转场”。过度依赖可能生成不稳定中间帧。

## 对话序列

- 建立镜头确定轴线和空间。
- 正反打保持 A 看右、B 看左或项目确定的相反关系。
- 每个镜头只允许当前说话者口型；反应镜头可保持画外声音。
- 过肩镜头明确前景肩属于谁。
- 台词分配遵守每段发声时间。
- 环境底床跨切持续。

## 动作序列

可拆为：

```text
建立威胁 → 准备 → 发力/接触 → 反作用 → 结果/落定
```

每段只承担一个动作中心。屏幕方向、道具手、伤势和环境破坏通过 continuity out/in 连接。

## 蒙太奇

蒙太奇不是随机美图合集。先选组织逻辑：

- 时间递进：同一对象状态逐步变化。
- 空间并列：不同地点同时发生关联事件。
- 动作并列：相似动作形成节奏。
- 因果压缩：准备、过程、结果的关键片段。
- 情绪累积：细节逐步提高压力或亲密感。

蒙太奇规则：

- 限定镜头数量，避免平台擅自增加。
- 每段时长足以识别信息。
- 同一主体的身份和状态按时间推进。
- 每段构图有差异但服从共同视觉母题。
- 声音可用共同底床、节奏音或明确静默连接。
- 最终镜头提供序列落点，不突然结束。

## 多镜头中的参考范围

同一个参考可能对不同段只继承不同属性。不要让第一段构图成为所有段的构图。全序列锁资产身份和状态，每段单独写摄影机和空间关系。

## 总时长预算

先计算：

```text
总时长 = 各镜头可读时间 + 切点/转场预算 + 最终落点停留
```

若五个镜头塞进五秒，每段只有一秒，复杂表演、对白和空间变化都难以读取。优先减少镜头数量，而不是要求“快速闪过但每个细节清晰”。

## 示例骨架

```text
总时长 8 秒；精确 3 个镜头；硬切；同一角色与湿透服装状态保持。

CUT A 0.0–2.5s：全景建立空旷站台，角色从屏幕左进入并停下。
接点：她抬头看向屏幕右上。

CUT B 2.5–5.0s：视线匹配到电子牌熄灭；固定近景；灯管声中断。
接点：黑暗中只剩红色应急灯。

CUT C 5.0–8.0s：中近景回到角色，红光从右侧扫过脸；她后退半步并落定。
最终落点：视线仍锁住右侧，环境底床只剩风声。
```

## 常见失败与修复

| 症状 | 先检查 | 最小修复 |
|---|---|---|
| 镜头数量错误 | 是否写精确镜头数量 | 在序列总契约和每段 ID 中重复一次 |
| 多镜变单镜 | 切点不明确 | 写 HARD CUT/匹配切和累积时间 |
| 镜头顺序乱 | 每段无功能 | 为每段写目的和前后因果 |
| 身份跨切漂移 | 每段重写角色 | 全序列引用同一资产状态版本 |
| 轴线混乱 | 屏幕方向未传递 | 在每段 close/open 写视线和运动方向 |
| 动作跳跃 | 缺动作接点 | 记录手、脚、道具和动作阶段 |
| 蒙太奇随机 | 无组织逻辑 | 选择时间/空间/动作/因果/情绪之一 |
| 结尾突然 | 缺最终落点 | 预留尾部停留和最终状态 |

## 序列质量门

- [ ] 总时长和精确镜头数量明确。
- [ ] 每段时长与累积时间不越界。
- [ ] 每段只有一个主功能和主摄影机意图。
- [ ] 切点、接点和屏幕方向明确。
- [ ] 资产状态和环境连续。
- [ ] 对白与声音桥按时间衔接。
- [ ] 蒙太奇有统一组织逻辑。
- [ ] 最终落点可读并服务下一场。
