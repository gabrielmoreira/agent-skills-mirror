# 失败诊断与最小修复

## 先定位责任层

按顺序检查：

| 层 | 问题 | 典型修复 |
|---|---|---|
| 资产 | 批准身份、状态和参考是否足够 | 修资产、状态版本、inherit/exclude |
| 镜头契约 | 人数、空间、动作、摄影机、声音是否可执行 | 降复杂度、拆镜、修首尾状态 |
| 提示词 | 契约是否被清楚表达、是否冲突/重复 | 重排、压缩、补缺失字段 |
| 平台适配 | 参数、参考槽、时长和模型能力是否匹配 | 只改适配层或换明确方案 |
| 生成随机性 | 同一控制批次中是否偶发 | 固定变量比较候选 |
| 后期 | 缺陷是否更适合剪辑、合成、调色或声音修复 | route_post 并记录 |

“结果不好”不是错误码。先描述可观察症状。

## 错误记录格式

```text
错误码
症状与证据帧/时间
先检查
责任层
最小修复
只改变的复测变量
不建议做法
```

## 资产与身份

| 错误码 | 症状 | 先检查 | 最小修复 |
|---|---|---|---|
| `F-ID-DRIFT` | 脸、体型、发型或核心轮廓漂移 | identity invariants、混合参考 | 只保留批准身份和明确引用范围 |
| `F-STATE-DRIFT` | 服装、伤势、湿度或携带物回退 | asset state version | 引用正确状态，写 must_hold |
| `F-REF-SCOPE` | 参考构图、背景或光线被带入 | inherit/exclude | 只继承需要属性，排除其余 |
| `F-DUP-SUBJECT` | 同一角色出现两次 | 人数、重复描述、镜面 | 精确人数、每个 ID 一次、针对反射风险 |
| `F-ASSET-MERGE` | 两个角色或道具特征融合 | 参考和空间是否重叠 | 分离资产注入、站位和接触边界 |

**不建议：** 在身份参考不稳定时继续堆“same face、consistent character”同义句。

## 空间与连续性

| 错误码 | 症状 | 先检查 | 最小修复 |
|---|---|---|---|
| `F-COUNT` | 人数错误或额外人物 | 允许集合、反射、背景 | 写精确人数、ID 与各出现一次 |
| `F-SCREEN-DIR` | 屏幕方向或解剖左右翻转 | 坐标是否含糊 | 同写摄影机侧、解剖侧、鼻尖方向 |
| `F-AXIS` | 越轴导致关系混乱 | 对话/运动轴线 | 保持方向或设计可见越轴桥梁 |
| `F-SPATIAL-RESET` | 场景布局重构 | 空间图、固定锚点 | 引用场景区域和唯一锚点，排除参考构图 |
| `F-PROP-DUP` | 家具或关键道具复制 | 数量、所有者、位置 | 声明唯一物体及接触关系 |
| `F-CONTINUITY` | 动作、伤势、天气或声音接不上 | close/open state | 对齐 continuity_out/in，登记变化 |

**不建议：** 用一个构图参考强行控制所有机位，或只写“保持连续性”。

## 动作与表演

| 错误码 | 症状 | 先检查 | 最小修复 |
|---|---|---|---|
| `F-ACTION-OVERLOAD` | 动作被压缩、遗漏或顺序错 | 时长和 beat 数 | 删除、合并或拆镜 |
| `F-PHYSICS` | 漂浮、无重量、碰撞无反作用 | 准备/接触/反作用/落定 | 补完整物理链和环境反馈 |
| `F-ACTION-ORDER` | 结果先于触发 | beat_timeline | 按时间写触发与动作阶段 |
| `F-PERFORMANCE` | 僵硬、过度或情绪不读 | 表演通道和触发 | 选视线、呼吸、停顿和重心中的少数信号 |
| `F-UNSCRIPTED-MOVE` | 静止角色自动转头、手势或说话 | 静止范围、主次表演 | 列允许微动和禁止动作 |

**不建议：** 用“更激烈、更震撼”修复缺失的动作因果。

## 摄影与剪辑

| 错误码 | 症状 | 先检查 | 最小修复 |
|---|---|---|---|
| `F-CAMERA-CONFLICT` | 多个主运镜互相争夺 | camera_path | 只保留一个主运动或拆镜 |
| `F-CAMERA-PATH` | 起点、路线、距离或落点错误 | start/path/end | 写物理可走通的完整路径 |
| `F-FRAMING` | 景别、主体占比或方向错误 | 起始/结束构图 | 用可画的构图和占比替代“电影感” |
| `F-FOCUS` | 对焦错误或随机漂移 | 主对焦对象、拉焦触发 | 只保留一个主对象或一次明确拉焦 |
| `F-CUT` | 镜头数、切点或转场错误 | 多镜头总契约 | 写精确数量、每段时长和切点 |
| `F-JITTER` | 手持变成故障抖动 | 稳定方式 | 写人体幅度/节奏；冲击震动绑定事件并恢复 |

**不建议：** 同时写 locked、orbit、push-in、whip pan，希望模型自己选择。

## 对白与声音

| 错误码 | 症状 | 先检查 | 最小修复 |
|---|---|---|---|
| `F-DIALOGUE-TEXT` | 加词、漏词或说话者错误 | 逐字对白锁 | 写精确文本、唯一发声窗口和说话者 |
| `F-DIALOGUE-TIME` | 台词太快、截断或挤掉动作 | 自然朗读时长 | 延长、缩短台词或拆镜 |
| `F-DIALOGUE-VISUALIZED` | 台词内容变成闪回/额外人物 | 视觉边界 | 写对白不视觉化和当前允许集合 |
| `F-LIPSYNC` | 未说话者嘴动或口型错 | 发声窗口和静默角色 | 只允许说话者在指定时间口型 |
| `F-AUDIO-POLLUTION` | 自动音乐、旁白、字幕或无关声 | 音轨边界 | 保留指定轨道，禁止额外音轨 |
| `F-AUDIO-MIX` | 人声、音效和底床优先级错误 | mix_priority | 重新排列前景/中层/底床和 duck |

**不建议：** 写“no sound”来修复额外音乐，同时又保留对白。

## 光色与材质

| 错误码 | 症状 | 先检查 | 最小修复 |
|---|---|---|---|
| `F-LIGHT-DIR` | 光源换边或无来源 | 场景光源位置 | 写真实来源、方向和人物关系 |
| `F-EXPOSURE` | 关键高光溢出或暗部压死 | 曝光保护优先级 | 选择必须保留的主体和范围 |
| `F-COLOR-DRIFT` | 主色、色温或强调色漂移 | 颜色脚本 | 锁叙事色和跨镜变化事件 |
| `F-MATERIAL` | 皮肤、布、金属、骨等都塑料化 | 材质分区与响应 | 分别写粗糙度、反射、透光和磨损 |
| `F-WEATHER` | 雨雪雾风像背景贴层 | 环境互动 | 让天气作用于人物、地面、光和声音 |

**不建议：** 同时堆“自然光、棚拍三点光、霓虹、月光、火光”而不定义来源和主次。

## 诊断决策树

```text
症状是否违反批准资产事实？
  是 → 修资产版本/参考范围
  否 ↓
镜头契约是否矛盾、超载或缺首尾？
  是 → 降复杂度/修契约/拆镜
  否 ↓
提示词是否遗漏、重复、含糊或混入平台参数？
  是 → 最小重写
  否 ↓
平台适配是否超出能力或参数冲突？
  是 → 只改适配层/换明确方案
  否 ↓
同一控制批次是否偶发？
  是 → 比较随机候选
  否 ↓
是否更适合后期修复？
  是 → 记录 route_post
```

## 复测规则

- 每次只改变一个主要责任层。
- 写明 changed_variables、hypothesis 和 expected improvement。
- 列出必须保持的资产、动作、摄影和声音字段。
- 使用相同评审门比较上一批与新批。
- 连续两个批次无改善时停止同一路径。

## 诊断输出

```text
首要失败码
证据与时间点
责任层
根因假设
最小修复
本轮 changed_variables
必须保持
复测方式
停止/升级条件
```
