# 七层提示词架构

## 使用方式

七层是组织信息和定位失败的框架，不要求最终提示词总是显示七个标题。先从上到下建立事实和契约，再压缩成适合精简版、标准版或导演版的文本。

```text
L1 意图与验收
  ↓
L2 资产、状态与引用
  ↓
L3 世界、空间与数量
  ↓
L4 表演、动作与物理
  ↓
L5 摄影机、时间与剪辑
  ↓
L6 光色、材质与声音
  ↓
L7 连续性、风险与交付
```

任何层失败，先修该层；不要默认在 L7 继续增加否定词。

### L1 创作意图与验收目标

**回答：** 观众需要理解、感受或发现什么；本图或本镜在项目中承担什么功能。

**输入：** brief、场次目标、前后镜头、发行用途、用户硬约束。

**写作公式：**

```text
本镜让观众[理解/感受/发现]……；通过[一个主要可见事件]完成；结束时观众应看到……
```

**规则：**

- 一个镜头只有一个主叙事功能。
- “高级、震撼、电影感”必须转译为可观察结果。
- 叙事事实与实现手段分开；“他很害怕”是意图，“视线锁住门缝、吸气后退半步”才是可见表演。

**常见失败：** 同时要求介绍地点、完成打斗、说完长对白和揭示反转；提示词很长但没有镜头落点。

**检查：** 删除所有风格词后，是否仍能说清本镜为何存在？

### L2 资产身份、当前状态与引用范围

**回答：** 谁或什么出现；使用哪个批准版本；哪些属性稳定，哪些是本镜状态；参考素材继承什么。

**输入：** 资产表、状态矩阵、参考范围、上一镜连续性输出。

**写作公式：**

```text
[稳定资产 ID @ 状态版本]；身份锁定[稳定特征]；当前状态[服装/伤势/湿度/污渍/携带物]；
参考[ID]只继承[属性]，明确排除[构图/机位/光线/背景等]。
```

**规则：**

- identity invariants 和 state variables 分开。
- 一个状态变化用版本表达，不重新发明角色描述。
- 每个参考都写 `inherit` 和 `exclude`。
- 未获批准或权利不明的参考不得进入生成前门。

**常见失败：** 把受伤状态写成新角色；参考图同时带入错误背景；同一人物的发型和服装在镜头间回退。

**检查：** 只看 L2，能否判断“同一个谁、此刻是什么状态、参考只管什么”？

### L3 世界、空间、数量与接触关系

**回答：** 地点如何组织；谁在前中后景；人物面向哪里；关键物体有几个、属于谁、在哪里、接触什么。

**输入：** 场景空间图、允许资产、轴线、上一镜屏幕方向。

**写作公式：**

```text
地点[ID]的[区域]；画面中恰好[N]个允许主体；
[主体 A]位于[屏幕侧+深度层]并面向[屏幕方向]；
[解剖侧肢体]接触[唯一道具 ID]；[出入口/固定锚点]保持在……
```

**规则：**

- 屏幕左/右与人物解剖左/右同时需要时都写。
- 多人镜头先写数量和站位，再写表演。
- 关键道具声明唯一性、所有者、当前位置和接触方式。
- 空间参考只继承布局时，排除其原构图和镜头。

**常见失败：** 人数增加、同一人物重复、左右翻转、家具复制、场景每镜重建。

**检查：** 能否画出一张粗略平面图并数清所有主体？

### L4 表演、动作与物理因果

**回答：** 角色从什么状态开始，被什么触发，怎样行动，如何接触和受力，最后停在哪里。

**输入：** 角色目标、动作节拍、身体和道具状态、环境反馈。

**写作公式：**

```text
[起始姿态/视线/呼吸] → 因[触发]开始[准备] → [发力] → [接触] →
[身体/物体/环境反作用] → [明确落定状态]
```

**规则：**

- 抽象情绪至少对应两个可见或可听表演信号。
- 动作遵循“准备 → 发力 → 接触 → 反作用 → 落定”。
- 质量、惯性、摩擦、碰撞、液体、衣料和碎片按需响应。
- 背景角色只做明确允许的持续动作，避免所有人争夺注意力。

**常见失败：** 物体漂浮、撞击无反作用、动作顺序倒置、要求完全静止又要求持续奔跑。

**检查：** 每个动作是否有起因和终点？镜头结束能否接下一镜？

### L5 摄影机、构图、时间与剪辑

**回答：** 摄影机从哪里开始、如何观察、怎样运动、对焦谁、何时切、最终停在哪里。

**输入：** 镜头时长、景别、透视目标、动作节拍、前后镜接点。

**写作公式：**

```text
camera_start=[机位+高度+景别+构图+对焦]；
camera_path=[一个主运动+方向+速度+距离+稳定方式]；
camera_end=[结束景别+主体关系+对焦+接点]；
时间=[动作/对白/切点节拍]
```

**规则：**

- 一个镜头只有一个主摄影机运动。
- 焦段优先写视觉效果：空间夸张、自然透视或压缩背景；毫米数是辅助。
- “手持”必须说明幅度和节奏；有意手持不是故障抖动。
- 多镜头写每段时长、硬切/匹配切点和最终落点。

**常见失败：** 锁定、环绕和快速推近同时出现；只写“推进”没有终点；动作和对白总时长超过镜头。

**检查：** 能否分别截取首帧和尾帧草图？路径是否只有一个主意图？

### L6 光线、色彩、材质与声音

**回答：** 光来自哪里、怎样塑造体积；颜色怎样分工；不同表面如何响应；观众听见什么。

**输入：** 场景真实光源、曝光重点、颜色脚本、材质表、对白与声音线索。

**写作公式：**

```text
光=[来源+方向+软硬+对比+曝光保护]；
色=[主色/辅色/强调色及叙事作用]；
材质=[粗糙度/反射/透光/湿度/磨损响应]；
声=[对白+动作拟音+环境底床+音乐/静默边界+混音优先级]
```

**规则：**

- 60:30:10 只在需要清晰颜色层级时使用。
- 同一光照下，不同材质必须有不同响应。
- 对白写说话者、逐字内容、时间和尾部静默。
- 未授权或未要求音乐时明确无配乐；静默也是设计元素。

**常见失败：** 自然光与棚拍主光冲突；所有表面塑料化；自动配乐、字幕或额外人声；对白时间挤掉动作。

**检查：** 闭眼是否能描述声音空间？去掉颜色词后，光源仍合理吗？

### L7 连续性、风险约束与交付规格

**回答：** 什么绝不能变、什么只在本镜变化、什么不能出现；怎样进入下一镜；真实交付要求是什么。

**输入：** continuity in/out、已知失败、平台能力、交付 brief。

每个复杂镜头使用三栏约束：

| 栏 | 内容 |
|---|---|
| **必须保持** | 身份、数量、批准状态、轴线、唯一物体、逐字台词等 |
| **本镜变化** | 本镜唯一允许改变的表情、动作、伤势、位置或环境状态 |
| **禁止出现** | 由本镜高风险推导的额外人物、重复道具、错误口型、自动字幕等 |

**规则：**

- continuity in 必须来自上一镜或场次事实；continuity out 写成下一镜可引用状态。
- 负向约束最多优先处理少数真实风险，先去重再输出。
- 平台无关主提示词和平台适配层分离。
- 视觉目标与真实交付规格分离；“8K 质感”不能冒充实际 8K 文件。

**常见失败：** 状态回退、下一镜无法接、否定词互相冲突、私有参数污染主提示词。

**检查：** 审核者能否逐项判定通过/失败，而不是只能说“感觉不对”？

## 三种信息预算

### 精简版

保留：L1 主目标、L2 主体与状态、L3 数量和关键空间、L5 构图、L6 核心光色、L7 交付和一到三个风险。简单静态图片可合并 L4/L5。

### 标准版

七层都覆盖，但只写决定结果的信息。批准资产事实使用 ID 和版本引用，不在每镜重复整份人物小传。

### 导演版

显式展示 open/close state、beat timeline、camera start/path/end、audio cues、continuity in/out 和三栏约束。适用于对白、复杂动作、多人、多镜头和严格连续性。

## 从需求到提示词的装配顺序

1. 建立意图与硬约束快照。
2. 从资产和项目记录取事实，不在提示词中重新发明。
3. 先解决数量、空间、动作和时长冲突。
4. 再设计摄影机、光色、材质和声音。
5. 写首尾状态和连续性。
6. 从已知失败中选择少量禁止项。
7. 把 provider 参数移入平台适配层。
8. 用质量量表和本地审计器检查。

## 冲突优先级

发生冲突时按以下优先级处理，低层不能静默覆盖高层：

1. 安全、法律、权利和平台明确限制。
2. 用户明确硬约束、精确数量、逐字文字/对白和时长。
3. 已批准资产与连续性事实。
4. 镜头叙事目标和时长可执行性。
5. 动作、摄影机、剪辑和声音契约。
6. 光色、材质和风格偏好。
7. 装饰性质量词和平台默认值。

若高优先级要求彼此冲突，列出冲突并请求选择；不要自行牺牲其中一个。

## 主提示词与平台适配层

**主提示词：** 只写可观察创作结果和连续性契约。

**平台适配层：** 只在提供方明确时写模型版本、时长字段、参考权重、seed、采样、运动强度、首尾帧槽位或 API 参数。未知时写 `provider: unspecified`，不能猜参数。

平台适配不得删改主提示词中的硬约束，也不能把模型能力限制伪装成用户选择。

## 最终结构检查

- [ ] 一个主意图。
- [ ] 精确主体和批准状态。
- [ ] 引用继承与排除范围。
- [ ] 空间、屏幕方向和唯一物体可画出。
- [ ] 动作有触发、接触、反作用和落定。
- [ ] 摄影机有起点、一个主路径和终点。
- [ ] 时长容纳动作和对白。
- [ ] 光源、材质和声音不冲突。
- [ ] 必须保持 / 本镜变化 / 禁止出现可检查。
- [ ] 主提示词和平台适配层分开。
