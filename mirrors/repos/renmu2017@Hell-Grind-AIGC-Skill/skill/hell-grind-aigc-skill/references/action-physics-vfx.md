# 动作、物理与视效反馈

## 动作写作公式

所有重要动作优先按：

```text
准备 → 发力 → 接触 → 反作用 → 落定
```

再补充触发、时间、轨迹、环境反馈和摄影机观察。动作词越多不代表动作越清楚。

## 五段物理链

### 准备

写身体重心、支撑点、握持、肌肉或机械预备状态。没有准备，复杂动作容易从静止瞬间跳到结果。

### 发力

写力量来源、方向、加速和身体协同。投掷来自腿、髋、躯干、肩、肘和手的连续发力，不是物体自己飞出。

### 接触

写接触点、接触时刻和材料。拳击、脚步、轮胎、刀刃、门、地面和液体产生不同接触。

### 反作用

写施力者、受力者、道具、环境和摄影机的合理反馈。撞击有减速、形变、振动、声音、尘土或液体飞溅。

### 落定

写动作停止后的姿态、位置、道具、碎片、伤势和环境状态。这是下一镜的 continuity out。

## 重量、惯性和摩擦

- 重物启动慢、停止慢，身体需要更大重心调整。
- 轻物加速快，但仍受空气和接触影响。
- 角色奔跑时衣物、背包和头发有滞后运动。
- 急停时上身和携带物继续前冲，再回落。
- 湿地、冰、沙、碎石和金属地面有不同摩擦与脚步反馈。
- 接触阴影和压痕帮助物体读出重量。

## 投掷

必须写：

- 哪只手、怎样握持。
- 准备姿态和重心。
- 释放点、方向、速度和轨迹。
- 物体旋转或姿态。
- 撞击目标、接触点和反弹/嵌入/破碎。
- 投掷者随后的手臂、躯干和重心。

最小示例：

```text
她将重心压到右后脚，右手从肩后加速向前；在胸口高度释放扳手，扳手沿低弧线旋转，撞击金属门中央后弹落地面；手臂顺势前伸，身体向前跨半步再站稳。
```

## 撞击与碰撞

撞击不只是“爆发”：

- 接触前速度和方向。
- 接触材料：肉体、布料、骨骼、金属、玻璃、混凝土。
- 瞬间压缩、弯曲或破裂。
- 受力者位移和旋转。
- 施力者的反冲或减速。
- 声音、粉尘、碎片、火花或液体。
- 撞击后谁保持控制、谁失去平衡。

摄影机震动只能绑定到明确冲击时刻，并在短时间内恢复；不要整镜随机抖动。

## 打斗与编排

复杂打斗先拆成可读节拍：

```text
威胁建立 → 一次攻击 → 一次防守/躲避 → 一次明确反击 → 落定
```

规则：

- 每个节拍只有一个动作中心。
- 明确谁先、谁因何反应。
- 写出手脚的解剖侧和屏幕方向。
- 避免多人同时做不同复杂动作。
- 镜头时长不足时拆镜，不用“高速连续完成十个动作”。
- 打击伤势若影响下一镜，写入状态版本和连续性。

## 行走、奔跑与追逐

- 起步：重心前移、支撑脚发力。
- 速度：步频和步幅，而不是只写“快速”。
- 路径：沿哪个锚点、是否转向、是否跨越障碍。
- 摄影机：与主体的相对位置和速度。
- 环境：脚步尘土、水花、衣料、背包、呼吸。
- 停止：减速、滑步、碰撞或转身后的落定。

追逐中屏幕方向应跨切稳定；改变方向时展示转向过程。

## 爆炸时间线

爆炸适合用毫秒/秒级阶段，但不要伪造平台精度承诺。结构：

```text
预兆：光、压力、裂纹或声音变化
起爆：明确源点和方向
火球/冲击波：传播速度和遮挡
碎片：材料、尺寸、轨迹和危险区
人物反应：先受光/声还是先受冲击
环境变化：门窗、尘土、火焰、照明
余波：烟、落尘、耳鸣、物体落定
```

不要同时要求爆炸巨大、所有人完全不动、环境无变化和声音安静。

## 粒子、烟、雨、雪和液体

粒子必须有来源、方向、尺度、速度、受力和结束：

- 雨打湿皮肤、衣物和地面，形成反光和滴落。
- 风改变头发、衣摆、烟和雪的共同方向。
- 灰尘从撞击点扩散，受光束显形并逐渐沉降。
- 液体飞溅来自接触点，落到附近表面并留下新状态。
- 火花沿金属切线或撞击方向飞出，亮度影响邻近表面。

只写“很多电影感粒子”会造成无来源噪点。

## 怪物与变形

怪物动作同时受解剖和性格限制：

- 肢体数量、关节方向、重心和步态来自资产身份。
- 攻击方式写身体准备和质量。
- 变形写阶段顺序、组织来源、体积守恒或明确超自然规则。
- 新材料出现时写表面、光照响应和与旧组织的过渡。
- 变形结束写新的批准状态，不在下一镜回退。

## 环境视效反馈

任何强动作至少检查：

- 地面：脚步、压痕、碎裂、摩擦痕、水花。
- 空气：尘、雾、烟、压力波。
- 光：火光、闪烁、遮挡、反射变化。
- 声：接触、破裂、回声和环境底床变化。
- 道具：位移、旋转、损坏和落定。
- 人物：衣物、头发、呼吸、姿态和伤势。

## 动作时长与降级

发现超载时：

- 删除不影响叙事的装饰动作。
- 把多个动作合并成一个清晰结果。
- 减少角色数量或让背景角色保持状态。
- 固定摄影机，避免动作和复杂运镜争夺。
- 拆成两个镜头并建立动作接点。
- 将复杂破坏放到后期合成，而不是继续要求单次生成完成一切。

## 常见失败诊断

| 症状 | 先检查 | 最小修复 |
|---|---|---|
| 物体漂浮 | 接触、重量、支撑和阴影 | 写接触面、受力和落定 |
| 投掷方向错 | 释放点和屏幕方向 | 写解剖侧、轨迹、目标和碰撞 |
| 撞击无力 | 缺反作用 | 补减速、形变、位移、声音和环境反馈 |
| 动作次序错 | 没有 beat timeline | 按触发和时间段拆分 |
| 身体融合 | 多人动作重叠 | 分配动作中心、空间位置和接触边界 |
| 爆炸像贴图 | 缺来源和阶段 | 写源点、冲击波、碎片、光和余波 |
| 粒子无来源 | 只写氛围词 | 绑定到风、撞击、火或天气 |
| 动作没结束 | 缺落定 | 写尾帧位置、姿态、道具和环境状态 |

## 动作质量门

- [ ] 重要动作遵循准备 → 发力 → 接触 → 反作用 → 落定。
- [ ] 时间线不越过镜头时长。
- [ ] 重量、惯性、摩擦和接触合理。
- [ ] 解剖侧和屏幕方向明确。
- [ ] 多人动作有唯一动作中心和因果顺序。
- [ ] 投掷、撞击、打斗、爆炸、粒子有来源和结束。
- [ ] 环境、声音和摄影机反馈与事件同步。
- [ ] close state 已写入下一镜连续性。
