# 灯光、色彩、材质与天气

## 从真实光源开始

每个主要光都回答：

- **光源**：太阳、天空、窗、灯具、火焰、屏幕、车灯或超自然源。
- **方向**：相对场景、人物和摄影机从哪里来。
- **软硬**：光源面积和距离带来怎样的阴影边缘。
- **对比**：明暗层级和填充程度。
- **曝光保护**：脸、窗外、火焰、金属高光或暗部中谁优先保留细节。

推荐写法：

```text
主光来自画面左后方开启的仓库门，冷而宽的天光形成柔边逆光；室内只有工作台小灯作为局部暖光，不填平脸部阴影；保护皮肤和门外天空高光。
```

## 光线五层

| 层 | 作用 | 需要写什么 |
|---|---|---|
| 环境底光 | 建立整体可见度和色温 | 天空、室内反弹、雾中散射 |
| 主光 | 建立主体体积和叙事焦点 | 来源、方向、软硬、强度关系 |
| 辅光/负补光 | 控制阴影信息 | 填充比例或有意压暗 |
| 轮廓/实景光 | 分离轮廓并证明光源存在 | 门、灯、火、屏幕的空间位置 |
| 互动光 | 事件对主体和环境的瞬时影响 | 爆炸、车灯扫过、屏幕变化 |

不是每个镜头都需要五盏灯。自然光场景可能只有天空与反弹；关键是光源逻辑一致。

## 摄影机在光的哪一侧

- 顺光：信息清楚，体积较弱。
- 侧光：强调面部和材质体积。
- 逆光：强调轮廓、空气和遮挡，脸部需要明确是否保持阴影。
- 阴影侧机位：强调反差和轮廓，但不能同时要求均匀明亮的正面肤色。

若写“脸在深影中”，可允许的可见信息应具体，例如轮廓边缘、眼睛反光或非常弱的天空反弹；不要同时追加“脸部每个毛孔明亮可见”。

## 曝光和动态范围

写优先级，而不是同时保住所有极端：

```text
曝光优先保护人物脸部中间调；窗外允许接近高光但保留云层；房间角落落入深影，不要求全部提亮。
```

常见冲突：

- 夜景要求“极暗”又“每个背景细节清晰”。
- 火焰是最亮源，却要求火焰完全不过曝且整个场景同样明亮。
- 逆光剪影又要求正面均匀美妆光。

## 60:30:10 的适用边界

60:30:10 是可选的色彩层级工具：

- 60% 主色建立世界和大面积背景。
- 30% 辅色分离主体或第二空间。
- 10% 强调色指向叙事焦点。

它不要求像素精确，也不适合所有纪实、单色、自然混光或高饱和场景。只在颜色层级真的有叙事用途时使用。不要把 60:30:10 固定复制到每个提示词。

## 颜色脚本

跨场次先记录：

- 世界基色。
- 角色识别色。
- 安全/危险、现实/幻觉、过去/现在等叙事色。
- 场次中的颜色变化。
- 禁止漂移的色温或强调色。

单镜头写颜色作用：

```text
冷灰环境维持压迫；人物褪色蓝制服与背景分离；红色警示灯只在尾帧进入，成为唯一高饱和焦点。
```

## 材质响应

材质不是名词，而是在同一光下的不同响应：

| 材质 | 重点响应 | 常见失败 |
|---|---|---|
| 皮肤 | 毛孔、细毛、油脂区、次表面透光、颜色不均 | 塑料磨皮、所有区域同亮 |
| 布料 | 织纹、褶皱、厚度、磨损、吸水 | 像橡胶或贴图 |
| 金属 | 边缘高光、环境反射、锤纹、氧化、划痕 | 统一灰色、无反射结构 |
| 玻璃 | 反射、透射、厚度、污渍、折射 | 完全透明无存在感 |
| 木材 | 纹理方向、粗糙度、边缘磨损 | 塑料木纹 |
| 骨骼/角质 | 多孔、细裂、半哑光、厚度 | 光滑陶瓷感 |
| 湿表面 | 窄高光、环境反射、滴落、颜色变深 | 只加亮度，不影响周围 |
| 烧焦表面 | 高粗糙度、裂缝、内部残留颜色、无均匀镜面 | 像黑色油漆 |

复杂角色先做材质分区：哪些区域是皮肤、布料、骨、金属、湿面、烧焦面；不同区域不能共享同一种高光。

## 天气必须作用于世界

### 雨

衣服吸水变深，皮肤和硬表面出现不均匀水膜，地面反光和水花有方向，雨受风影响。

### 雪与暴风

雪积在迎风面和水平面，人物呼吸、头发、衣摆和能见度共同变化；不能只有背景贴一层雪点。

### 雾与烟

雾显示光路并降低远景对比；烟有来源、温度、方向和消散。不要让前景主体与远景保持同样清晰对比。

### 尘土

尘土来自脚步、撞击或崩塌，受光束显形，随后扩散和沉降。

### 风

头发、布料、雨雪、烟和植被方向一致。不同重量产生不同延迟和幅度。

## 光色连续性

跨镜头记录：

- 主光源的场景位置。
- 人物相对光源的位置和面向。
- 色温与曝光重点。
- 天气强度和方向。
- 湿度、积雪、烟尘和破坏状态。
- 互动光发生的时间点。

换机位会改变脸部受光，但不能让固定窗光从房间另一侧出现。

## 常见失败与最小修复

| 症状 | 先检查 | 最小修复 |
|---|---|---|
| 光源无来源 | 只写“电影灯光” | 指定真实光源、方向和作用范围 |
| 脸部要求矛盾 | 深影与均匀明亮并存 | 选择曝光优先级，列允许高光信息 |
| 材质都塑料化 | 只写材质名称 | 写粗糙度、反射、透光、湿度和磨损差异 |
| 颜色混乱 | 堆多个主色 | 分主色、辅色、强调色及叙事作用 |
| 强调色面积失控 | 把 10% 当全局滤镜 | 限定到一个物体或事件 |
| 天气像贴层 | 未写互动 | 让天气影响人物、地面、声音和能见度 |
| 跨镜光反转 | 没记录光源位置 | 在连续性矩阵锁定场景光源 |

## 质量门

- [ ] 每个主要光源有空间来源。
- [ ] 方向、软硬、对比和曝光保护不冲突。
- [ ] 60:30:10 只在适用时使用。
- [ ] 主色、辅色、强调色有叙事作用。
- [ ] 关键材质响应彼此不同。
- [ ] 天气同时作用于主体和环境。
- [ ] 光色与上一镜和下一镜连续。
