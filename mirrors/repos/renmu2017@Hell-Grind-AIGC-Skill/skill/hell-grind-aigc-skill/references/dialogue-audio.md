# 对白、环境声、拟音与混音

## 声音是镜头数据

声音至少分为：

- 逐字对白。
- 呼吸和脚步等表演声。
- 动作拟音。
- 环境底床。
- 场外事件声。
- 音乐或明确无音乐。
- 静默。

每条重要声音使用 `audio_cue_id`、时间、声源、空间位置和混音优先级记录。

## 逐字对白锁

逐字对白必须写：

```text
说话者：[稳定 ID]
发声时间：[开始–结束]
精确台词：“……”
语速/音量/情绪：[可听参数]
口型：只在精确台词期间运动
尾部：最后一个字后嘴唇静止并保留[时长]静默尾拍
```

“只说这句”仍应明确无加词、无语气词、无即兴、无额外笑声/叹气/呻吟，尤其在严格脚本场景中。

## 发声时间

- 用自然语速朗读并实测，不按字符数猜。
- 台词前留吸气或决定开口的短停顿。
- 台词后留静默尾拍，让表演和剪辑落地。
- 对话轮次不无意重叠；需要抢话时明确重叠区间。
- 动作和对白共享镜头时长，不能分别把全部时长占满。

简单分配：

```text
0.0–0.8s 看向门缝并吸气
0.8–2.4s 逐字说“别开门”
2.4–4.0s 嘴唇静止，手从门把收回，保留静默尾拍
```

## 对白不视觉化

对白提到过去事件、未在场人物、地点或想象内容时，模型可能自动生成闪回、幻象或额外人物。严格写：

```text
对白内容只作为声音信息；对白不视觉化。没有闪回、插入画面、幻象、额外人物或场景变化。画面只包含当前允许集合。
```

若项目确实需要闪回，应把它设计成明确的新镜头，而不是让台词自动决定画面。

## 未说话者

- 未说话者嘴唇保持静止或自然轻闭。
- 可以有无声面部反应，但不发出即兴语气词。
- 视线和呼吸按表演契约执行。
- 不同步复制说话者口型。
- 画外音说话者是否在空间中必须明确。

## 环境底床

环境底床证明空间持续存在：

- 室内：HVAC、冰箱、灯具电流、远处管道、房间反射。
- 城市：交通、远处人声、风、雨、信号声。
- 荒野：风、昆虫、水、植被、远雷。
- 工业：机器低频、金属振动、蒸汽、警报。

写声源远近和方向，不用无来源“电影氛围音”。环境底床在对白下方持续，但可轻微 duck，让人声清楚。

## 动作拟音

拟音绑定到可见接触：

- 脚步对应地面材质、速度和重量。
- 衣料对应动作幅度、湿度和服装材质。
- 道具对应握持、摩擦、开合、撞击和落地。
- 肉体、金属、木、玻璃和混凝土撞击音不同。
- 远处爆炸先见光还是先听声取决于叙事距离和设计，不要随机。

没有可见接触时，不自动添加撞击声。

## 声音空间

记录：

- 屏幕内/屏幕外。
- 摄影机前后左右。
- 近、中、远距离。
- 室内反射或室外开放感。
- 声源是否移动。
- 遮挡、门墙和头部转向对声音的影响。

画外喊声来自摄影机后方时，应同时明确说话者不在画面边缘、背景或倒影中。

## 混音优先级

常见优先级：

```text
关键逐字对白 > 叙事关键音效 > 表演呼吸/拟音 > 环境底床 > 音乐
```

并非固定。声音主导镜头可以让环境事件高于对白，但必须明确。

Voice-first 写法：

```text
人声近讲、清楚、占据混音前景；环境底床保持低电平，台词出现时轻微压低；关键门锁咔哒声在台词结束后的静默中突出。
```

不要同时要求“完全无混响”和“巨大教堂自然回声”，除非说明人声是后期近讲、环境另保留空间反射。

## 音乐、字幕和旁白边界

- 无音乐时同时写 `无配乐、无乐谱、无自动情绪音乐` 即可，不需重复十种同义句。
- 字幕与画面文字是不同轨道；无字幕不代表场景招牌消失。
- 无旁白时明确没有额外解释性声音。
- 发布字幕文件属于交付阶段，生成画面中不烧录字幕。

## audio cue 表

| 字段 | 说明 |
|---|---|
| `audio_cue_id` | 稳定 ID |
| `shot_id` | 所属镜头 |
| `start_seconds/end_seconds` | 发声时间 |
| `category` | dialogue / foley / ambience / music / silence |
| `source` | 稳定资产或空间源 |
| `content_or_effect` | 逐字内容或音效描述 |
| `spatial_position` | 画内外、方向、距离 |
| `mix_priority` | foreground / mid / bed 或项目等级 |
| `continuity_key` | 跨镜持续的声音状态 |

## 声音连续性

- 环境底床跨同一场次保持。
- 门、机器、警报等持续声记录开启/关闭时刻。
- 声音桥明确从上一镜延续到下一镜的时间。
- 角色声音、语速和空间距离保持。
- 伤势、疲劳和环境改变呼吸时写状态变化。
- 音乐开始、停止或不使用都记录，不让平台自动决定。

## 常见失败与修复

| 症状 | 先检查 | 最小修复 |
|---|---|---|
| 台词加词 | 是否只写了大意 | 提供逐字台词、说话者和唯一发声窗口 |
| 台词太快 | 发声时间不足 | 实测朗读，删动作或延长/拆镜 |
| 未说话者嘴动 | 口型范围不清 | 明确只有说话者在台词窗口口型运动 |
| 台词变闪回 | 缺视觉边界 | 写对白不视觉化和当前允许集合 |
| 自动音乐 | 音乐边界缺失 | 明确无配乐，并写环境底床替代空白 |
| 声音混乱 | 没有混音优先级 | 排人声、关键音效、拟音、环境和音乐层级 |
| 画外人入镜 | 空间位置含糊 | 写声音方向、距离及人物不在画面空间 |
| 环境声断裂 | 无 continuity key | 记录跨镜底床和开关事件 |

## 声音质量门

- [ ] 逐字对白、说话者和发声时间明确。
- [ ] 未说话者口型和声音边界明确。
- [ ] 静默尾拍有真实时长。
- [ ] 对白不视觉化规则按需声明。
- [ ] 环境底床有空间来源。
- [ ] 拟音绑定到可见动作。
- [ ] 混音优先级明确。
- [ ] 音乐、字幕和旁白边界明确。
- [ ] 跨镜声音连续性已记录。
