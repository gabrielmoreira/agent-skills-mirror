# 视频提示词镜头契约

## 先判断是一镜还是多镜

- **单镜头**：摄影机连续观察，没有剪辑；只有一个主运动。
- **多镜头序列**：包含明确切点；每段分别拥有时长、构图和动作接点。
- **蒙太奇**：通过并列片段表达变化；仍要限制镜头数量、顺序和总时长。

不要把多个互不相容的摄影机运动塞进“单镜头”，也不要把一段动作列表误称为蒙太奇。

## 12 段镜头契约

1. **镜头目标与叙事功能**

   **目的：** 定义观众在本镜需要理解、感受或发现什么。

   **必填：** 一个主功能、一个主要可见事件、结束时的叙事落点。

   **写法：** `本镜通过[主要事件]让观众[理解/感受/发现]；结束时停在[信息/情绪]。`

   **冲突：** 同时要求介绍地点、完成复杂动作、说长对白和揭示反转。

   **验收：** 删除风格词后，本镜存在理由仍清楚。

2. **精确角色数量、稳定 ID 与允许集合**

   **目的：** 锁定可见、可听和空间中允许存在的角色或生物。

   **必填：** 精确总数、资产 ID、各出现一次或零次、画外音是否计入空间。

   **写法：** `画面中恰好[N]个主体：[ID 列表]各出现一次；未列出的角色不在画面和空间中。`

   **冲突：** 列出两人但要求“只有一人”；画外说话者既声明不在场又在背景出现。

   **验收：** 每帧人数可数，反射、屏幕和背景不产生额外人物。

3. **当前外观、状态与引用范围**

   **目的：** 将身份不变量、当前状态和参考继承范围分开。

   **必填：** 资产状态版本、服装、伤势、湿度、污渍、携带物、参考 `inherit/exclude`。

   **写法：** `[资产@状态版本]；保持[身份锚点]；当前[状态]；参考只继承[属性]，排除[构图/机位/光线等]。`

   **冲突：** 同一角色同时穿两个版本服装；上一镜伤口在右侧、本镜改为左侧。

   **验收：** 任何状态变化都能追溯到场次或上一镜。

4. **场景、空间、屏幕方向与唯一道具**

   **目的：** 确定场景区域、前中后景、人物站位、轴线、出入口和接触关系。

   **必填：** 场景 ID、空间锚点、屏幕位置、解剖方向、唯一物体、所有者与接触。

   **写法：** `[场景区域]；A 在屏幕左中景面向右，B 在屏幕右；唯一道具位于……并由……接触。`

   **冲突：** 人物解剖左和屏幕左混用；场景参考被错误当作构图参考。

   **验收：** 能画出粗略平面图并建立对话或运动轴线。

5. **open_state、beat_timeline 与 close_state**

   **目的：** 让动作在时长内按因果执行，并形成可接下一镜的尾部状态。

   **必填：**

   - `open_state`：首帧人物姿态、视线、道具、环境和声音状态。
   - `beat_timeline`：触发、动作、对白、碰撞、反应和停顿的时间段。
   - `close_state`：尾帧位置、姿态、道具、表情、环境和声音状态。

   **写法：** `0.0–1.0s 保持……；1.0–3.2s 因……做……；3.2–5.0s 落定……；尾帧……。`

   **冲突：** 节拍总时长超过镜头；要求“全程静止”又安排移动；动作没有落定。

   **验收：** 时间段不重叠越界，首尾帧可分别画出，结束状态可直接输入下一镜。

6. **camera_start、camera_path 与 camera_end**

   **目的：** 建立完整摄影机契约，而不是只给一个运镜动词。

   **必填：**

   - `camera_start`：起始构图、机位、高度、角度、景别、焦段视觉效果、对焦对象。
   - `camera_path`：一个主运动、方向、速度、距离、稳定方式、是否重新对焦。
   - `camera_end`：结束构图、景别、主体关系、对焦与下一镜接点。

   **写法：** `从[起始]开始，以[速度/距离]进行[主运动]，保持[稳定方式]，最终落到[结束构图]。`

   **冲突：** 锁定机位同时快速环绕和推进；“自然手持”同时要求完全无微动。

   **验收：** 只有一个主运动；起点、路径和终点空间上连续。

7. **光线、曝光、色彩、材质与天气**

   **目的：** 让光源和环境作用于主体，而非附加一串质感词。

   **必填：** 真实光源、方向、软硬、对比、曝光保护、颜色层级、关键材质响应、天气作用。

   **写法：** `主光来自……；保护……；主/辅/强调色承担……；湿布/金属/皮肤分别响应……；风雨作用于……。`

   **冲突：** 自然光 only 与明确人工主光并存；脸部要求深影和均匀亮肤同时成立。

   **验收：** 每束主要光有来源，材质不同，天气同时影响人物和环境。

8. **表演、视线、呼吸与动作物理**

   **目的：** 把情绪变成可见表演，把动作变成有重量的因果链。

   **必填：** 视线来源、微停顿、呼吸、面部变化、身体重心、接触、反作用和落定。

   **写法：** `[触发]后先[微停顿/吸气]，视线……，重心……；准备 → 发力 → 接触 → 反作用 → 落定。`

   **冲突：** “克制”却要求持续夸张动作；物体被投掷但没有发力、轨迹或撞击反馈。

   **验收：** 情绪至少有两个表演信号，动作有接触和反作用。

9. **continuity_in、continuity_out 与三栏约束**

   **目的：** 把跨镜头状态变成明确输入输出。

   **必填：**

   - `continuity_in`：上一镜/场次带入的身份、状态、位置、轴线、道具、环境和声音。
   - `continuity_out`：本镜结束后交给下一镜的同类状态。
   - `must_hold`：本镜必须保持。
   - `changes_here`：本镜唯一允许变化。
   - `must_not_appear`：当前风险驱动的禁止项。

   **写法：** 三栏分别列出，不把所有内容都塞进否定句。

   **冲突：** `must_hold` 和 `changes_here` 同时包含同一状态；下一镜输入与本镜输出不一致。

   **验收：** 每个变化有起因，未声明状态保持稳定。

10. **逐字对白、audio_cues 与混音边界**

   **目的：** 控制说话者、逐字内容、时间、口型、环境声、拟音、音乐和静默。

   **必填：**

   - 说话者和精确台词。
   - 台词开始/结束和尾部静默。
   - `audio_cues`：时间、声源、空间位置、内容、优先级。
   - 对白是否仅为声音、不可被视觉化。
   - 音乐、字幕、旁白和非脚本声音边界。

   **写法：** `1.0–2.7s A 只说“……”；随后嘴唇静止；环境底床……；无配乐/字幕。`

   **冲突：** 台词时长超过分配；未说话者嘴动；台词提及的人物被错误生成进画面。

   **验收：** 所有声音有来源和时间；对白内容与视觉事件分开。

11. **risk_focus 与针对性负向约束**

   **目的：** 只防本镜最可能的少数失败，并支持后续按错误码复测。

   **必填：** `risk_focus` 最多优先列出三个风险；每个风险对应一个正向契约和必要的禁止项。

   **写法：** `优先风险：人数、左右、口型。禁止额外人物、解剖侧翻转、非说话者嘴动。`

   **冲突：** 负向词重复；禁止“抖动”却又要求重度手持；禁止“声音”却要求对白。

   **验收：** 每个禁止项能追溯到当前镜头风险，不含无关通用词。

12. **交付规格与平台适配层**

   **目的：** 分开真实交付要求、视觉目标和提供方私有参数。

   **必填：** 时长、帧率目标、画幅、方向、实际分辨率目标、用途；provider 未知时写 unspecified。

   **写法：** `交付：6 秒、24fps 运动目标、16:9、1920×1080、横版剪辑；平台参数另列。`

   **冲突：** “8K 质感”被写成平台一定返回 8K；主提示词混入 seed、CFG、采样器。

   **验收：** 主提示词不依赖某平台语法；适配层不覆盖硬约束。

## 动作与时长预算

粗略预算只用于发现明显超载，不替代真实表演计时：

| 内容 | 通常至少预留 |
|---|---:|
| 观众读清初始状态 | 0.3–0.8 秒 |
| 简单反应 | 0.5–1.2 秒 |
| 一次完整身体动作 | 1–3 秒 |
| 短句对白 | 按自然朗读实测并留前后停顿 |
| 冲击后的可见落定 | 0.3–1 秒 |

超载时按顺序处理：删除装饰动作、缩短台词、降低摄影机运动、拆镜头。不要靠“快速完成所有动作”掩盖物理不可能。

## 项目内调用

从镜头表读取 shot ID、时长和叙事目标；从资产与状态表读取批准身份；从 beat/audio 表读取时间；从连续性矩阵读取输入输出。提示词不得创建未登记的主要角色、怪物、地点或关键道具。

## 输出顺序

```text
模式与丰富程度
原始意图/硬约束快照
平台无关主提示词
平台适配层
设计或修改摘要
假设与待确认项
质量评分
风险与首轮测试建议
```
