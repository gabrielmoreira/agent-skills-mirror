# 表演指导：把情绪写成可见行为

## 表演不是情绪标签

“悲伤、恐惧、愤怒、震惊”只说明意图。可执行表演需要写视线、面部、呼吸、停顿、声音、身体重心、手部和动作幅度。

推荐结构：

```text
触发 → 微停顿 → 视线变化 → 呼吸变化 → 面部变化 → 身体重心/动作 → 落定
```

## 六个表演通道

| 通道 | 可见/可听信息 | 风险 |
|---|---|---|
| 视线 | 看谁、何时移开、是否锁住目标 | “看左”坐标含糊 |
| 面部 | 眉、眼睑、嘴角、下颌、吞咽 | 堆太多会变夸张 |
| 呼吸 | 吸气、屏住、呼出、胸口起伏 | 未授权声音可能污染对白 |
| 停顿 | 反应前后留白、台词间空拍 | 时长不足会被压缩 |
| 身体重心 | 前倾、后移、脚步、肩线 | 与动作物理冲突 |
| 手部 | 抓紧、松开、悬停、触碰 | 左右和道具接触易漂移 |

## 情绪转译词典

### 克制恐惧

- 视线锁住威胁，不快速乱看。
- 吸气后短暂屏住，胸口轻微抬起。
- 下颌收紧，嘴唇微张但不说话。
- 身体重心后移，脚仍未迈出。

### 突然震惊

- 触发后先有很短停顿。
- 眼睑张开、瞳孔目标固定。
- 呼吸中断或快速吸气。
- 肩膀和头部只做一次小幅后撤。

### 压抑愤怒

- 视线持续，不来回扫动。
- 下颌和咬肌收紧。
- 呼气更慢，肩线保持压低。
- 握紧物体后克制地放松，而不是挥舞。

### 疲惫

- 眨眼变慢，视线抬起需要时间。
- 肩膀下沉，身体重心依赖支撑物。
- 呼吸较深，动作开始前有延迟。
- 手部抓握不完全，仍保持真实接触。

### 决心形成

- 先看向障碍或目标。
- 呼吸从短促变为一次稳定呼气。
- 身体重心从后脚移到前脚。
- 眼神和下颌稳定，动作随后开始。

这些不是固定配方。每个镜头选择少量信号，避免所有面部和身体通道同时“最大强度”。

## 微停顿和反应因果

自然反应通常不是触发与动作同时发生：

```text
听见门后撞击 → 0.2 秒停顿 → 眼睛先转向门 → 头和肩随后转动 → 右手从把手收回 → 落定
```

时间很短时至少保留触发和一个可见反应，不要把五个表演节拍压在半秒内。

## 视线

写清：

- 视线目标是人物、道具、空间锚点还是画外方向。
- 目标在屏幕哪侧、是否移动。
- 眼睛先动还是头部先动。
- 何时断开视线。
- 多人对话中谁看谁、谁回避。

不要写“看向左边”；写“眼睛先转向屏幕右侧门缝，头部随后只转约四分之一侧面”。

## 呼吸与声音边界

呼吸既是表演也是声音。若镜头有逐字对白：

- 写呼吸发生在台词前、台词中还是台词后。
- 区分可见胸口起伏和可听喘息。
- 没有脚本声音时，不要自动加入呻吟、笑声、叹气或语气词。
- “半笑”可只是面部表情，除非明确要求可听笑声。

## 身体重心

身体动作从重心开始：

- 站立：重量在哪只脚、膝盖是否锁定、是否靠墙或桌。
- 起步：重心先移到支撑脚，另一脚才能离地。
- 后退：身体先缩回还是脚先探路，决定恐惧程度。
- 下蹲：髋、膝、脚和上身如何协调。
- 撞击：重心被打断，身体和道具产生反作用。

没有重心描述的“突然下蹲”容易变成身体整体下沉或穿地。

## 主体与背景表演层级

复杂镜头明确：

- 主表演者：完成镜头叙事变化。
- 次表演者：做一个可见反应或保持状态。
- 背景角色：执行低幅度持续动作，或明确静止。

不要让所有角色从第一帧同时高强度移动、转头、说话和挥手。每个角色只承担当前镜头需要的动作。

## “静止”如何写

完全静止用于严格动作锁，但需要说明允许范围：

```text
身体位置、头部方向、双手和脚步保持不变；允许自然眨眼和很弱的胸口呼吸；不说话、不转头、不做手势。
```

若必须像雕像般零微动，则明确禁止眨眼和呼吸，但要知道这可能降低真人感。

“保持静止”和“持续表现强烈恐惧”可以共存，前提是恐惧主要通过已建立的表情和低幅呼吸保持，而不是新增动作。

## 对话表演

- 台词前：视线、吸气、决定开口的微停顿。
- 台词中：自然语速、重音、声音强度、是否保持视线。
- 台词后：嘴唇停止、呼气、视线或身体落点。
- 未说话者：明确一个反应，不让其同步口型。
- 台词提及的过去事件默认只存在于声音，不自动视觉化。

## 常见失败与修复

| 症状 | 原因 | 最小修复 |
|---|---|---|
| 表演僵硬 | 只有情绪词 | 添加触发、视线、呼吸和一个重心变化 |
| 表演过度 | 所有信号都最大化 | 保留两到三个通道，降低动作幅度 |
| 所有人抢戏 | 未分主次 | 指定主表演者，其他人只做一个反应或静止 |
| 未说话者嘴动 | 声音边界缺失 | 明确只有说话者口型，其他嘴唇静止 |
| 反应顺序错误 | 没有触发链 | 写触发 → 停顿 → 眼睛 → 头/身体 |
| 静止角色乱动 | “静止”范围含糊 | 列允许微动和禁止动作 |
| 情绪断裂 | 缺 continuity in/out | 写起始情绪、变化时刻和结束情绪 |

## 表演质量门

- [ ] 情绪已翻译为可见或可听行为。
- [ ] 触发和反应顺序明确。
- [ ] 视线目标和屏幕方向明确。
- [ ] 呼吸不污染逐字对白。
- [ ] 身体重心支持动作。
- [ ] 角色表演有主次。
- [ ] 静止的允许和禁止范围明确。
- [ ] 结束表演状态可接下一镜。
