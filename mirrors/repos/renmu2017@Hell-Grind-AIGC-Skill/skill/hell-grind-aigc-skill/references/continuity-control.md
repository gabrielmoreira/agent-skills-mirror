# 连续性控制

## 连续性不是一句“保持一致”

连续性需要把上一镜输出变成下一镜输入。每个关键字段记录 `continuity_in → changes_here → continuity_out`，并明确哪些是 must_hold。

## 八类连续性

### 身份连续性

脸、体型、年龄段、发型核心轮廓、怪物解剖和道具几何保持。镜头只引用批准资产 ID 和版本。

### 状态连续性

服装层级、伤势位置、湿度、污渍、携带物、门的开合、道具损坏和怪物变形阶段保持或有明确变化事件。

### 空间连续性

场景分区、出入口、唯一家具、人物相对位置、前中后景和接触关系可以追溯。换机位不等于重建房间。

### 轴线与屏幕方向

对话轴线、运动方向、视线方向和解剖左右保持。越轴或转向必须可见、可解释。

### 动作连续性

上一镜手、脚、道具、身体方向和动作阶段成为下一镜 open state。动作接切要匹配接触前/后、抬手/落手、起步/落脚等阶段。

### 光线与曝光连续性

固定光源的场景位置、色温、天气、互动光和曝光重点保持。换机位可以改变明暗面，但不能让窗光瞬移。

### 天气与环境连续性

风向、雨雪强度、积水、烟尘、火焰、破坏、散落物和能见度保持或记录变化。

### 声音连续性

环境底床、持续机器声、警报、音乐、角色声音距离和声音桥有 continuity key。画面切换不自动重置同一空间声音。

## 连续性矩阵字段

| 字段 | 问题 |
|---|---|
| `shot_id` | 哪个镜头 |
| `asset_version_ids` | 当前批准资产状态是什么 |
| `screen_direction` | 每个主体面对和移动方向 |
| `spatial_state` | 区域、深度层、相对位置 |
| `costume_state` | 服装和表面状态 |
| `injury_state` | 伤势位置、程度、可见范围 |
| `prop_state` | 所有者、手、位置、开合/损坏 |
| `environment_state` | 天气、烟尘、破坏、光源 |
| `action_in/action_out` | 首尾动作阶段 |
| `audio_state` | 持续声、音乐、声音桥 |
| `open_issues` | 未解决问题和严重级别 |

## 变化账本

对每个变化记录：

```text
之前状态
触发事件
本镜发生的可见变化
之后状态
从哪个镜头开始生效
是否需要新资产状态版本
```

未记录变化的字段默认保持。不要让提示词用新形容词悄悄改动连续性。

## 镜头首尾卡

### open state

- 人物和生物的位置、朝向、姿态、视线、表情。
- 手脚与道具接触。
- 服装、伤势、天气和环境破坏。
- 摄影机起始关系。
- 持续声音。

### close state

同样字段记录尾帧。下一镜若不直接连续，标记时间跳跃、地点跳跃或省略动作。

## 场次内连续与跨场次变化

### 同场次直接连续

严格继承上一镜 close state；只允许本镜 `changes_here` 中的变化。

### 同场次省略时间

记录省略时长和允许发生的状态变化；不能让重大伤势、换装或道具转移在无说明中发生。

### 跨场次

允许时间、地点、服装和环境改变，但新的 scene open state 必须有来源。角色身份和故事状态仍保持。

### 梦境/幻觉/闪回

作为明确场次或镜头类型登记，不由对白内容自动触发。视觉规则和返回现实的接点单独写。

## 连续性审核顺序

- 先看身份和精确人数。
- 再看状态版本和道具。
- 再看空间、轴线和屏幕方向。
- 再看动作接点。
- 再看光线、天气和环境。
- 最后看声音和剪辑桥。

先修高影响事实，不用调色或风格掩盖身份、人数或动作错误。

## 豁免

如果选中镜头存在可接受的连续性缺陷，记录：问题、影响、原因、批准人、适用范围和后期修复。口头“没关系”不能让 locked 镜头跳过质量门。

## 常见失败与修复

| 症状 | 责任层 | 最小修复 |
|---|---|---|
| 脸/体型变化 | 资产与引用 | 绑定批准资产状态，去掉相互冲突参考 |
| 伤口换边 | 状态矩阵 | 记录解剖侧、可见范围和版本 |
| 道具换手 | 动作接点 | 写上一镜 close 与下一镜 open 的手部接触 |
| 人物方向反转 | 轴线 | 锁屏幕方向或展示转身/中性镜头 |
| 房间布局变化 | 空间资产 | 使用场景分区和唯一锚点，不继承参考构图 |
| 光从另一侧来 | 场景光源 | 记录真实光源位置和人物面向 |
| 雨雪忽强忽弱 | 环境状态 | 写强度、方向和状态变化事件 |
| 环境声切断 | 声音连续性 | 使用 continuity key 或明确声音切断事件 |

## 连续性质量门

- [ ] 身份连续性和状态连续性分开检查。
- [ ] 空间连续性、轴线和屏幕方向可追溯。
- [ ] 动作连续性从 close state 接到 open state。
- [ ] 光线、天气和环境状态不瞬移。
- [ ] 声音连续性有 key 或明确切断。
- [ ] 所有变化出现在 changes_here。
- [ ] error 级问题已修复或有批准豁免。
