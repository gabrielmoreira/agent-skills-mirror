# 提示词意图保护与润色规则

## 先建立约束快照

把输入分为：原始意图、硬约束、可增强信息、显式冲突、歧义和缺失信息。润色前先输出或内部记录快照，润色后逐项对照。

硬约束通常包括主体身份与数量、动作结果、品牌与文字、逐字对白、参考图继承范围、镜头时长、画幅、交付用途和明确禁止项。润色时不得静默改变硬约束。

复杂视频镜头再建立三栏约束：

- **必须保持**：来自用户、批准资产和上一镜的稳定事实。
- **本镜变化**：本镜唯一允许发生的状态、位置、动作或情绪变化。
- **禁止出现**：根据当前高风险选择的少量失败项。

## 润色顺序

- 保留原始意图和叙事重心。
- 把抽象词改成可见、可听、可计时、可检查的描述。
- 消除主体数量、左右位置、动作时间、摄影机运动和声音规则之间的冲突。
- 只补充不会改变用户选择的细节；其他内容放入“假设与待确认项”。
- 输出修改摘要，逐项说明增强、澄清、移动到适配层或保留未改的内容。

## 冲突处理

按安全与权利、用户硬约束、批准项目事实、镜头可执行性、视听契约、美学偏好的顺序处理。若两个同级硬约束不可同时成立，指出冲突并询问，不得静默选择。

## 平台分层

主提示词保持模型无关。平台适配层只放提供方特有的模型名、参考权重、种子、采样、运动强度、首尾帧设置或 API 字段。适配时不得删掉主提示词中的硬约束。

## 从零生成

根据用户目标建立同样的约束账本。若用户未指定且选择不会改变创意方向，可给出明确假设；若会改变主体、数量、核心动作、逐字文字/台词、品牌、权利、预算或交付规格，先提一个最关键的问题。

## 三种丰富程度

- 精简版：保留最少必要结构，适合快速试验。
- 标准版：默认选择，覆盖完整视觉/镜头契约并控制长度。
- 导演版：加入时间线、表演、物理、声音、连续性和验收细节，适合关键镜头。

丰富程度只改变表达密度，不允许改变原始意图、数量、时长、逐字内容或引用范围。
