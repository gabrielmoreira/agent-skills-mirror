# 摄影机与剪辑语言

## 摄影机契约的最小闭环

完整镜头至少写：

```text
起始构图 → 一个主运动 → 稳定方式与对焦 → 结束构图 → 下一镜接点
```

只写“镜头推进”没有距离、速度、对焦和结束构图，无法评审是否正确。

## 起始构图

起始构图包含：

- 机位方向：正面、侧面、肩后、主观、俯视、仰视。
- 机位高度：地面、腰部、胸口、眼睛、头顶或明确尺度。
- 景别：大远景、全景、中景、中近景、近景、特写、极特写。
- 主体在画面的位置和占比。
- 前中后景关系。
- 对焦对象与景深。
- 屏幕方向和轴线。

示例：

```text
起始构图：人物解剖左后方肩后中景，摄影机略低于肩线；人物占屏幕右三分之一，门缝在左中景；焦点在她悬停的右手。
```

## 焦段视觉效果

优先写焦段视觉效果，再用毫米数辅助：

| 视觉效果 | 常见用法 | 风险 |
|---|---|---|
| 强广角空间展开 | 强调环境尺度、前后距离和速度 | 近脸变形、边缘拉伸 |
| 自然透视 | 对话、日常动作、克制观察 | 空间戏剧性较弱 |
| 中长焦压缩 | 隔离人物、压缩背景、亲密表演 | 动作空间和环境关系变弱 |
| 微距 | 材质、眼睛、机械细节 | 景深极浅、动作难保持 |

“24mm 焦段感”应同时说明为何需要前景夸张或空间纵深；“85mm”应说明背景压缩和面部自然比例。不要同时要求极广角夸张和强长焦压缩。

## 主运动选择

一个镜头只选一个主运动：

| 主运动 | 观察效果 | 必填参数 |
|---|---|---|
| locked | 等待表演进入构图 | 是否允许呼吸式微动 |
| pan | 横向重新分配注意力 | 起止对象、方向、速度 |
| tilt | 垂直揭示尺度或信息 | 起止高度、速度 |
| push/dolly in | 缩短距离、增加压迫或亲密 | 距离、速度、终点景别 |
| pull/dolly out | 揭示环境或隔离 | 距离、速度、终点关系 |
| track/follow | 与主体共同移动 | 相对位置、距离、速度 |
| orbit | 改变主体与背景关系 | 角度、方向、半径、终点 |
| crane/boom | 改变高度和空间层级 | 高度、路径、终点 |
| handheld | 人体参与感 | 幅度、频率、步伐、是否跟随呼吸 |

若需要“先推近再环绕”，通常已经是两个主运动。应删除其一、拆成多镜头，或明确第二段只是很小的构图修正。

## camera_start / camera_path / camera_end

推荐结构：

```text
camera_start: [机位、景别、构图、对焦]
camera_path: [主运动、方向、速度、距离、稳定方式、对焦变化]
camera_end: [结束景别、主体关系、对焦、下一镜接点]
```

摄影机路径必须在物理空间中可走通，不能穿过墙、人物或唯一家具，除非明确是非现实视效。

## 稳定方式

### 锁定

完全固定构图。若允许极轻微镜头呼吸，应明确“构图不漂移，仅有很弱的人体呼吸微动”。

### 稳定跟随

运动平滑但仍有重量，不等于无摩擦漂浮。写清加速、减速和停止。

### 自然手持

自然手持来自摄影师身体：小幅水平/垂直变化、步伐和呼吸节奏。写幅度和主运动关系。不要用“每帧随机抖动”。

### 重度肩扛

适合混乱和即时性，但仍要保持主体可读。说明是否允许构图边缘短暂切到、是否允许焦点追赶。

### 故障抖动

无因果的高频跳动、画面撕裂或随机位移属于失败，不是自然手持。若需要冲击震动，绑定到明确碰撞时刻并让摄影机恢复。

## 对焦与景深

对焦是叙事选择：

- 单一对焦对象优先。
- 拉焦必须写起点、触发、终点和时长。
- 复杂动作不要同时要求极浅景深和所有层始终清晰。
- 对白镜头关注说话者并不意味着未说话者完全失焦；可用层次保持反应可读。
- 镜头结束对焦对象应服务下一镜接点。

## 屏幕方向与轴线

- 对话两人通常保持 A 看右、B 看左。
- 运动方向跨切保持，除非镜头展示转向。
- 过肩镜头明确肩膀属于谁、前景肩在屏幕哪侧。
- 侧脸明确摄影机位于人物哪一解剖侧、鼻尖指向哪一屏幕侧。
- 有意越轴要设计视觉桥梁，不让生成结果偶然越轴。

## 单镜头剪辑感

即使没有切，镜头内部也可通过遮挡、拉焦、人物进出和构图重排产生节拍。仍然保持一个连续摄影机路径，不用“硬切”词混入单镜头。

## 多镜头切点

多镜头需要：

- 精确镜头数量。
- 每段时长。
- 每段起始和结束构图。
- 切点类型：硬切、动作匹配、视线匹配或声音桥。
- 动作接点：手、脚、道具和方向。
- 最终镜头落点。

示例结构：

```text
CUT A 0.0–2.0s：中景建立 A 抬头，尾帧视线指向屏幕右上。
HARD CUT。
CUT B 2.0–5.0s：A 的视线匹配到屋顶上方目标，摄影机锁定，目标从左向右进入。
```

## 常见失败诊断

| 症状 | 先检查 | 最小修复 |
|---|---|---|
| 运镜乱跳 | 是否有多个主运动 | 只保留一个，其他改为微调或拆镜 |
| 终点错误 | 是否缺 camera_end | 写结束景别、位置、对焦和接点 |
| 手持像故障 | 稳定方式是否只有“handheld” | 写幅度、节奏、身体来源和恢复 |
| 主体出画 | 路径与主体速度是否匹配 | 写相对距离和跟随位置 |
| 焦点漂移 | 是否有多个对焦对象 | 选主对象，必要时写一次触发拉焦 |
| 左右翻转 | 机位侧和屏幕方向含糊 | 同时写解剖侧、摄影机侧和鼻尖方向 |
| 多镜变一镜 | 是否缺切点和段落时长 | 写镜头数量、明确 HARD CUT 与每段契约 |

## 摄影机质量门

- [ ] 起始构图可画出。
- [ ] 焦段视觉效果与毫米数一致。
- [ ] 只有一个主运动。
- [ ] 路径、速度、距离可执行。
- [ ] 稳定方式不是含糊的“电影感”。
- [ ] 对焦对象和拉焦触发明确。
- [ ] 结束构图可画出并服务下一镜。
- [ ] 轴线和屏幕方向与连续性一致。
- [ ] 多镜头总时长和切点明确。
