# Agent Note: 对外帮助文档与当前技能契约对齐

Status: implemented

## Problem

13 个 skill 已逐文件精修并合入，但部分帮助文档仍写八款宿主、以禁用词单项决定去味等级、整读卷纲和写后先追踪再审查。连续性说明也把状态卡的读取上限误写成全部状态不会增长，英文目录示意未说明实际中文路径。

## Decision

对当前帮助、开发与演示导航逐文依次执行五步精修，以现行技能、模板和脚本为事实来源。纠正宿主数量、去味定档、按需取段和先检查再提交的顺序；删改稿元说明和无依据的泛化。复用已合入的367份技能文档五步证据，原样保护去AI味badcase、配对和真实运行记录，只复核新增或变更处。

## Alternatives considered

- 只处理技能本身可减少改动，但帮助文档会继续把旧规则带给使用者，故补齐当前指引。
- 全文重写可以统一口吻，但会破坏真实示例并重复已完成的工作，故保留准确正文和样本。

## Consequences

当前指引与历史案例需要明确区分。保留 badcase、配对、运行输出和实际案例；两份普通短篇目录树只校正过期 Phase 7 注释，不伪造新运行结果。

## Verification

25 份当前导航和开发/帮助文档完成五步核对，其中双语 README 复用本会话已合入的精修与独立复核，原文保留。53 个代码围栏中 51 个逐字保持，两份普通目录树仅校正 Phase 7 注释；真实运行输出和去 AI 味配对保持原文；当前指引按现行技能和脚本校正。13 个技能先前的 367 份逐文五步证据继续保留，本轮长篇补漏另有独立覆盖记录。代价是同一机制的中英文帮助需要同步维护。
