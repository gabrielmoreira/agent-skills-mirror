# 情绪弧线：卷与剧情单元
> 出卷纲、建剧情单元卡时选弧线、排高低；百分比按本卷或本单元的章数算。写一章时怎么把情绪写出来见 emotion-on-page.md。

## 六种弧线速查

| 想要的效果 | 弧线 | 关键位置 |
|---|---|---|
| 先虐后翻 | V形 | 谷底在 60-70%，停一两场戏就转 |
| 先得到再失去 | 倒V形 | 高点在 40-50%，跌得比升得快 |
| 反复拉锯，以为赢了又出事 | W形 | 每个峰比前一个高，最终峰在 80-90% |
| 层层打脸升级 | 渐进形 | 不回落，最高点在 85-95%，中间只给小胜 |
| 隐忍后大爆发 | 延迟满足形 | 前 70-80% 压，最后集中爆发 |
| 结尾翻转认知 | 急转弯形 | 70-80% 处转向，前面的线索回看说得通 |

一个单元最多叠两种，如延迟满足形加急转弯形。卷纲「情绪弧线」的模板字段填这里的弧线名。

### V形
- 谷底要深、转折要突然，回升不拖；单元收尾时情绪高于起点。
- 常见：重生复仇（前世被害，重来翻盘）、破镜重圆、低谷逆袭。

### 倒V形
- 用在单元或卷的中段；收在低谷时，下一单元开头就给翻盘的抓手，长篇不整卷收在低谷。
- 常见：亲密关系里的算计曝光、深信不疑后被骗。

### W形
- 至少两峰一谷，谷与峰之间留喘息章。
- 常见：追妻拉扯、商战博弈、多反转悬疑。

### 渐进形
- 每一阶比上一阶狠，从三个方向加：影响范围（个人到群体到社会）、揭示深度（表象到本质到颠覆）、身份落差（路人到大佬，再到看低他的人低头）。
- 常见：打脸爽文、层层揭秘、逆袭翻盘。

### 延迟满足形
- 压的阶段每章都要有信息量和张力，压法换着来；爆发要密，爆发后快收。
- 常见：隐忍复仇、隐藏身份或实力、长线布局收网。

### 急转弯形
- 急转在一两场戏内完成。
- 常见：细思极恐、身份错位、动机反转。

### 中段加压四手段

1. **公开升级**：把私下的伤害搬到公开场合，如家宴、宗门大比、公司会议、直播。
2. **双重背叛**：已知一层背叛后再揭一层，落在钱、名誉、立场或证据上。
3. **代价加速**：不行动的代价不断升高，如错过机会、当众受辱、连累他人。
4. **战略性沉默**：主角暂不反击，对方误读、更放肆，压力继续加。

## 质量检查清单

- [ ] 弧线和想要的效果对得上，关键转折落在单元或卷的对应章位
- [ ] 每个单元有压有放：只压不放会憋屈弃书，只放不压读着平淡
- [ ] 单元高潮、卷高潮逐级加码
- [ ] 下行段读者看得到翻盘的筹码
