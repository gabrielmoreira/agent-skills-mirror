# 七猫：采集与分析

选择七猫时读取。排行榜先用 `/browser-cdp` 启动 Chrome，脚本切换男生/女生榜并滚动加载；书库新书直接请求网页，不用 Chrome。

## 榜单与命令

入口 qimao.com/paihang：大热榜（日榜/月榜）、新书榜、完结榜、收藏榜、更新榜。

```bash
node scripts/qimao-rank-scraper.js --channel male --type hot --period day --outdir {输出目录}   # 男生大热榜日榜
node scripts/qimao-rank-scraper.js --channel all --type all --outdir {输出目录}                 # 全部
```

大热榜用 `--period day|month|all` 选日榜、月榜或两者（默认 day），周期进文件头与文件名；其他榜不分周期。默认组合：男频大热榜日榜 + 女频大热榜日榜。

### 书库新书

作者说「新书」「最近冒头」「什么在起量」时再加，不进默认组合。书库筛选页 qimao.com/shuku/a-a-a-1-1-a-0-click-{页码}/：全部频道、30 万字以下、3 天内更新、连载中，按点击量排，每页 15 本。

```bash
node scripts/qimao-rank-scraper.js --source library --pages 3 --outdir {输出目录}   # 前 3 页（默认 3，最多 10）
```

所有页合写 `七猫全站书库点击新书_{YYYYMMDD}.md`，名次连续，表示点击排名。该筛选会拉低字数中位，长篇篇幅另看排行榜。页面不提供热度数字，无热度属正常；仅采书库时分析题材、字数和标签。跟作者说「七猫最近三天还在更新的 30 万字以内新书，按点击取前 3 页」。

## 字段

书库从分类页补主类，补不到时退用子类；聚合出现细分类时先核对分类来源。

排名、书名、作者、题材、分类标签（聚合时进标签）、状态、字数（万字）、热度（核心指标，聚合的热度口径；书库新书没有）、最新更新、作品页链接、简介。文件头带 `数据质量`、`有效条目`、`问题摘要`、链接与热度命中数；热度缺失写 `[待补]`。

## 分析维度

| 维度 | 看什么 |
|---|---|
| 大热榜 | 热度排名，流量集中度 |
| 新书榜 | 流量风口候选，与大热榜及可比上期对照 |
| 完结榜 | 长尾价值作品 |
| 热度 | 平台公开指标，按同周期比较，不换算为读者人数 |
