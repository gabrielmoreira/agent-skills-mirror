# 七猫：采集与分析

排行榜先用 `/browser-cdp` 启动 Chrome；书库新书直接请求网页，不用 Chrome。

## 默认命令

`--channel` 按 Phase 1 的频道取：male=男频、female=女频、all=男女都采。

```bash
node scripts/qimao-rank-scraper.js --channel all --type hot --period day --outdir {outdir}   # 男女频大热榜日榜
```

作者要看新书里在冒头的，再加新书榜和书库新书：

```bash
node scripts/qimao-rank-scraper.js --channel all --type new --outdir {outdir}    # 男女频新书榜
node scripts/qimao-rank-scraper.js --source library --pages 3 --outdir {outdir}  # 书库新书，前 3 页（最多 10）
```

书库新书是全部频道「30 万字以下、3 天内更新、连载中」按点击量排的前几页，每页 15 本，名次即点击排名，没有热度数字，会拉低字数中位；只看题材、字数和标签。跟作者说「七猫最近三天还在更新的 30 万字以内新书，按点击取前 3 页」。

## 可选参数

- `--type`：hot 大热榜 / new 新书榜 / finish 完结榜 / collect 收藏榜 / update 更新榜 / all 全部。
- 大热榜用 `--period day|month|all` 选日榜、月榜或两者，默认日榜；其他榜不分周期。

## 字段与热度口径

排名、书名、作者、题材、分类标签（聚合时进标签）、状态、字数、热度（核心指标，聚合的热度口径；书库新书没有）、最新更新、作品页链接、简介。书库从分类页补主类，补不到时改用子类；聚合出现很细的题材名时先核对来源。

## 采不到时

- 终端提示「页面实际榜单与请求不一致，已跳过」：页面没切到要的频道或榜单。在 Chrome 里手动点一次对应的男生榜/女生榜和榜单标签，再重采这一条。
- 文件头「数据质量」标了问题：看「问题摘要」，缺热度或链接的条目多时，结论只用有热度的书。

## 分析维度

| 维度 | 看什么 |
|---|---|
| 大热榜 | 热度排名，流量集中度 |
| 新书榜、书库新书 | 流量风口候选，与大热榜及可比上期对照 |
| 完结榜 | 长尾价值作品 |
| 热度 | 平台公开指标，按同周期比较，不换算为读者人数 |
