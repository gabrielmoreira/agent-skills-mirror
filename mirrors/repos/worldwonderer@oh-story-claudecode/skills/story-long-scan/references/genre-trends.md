# 网文题材趋势与流派参考
流派、书名示例作候选，趋势看本次榜单。

---

## 脑洞文创作

### 从灵感到成书

1. 得到点子（金手指雏形/画面/切入点）
2. 评估潜力（纯原创？有市场铺垫？）
3. 匹配题材（放进熟悉题材看效果）
4. 提炼核心卖点（能否转化为情绪缺口/期待感）
5. 检验故事雏形能否持续推进
6. 动笔验证

### 金手指创新

金手指以“满足条件→得到反馈”为基础，可用多条件触发、阶段反馈、概率反馈或反馈叠加。

### 写长方法

1. 从核心卖点推演不同矛盾，每套可展开1-2卷
2. 让各卷目标、代价与关系相互影响，持续推进主线
3. 将大目标拆成中目标、小目标与细纲，检验每轮剧情的新变化

### 跟风与换皮

只换题材外壳属于换皮。跟风保留已验证的情绪期待，让金手指机制、人物选择或切入角度随题材变化。

---

## 题材选择

用熟悉题材建立预期，以新元素制造惊喜；方向有样本，素材能撑主线。

---

## 边界感三层圈

| 圈层 | 示例 | 规则 |
|------|------|------|
| 题材圈 | 都市、玄幻、仙侠 | 大分类 |
| 流派圈 | 极道流、凡人流、种田流 | 细分 |
| 核心梗圈 | 具体卖点/金手指/情绪点 | 主线持续兑现核心期待，副线为它服务 |

高武写官场、种田写商战时，检查副线是否仍服务升级或经营反馈；悬疑去掉核心悬念后，需重新明确追读理由。

## 扫榜

### 三级分类

| 级别 | 频率 | 要点 |
|------|------|------|
| 新题材 | 极少 | 只有出现跨榜单、跨作者重复样本时才标记为趋势；否则作为观察项 |
| 新金手指 | 较少，翻新为主 | 适合作为低成本验证点，但必须换题材外壳和情绪触发方式 |
| 新噱头 | 常见 | 高同质化风险；没有差异化机制时降低优先级 |

### 各网站方法

**起点**：结合三江、签约新书榜与付费榜选对标；首订图指作者提供的订阅数据截图，脚本不采首订。
**番茄**：对照新书榜、阅读榜与书库新书，比较同题材、同书龄的在读差距。

### 起点题材候选

| 题材 | 要点 |
|------|------|
| 都市 | 重生/种田/娱乐；重生可与任何元素融合 |
| 玄幻 | 极道流、加点横推等强反馈样本优先；传统玄幻若近期样本稀疏，标记为高风险 |
| 仙侠 | 优先检查脑洞融合路线的近期样本；纯传统路线需额外验证受众 |
| 历史 | 秦/唐/明/宋/三国；类同人写法 |
| 诸天无限 | 比较同人与原创副本样本，看世界规则能否持续兑现核心期待 |
| 科幻 | 末世类（含脑洞/种田/游戏设定） |

## 流派写作要点

| 流派 | 核心要点 |
|------|----------|
| 极道流 | 金手指属性加点，横推一切；用样本检验反馈是否足够直接 |
| 凡人流 | 小人物攀爬+精打细算；战力数据化+寿命驱动 |
| 巫师流 | 知识体系+实验探索升级，门槛较高 |
| 种田流 | 以餐馆/书店/渔场的经营反馈推进，可与多界穿梭结合 |
| 都市高武 | 可观察武馆+学校双线、死党对比、师姐互动、模拟考装逼；以《武圣》前三章为拆文候选 |
| 同人文 | 仅在用户明确目标 IP、平台允许且近期样本有效时使用；默认只抽“已知世界+新变量+名场面改写”结构 |
| 盘点文 | 盘点对象与切入点要鲜明 |
| 模拟文 | 模拟制造情绪缺口→得奖励→现实满足 |
| 两界穿梭 | 标准模板：金手指+震惊历史人物+改变命运 |
| 历史文 | 秦/唐/明/宋/三国可作候选；用危机感、由小及大的目标与清晰主线组织剧情 |

## 都市重生文

| 维度 | 要点 |
|------|------|
| 事业感情配比 | 按作者擅长的事业线或感情线确定主次，检查另一条线是否促进人物选择 |
| 期待感 | 没有升级线时靠人物目标持续维持期待感，反转服务当下选择 |
| 短视频化 | 用人物关系与反应形成笑点；复用梗时让关系或结果有新变化 |
| 同质化 | 分别检验开篇差异与中段持续兑现，不把数据低一概归因于流量 |

## 轻小说

核心是有戏剧性的人设（尤其美少女人设），以及令人羡慕的互动。

- 事业线：美少女当前困境+她与别人的恩怨
- 爱情线：有戏剧性的发展+人设搭配造成事件

---

## 喜剧/沙雕文

可组合中计掉坑、弄巧成拙、降智反派与误解错位。先让麻烦落到角色身上，再借意外变化制造笑点；读者对角色的好感会影响他们是心疼还是看笑话。

---

## 霸道总裁文（女频）

| 维度 | 传统 | 现代 |
|------|------|------|
| 女主 | 傻白甜 | 独立职业女性 |
| 相遇逻辑 | 善良行为偶遇 | 职业交集+独特价值 |
| 男主便利 | 全方位照顾 | 情绪价值+锦上添花 |
| 底层逻辑 | 嫁好男人不用干 | 我很强+征服了强者的心 |

情敌反派避免传统"绿茶"模式。
