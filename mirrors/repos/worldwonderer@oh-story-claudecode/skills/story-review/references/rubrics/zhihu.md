# 知乎盐言故事 Quality Rubric

## 评分标准

| 指标 | PASS 标准 | FAIL 标准 |
|------|----------|----------|
| 第一人称 | 采用「我」视角时，所知信息与叙述姿态一致 | 已定第一人称却无依据换视角；明确采用其他视角不据此判错 |
| 情绪拉扯 | 关键场景有期待→失望→惊喜等情绪变化，承接段服务于变化 | 连续 3 段重复同一情绪且无新信息或行动 |
| 反转设计 | 至少 1 个有效反转（前文有伏笔） | 无反转或反转无伏笔支撑 |
| 结尾余韵 | 兑现本篇情绪目标，收口有具体后果或情感余韵 | 只有空泛总结，或承诺的情绪没有落点 |
| 格式合规 | 段落以短为主（有长短/疏密变化）、无空行、对话格式正确 | 通篇同长度或连续超长段落/空行/对话标签 |
| 开头钩子 | 第一句话包含信息量（动作/冲突/悬念） | 第一句话纯描写/背景 |
| 字数控制 | 全文在本次锁定的字数范围内，并符合已核实的投稿要求 | 超出或不足，且作者未变更范围 |
| 开头跳失风险 | 第一句用动作、冲突或悬念建立阅读理由 | 纯描写/背景未建立阅读理由；跳失率须用实际数据验证 |

## 使用方式

- story-architect 与 character-designer 用本表核对盐言故事的钩子、反转和情绪交付。
- 本表只作 advisory，不 blocking；叙述视角与收口按本篇已定文风检查。
