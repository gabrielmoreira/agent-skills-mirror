# 起点中文网 Quality Rubric

## 评分标准

成长与金手指项用于对应题材；没有等级或金手指的作品不据此判缺失。其余阈值按本书节奏与更新计划选用。

| 指标 | PASS 标准 | FAIL 标准 |
|------|----------|----------|
| 爽点密度 | 每 3000 字 ≥1 情绪节点（升级/打脸/获宝） | 连续 5000 字无情绪节点 |
| 升级节奏 | 每 50 章有等级/实力突破 | 100 章无任何升级 |
| 金手指使用 | 每章提及或使用金手指（系统/戒指/功法） | 连续 5 章未提及金手指 |
| 日更支持 | 大纲支持本书更新计划，如 4000 字/天（每章 2000 字，每天 2 章） | 既定更新量与大纲可交付内容不匹配 |
| 钩子密度 | 每章结尾有悬念/钩子 | 连续 3 章结尾无钩子 |
| 角色存在感 | 主角每章出场并推进 | 连续 2 章主角不出场或无推进 |
| 追读风险 | 章尾钩子与情绪连续性支撑后续期待 | 连续 3 章无钩子或情绪断裂；追读比须用实际数据验证 |

## 使用方式

- story-architect 用本表核对起点作品的成长线、金手指和连载期待。
- 本表只作 advisory，不 blocking；作者可按本书目标调整阈值。
