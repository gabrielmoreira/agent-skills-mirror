# 源文角色关系分析标尺

## 用作拆文标尺时

按源文证据识别关系类型、独立目标与态度变化。下列感情线模型描述不同读者承诺，不按男女频标签推定每位读者的偏好，也不要求源文经历所有阶段。

## 决策路由

| 你在分析什么 | 使用本章方法 |
|-------------|-------------|
| 角色间关系类型 | 人物关系类型表 |
| 感情线核心人设 | 感情流人设核心法 |
| 爱情线底层逻辑 | 男频/女频爱情线差异 |
| 穿书/穿游戏角色选择 | 穿书角色选择法则 |
| 多角关系/修罗场 | 修罗场收场策略 |
| 好感度推进节奏 | 好感度体系 + 男频恋爱文攻略 |
| 配角态度变化 | 配角攻略缓冲区 |
| 角色共情写作 | 角色行为自洽检查 |
| 角色目标与关系线 | 角色目标独立性 + 关系线设计 |

## 人物关系类型

按具体互动识别关系；同一人物对可以同时具有多种关系。

| 关系类型 | 定义 | 功能 | 示例 |
|---------|------|------|------|
| 冲突型 | 双方利益/理念对立 | 制造张力，推动情节 | 宿敌、竞争对手 |
| 联盟型 | 双方有共同目标 | 提供助力，制造羁绊 | 战友、师徒 |
| 亲密型 | 情感纽带连接 | 制造软肋，提供情感支点 | 恋人、家人、兄弟 |
| 权威型 | 上下级/支配关系 | 制造压力，限制主角行动 | 师父、老板、监管者 |

**执行规则**：
- 定位关系受到考验或保持稳定的情节
- 关系变化须标触发事件；稳定关系也可能承担安全感或对照功能
- 比较各段关系在情节、情绪和人物理解中的作用

## 感情流人设核心法

感情流重点观察事件如何显露人物、改变关系或检验共同选择。

### 构建步骤

1. **识别人设核心**：从行为归纳突出特征、目标或困境
2. **回查成因**：寻找过去经历、环境与性格的已知联系
3. **追踪作用**：目标或伤痛如何进入人物选择与关系后果

### 执行规则

- 俗套剧情配上丰满人设也能脱离套路感
- 比较双方的吸引力、独立行动与变化，说明叙事焦点如何分配
- 高光不等于装逼——所有让读者对角色印象深刻的时刻都是高光，包括痛彻心扉的时刻
- 检查恋爱之外的目标是否参与选择；缺少独立目标时说明其具体影响

## 男频与女频爱情线底层逻辑差异

以下区分“被认可、受羡慕”与“建立独特连接”两类承诺。两者可并存，是否适合目标读者须由文本与反馈判断。

### 男频爱情线逻辑

| 维度 | 说明 |
|------|------|
| 核心 | "外在因素展示"——主角和对象在一起体现两人的外在因素多优秀 |
| 三种核心逻辑 | "她要是我的该多好" → "这么优秀的人是我的了" → "这么优秀的人都喜欢我，我更优秀" |
| 围观者想法 | "能得到这么优秀的女人，我好羡慕"（非"恋爱好甜"） |
| 女主 | 多人倾慕可能被用于强化主角受认可的体验，人数不直接证明人物优秀 |
| 对象本质 | 奖赏式爱情把伴侣当作成功标志；同时检查对方的独立目标是否被压缩 |

定位伴侣条件与他人评价如何体现“展示优秀”。

### 女频爱情线逻辑

| 维度 | 说明 |
|------|------|
| 核心 | "连接"——两人之间唯一、坚不可摧、最优先的情感连接 |
| 连接要求 | "我爱的是你这个人，外貌、财富、才华都不能替代这份连接" |
| 纯洁性 | 观察人物如何证明连接不能被外在条件替代 |
| 双方 | 初恋、双洁是部分作品的承诺，不能据此推定感情更纯粹或更唯一 |
| 围观者想法 | "他们的恋爱好甜，我好羡慕" |

定位共同经历和选择如何“深化连接”。

## 穿书/穿游戏角色选择法则

### 观察条件

- 主角对原世界知道多少，知识何处有效、何处失效？
- 文本何时交代穿越处境，延迟是否制造有效问题？
- 穿越后的身份如何改变主角的目标、风险与选择？

### 信息差设计

- 在原世界基础上适当设计信息差，为叙事主角提供探索空间
- 可以用原世界知识卡bug获取超额收益

---

## 修罗场收场策略

多角关系的冲突可以被调停，也可以导向决裂。观察对抗烈度与最终关系是否相符，不能预设所有对象必须和解。

| 收场方法 | 操作 |
|---------|------|
| 关联回事业线 | 让爱情线对象们把争风吃醋转化为"比谁对主角事业线贡献更大" |
| 插入事业线突发事件 | 对抗进入白热化时，用突发事件让所有人从内斗切换成一致对外 |
| 一笔带过 | 最多两人互相看不惯、说两句嘲讽话就过去，非常克制 |

---

## 傻白甜角色塑造避坑

### 六个观察点

1. 犯错来自信息不足、经验不足，还是明知后果仍坚持？
2. 人物自称的道德标准与实际行为是否一致？
3. 对他人与自己的要求是否一致？
4. 冲突后谁承担代价，文本如何评价责任？
5. 坚持更高道德标准时，人物是否亲自承担成本？
6. 经历同类处境后，人物判断是否发生有依据的变化？

### 反向用法

若相同特征被用于反派，说明文本通过哪些后果引导读者评价，不预设读者必然厌恶。

---

## 人设改变的双向翻转法

爱情线中关系发生变化时的人设调整方法。

### 核心思路

- 比较双方是否都发生变化，以及变化是否重排原有的关系位置
- 改变要基于原人设做局部调整，和原人设保持密切联系，避免随意改造

### 执行规则

- 主要阻碍解决后，检查亲密互动如何兑现前文期待
- 若再起矛盾，说明它是否来自已有关系问题，还是无因果地延长篇幅
- 对照台词、照顾与共同选择，判断爱意表达是否有具体情境支撑

## 角色行为自洽检查

### 第一步：排除外部强推

检查关键行为能否由角色已知信息与动机解释。只有推进剧情的结果却缺少依据时，记录为“人设偏移/动机证据不足”，不替源文补理由。

### 第二步：目标情绪确认

对照三个层面：
1. 文本通过哪些事件与措辞传递情绪？
2. 角色的性格、处境与反应是否相互支持？
3. 角色行为改变了什么情节、关系或读者判断？

### 第三步：人设行为推导

从经历、性格、目标与当前状态回查实际行为，记录支持与冲突证据。其他可能反应只用于比较，不改写源文。

### 第四步：情绪一致性校验

区分角色情绪、文本传递情绪与读者可能感受。三者不同可以形成反讽或信息差，不能直接判为矛盾。

**两种执行路径**：
- 路径A：从文本情绪效果回查人物行为及其依据
- 路径B：从人物实际选择分析场景产生的情绪效果

## 配角攻略缓冲区

配角对主角态度的变化过程 = 主角攻略配角的过程，伴随巨大的期待感和爽点。

### 缓冲区类型

线上线下、背后议论、异地相处、地位差距、亲密度差距、信任程度、信息差等。

### 操作步骤

1. 识别距离、信息或信任差异如何延迟态度变化
2. 从全文已提取节点中定位关系拐点
3. 对照拐点前后的状态、态度与触发事件
4. 分析态度变化带来的情绪和期待，不预设拐点数量

### 执行规则

- 配角不能像NPC一样站着等主角触发
- 配角要有自己的行动，由配角观点引出事件
- 正面角色也一样：和主角立场相同的人也应有自己的行动和动机

## 利用角色身份认知差制造冲突

同一个角色在不同人眼中的"声望"是动态变化的，不是恒定值。

| 视角 | 看重什么 | 对男主的评价 |
|------|----------|-------------|
| 世俗视角 | 家境对等，抗风险能力 | 综合条件匹配度 |
| 男主自身 | 赚钱养家+感情 | 相对门当户对 |
| 女主视角 | 感情+专一+爱 | 只要在乎的就门当户对 |
| 富二代 | 外貌家世匹配度 | 我才更门当户对 |
| 路人 | 综合条件对比 | 女主该嫁富二代 |

**操作要点**：
- 不同人对同一个角色的评价差异 = 天然的矛盾冲突来源
- 恋爱文的核心爽点之一：不同维度的评价差

## 亦敌亦友关系

适用于相互认可且利益或理念仍有冲突的关系。

### 执行规则

- 前提：两个角色本身都要有魅力，否则只是强行五五开的狗皮膏药
- 核心：相互认可与立场冲突并存，具体魅力来自两者如何影响选择
- 真正的宿敌 = 双方相互认可，外人盖章不算

---

## 竞争者定位与亲情线用法

### 竞争者（鲶鱼效应）

- 定位：给男主/女主增加紧张感上压力 → 推动攻略进度
- 剧情设置重点在"高潮节点前" → 属于铺垫环节
- 对高潮后续写剧情作用不大 → 不是续命手段

### 亲情线的四个方向

| 方向 | 作用 | 使用时机 |
|------|------|---------|
| 男方助力 | 提供金钱地位权力 | 高潮前发挥 |
| 男方阻力 | 设置障碍让主角得到认可 | 节点前后都能用 |
| 女方助力 | 温柔乡感情补给站 | 高潮前发挥 |
| 女方阻力 | 父母不同意→为了认可去努力 | 节点前后都能用 |

助力主要在高潮前，阻力节点前后都能用，阻力更好发挥。

## 男频恋爱文写法攻略

### 读者为什么看恋爱文

| 价值 | 来源 |
|------|------|
| 情绪价值 | 填补"被需要、被在乎"的情感空缺 |
| 自尊价值 | 女主条件好→带出去有面子→配角羡慕嫉妒 |
| 高身份女主原因 | 更强的装逼打脸工具人+更大的自尊满足 |

### 核心技法：把恋爱当升级文写

- 暧昧拉扯的过程才是最有吸引力的
- 好感度进度条：每一步推进 = 升级文中的一个"等级"
- 每一个事件是一次"升级"→ 通过冲突、化解、理解和共鸣让好感攀升

### 好感度升级路径

路人 → 好人（扶老奶奶过马路） → 正直勇敢的好人（挺身而出） → 不错的朋友（理解原生家庭困境） → 喜欢但不知（特殊契机看到彼此不为人知的一面）

### 主角不主动追求的模式

- 定位被倾慕如何形成主角受认可的体验
- 观察好感来自品质、共同经历、主动追求还是多种因素
- 若采用举手之劳引发好感的写法，检查后续是否有独立选择支持关系深化

### 感情升级的不对称性

- 两条进度线：表面社会关系（路人→朋友→情侣）+ 实际情感好感度
- 两条线不应齐头并进 → 一条快一条慢 → 带来丰富的矛盾冲突
- 情感线快于社会线 → 辉夜大小姐模式（双方好感拉满但嘴硬不表白）
- 社会线快于情感线 → 赘婿/择天记模式（表面夫妻实际好感为零）

### 写女主对主角好

| 女主类型 | 付出方式 |
|---------|---------|
| 自卑社恐 | 偷偷帮忙塞东西但害怕被发现 |
| 傲娇型 | 用心做便当但嘴硬"做多了顺便带的" |
| 直率泼辣 | 大大方方送礼物或直球表白 |

### 善用对比

| 对比类型 | 操作 |
|---------|------|
| 时间线对比 | 女主刚认识主角时 vs 熟悉后的态度变化 |
| 双标 | 不允许别人摸头但主角可以 → 凸显特殊地位 |
| 信息差 | 男女主双重身份（网上vs现实）→ 期待揭穿时反应 |

## 好感度体系（通用框架）

### 四阶段

萍水相逢 → 爱情喜剧 → 爱隔山海 → 大结局

### 好感度 × 关系阶段对照表

好感度（负/零/半/满） x 关系阶段（熟悉/试探/暧昧/确认）

将好感程度与社会关系分开记录，尤其关注双方意愿不一致时，行为是否尊重已表达的边界。

### CP行为三类门槛

| 行为类型 | 门槛 | 说明 |
|---------|------|------|
| 需容忍行为 | 半好感+ | 观察主动亲密或妥协的原因、回应与代价 |
| 特殊对待行为 | 半好感+ | 主权、信赖、牺牲、特殊待遇、安抚 |
| 关联行为 | 双方半好感+ | 默契、分享、陪伴 |

关系行为的效果须结合双方反应与具体情境判断，不能由抽象好感度直接推定。

### 5套感情线结构模板

| 模板 | 核心 |
|------|------|
| 好感度变化 | 可能升/降/已降 → 各自处理路径 → 余韵 |
| 受益 | 享受伴侣带来的好处 = 爱情线装逼核心 |
| 争风吃醋 | 多角色为主角争风，不是主角吃别人醋 |
| 发展受阻 | 阻碍→试图解决→解决→余韵 |
| 狗粮 | CP日常互动 |

## 角色目标的独立性与关系线设计

### 主角目标独立性原则

- 帮助他人也可以是主角自主选择的目标，须检查动机与代价
- 区分主动承担、被迫服从与缺乏选择，说明其对终局的影响
- 结合全文判断行动权，不以某一节的被动处境直接判定主角失去主体性

### 感情线的层次设计

- 记录感情推进、停滞或回退与事件转折的联系
- 社会关系线 vs 实质情感线的错位制造张力
- 先慢后快、逐步深化或突然确认均可成立，须说明积累与转折证据

### 配角的功能性定位

| 类型 | 功能 | 使用时机 |
|------|------|---------|
| 竞争者（鲶鱼型） | 制造压力推动主角行动 | 高潮节点前 |
| 助力型亲友 | 提供资源/情感支持 | 高潮前发挥 |
| 阻力型亲友 | 不认可→设置条件→主角克服→获得认可 | 节点前后都能用 |

---

## 绿茶/负面角色

- 可以推动剧情但要谨慎使用
- 确认该角色是否有不可替代性
- 主角强势时任何角色都能变正反馈
- 主角弱势时负面角色会被读者恨

---

## 质量检查清单

完成关系分析后逐项回查证据：

- [ ] **关系类型明确**：每个重要关系已归类为冲突/联盟/亲密/权威之一
- [ ] **关系状态清楚**：变化有触发证据，稳定关系的功能也已说明
- [ ] **人设有核心**：主角人设有明确的核心特征和发散依据
- [ ] **目标独立性**：已区分自主帮助他人与被迫服从
- [ ] **好感度匹配**：关系进展、双方意愿与行为边界各有证据
- [ ] **读者承诺清楚**：认可、羡慕或独特连接的判断来自文本与反馈
- [ ] **配角有行动**：配角不是NPC式站桩等待触发，有自己的行动和动机
- [ ] **态度变化可追踪**：已定位距离、信任或信息差及其变化
- [ ] **多角关系有后果**：和解、决裂或持续冲突均有因果依据
- [ ] **亲密互动有支撑**：已说明互动如何回应前文期待
- [ ] **角色目标有依据**：恋爱之外的目标及其缺失效果已如实记录
