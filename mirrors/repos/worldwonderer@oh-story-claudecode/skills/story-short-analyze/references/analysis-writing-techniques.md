# 源文写作技法分析标尺

> 分析源文采用的技法、文本证据与适用条件；按具体问题查对应部分。
> 短篇结构功能链见 analysis-short-patterns.md。

## 用作拆文标尺时

先描述源文发生了什么，再解释技法对信息、选择、关系和情绪的作用。模型按具体读者承诺使用，男女频标签不直接证明读者偏好，未采用某种技法不自动构成缺陷。

## 通用写作铁律

### 核心梗驱动法

核心梗 = 完整情绪链条（特定期待→特定满足）。

**核心梗三层递进设计**：
- 一代 = 主题/中心思想（如：改变命运）
- 二代 = 题材核心（如：升级修炼）
- 三代 = 核心情绪（如：莫欺少年穷）

**构建顺序**：核心卖点→情绪套路→根据套路设计剧情

### 三层标签反差人设法

| 层 | 说明 | 示例 |
|----|------|------|
| 身份标签 | 大众刻板印象 | 合欢宗圣女→蛇蝎美人 |
| 表现标签 | 普通关系中的特质 | 高冷、不食人间烟火 |
| 内在标签 | 突发事件/亲密关系揭示 | 底色善良、勤俭持家 |

比较标签差异与行为证据。关系亲密后，早期行为可能因顾虑改变；反差大小不能单独证明效果。

### 展示优于告知

区分行为展示、心理独白与旁白概述，说明各自如何传递人物目的、态度和情节后果，不要求同一段包含全部功能。

### 事件驱动 vs 情感驱动

| 类型 | 驱动来源 | 读者关心 | 特点 |
|------|----------|----------|------|
| 事件驱动 | 外部冲突 | 能不能打赢？ | 节奏快、爽点明确 |
| 情感驱动 | 内部冲突 | 为什么这么想？ | 持续拉扯、人物悬念 |

事件问题与人物问题都可以持续推进，具体看后续是否改变答案、选择或代价。

### 矛盾冲突抛出公式

【反派人设】+【动机】+【行为】+【态度】+【主角受伤害程度】

三种冲突类型：
1. **利益掠夺型** — 反派需要资源，代价转给主角
2. **祸害转移型** — 反派受罚，主角承受代价
3. **针锋相对型**（矛盾最激烈）— 主角特质打破反派秩序

### 叙事单元体系

| 情绪模块 | 核心 | 必备要素 | 爽点来源 |
|--------|------|----------|----------|
| 英雄救美 | 关系质变 | 危机→拯救→评价上升 | 被救者好感UP |
| 装逼 | 落差对比 | 展示能力→他人震惊 | 优越感 |
| 以小搏大 | 赌博赢利 | 小代价→搏的过程→大收获 | 占便宜心理 |
| 少年热血 | 明知不可为而为之 | 不公→善良人受苦→决心→成功 | 正义感 |
| 临危受命 | 超越众人 | 突发危机→众人无法→主角出手 | 孤胆英雄感 |
| 好人好报 | 善有善报 | 善举→暗示回报→兑现 | 因果报应 |

比较情绪模块的重复与变化：相同结果反复出现也可能造成疲劳；下行之后是否上行取决于作品承诺，不强制补爽。

### 升级感三步设计法

1. **列出起点** — 主角当前身份、资源、处境
2. **列出终点** — 场景结束后主角的收获
3. **反向设置情绪缺口** — 针对终点收获，前文铺垫需求

| 获得什么 | 铺垫什么 |
|----------|----------|
| 关键证据 | 配角强调证据稀缺 |
| 地位提升 | 展示该地位的权力威势 |
| 人物帮助 | 展示该人物的价值 |
| 金手指觉醒 | 展示主角此前的无力 |

**多角度对比法**：伤害输出、社会地位、他人评价、自身感受——四维度体现升级前后差异。

### 开头技法

| 技法 | 说明 | 范例 |
|------|------|------|
| 病中被逼 | 身体最脆弱时被逼最累的事 | "我刚做完脊椎手术...妈妈却攥着我的手腕：快点，祭祀要开始了。" |
| 异常物件 | 不该出现的物件引发全局 | "避孕套日期突然变了，连味道也变成了我过敏的芒果味。" |
| 旁观死亡 | 第一句灵魂飘起 | "我的魂魄慢慢飘起来，看着妈妈铁青的脸。" |
| 公开背叛 | 第一句被当众背刺 | "我亲手养大的妹妹，拿着百亿签字笔，越过了我。" |
| 假意顺从 | 重生后主动给出前世拼死保护的东西 | "你既然想要，就都给你吧。反正谁拿到谁就大祸临头。" |
| 死亡回溯 | 第一句交代死法和凶手 | "孕八月发现老公出轨，情绪崩溃导致早产。手术台上大出血。" |
| 冷发现 | 发现异常后冷笑而非哭闹 | "我笑着点头。当天就去月子中心记下预约单，转身给法务部写了封举报信。" |

### 情绪操控高级技法

1. **阶梯式背叛**：记录背叛如何在类别、代价或关系后果上升级（道德→经济→生命），不要求逐章揭露
2. **冷热对比法**：分析筹码、选择和行动后果如何形成反差，不预设主角必须冷、对方必须歇斯底里
3. **双面人剥皮术**：先写表面好，再层层剥开真相（复制粘贴的关心模板）
4. **前世记忆穿插法**：记录前世记忆如何改变当下判断、选择或信息，不把逐章穿插当质量线
5. **审判式对话**：记录提问是否迫使对方选择、暴露矛盾或改变关系；没有筹码的连续审问不算有效技法

### 结构创新技法

1. **短章推进**：观察小节长度如何服从完整动作链，以及爆点、选择、信息或后果如何持续前推；不把逐章字数和爆点数量当质量线
2. **线索物贯穿法**：一个物件贯穿全文，承载情绪+剧情双重功能
3. **时空对照法**：同一时间两个空间对比（哥哥被打vs渣男给小三挑飞机）
4. **定时炸弹式证据**：主角生前设置的自动发送证据，关键时刻引爆

### 结尾高级技法

1. **重生暖心式**：投胎温暖家庭，温馨细节呼应前世缺失
2. **余韵道具式**：用一个物件暗示未来，不说破
3. **大长镜头式**：主角一步步走向大门，身后所有人震惊
4. **反讽对位式**：用反派视角写最讽刺的结局——漠视比报复更有力

### 对话功能与边界

| 场景倾向 | 对白主要作用 | 无对白时的推进引擎 |
|----------|--------------|--------------------|
| 情绪拉扯 / 关系博弈 | 改变信息、策略、权力、关系或下一步行动 | 选择、物件、证据、空间距离或行动后果 |

对白占比只作为该文本及同题材、同平台样本的描述数据，不设全文通过阈值。分析时同时说明无对白场景由什么推进。

### 核心金句模板

| 场景 | 金句 |
|------|------|
| 冷静审判 | "你的人情味不是用来原谅背叛和欺骗的。我的温情很贵，只给值得的人。" |
| 彻底决裂 | "血缘，原来并不可靠。" |
| 身份揭露 | "一派胡言！我沈家家主明明是简希。" |
| 旁观死亡 | "她不知道，我想要的，只是一句疼不疼。" |
| 最终漠视 | "那是他们的故事了，与我再无瓜葛。" |
| 讽刺审判 | "你三十三岁了，不是十三岁。一句被迷惑，就能把责任推干净？" |

### 短篇写作边界

| 规范 | 要求 | 违规示例 |
|------|------|----------|
| 开头100字内冲突 | 记录冲突建立的位置及前文作用，字数只作定位 | "在一个阳光明媚的早晨..." |
| 对白服从场景功能 | 改变信息、策略、权力、关系或行动 | 为抬高占比补问答、复述或无效狠话 |
| 段落服从戏剧单元 | 一件事、一个镜头或一条推理链完成再断段 | 按句数强拆，形成提纲体或电报体 |
| 情绪直写与场景支撑 | 观察情绪词由哪些事件、关系、动作或物件支撑，不因没有后接反应就判为AI腔 | 《为给白月光出气，男友群发我私密照》我紧紧抿着嘴唇，直到尝到血腥味 |
| 场景产生真实变化 | 改变风险、信息、关系、资源、决定、行动或读者理解之一 | 为凑多功能添加旁人反应、回忆或独立障碍 |
| 结尾用动作/对话 | 比较动作、对白与总结各自承担的收束功能 | "从此以后她明白了..." |
| 主角有辨识度 | 记录冷静由取证、选择、延迟回应还是资源调度体现，标志动作是否本篇独有 | 把端水杯、整理西装等通用动作当成必备项 |
| 信息与后果持续前推 | 新信息、行动、关系变化、局部兑现或后果均可承接 | 为逐章达标另造信息炸弹 |

**结尾三种常见模式**：反派视角收尾、开放式暗示、仪式感收场。

**重生文观察**：前世知识是否改变今生的关键选择与后果。

**灵魂/鬼视角**：分别确认知情范围与行动限制；鬼魂身份本身不等于全知，旁观的效果由具体信息差和损失决定。

## 情绪操控核心法则

1. **情绪对等释放**：爽向故事中，比较受压、反击与后果是否回应同一承诺；情绪不能按数量直接抵消
2. **情绪缺口制造**：先让读者渴望，再满足
3. **兑现检查**：底牌或能力亮出后是否产生承诺过的作用，失效是否有依据
4. **情绪与因果**：同时分析情绪效果及其行动、信息和关系支撑

### 信息差运用法则
- 区分读者领先、角色领先、角色之间及共同误判的信息差
- 在信息差基础上，反派恰好被克制——期待叠加
- 信息差抹平时就是爽点爆发
- 传递信息差的重点是关系网角色前后情绪反转
- 熟人与陌生人的反应分别改变了什么评价、关系或行动？

### 毒点排查核心
- 爽向承诺是否兑现，能力效果是否清楚
- 连续多次破坏读者期待引发信任危机
- 区分行为可理解、情感共鸣与价值认同
- 对手结局是否承接前因和人物选择；不能仅凭结局形式断言完读率
- 突兀玩梗是否打断既有氛围或产生有意的喜剧效果

## 感情线写作法则

### 爱情线阶段推进原则
- 推进 = 爱情阶段的推进（萍水相逢→怦然心动→暧昧→确认→深化）
- 定位好感质变的具体事件及其前置积累
- 比较小事件积累与大事件转折各自的作用
- 开头亲密程度是否由既有关系、双方意愿或前情支持

### 日常文/狗粮文核心
- 核心是男女主之间的**细节互动**
- 从人设入手构建关系进展
- 情绪变化 + 细节互动 = 读者想看的
- 新鲜舞台 + 稳定人设 + 重复亲密接触 = 有效循环

### 好感度与事业线绑定法
- 帮助女主和事业线目标完全绑定，本质是同一件事
- 事业线推进自然带动好感度提升
- 主事业线的文：能忍受较长接触
- 主爱情线的文：尽快进入女主主动给予情绪价值的阶段

## 女频读者心理与写作技法

### 读者心理特征

1. **围观与代入**：区分看关系变化的趣味与亲历困境的共情
2. **安全感**：观察简介承诺成功、希望、未知还是悲剧
3. **主体性**：记录主角能作出的选择及其对后果的影响
4. **情绪承诺**：定位具体触发情节，并对照读者反馈

### 感情流"扮猪吃虎"写法
- 核心机制：通过能力反差打破强弱定位，制造性张力
- 扮猪理由必须合理——有明确动机
- 能力揭露时机精准——对方最需要保护时反转
- 反差是否改变双方的认知、关系或选择
- 隐藏身份线索提前埋，不能突然冒出

### 沙雕风写作（女频修真/古言）
- 人物互动、反应、玩梗是主要看点
- 轻松表面下主线可能严谨甚至带刀
- 角色被"调侃"不硬刚而是宠着让着→"团宠"
- 主角"不正经"但实力在线，反差是魅力
- 轻度沙雕也可火；对话造梗是核心技能

### 女频平台写法定位

| 平台 | 定位 | 写作校准 |
|------|------|------|
| 晋江 | 对照人物与关系型样本 | 核查简介承诺、主体性与人物细节 |
| 起点女频 | 区分长篇与短篇样本 | 不直接迁移长线连载经验 |
| 番茄 | 对照强情绪、快反馈样本 | 核查钩子与兑现，不能代表全平台 |
| 七猫 | 对照甜虐与关系冲突样本 | 以近期同题材样本验证 |

### 简介文案安全法则
- 比较简介承诺与正文交付；成功、悬疑与悲剧都可形成有效期待
- 悬念叠加后，人物关系与核心问题是否仍可理解？
- 受虐、反击与事业成就是否符合承诺，实际留存效果是否有数据支持？

### 写作关键认知
- 参考优先级：对标书分析 > 理论框架
- 多样本比较有助于区分共性与偶然；样本不足时缩小结论范围
- 读者反馈分析：从目标平台最新读者评论或 scan/analyze 报告中提取高频需求关键词，作为写作校准依据
- 只分析源文已有的铺垫与兑现，不替它续推未来剧情
- 文风服务于情绪，关键是精准满足目标读者情感需求

## 震惊场景九种写法

| 类型 | 手法 | 示例 |
|------|------|------|
| 普通震惊 | 事件+一人震惊 | 配角目睹主角实力直接反应 |
| 多人递进 | A震惊→B震惊（B身份高于A） | 小人物先惊，大佬更惊 |
| 解说式 | 旁白解说+角色震惊 | 先渲染一击精妙，再写观者反应 |
| 画面式 | 宏大画面+角色震惊 | 天地变色特效后接观者跪拜 |
| 对比式 | 角色与自身对比后震惊 | "这还是刚才那头魔猿？" |
| 问号式 | 自问自答后震惊 | "我扪心自问能做到吗？不可能！" |
| 变换地点 | 地点1→2→3依次震惊 | 消息扩散式多方势力被震撼 |
| 身心分层 | 身体反应+心理反应 | "浑身冰寒"+"心神俱震"分层 |
| 人设反差 | 先不屑后震惊 | "不过如此"→"我一定是在做梦" |

**核心**：震惊的爽感来自"落差"——先铺垫角色原有认知（轻蔑/自信），再打破它。

### 三翻四震技法

```
翻1：主角宣布选择→众人反应
翻2：具体选择内容（出人意料）→众人再反应
翻3：追问原因/更深反转→更大反应
震终：权威角色最高评价→落选者黯然退场（压一压情绪）
```

对照每次“翻”新增的信息、改变的判断与后果，检查层层反应是否重复同一内容。

## 比赛场景写作前提

分析比赛或对决时，回查文本何时交代：

1. **赌注/代价**：输赢的得失
2. **双方实力对比**：至少暗示优劣势
3. **主角获胜路径**：至少能看到一条可能的路径
4. **对手特殊性**：这一战为什么值得写

### 胜负设计

| 模式 | 难度 | 效果 | 要点 |
|------|------|------|------|
| 以强击弱 | 低 | 优势可形成明确落差 | 检查胜负已知时，期待来自手段、反应还是代价 |
| 势均力敌 | 中 | 可形成持续悬念 | 检查较量是否改变条件和选择，避免同一过程重复 |
| 以弱胜强 | 高 | 反差大，需要因果支撑 | 回查优势、限制与胜机，不以对手突然失去能力代替解释 |

## 感情线四阶段推进法

```
熟悉阶段→试探阶段→暧昧阶段→确认关系
```

| 阶段 | 状态 | 核心写法 | 禁忌 |
|------|------|----------|------|
| 熟悉 | 朋友/陌生人 | 展示人设，制造初印象 | 亲密行为缺少前情或双方意愿支持 |
| 试探 | 有好感不确定 | 试探行为，误会和甜蜜 | 表白或退缩缺少已有情境依据 |
| 暧昧 | 朋友以上恋人以下 | 观察亲密行为与关系认知的错位 | 反复拖延却没有新选择或变化 |
| 确认 | 正式情侣 | 亲密互动与共同面对阻力 | 无触发事件就退回此前状态 |

阶段只是比较模型。关系可以跳跃或回退，关键是人物意愿、前情与触发事件是否支持。

### CP行为八种类型（对照好感、关系与双方意愿）

| 行为类型 | 适用好感度 |
|----------|-----------|
| 亲密行为（肢体接触+） | 高好感 |
| 主权行为（争风吃醋、宣示主权） | 中高好感 |
| 信赖行为（无条件信任、分享秘密） | 中好感+ |
| 护短行为（对方犯错也优先维护） | 中好感+ |
| 特殊待遇（对待对方与别人完全不同） | 中好感 |
| 安抚行为（敏锐察觉不好情绪并安抚） | 中好感+ |
| 优先特权（做决定时对方是最重要因素） | 中高好感 |
| 默契行为（不约而同做同一件事） | 高好感 |

记录好感变化的事件依据。

## 喜剧 flag 机制

| 角色 | flag 规则 |
|------|-----------|
| 主角 | 比较承诺被兑现、落空或反讽时的效果 |
| 反派 | 大话被后果推翻时，可形成报应预期 |
| 其他 | 按人物功能与实际回应判断 |

反派的 flag 是爽点预告；主角的 flag 是喜剧张力——"我绝不会..."紧跟被打脸才好笑。

## 短篇视角控制法则

### 出场人物控制
- 记录开篇人数、出场顺序及辨识信息
- 多人场景是否通过行动、称呼和焦点区分人物
- 配角观察与独立行动如何支持主线或群像

### 视角数量控制
- 先识别人称、叙事距离与知情范围，不由平台名称推定视角
- 多视角时说明各自新增的信息、情绪与行动，不设数量上限
- 切换是否清楚、各线是否回到核心问题？没有数据时不推断追读率
- 对手视角如何改变读者对危险、动机与结果的预测？

## 情绪的三个层次与共鸣触发

### 情绪的三层分离

| 层次 | 说明 |
|------|------|
| 角色情绪 | 角色自己感受到的 |
| 文本传递情绪 | 文本要传达给读者的 |
| 读者感受情绪 | 读者实际感受到的 |

三者不能混为一谈。同一场景可以角色在哭、文本在撩、读者在爽。

### 情绪锚点

**定义**：承载情绪与共鸣的具体桥段。分析事件、关系和细节怎样支持情绪表达；直写情绪也可成立，关键是它是否提供新信息或转折。

**特征**：发生在现实世界、大众经常经历或感受的；不需要细致描写，几个关键细节就够。

**示例**：

| 传递情绪 | 差的写法 | 好的锚点 |
|----------|----------|----------|
| 母爱伟大 | 母亲天天煮饭搞家务 | 母亲偷偷给每个同学鞠躬拜托善待失明的孩子 |
| 生存很难 | 主角挖草根吃树皮 | 众人争相压低价格，主角直接举手"我不要钱，只要一顿饭" |
| 师生情深 | 老师认真上课 | 老师把唯一棉袄给学生，自己穿单衣在雪地里走 |

### 好钢用在刀刃上
1. 定位主要矛盾与高潮
2. 检查关键情绪桥段如何承接此前选择与损失
3. 比较高潮与过渡的详略作用
4. 说明情绪积累如何伴随情节推进

**设计路径**：矛盾→情绪要求→人物/背景/设定→具体桥段

## 反派嘲讽新思路

| 类型 | 传统做法 | 新思路 |
|------|----------|--------|
| 目的 | 戳主角痛点，引发不爽 | 显露反派无知，引发看乐子 |
| 读者反应 | 替主角委屈 | 看笑话等反转 |
| 主角回应 | 绞尽脑汁想反击 | 放松、不在意即可 |

**观察**：对手若嘲讽主角实际拥有的优势，读者领先的信息可能使嘲讽转为反讽；攻击弱点时，则检查伤害与愤怒如何建立。

## 人设拆解从缺点开始

- 正面人物 = 优点掩盖了缺点
- 负面人物 = 缺点掩盖了优点
- 观察人物的不满如何进入选择，以及哪些处境可能引发共鸣

**人设丰富法**：以杀伐果断为例——正向=干净利落；反向=没人情味。强化或弱化"人情味"区分主角/配角。角色有血有肉 = 优缺点共存。

---

## 以小搏大情绪模块四要素

1. **主角独有手段**：为什么能以小搏大
2. **搏的过程**：关键在过程不在结果
3. **赚翻了的感觉**：收获远超预期
4. **明确的搏的目标**：主角必须清楚自己要什么

---

## 爽点本质与修仙三境界

**爽点的一种来源**：能力或地位变化使人物关系被重新评价。

修仙界三大境界的本质：蝼蚁→道友→前辈。主角不断前进与小剧情点形成失衡产生爽感。小剧情小爽，大剧情大爽。

## 质量检查

分析时回查：

- [ ] 开头如何建立关注点，冲突何时出现，此前内容承担什么功能？
- [ ] 每个场景改变了风险、信息、关系、资源、决定、行动或读者理解中的哪一项？
- [ ] 直接情绪表达、场景细节与关键桥段分别起什么作用？
- [ ] 震惊场景有落差铺垫（先建立角色原有认知再打破）？
- [ ] 感情线的推进、跳跃或回退是否有前情与选择支持？
- [ ] flag 如何被兑现、落空或反讽，是否回应了前文承诺？
- [ ] 视角切换是否清楚，各自增加了什么？
- [ ] 对白是否改变信息、策略、权力、关系或行动；无对白场景是否有其他清晰推进引擎？
- [ ] 结尾的动作、对白或总结如何完成情绪与因果收束？
- [ ] 没有"该爽不爽"的段落（金手指效果展示清楚）？
