
# 源文质量评估清单

> **定位**：story-short-analyze（短篇拆书）的质量自检清单，评估**拆解对象（源文）**的成文质量时逐项核对。
> 拆文管道完整度见 quality-checklist.md；结构计数门槛见 output-contract.md。本文件只评源文效果，所有判断须附位置与证据。
>
> **三类质量的分工（别混用）**：
>
> 1. **拆书管道质量检查**（执行过程中）→ [quality-checklist.md「质量检查必填字段」](quality-checklist.md)。每条带 `[BLOCK]` / `[WARN]` 标注；`[BLOCK]` 缺失 → 「BLOCK 项扫描」阻断。
> 2. **评估对象（源文）质量**（拆什么样的料）→ 本文件。回答"这篇源文写得好不好"。
> 3. **拆文报告本身质量**（写什么样的报告）→ [analysis-report-style.md](analysis-report-style.md)。报告自身由「拆文报告表达自检」守门；源文中的套话和 AI 腔仍是分析对象，不作输入过滤。

## 一、通用检查

### 章节结构
- [ ] 已定位开头建立的关注点
- [ ] 已说明中段的行动、信息或关系推进
- [ ] 已记录局势或读者理解的变化
- [ ] 已说明结尾如何承接或收束

### 开篇检查（前 300-500 字）
- [ ] 有钩子，能抓住注意力
- [ ] 已说明天气、风景或日常若出现，承担什么作用
- [ ] 主角快速出场
- [ ] 卖点或危机可见

### 章节推进
- [ ] 有核心事件
- [ ] 局势有变化
- [ ] 不是水字数（删掉这章会影响理解吗？不会 = 水了）
- [ ] 推进了主线/关系/设定中的至少一项

### 信息传递
- [ ] 设定说明的详略与当前问题、行动相符
- [ ] 信息跟着冲突走（通过事件传递设定）
- [ ] 新概念有足够语境，读者能理解其后果

### 场景检查
- [ ] 场景有目标（人物要什么）
- [ ] 场景有阻碍（什么挡着）
- [ ] 场景有变化（结束后跟之前不同）
- [ ] 行动、感受与选择之间的关系清楚
- [ ] 段落对因果、情绪、人物或氛围有作用

### 章尾
- [ ] 结尾落在变化上
- [ ] 已记录危机、决定、发现、反转或余韵的作用
- [ ] 总结若出现，是否完成收束或只是复述
- [ ] 拉住读者翻下一页

### 语言
- [ ] 没有空洞的抒情段落
- [ ] 没有连续多段同一情绪
- [ ] 对话符合人物身份（不同人说话方式不同）
- [ ] 情绪词有落点（融进动作句、当对话提示语、结句后直接换事或接场内物件），不是接更多情绪

### 全文连续性
- [ ] 没有遗忘之前的承诺/伏笔
- [ ] 没有突然塞入大量新设定
- [ ] 伏笔有推进
- [ ] 故事引擎还在运转

### 水（filler）检测
出现以下信号时，回查是否仍有人物、氛围或关系作用，再判断冗余：
- 对话只复述双方与读者已知信息
- 情绪反复表达，却不改变选择、理解或后果
- 场景描写、回忆或过渡未提供新视角，也未承接行动

## 二、通用五维评估

### 五维评分标准

每个维度 0-100 分，用于补充诊断，与 Stage 6 的五项 1-5 分评分分开记录。
严重度 critical、high、medium、low 表示影响程度；默认只解释源文问题，用户要求编辑建议时再给修法。

### 维度 1：核心一致度
检查：关键冲突、关键行动、人物动机是否前后一致。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 人物动机突然改变无铺垫 | critical | 补充动机转变的触发事件 |
| 核心冲突前后不一致 | high | 回溯修改冲突设定 |
| 关键行动与人物性格矛盾 | high | 调整行动或补充解释 |
| 次要矛盾遗忘 | medium | 回收或弱化 |

### 维度 2：表层表达
检查：句式与措辞是否符合人物、语境和叙事功能；无来源对照时不判断原创程度。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 引用或套句与当前语境脱节 | medium | 说明语气或信息为何不合当前场景 |
| 套话反复出现且没有具体作用 | high | 定位空泛表达及缺少的文本支撑，不据此判断作者身份 |
| 同一句式重复出现 | medium | 变换表达方式 |
| 描写过于文学化（辞藻堆砌、书面腔、比喻成串） | medium | 改为口语化/动作化；动作化不是切成三五字短句串，改写后叙述仍以逗号长句为主 |

### 维度 3：格式一致度
检查：段落结构、字数分配、开头结尾格式是否统一。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 段落划分割裂动作或推理链 | medium | 说明断段如何影响理解，不因长短差异直接扣分 |
| 格式混乱（对话/描写不统一）| low | 统一格式 |

### 维度 4：可读性
检查：是否有啰嗦、AI 腔、空泛总结、套路修辞。

| AI 腔特征 | 如何识别 | 如何修复 |
|-----------|----------|----------|
| 空泛总结 | 「他终于明白了」「一切尽在不言中」 | 删掉，用行动代替 |
| 套路修辞 | 「命运仿佛在和他开玩笑」 | 删掉或换成具体描述 |
| 空转情绪句 | 「他感到一阵悲伤」，无落点 | 删，或写他此刻做不成的事；直写本身不算缺陷 |
| 心理描写空转 | 内心独白无新信息、重复同一情绪或复述读者已知 | 只压缩空转部分；带新信息、决断或情绪转折的独白不按句数压缩 |

### 维度 5：逻辑连贯
检查：句间/段间是否通顺，有无设定冲突。

| 问题 | 严重度 | 修复 |
|------|--------|------|
| 设定前后矛盾 | critical | 查找并统一设定 |
| 时间线错误 | high | 标记时间线并修正 |
| 角色信息不一致 | high | 建立角色档案对照 |
| 因果链断裂 | medium | 补充过渡 |

### 精修策略

用户明确要求编辑建议时，可根据问题选择下列策略：

| 主要问题 | 策略 | 说明 |
|----------|------|------|
| 核心一致度低 | rewrite | 围绕核心冲突重写相关段落 |
| 字数超标 | compress | 删减不推动剧情的内容 |
| AI 腔重 | de_ai | 替换禁用词、改写句式 |
| 小问题多 | polish | 打磨语言细节 |

## 三、短篇专项

### 虐爽节奏检查

对承诺先虐后爽的源文，可比较下列示意分布；悲剧、治愈或纯喜剧不套此模式：

```
理想分布：虐1 → 虐2 → 虐3 → 爽1(小) → 虐4 → 爽2(大)
禁忌分布：虐1 → 虐2 → 虐3 → 虐4 → 虐5（无爽点，读者流失）
禁忌分布：爽1 → 爽2 → 爽3 → 爽4（无铺垫，爽感疲劳）
```

分析规则：
- 标出场景或小节实际改变了风险、信息、关系、资源、决定、行动还是读者理解，以及上一个选择的后果在哪里落地
- 区分直接冲突与任务、证据、等待、手艺、空间、关系等压力来源，不拿固定字数间隔判优劣
- 记录最大爽点由哪些前因、选择和证据汇合而成，以及之后留了多少后果篇幅；不按固定百分比判定
- 记录结尾采用情绪落点、局部兑现、明确余波或其他收束方式及其效果

### 对话密度检查

| 分析项 | 记录内容 | 避免误判 |
|--------|----------|----------|
| 对白功能 | 是否改变信息、策略、权力、关系或下一步行动 | 不用全文占比代替逐场景功能判断 |
| 无对白场景 | 由任务、物件、证据、空间、等待或手艺中的哪一项推动 | 不把无对白直接判成“太干” |
| 对话节奏 | 话轮长短如何表现人物权力和现场压力 | 区分有效短促与碎片化微型问答 |
| 对白占比/条数 | 作为该文本及同题材、同平台样本的描述数据 | 不设跨题材通过阈值 |

### 主角筹码与情绪分析（打脸/复仇文专用）

| 分析项 | 记录内容 |
|--------|----------|
| 主角的冷静如何可见？ | 记录取证、选择、延迟回应或资源调度；不把端水杯、整理西装、转笔当通用标准 |
| 情绪失控产生什么后果？ | 记录累积压力、位置及其对行动、关系或代价的改变，不按次数和百分比判定 |
| 主角与反派的反差来自哪里？ | 记录筹码、判断、行动后果或信息差，不预设反派必须歇斯底里 |
| 台词长短如何体现权力？ | 结合打断、沉默、回避和现场筹码分析，不设固定比例 |
| 审判式对话是否有效？ | 记录提问是否迫使对方选择、暴露矛盾或改变关系，不按处数判定 |

### 证据链完整性检查（复仇/打脸文专用）

| 检查项 | 标准 |
|--------|------|
| 证据如何释放？ | 记录每次释放如何改变行动或读者模型；完整证据链集中落地也可成立 |
| 每个证据是否有铺垫？ | 检查来源与取得条件是否已建立，关键反转能否回溯 |
| 反派反应是否有因果？ | 记录其筹码、误判和损失，识别是否机械重复“先得意再被打脸” |
| 最终证据是否最致命？ | 记录其改变的判断或行动；最后出现不必等于作用最大 |
| 是否使用"定时炸弹"证据？ | 分析提前布局是否符合主角能力、时间线和取证条件，不要求必有 |

### 毒点/代入感/震惊/开头/结尾/情绪/期待感速查

> **本表评估的是源文**（拆解对象写得好不好），毒点判断必须引用源文证据，不替源文改写。
> **不要把本表用来评估拆文报告本身**：报告自身走「拆文报告表达自检」+ [analysis-report-style.md](analysis-report-style.md)。
> **拆文管道完成度** 走 [quality-checklist.md「质量检查必填字段」](quality-checklist.md) 的 `[BLOCK]` / `[WARN]` 清单。

| 检查项 | 标准 |
|--------|------|
| 爽文不爽 | 承诺的能力或反击效果是否实际出现 |
| 压制无目的 | 压制是否改变选择、代价或后续期待 |
| 反派结局与主角无关 | 结局如何由前因与人物选择促成，主角是否拥有关键选择 |
| 经济/战力崩坏 | 设定前后一致，以普通人为锚点 |
| 女主/女配降智 | 关键行为是否符合人物当时的信息、动机与能力 |
| 读者期待长时间不满足 | 适时满足或引入新期待 |
| 主角行为不可理解 | 分别检查动机可理解、情感共鸣与价值认同，三者不必相同 |
| 氛围被突兀梗破坏 | 氛围 > 突兀梗（乐子文除外） |
| 钩子不回收 | 区分有依据的留白与遗漏，说明未回应的承诺 |
| 震惊分层 | 反应是否带来专业信息、关系或行动变化 |
| 震惊阶梯递进 | 每层新增什么，是否只重复震惊措辞 |
| 震惊有广度 | 多方反应是否各有作用，不要求全关系网回应 |
| 前50字有冲突/异常 | 记录有无及铺垫作用，不作通过条件 |
| 前100字知核心矛盾 | 记录读者已知的问题与关注点 |
| 开头情绪强度 | 用1-10量表记录，并附触发证据 |
| 结尾是具体的 | 动作、对白、画面或反思是否完成收束 |
| 结尾有余韵 | 读者还想往下看 |
| 结尾情绪强度 | 用1-10量表记录，不以不同情绪的固定分数验收 |
| 情绪对等释放 | 在相应承诺下，受压与兑现是否属于同一因果链 |
| 期待管理 | 核心问题、局部回应与后续行动是否持续衔接 |
