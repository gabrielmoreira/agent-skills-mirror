# 信号库：执行阻滞的六种信号

识别出信号后读取对应条目。每条包含：表现、机制、鉴别要点、解法、可用的一句话。

「可用的一句话」里凡是「你不是在 X，你是在 Y」的句式，都附有使用条件：只有用户自己说过 X，才可以这样说；否则改用条目里的直述版本。

---

## 信号 A：执行模拟器

**表现**：把身边的人和工具都当成「模拟器」，用别人的预判代替执行。

- 「你觉得这个方案怎么样？」——你成了他的方案模拟器；
- 「如果我把这段发给 AI 会怎样？」——你成了他的 AI 模拟器；
- 「你帮我看看这个能不能做」——你成了他的市场调研模拟器；
- 发一篇文章给你，问「你看完感受怎么样」——你成了他的阅读模拟器。

**机制**：承受不了任何微小的失败风险，所以每件事都要先在别人的脑子里跑一遍。模拟的结果不会失败，也不会产生真实反馈。dontbesilent 的观察：模拟很多次，真正执行的极少。

**鉴别**：

- 问过一次、拿到意见后就去做了，属于正常咨询；
- 同一件事反复问不同的人，问完不动，才是执行模拟器；
- 问题本身需要专业判断（法律、医疗、资金安全），先咨询是合理的。

**解法**：

1. 列出最近反复问别人的那件事，找到它最小的可执行版本；
2. 把这个版本直接放进真实场景：发出去、报价、上架、发给真实的人；
3. 规定反馈来源只能是现实：用户的反应、成交、平台数据；
4. 下次想问「你觉得行不行」时，先问自己：这个问题现实能不能直接回答？能，就去做。

**可用的一句话**：

- 直述：「你在用别人的预判代替现实的反馈，而只有现实能告诉你行不行。」
- 条件句式：用户说过「我在做准备 / 我在调研」时，可以说「你不是在准备执行，你是在用准备代替执行」。

## 信号 B：用思考替代行动

**表现**：反复思考、分析、计划，从不开始。

- 「我再想想」
- 「我先把方案想清楚」
- 「等我准备好了就开始」
- 规划、复盘、梳理、讨论、总结占满了时间，产出很少。

**机制**：思考本身带来「事情在推进」的感受，于是成了终点，而不是行动的前序。准备可以无限重启、反复享受。dontbesilent 把规划、复盘这类活动的一部分称为「给自己做心理按摩」：感受变好，事情没动。

dontbesilent 还认为，「过度思考导致没执行力」这个说法，是对不愿执行的美化。执行意味着可能失败，还意味着失败后要面对结果；思考是绕开这两个风险的方式。另一个依据是：不行动就没法想清楚，很多问题只有做完才知道是什么。

**鉴别**：dontbesilent 区分了两种人。缺执行力的人，思绪乱时要停止思考、先动起来（stop thinking）；不缺执行力的人，思绪乱时要停下动作、先想清楚（stop doing）。用户近期大量行动、只是方向混乱时，不归入信号 B。

**解法**：

1. 给思考设截止点：今天之内必须结束规划，写下当前最好的版本；
2. 找一个做完就能产生新信息的小动作，信息来自现实，不来自脑内推演；
3. 想不清的问题记下来，标注「行动后再想」；
4. 时间管理只抓一件事：每天优先做最重要的一件，其余都可以拖延甚至放弃。

**可用的一句话**：

- 直述：「这件事你想不清楚，是因为还没做；做了才有新的信息可想。」
- 条件句式：用户自称「我就是想太多 / 过度思考」时，可以说「你不是在过度思考，你是在用思考回避行动」。

## 信号 C：方向跳跃

**表现**：频繁更换方向，每个方向都做不久。

- 「这个不太适合我，换一个」
- 「我又发现了一个更好的方向」
- 「上一个太难了，这个简单一点」

**机制**：每次在要深入时撤退。深入意味着可能被证明失败；不断换方向，失败就永远停在「还没验证」的状态。dontbesilent 的失败观：失败越快，成功越快，做事应该尽快拿到负反馈。方向跳跃恰好躲开了负反馈。

**鉴别**：

- 换方向前有明确的负反馈证据（数据、成交、用户反应），属于正常迭代；
- 换方向的理由只有「感觉不适合」「新的更好」，且每次都在差不多的阶段放弃，才是信号 C；
- 用户一直在一个方向上埋头做、从不看数据，属于另一种问题：固执，不在此列。

**解法**：

1. 选一个方向，先写下「做到什么程度才允许换」，例如发满约定数量的内容，或拿到第一笔收入；
2. 到达这个标准之前，新方向只记录，不启动；
3. 真要换时，先写下上一个方向的负反馈证据，证据不足就继续；
4. 把每次放弃的阶段列出来，看是否总在同一种难点前撤退，那个难点才是要处理的问题。

**可用的一句话**：

- 直述：「你每次都在同一个位置撤退，换的是方向，躲的是同一件事。」
- 条件句式：用户说过「我还在找方向」时，可以说「你不是在找方向，你是在逃避深入」。

## 信号 D：知识上瘾

**表现**：不停学习、看课、买书、听播客，但不开始做。

- 「我觉得我还需要学更多」
- 「等我把这个课学完就开始」
- 「我先看看别人怎么做的」

**机制**：学习成了不执行的合法理由。dontbesilent 的判断：很多所谓学习，是不想干又不愿意承认，所以假装在努力。极度的不自信加上残留的幻想，结果就是一直学下去。购买知识时，买到的常常是「我正在进步」的感受。

**鉴别**：

- 正在做，因为碰到具体问题去学，属于正常学习；
- 学习内容和要做的事没有直接关系，或学完一门又开一门、始终没有产出，才是信号 D；
- 用户缺的是一项必须先掌握的硬技能（例如必须持证上岗），先学是合理的。

**解法**：

1. 停止新增输入：暂停购买新课、新书；
2. 用已有知识交付一个结果，哪怕粗糙；
3. 之后只为执行中碰到的具体问题去学，学完立刻用；
4. 例如镜头恐惧，dontbesilent 的说法是拍够足够多条之后就没有了，靠拍解决，不靠学解决。

**可用的一句话**：

- 直述：「你买到的是『正在努力』的感受，事情本身没有往前走。」

## 信号 E：完美主义

**表现**：因为做不到完美而不开始、不发布。

- 「我的产品还不够好」
- 「等我再打磨一下」
- 「我不想做出一个平庸的东西」

**机制**：完美主义常常是自卑的高级伪装。它让人可以说「我做不好，是因为我对自己要求高」，用高标准合理化不行动。高标准的作用是推迟被评价的时刻。

**鉴别**：

- 已经在持续交付，只是在某个环节反复打磨，可能是正常的质量要求；
- 从未交付过，或交付物长期停在「快好了」，才是信号 E；
- 行业有硬性标准（安全、合规、医疗），未达标不发布是必要的。

**解法**：

1. 把发布门槛降到「能让一个真实的人用起来」；
2. 先给小范围的人看：几个朋友、一个群、一个小号；
3. 把评价当信息收集：只记录反馈里能用来改进的具体内容；
4. 课题分离：别人怎么评价是别人的课题，按时交付是自己的课题。

**可用的一句话**：

- 直述：「完美主义让你推迟被评价的时刻，产品没有因此变好。」
- 条件句式：用户说过「我只是对自己要求高 / 标准高」时，可以说「这不是标准高，是害怕被评价」。

## 信号 F：归咎外部

**进入条件**：只有通过真实困难判断（见 `safety-screening.md`）之后才使用本条。用户提到的限制真实存在、且确实排除了所有可行版本时，不进入信号 F。

**表现**：把不行动归咎于外部。

- 「家人不支持我」
- 「我现在的工作太忙了」
- 「没有启动资金」

**机制**：阿德勒视角下，很多「被迫」其实是自愿选择后归咎于外部。dontbesilent 的说法是：对方手里没有枪，就很难真正强迫你。把选择叙述成被迫，可以免除选择的责任。

**鉴别**（判断后仍需注意）：

- 限制只排除了用户心里那一个版本（例如「辞职全职做」），没有排除更小的版本（例如下班后做），而用户放弃了全部版本，才是信号 F；
- 用户说「工作太忙」，但每天有可观的时间花在刷手机、看课等替代行为上，可以作为依据；
- 家人反对涉及共同财产、共同债务、照护分工时，反对本身就是需要协商的真实约束，不只是别人的课题。

**解法**：

1. 把用户列出的理由逐条分成两类：客观约束、可以选择的理由；
2. 课题分离：家人支不支持是家人的课题；在不违背共同承诺的前提下做不做，是自己的课题；
3. 在约束内找一个可做的版本：更小规模、更低成本、利用现有时间；
4. 直接说出选择：「在目前条件下，我选择暂时不做」也是一个诚实的结论，比「我被困住了」更能让人重新做决定。

**可用的一句话**：

- 直述：「这些限制排除了你心里的那种做法，没有排除所有做法；剩下的那些你还没试。」
- 条件句式：仅在困难判断确认没有真实约束、且用户说过「我被困住了」时，可以说「你不是被困住了，你是选择了留在原地」。语气保持冷静，不带嘲讽。

## 补充：价值感低、依赖外部正反馈

不单列为信号，可以叠加在任何信号上。表现为：做事完全靠别人夸奖驱动，一次没反馈就停；遇到逆境时找不到自己的动力。

**解法**（阿德勒：共同体感觉）：

1. 找一个需要帮助的具体的人；
2. 用自己已有的知识，帮他解决一个具体的小问题；
3. 从他的反应里拿到「我对别人有用」的证据；
4. dontbesilent 的经验：先做能快速拿到正反馈的事情，比如先拿到一笔短期收入，再用这份底气推进难的事。
