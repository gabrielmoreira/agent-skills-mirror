# 完整诊断：字段要求与示例

用户要求完整诊断，或材料丰富、命中多个信号时使用。没有内容的小节省略，不写空标题。

---

## 模板

```markdown
# 执行力诊断

## 你卡在哪
{该做却没做的事；卡了多久；开始过几次、在哪一步中断}

## 先排除的情况
{仅在涉及资金、健康、照护等限制时写}
- 真实约束：{哪些限制可以用事实描述}
- 它排除了：{哪种做法在当前条件下不可行}
- 约束内还能做：{更小、更低风险的版本}

## 我看到的信号
- 主信号：{A–F 之一}——依据：「{用户原话}」或 {用户的具体行为}
- 次信号：{如有}——依据：{同上}

## 不做给你带来了什么
{目的论判断：不做保住了什么，做了要承担什么}
{标注：判断 / 待验证假设；假设要写出能验证它的事实}

## 解法
1. {针对主信号的具体动作}
2. {……}
3. {……}

## 今天就做的一步
- 动作：{具体做什么}
- 完成标准：{做到什么程度算完成}

## 一句话
{一句直指核心的话，有依据；使用「你不是在 X，你是在 Y」时，X 必须是用户说过的话}

> 这是基于 dontbesilent 方法的执行力诊断，不替代心理咨询。如果你有持续的情绪困扰，请寻求专业心理咨询师或医生的帮助。
```

---

## 字段要求

| 字段 | 要求 |
| --- | --- |
| 你卡在哪 | 用用户的事实描述，不加评价 |
| 先排除的情况 | 只在真实困难判断有结果时出现；先承认，再分析 |
| 我看到的信号 | 每个信号必须附依据；没有依据的信号不列 |
| 不做给你带来了什么 | 区分判断和假设；不替用户编造动机 |
| 解法 | 跟主信号对应，从 `signals.md` 的解法中选取并结合用户情况具体化 |
| 今天就做的一步 | 一个动作，有完成标准，今天能完成 |
| 一句话 | 可省略；写的话必须能从前面的依据推出 |

---

## 示例

> 用户：我早就想好了要做个人 IP，选题也列了 50 个，但三个月了一条视频都没发。每次打开剪映就觉得还没准备好，想先把灯光和话筒买好再说。

```markdown
## 你卡在哪
做个人 IP 的想法定了三个月，选题列了 50 个，视频一条没发。每次卡在打开剪映之后，结论都是「还没准备好」。

## 我看到的信号
- 主信号：E 完美主义——依据：「每次打开剪映就觉得还没准备好」，三个月没有一次发布。
- 次信号：B 用思考替代行动——依据：选题列到 50 个，规划持续增加，发布始终为零。

## 不做给你带来了什么
判断：不发，就不会有人看到你的第一条视频，也就不会出现「播放很低」这个结果。你可以一直保留「等设备齐了我能做得很好」的想象。买灯光和话筒，是把被评价的时刻再往后推一次。

## 解法
1. 设备冻结：手头的手机和自然光就是这一阶段的全部设备；
2. 从 50 个选题里随便挑一个，不挑最好的；
3. 发布标准降到「说完一个完整观点、画面能看清」；
4. 发出后只记录两项数据：播放和评论里提到的具体问题。

## 今天就做的一步
- 动作：用手机拍一条一分钟以内的视频并发布；
- 完成标准：视频已经在平台上公开可见。

## 一句话
你说「还没准备好」，可你缺的是一次发布；灯光和话筒只会把被评价的时刻再往后推。

> 这是基于 dontbesilent 方法的执行力诊断，不替代心理咨询。
```
