# 内容兑现检查

推荐最终文案前读取。检查结果用于修正文案，无需给用户展示整张清单。

1. **事实**：每个数字、经历、引语、身份和因果都有材料支撑吗？是否把曝光写成人数、个人结果写成普遍保证？
2. **具体性**：是否保留这份材料的辨识度？换一篇同类内容也完全适用时，检查是否遗漏具体事实或问题。
3. **继续了解的理由**：观众能否预期后面还有什么值得看？解释型内容承诺的新增认识是否超过常识复述；故事、幽默和审美内容是否有值得继续的过程或体验。结论先行允许，空泛吊胃口应改写。
4. **兑现**：正文是否真的给出承诺的结果、证据、过程、体验或方法？不要求所有内容都改变观众的理解。没有正文时标为暂定并指出需要补什么。
5. **一致性**：本次同时提供的文字标题、封面标题和开头是否指向同一内容？已确定的观点与关键条件有没有被改掉？
6. **分工**：文字标题、封面标题和开头是否各自提供了有用信息？方向一致不等于逐字重复；文字标题帮助观众识别与选择，封面标题负责推荐流或主页识别，开头独立建立观看理由并推进内容。
7. **独立性与衔接**：两种标题在各自位置能否独立辨识主题？开头能否让没看标题的人进入当前事件、问题或体验，下一句是否推进正文？
8. **素材来源**：新写口播、原素材原话和 Agent 概括是否标记清楚？处理已拍素材时，不能把改写句冒充成现有画面里的原话；没有时间码时不能编造精确切点。
9. **使用约束**：文字能否在实际位置读懂，封面标题的换行与字数是否符合对应类型，口播能否自然念出，用户指定的字数、时长和范围是否满足？
10. **角度与制作范围**：标题和封面对应的是当前完整成片，还是只对应其中一个片段？需要改稿或补拍的命题是否已明确标记，未拍版本的正文是否已安排兑现？同一成片范围的候选才可并列比较。
11. **理论推断**：12 视角提出的新受众、机制或公共问题是否仍标为推断？理论名、路径数量和共鸣猜测不能替代原文事实或实际结果；无有效路径的视角不为凑数写进承诺。

先修正失真、无法兑现和误解，再比较表达力度。不能用刺激程度抵消事实缺陷。补充事实才能成立的版本不得混入可直接发布的推荐。
