# 封面标题

本文件提供封面标题规则，与文字标题共用已确认的角度和证据边界。

仅在用户需要封面标题时读取。

封面标题是直接放在内容封面上的标题。它与发布界面中的文字标题属于两种标题表面，共享同一个内容角度，同时分别提供有效信息。封面标题不拆成「封面大字／封面小字」。

先读取已经确认的角度简报，再从原素材中选一个能支撑该主线的具体处境、动作、人物、数字或结果。12 视角发现的上层命题用于确定观众关心什么；封面仍要保留这份内容的独特锚点。未拍视频可以先调整正文来兑现更强的封面承诺；已拍且不能补拍时，只使用现有成片能够兑现的信息。不能把待验证的跨人群推断写成视频已经证明的事实。

本 Skill 只交付封面标题及换行方式，不生成画面、构图、人物、字体、颜色或其他视觉建议。

## 图文封面标题

适用：小红书、B 站、快手、视频号。

默认写成 3 行，每行 3～6 个字，总字数 12～18 个字。封面标题优先使用具体对象、数据、行为、结果或场景；避免单独使用「真相、秘密、方法论、底层逻辑、认知、干货、爆款密码」等抽象包装词。

### 与文字标题分工

| 文字标题承担 | 封面标题承担 |
| --- | --- |
| 问题或争点 | 证据、数字或场景 |
| 异常解释 | 具体事件 |
| 价值判断 | 行为对比 |
| 观众判断任务 | 人物或结果 |

两种标题不能重复完整信息，也不能分别指向两个角度。封面标题设置的期待必须由文字标题和正文兑现。

事件本身足够具体时，优先使用朴素陈述：

```text
主体／数据
关键事件
具体问题
```

避免自嘲加戏、卖弄文气、空口态度、自我抬高和与主题无关的强行反转。

## 抖音主页索引封面标题

功能：让没有看过视频的人在主页中快速判断这条视频具体讨论什么。

先在内部写出一句完整主题说明：这条视频在讲谁或什么事件，以及围绕它讨论什么问题。再压缩为两行：

```text
具体对象／事件
具体问题／角度
```

默认每行不超过 6 个字，总字数不超过 12 个字。只有两行无法讲清时才使用三行。

候选必须通过：

1. 陌生人只看封面标题，能否知道视频讨论什么；
2. 是否容易被理解成另一件事；
3. 能否与主页其他视频区分；
4. 去掉文字标题后能否独立完成索引。

准确性优先于吸引力，直白表达优先于漂亮表达。
