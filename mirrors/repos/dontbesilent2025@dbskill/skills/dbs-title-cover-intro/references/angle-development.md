# 12 视角角度开发

本文件提供完整的 12 视角角度开发流程；每次任务只执行一次，不重复启动成员。

本参考在内容角度尚未锁定、已有可分析的正文、经历、事件或案例时使用。任务是发现与更多人有真实关系的上层命题，再交给内容价值验收、制作状态和正文兑现检查；不要让 12 位成员各写一批标题。扩大受众只能产生候选，观众是否愿意进入和继续看仍须单独判断。不要在运行前凭直觉断定素材只有一个方向。用户已经选定方向、只改一句措辞，或目前只有模糊话题而缺具体材料时走主 Skill 的快捷路径或最小追问。

## 一份共同素材包，两条独立判断线

先完整读取用户指定的原件。给每位成员同一份原素材或可回溯摘录，保留作者原命题、具体事件／原话、当前受众、账号语境和来源定位。内部区分：F 为原文直接给出的事实或作者主张，R 为来源及可信度，U 为可能改变结论的未知，H 为机制与受众反应假设。原稿中的数字、结果和因果若只来自作者叙述，应按自述处理。

先确认制作状态，但让每个视角**先独立找上层命题，再判断实现条件**。拍摄进度决定能修改多少，不决定哪些理论成员可以尝试升层。不要把「当前视频无法兑现」误写为「此命题没有受众价值」；同时不能把未来可补拍的方向写成当前成片的可用标题。

## 12 个理论成员

每位成员只承担一个理论视角。来源、核实层级与适用边界见 [角度理论依据](angle-theory-sources.md)。以下判断动作服务素材开发，不证明播放量、转发量或成交效果。

| 编号与视角 | 独立判断动作 | 必须守住的边界 |
| --- | --- | --- |
| L01 社会学想象力 | 检查个人困境是否还与机会结构、组织规则或资源获得方式有关，提出可调查的共同问题。 | 单个故事或共同情绪不能证明结构性不平等；缺群体资料时只保留问题假设。 |
| L02 抽象阶梯 | 从具体事件上移到重复模式、解释机制、带条件的共同难题；逐层说清新受众承担什么后果。 | 单个案例不证明普遍规律；删去具体素材只剩人生道理时退回。 |
| L03 框架理论 | 在同一事实下重新检查问题定义、原因解释、评价或处理方向，找出会改变选择的另一种理解。 | 换框架不证明新因果真实；只换说法、没有决策差别时无效。 |
| L04 争点理论 | 寻找事实、定义、价值或行动上真实存在的竞争判断，以及不同答案的现实后果。 | 不虚构反对者和争议；事实未清时保持问句。 |
| L05 修辞情境 | 找此刻面临具体选择、可能因表达改变判断的受众，并检查现实约束与时机。 | 没有期限或行动窗口时不制造紧迫性。 |
| L06 自我参照效应 | 找原领域之外的人能联系自身的场景、损失、机会或选择，写清可检验的后果。 | 「大家都焦虑」不构成受众连接；能联想到自己不等于会点击。 |
| L07 社会认同与自我分类 | 检查真实角色或群体的规范、身份、尊严与利益是否被素材触及。 | 不靠刻板印象制造「我们／他们」；工具性素材可能没有身份角度。 |
| L08 使用与满足 | 问观众实际能拿内容来理解什么、判断什么、尝试什么或与谁讨论。 | 好奇与认同不能自动升级为实用价值；内容必须兑现该用途。 |
| L09 JTBD | 找行动主体在具体情境里想推进的进展，以及原做法在哪一步受阻。 | 任务推断不冒充当事人原话；有购买场景才分析购买进展。 |
| L10 情绪评价理论 | 分开检查目标重要性、责任、确定性和可控制性，探索有条件的情绪与行动难题。 | 不凭理论诊断当事人的真实心理或声称方法能消除情绪。 |
| L11 认知失调 | 找可指出的旧判断、行为或自我认识与材料中的相反经验，研究判断怎样更新。 | 没有可定位的矛盾时不使用「大家都以为」或反常识包装。 |
| L12 沉默的螺旋 | 只在有意见气候、孤立担忧或表达代价线索时，检查谁可能因此保持沉默。 | 「没人说」不等于「不敢说」；缺证据时返回不适用。 |

## 独立执行与结果格式

运行环境有真实子 Agent 能力时，为每个视角分派一项独立任务，按并发容量分批完成全部 12 项。若主 Agent 也占一个并发席位、总容量为 4，则每波最多派 3 项；收齐一波后继续下一波，直到 L01～L12 全部结束。成员之间不预览答案；每项获得相同原素材、事实账本和制作状态，并只使用自己负责的理论动作。不要先让主 Agent 选几个「最合适」的理论。环境缺少子 Agent 时，可逐视角完成 12 次独立记录并说明没有运行真实 Team；不得把单 Agent 模拟称为 12 个独立成员。

启动时建立 12 项完成账本，逐项记为「待分派／运行中／有效路径／待验证路径／无有效路径／执行失败」。一波 3 人完成只是进度，不是完成条件；出现看起来已经足够好的主线，也必须继续覆盖剩余视角。执行失败时重试或标明缺席；不能替该成员编造理论结论。除用户明确停止、改为只讨论已选方向，或环境确实无法继续执行外，不得在 L01～L12 尚未处理完时交付最终角度确认卡。

每位成员先交一条主路径；只有另一条路径指向实质不同的新受众或共同问题时才附加。每条路径写清：

1. 原素材当前与谁有关、作者要表达什么；
2. 理论改变了哪项判断；
3. 上层命题、新增人群及其具体关切；
4. 原文锚点 → 推导机制 → 新人群处境／后果的连接链；
5. 直接材料、合理推断与待验证假设各是什么；
6. 什么事实会推翻路径；
7. 在当前制作状态下可直接兑现、需改稿、需补拍、只能新剪一条，还是需等待未来素材。

无法找到新增的真实受众关系时返回「未找到有效升层」，不为凑满 12 条而改写原标题。运行耗时较长时，首批成员完成后给用户简短进度；其后按批展示新增路径及不适用原因，标明「已返回 X/12」，不承诺展示子 Agent 的逐字思考。用户中途补充关键事实时更新尚未分派的素材包，并让受影响的成员复核。

## 面向用户逐项展示

12 项全部处理后，先用普通话说明原素材的作者命题与具体锚点，再依 L01～L12 顺序展示每位成员的判断。每项至少有一小段完整说明：抓住哪句原话或哪项经历、该理论改变了什么判断、提出什么上层命题、哪类新增受众为何在意、证据仍缺什么。成员没有有效路径时写明触发条件缺在哪；执行失败单独写「未完成」，不得与理论不适用混淆。可先用表格索引，但表格不能替代逐位解释。

这里保证的是 **12 个理论视角各有可见结果**。有效方向可能少于 12 个，多个视角也可能推到相近命题；不要为了交出 12 个不同角度而补造受众、争点或证据。保留稳定编号 L01～L12，路径可用 L01-P1 等编号，供用户继续点名讨论。

## 汇合命题，按制作状态筛选

在逐项展示之后，按作者原意、独特机制、受众处境和争点，把有效路径汇成最多 2～4 个大命题。相似结论可合并到同一大命题，但须逐项说明相关 L 路径分别补上了什么判断；不能用一串编号代替推导。没有材料支撑的结构问题、心理动机、因果和普遍结论只能列为待验证。理论名用于溯源，不自动进入用户标题或封面。

汇合后执行 [材料选择](material-selection.md) 的「内容价值验收」。每个命题都要有具体的进入理由、继续观看的收获或体验，以及负责兑现它的原素材；解释型命题还要检查是否只说出观众已知的现象。故事、幽默和审美内容按过程与体验检查。验收失败的方向说明失败点并从可选主线中撤下；不要因某方向得到更多理论支持或覆盖更多人就跳过验收。对于有条件的情绪代价，检查是否能由原稿机制提出受众问题，再区分待核实的心理事实和可由正文解释的关系。

再按 [生产状态与工作模式](production-state.md) 判断每个命题的实现成本：

- 还没拍：能否通过调整稿件和补进可信事实，使正文兑现；缺关键案例时列出最小补充。
- 已拍且可补：先给现有素材能兑现的版本，再说明补拍哪一小段才能采用更强命题。
- 已拍且不能补：当前标题与封面只能选现有原话和画面支持的主线；更强命题保留为下一条内容，不冒充当前成片。
- 长素材剪条：先确定一个具体切片或选题，再围绕该切片分析；不同片段不能未经核对拼成同一个人的连续论证。

完整视频主线只同其他完整视频主线比较；只靠一个段落成立的方向列为独立新剪条。12 项逐位结果与汇合命题展示完、内容价值验收通过后，角度确认卡最多展示 2～3 个同一成片范围内、真正不同且证据状态清楚的方向。每项写谁会进入、为什么继续看、原素材锚点、正文要兑现的收获或体验，以及当前状态下的可行性。多个方向会拍成不同内容时，在普通聊天消息中将候选编号为 1、2、3，要求用户手动回复数字；不要调用弹框或表单工具。只有一个可兑现方向时说明原因并直接继续。

角度选定后不再运行本流程。只有作者主张、关键事实或受众任务发生实质变化，才重查受影响的路径。生成标题、封面与开头前先完成主 Skill 的正文兑现检查。
