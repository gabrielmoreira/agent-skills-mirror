# 角度、标题与开头的模块交接

本 Skill 是单次任务的协调者。它保留制作状态、原稿入口基准、内容价值验收、角度确认、正文兑现和视频开头。全部能力使用本 Skill 自带参考文件。一次任务只运行一套角度开发和一套标题规则。

## 1．交给角度 Team

仅当用户尚未锁定方向、有可分析材料，且任务并非只处理已拍素材的现有冷开场时，读取 [角度开发](angle-development.md) 与 [理论依据](angle-theory-sources.md)。

向成员提供同一份原素材及下列信息：作者原意、当前受众与证据边界、原稿标题或强句及其历史表现口径、制作状态、用户已确认和排除的方向。成员仍须独立判断；原标题是原文资产，不是预先选定的答案。Team 完整返回 L01～L12 路径和 2～4 个母命题。它不替本 Skill完成内容价值验收、成片范围筛选或最后的角度确认。

## 2．协调者筛选与确认

让每个母命题和通过初步事实检查的原稿入口基准完成 `material-selection.md` 的内容价值验收，再按 `production-state.md` 判断当前能改稿、补拍或只剪已有素材的范围。角度确认卡只出现同一成片范围内可兑现、真正不同的主线。角度 Team 已逐批展示的路径属于研究结果，不额外触发它自己的第二次选题确认。

用户选定主线后，固定一张交接卡；用户已锁定方向时直接建立这张卡：

```markdown
本轮所需：文字标题／封面标题／视频开头；指定平台与位置
制作状态与可改范围：
主角度及用户确认状态：
有效受众、进入理由、继续观看价值：
原稿入口基准：原句、来源、历史表现及证据口径
原素材锚点与正文兑现位置：
已核实事实／用户自述／合理推断／未知：
不可扩大或虚构的条件：
```

## 3．交给全平台标题模块

用户需要文字标题或封面标题时，读取 [展示位置与标题](title-surfaces.md) 和 [封面标题](cover-title.md)，使用上面的交接记录进行生成。原稿入口基准先参加标题诊断；新标题须说明比原句新增的受众利害、注意力理由或平台适配价值。原句通过门槛且新候选没有明确优势时，保留原句。

本 Skill 的用户指定平台、默认平台范围、文字字段名称和默认交付 1 组首选，优先于标题模块的批量数量和平台默认值。标题模块负责文字标题、封面标题及其质量门槛；不写视频开头、不改已选主线。

标题模块若发现已选角度无法由正文兑现，把失败点交回本 Skill，按内容价值验收和制作状态收窄或补足；不要因此启动标题模块的完整角度发现，再让用户选一次。

## 4．由本 Skill 完成

视频开头始终读取 `opening-continuity.md`，依制作状态决定新写口播或选择已有原话，附准确接入位置。最终由本 Skill 检查标题、封面、开头与正文是否共享同一主线；只交付用户要的表面。模块分工不得改变事实、授权、证据和已拍素材的边界。
