# 概念拆解框架详解

本文件在以下情况读取：

- 拆解对象牵涉多个相互缠绕的概念，正文的判断顺序不够用；
- 需要判断一个词属于「包装」「混用」「错误预设」还是「伪概念」，且边界不明显；
- 用户要求深度拆解，或要求做本体论的 7 张表；
- 需要用奥派经济学校准一个商业概念，但不确定该问哪一项。

---

## 一、维特根斯坦的四件工具

### 1．意义即使用

一个词的意义，看它在具体场合中让说话的人和听的人做了什么。查词典给出的定义只覆盖其中一种用法；商业词汇常常同时活在好几种场合里，每种场合的用法不同。

拆解时对每一种用法回答三个问题：

1. 谁在说：卖课的人、平台、投资人、财务、老板、用户自己；
2. 说的时候想让对方做什么：付钱、改选题、批预算、认同自己、停止追问；
3. 听的人据此会采取什么行动。

三个问题的答案不同，就是不同的用法。

### 2．语言游戏

同一个词在不同的「游戏」里遵循不同的规则。例：「确实是道具」这句话——

- 在税务审计中，「确实」指有完整的凭证链；
- 在日常报销中，「确实」指看起来不像私用；
- 在老板那里，「确实」指这笔钱花得合理。

拆解的关键动作：先认出用户此刻身处哪一个游戏，再判断对方用的是哪一个游戏的规则。两人吵不清楚，往往是因为在用不同游戏的规则说同一个词。

### 3．家族相似

很多概念没有所有成员共有的本质，只有一组交织的相似特征。处理办法：

1. 列出这个概念常见的特征；
2. 判断哪一个特征都不是必要条件；
3. 指出在用户当前的游戏里，哪几项特征真正决定结果。

满足的特征越多越像这个概念，但没有一刀切的门槛。用户执意追问「到底什么才算 X」时，交付特征清单和当前场合的判定依据，不硬造一条本质定义。

### 4．可说与不可说

能说清楚的就说清楚；说不清楚的不硬说。落到拆解中：

- 概念的原始语境、词源、学术出处，不确定时写「我不确定出处」，不编造；
- 某件事只能靠实践回答（见下方 Question 与 Problem），就说明答案的形式是实践，不给一段看似完整的文字答案；
- 不用更复杂的概念去解释一个概念。

## 二、四种问题词及判定

| 类型 | 判定方法 | 处理 |
| --- | --- | --- |
| 包装词 | 用大白话重说后，可指认的对象、行动、结果都没有丢失 | 说明它只是包装；用户觉得好用可以继续用 |
| 混用词 | 同一段对话或同一个行业里，有两种以上会导致不同行动的用法 | 列出各用法，指出混淆在哪一步造成损失 |
| 错误预设 | 问题本身预设了一个不存在的东西（最佳时间点、正确定位、通用价格组合） | 指出预设，改写成能回答的问题 |
| 伪概念 | 用大白话重说时说不出来，或说出来后没有任何可观察的差异 | 直接说它是伪概念，说明它掩盖了哪一处理解空白 |

补充两条判断：

- **大白话测试是语义测试**：判断依据是重说之后对象、行动、结果有没有丢失；句子读起来是否通顺不作为依据。

## 三、Question 与 Problem

- **Question**：有标准答案，可以用一段线性文字回答。例：「我可以在哪里注册公司」。
- **Problem**：答案的形式是一段实践过程，文字只能给出视角。例：「某个 Agent 能做什么」「坐过山车是什么感受」。

dontbesilent 的经验判断：创业中的绝大多数问题属于 Problem，Question 只是入门门槛。很多 Problem 以 Question 的句式出现，用户便期待一段文字答案。识破这一点本身就有价值。

识破之后的处理：

1. 指出这是 Problem，说明它以 Question 句式出现在哪里；
2. 给出能用文字回答的部分（前提、边界、判断标准）；
3. 说明剩下的部分需要通过什么实践得到答案，以及最小的那一步实践是什么。

## 四、奥派经济学校准

概念涉及价值、价格、需求、市场、竞争、增长时使用。逐项检查，只写出有发现的项：

| 检查项 | 要问的问题 | 常见发现 |
| --- | --- | --- |
| 主观价值 | 这个概念是否预设了脱离具体买家的「客观价值」？ | 「刚需」「有价值的内容」常把个人评价说成客观属性 |
| 行动 | 这个概念描述的是一个人的行动，还是替代了行动？ | 「赛道」「风口」让人以为选择本身能产生收益 |
| 自发秩序 | 这个概念是否假设市场可以按图纸设计、存在一个可计算的正确答案？ | 「IP 定位」「最佳价格组合」 |
| 价格与利润信号 | 这个概念能否落到成交、价格、利润等可观察信号上？ | 无法落地时，用可观察信号替代它 |

价格信号检查只针对声称有商业价值的概念。审美、伦理、情感类概念无法被价格验证，这不代表它们为空。

dontbesilent 的典型做法：「刚需」的刚性是一个光谱，买家自己也说不清；与其争论是不是刚需，不如直接看曝光量和转化率，最终看利润。

## 五、说清楚的杠杆

dontbesilent 把「说清楚」的能力分成三级，用来解释为什么要拆解概念：

- 会做但说不清楚：只能自己做；
- 说得不太清楚但别人能领会：可以雇人做；
- 能把隐性经验变成显性规则：可以交给 AI 做。

拆解概念的产出，就是把第一级、第二级的经验推向第三级。用户问「拆这个词有什么用」时，用这一段回答。

## 六、深度模式：7 张表

来源：dontbesilent 用《逻辑哲学论》的结构重组奥派经济学的经济与商业概念。用户要求深度拆解，或概念牵涉的对象和关系较多时使用。

| 表 | 内容 | 填写要求 |
| --- | --- | --- |
| 对象表 | 不可再分的基本对象 | 只放能被指认的东西：人、钱、商品、内容、平台、时间 |
| 事态表 | 原子事态：最小的事实单元 | 每条只含一个事实，例：「用户看到了内容」 |
| 复合事态表 | 由原子事态组成的复杂现象 | 标出由哪几条原子事态组成 |
| 关系表 | 对象与事态之间的关系 | 区分因果、先后、包含、交换 |
| 规则表 | 关系遵循的规律 | 标注是经验规律还是逻辑必然，经验规律注明适用条件 |
| 形式表 | 逻辑结构 | 写清条件、充分、必要、或、且 |
| 定义表 | 每个概念的严格定义 | 定义只能使用前面表中出现过的对象和事态 |

填写纪律：

- 早期维特根斯坦的要求是命题原则上可验证，不要求真的列尽所有原子命题。列到能支撑当前判断即可；
- 任何一张表填不出来，就说明在哪一层出现了理解空白，这正是拆解的发现，不要用空话补齐；
- 表格之后用三五句大白话说明 7 张表揭示了什么。

示例片段（「精准流量」）：

- 对象：创作者、内容、平台、观众、商品；
- 原子事态：观众看到内容；观众点开商品；观众付款；
- 复合事态：精准流量 = 看到内容的观众中，付款的比例高于创作者的预期；
- 规则（经验规律）：付款比例由内容筛选和承接能力共同决定；
- 定义：精准流量指在当前承接能力下转化率较高的那部分观众。这个定义依赖承接能力，承接能力变化后，同一批观众是否「精准」也随之变化。
