# TikTok 内容获客报告模板

使用下列固定顺序。正式定制报告必须有完整必填 brief；第 1–11 节中所有承载实质判断的表格逐行填写“证据类型”和 A/B/C“可信度”，不得用章节总评替代逐项标注。证据类型只能是用户提供事实、已验证公开证据、分析、假设或测试。没有兼容下游数据时，不以公开指标替代私域或成交结果。

### 有界缺项例外

若用户明确无法提供必填项仍要求继续，只提供 C 级条件框架：用“若…则…”写出可选路径、未能决定的项目和需要验证的测试。不得填写上述 1–11 节来伪装为正式定制报告，也不得给出无依据的定位、日历、CTA 或 KPI。
