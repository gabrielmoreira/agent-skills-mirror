# Conditional Protocols - Layered Improve Prototype

Read only the section whose trigger is true. These protocols are separated so routine Improve runs do not carry instructions for paths they are not taking.

## Standalone Fallback

**Trigger:** Intent, Trail, or Orient is not installed or cannot be invoked.

- Without Intent: narrate the interpreted destination, why it matters, and material alternatives before examination.
- Without Trail: append one entry to the target repo's `.acm/audit-trail.md`. Include interpretation, evidence and lenses, decision and rejected alternatives, pre-action prediction, action and validation, actual-versus-predicted result, reflection, trigger evaluation, Orientation freshness, and marked decisions/reversals/realisations. Never edit prior entries.
- Without Orient: if Orientation is stale, record the stale evidence and report that the passive refresh could not run. Do not fabricate arc claims from a partial read.

Create `.acm/` before a fallback write when needed. If derived history or learning views already exist, regenerate them with the target's tooling after appending.

## Convergence Evaluation

**Trigger:** the ask concerns convergence, publication readiness, or cross-run silence.

Read the target's convergence protocol if present and declare the exact layer, surfaces, and quality bars being evaluated. Silence in one layer says nothing about untested layers.

A single Improve run may produce bounded silence but cannot establish convergence. Convergence requires diverse independent evaluators, fresh contexts, zero material changes, and independent re-derivation of the measurement scheme unless an external standard fixes it.

Record which conditions were actually observed and which remain open. Never convert a score, elapsed iteration count, or one evaluator's confidence into convergence.

## High-Fidelity Writer Separation

**Trigger:** the operator requests the highest available anti-rationalization protection, or the work's consequences make same-agent Trail authorship inadequate.

The acting agent stops after validation and emits the contemporaneous interpretation, evidence, decision, prediction, actions, raw outcomes, uncertainties, and reversals. A second independent agent applies Trail from that material.

Do not let the acting agent polish the final Trail entry after learning the outcome. Link independent harness or host-session capture when available and label fidelity accurately. Agent-authored reconstruction is testimony, not independent evidence.

## Multi-Iteration Checkpointing

**Trigger:** one operator request authorizes more than one Improve iteration.

Each iteration completes the full cycle independently:

1. Decide and predict one change.
2. Act and validate it.
3. Append Trail and regenerate derived evidence.
4. Commit the checkpoint when repository policy permits.
5. Run scheduled Orient if stale.

Only then begin the next iteration. Never buffer multiple decisions into one end-of-session narrative. If interrupted, completed iterations must remain reconstructable and incomplete work must be reported as incomplete.

## Destination Boundary Failure

**Trigger:** destination completeness markers are missing, duplicated, malformed, reversed, or enclose an ambiguous current mandate.

Read the full destination file. Do not infer authority from the first heading, newest date, horizontal rule, or file position. If active and historical commitments conflict, stop and run Destination rather than choosing the convenient interpretation.

## Precedent Conflict

**Trigger:** the proposed decision may repeat or contradict prior learning, or the recent learning surface does not cover the relevant period.

Search recent Learning first, then its archive, then only the Trail entries needed for context. State which precedent was checked and whether it still applies to the current target. Historical decisions are evidence, not immutable rules; when their factual boundary changed, explain why the precedent no longer controls.
