# Skill: AI-Native Dashboard UI

## Purpose
Implement the Reckon SEO Autopilot dashboard with the supplied Aura visual reference.

## Visual Direction
- Clean B2B SaaS layout
- Light neutral canvas and navy navigation
- Blue primary actions, restrained green success and Aura gradients for AI affordances
- Responsive desktop/mobile behavior
- Accessible focus states and color contrast
- Light/dark theme support

## UX Priorities
Evidence, next actions, agent status, approvals and execution history should dominate charts
and decorative content. Use typed navigation and loading/error/empty states.

## Guardrails
Do not copy Frappe code or framework structure. Use React components and the mock only as a
visual reference. Do not present demo metrics as live product data.
